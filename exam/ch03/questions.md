# Chapter 3 — Built-In MATLAB Functions 문제지

- 모든 코드는 MATLAB R2026a Command Window에 `>>` 프롬프트 순서대로 한 줄씩 입력한 것이다.
- 별도 언급이 없으면 시작 상태는 `clear`, `format short`, `format loose`다.
- `[출력]` 문제는 화면에 찍히는 결과를 빈 줄까지 그대로 쓴다. 오류가 나는 줄이 있으면 오류 메시지 첫 줄을 쓰고, 그 뒤 줄은 실행되지 않은 것으로 본다.
- `[코드]` 문제는 주어진 화면을 만드는 명령을 `>>` 줄 단위로 쓴다. 세미콜론 유무도 채점한다.
