## 4.1 배열의 정의·결합·인덱싱

### Q04-01 [출력] ★

원본: p.6 `A = [3.5]; B = [1.5, 3.1]; C = [-1, 0, 0 ⏎ 1, 1, 0 ⏎ …]` → 변형: 값 바꾸기, `C` 정의 줄에 세미콜론을 붙이고 마지막에 `C`만 따로 출력

```
B =

     1     4

C =

    -2     0
     1     3

```

- `A = [2.5];`는 세미콜론이 있어 출력이 없다.
- 대괄호 안의 줄바꿈은 세미콜론처럼 새 행을 뜻한다. 그래서 `C`는 2×2다.
- 정수만 있는 배열은 폭 6 정수 형식이다. 음수는 `    -2`처럼 부호까지 폭 6 안에 들어간다.
- 근거: [4.1.1](../../textbook/ch04/4.1-array-basics.md#411-배열-정의하기)

### Q04-02 [출력] ★★

원본: p.6 원소를 공백·쉼표로 구분하는 규칙 → 변형: 음수 부호와 뺄셈 연산자 사이의 공백

```
v =

     3    -1

w =

     2

u =

     3     1

```

- `[3 -1]`: `-` 뒤에 공백이 없으므로 음수 `-1`로 읽힌다. 원소 2개.
- `[3 - 1]`: `-` 양쪽에 공백이 있으므로 뺄셈 `3-1 = 2`. 스칼라.
- `[3 -1 + 2]`: `-1`은 음수, ` + ` 양쪽 공백은 덧셈이다. 원소는 `3`과 `-1+2 = 1`.
- 근거: [4.1.1](../../textbook/ch04/4.1-array-basics.md#411-배열-정의하기) ⚠️ 함정 (`[1 -1]` vs `[1 - 1]`)

> **[보강]** R2026a에서 실행해 확인: `u = [3 -1 + 2]`는 `3     1`로 표시된다. 위 출력 그대로다.

### Q04-03 [오류] ★★

원본: p.7 `F = [1, 52, 64, 197, 42, -42, ... ⏎ 55, 82, 22, 109];` → 변형: 줄 끝의 말줄임표(`...`)를 뺐다

```
Error using vertcat
Dimensions of arrays being concatenated are not consistent.
```

- `...`이 없으면 대괄호 안의 줄바꿈은 **새 행**이 된다. 1행은 원소 3개, 2행은 원소 2개라 세로로 붙일 수 없다.
- 고친 코드: `F = [1, 52, 64, ...`. 줄 끝에 쉼표와 말줄임표를 붙이면 다음 줄이 같은 행으로 이어진다.
- 근거: [4.1.1](../../textbook/ch04/4.1-array-basics.md#411-배열-정의하기)

### Q04-04 [출력] ★★

원본: p.8 `S = [3.0, B]; T = [1, 2, 3; S]` → 변형: 앞뒤 순서와 값 바꾸기

```
S =

    1.0000    2.5000    4.0000

T =

    1.0000    2.5000    4.0000
    7.0000    8.0000    9.0000

```

- 이미 만든 배열 `B`를 원소처럼 넣어 이어 붙이는 것이 concatenation이다.
- `2.5`가 하나라도 있으면 배열 전체가 소수 형식(소수점 아래 4자리, 폭 10)으로 찍힌다. `T`의 2행은 정수뿐이지만 같은 배열이므로 `7.0000`이다.
- 근거: [4.1.1 배열 결합](../../textbook/ch04/4.1-array-basics.md#배열-결합-concatenation)

### Q04-05 [오류] ★

원본: p.8 `T = [1, 2, 3; S]` → 변형: 위 행의 원소 수를 2개로

```
Error using vertcat
Dimensions of arrays being concatenated are not consistent.
```

- `[1, 2]`는 1×2, `S`는 1×3이다. 세로로 붙이려면 열 수가 같아야 한다.
- 근거: [4.1.1 배열 결합](../../textbook/ch04/4.1-array-basics.md#배열-결합-concatenation)

### Q04-06 [출력] ★★

원본: p.9 `S(2)`, p.10~11 `S(2) = -1`, p.12 `S(4) = 5.5` → 변형: 값을 정수로 바꿔 소수가 사라지게, 인덱스 하나 건너뛰어 확장

```

    1.5000

     4    -2     6     0     3

```

- `S(2)`는 변수에 대입하지 않았으므로 `ans`에 담긴다.

- 결과가 모두 정수이므로 정수 형식(폭 6)으로 찍힌다. 원본(p.12)은 `5.5`가 들어가 소수 형식이었다.
- 근거: [4.1.2](../../textbook/ch04/4.1-array-basics.md#412-인덱싱과-배열-확장)

### Q04-07 [코드] ★★

원본: p.12~13 `S(4) = 5.5`, `S(8) = 9.5` → 변형: 스칼라에서 시작해 중간을 0으로 채우기

```

- 첫 줄은 출력에 `S = 2`가 없으므로 세미콜론이 있어야 하고, 둘째 줄은 결과 `S`가 보이므로 세미콜론이 없어야 한다.
- 스칼라도 1×1 배열이라 인덱스 4에 대입하면 1×4로 늘어나고 `S(2)`, `S(3)`은 `0`이 된다.
- 근거: [4.1.2](../../textbook/ch04/4.1-array-basics.md#412-인덱싱과-배열-확장)

### Q04-08 [출력] ★

## 4.2 원소별 연산과 meshgrid

### Q04-17 [출력] ★

원본: p.37 `x=3; y=5; A=x*y`, p.38 `x = 1:5; A = x*y` → 변형: 값 바꾸기, `C` 줄에 세미콜론

```
B =

     2     4     6     8

```

- 스칼라끼리, 또는 배열과 스칼라의 곱은 `*`와 `.*` 어느 쪽이든 결과가 같다.
- `A`와 `C`는 세미콜론 때문에 출력이 없다.
- 근거: [4.2.1](../../textbook/ch04/4.2-elementwise-meshgrid.md#421-스칼라-곱셈은-모호하지-않다)

### Q04-18 [오류] ★★

원본: p.39~40 `x = 1:5; y = 1:3; x*y` → 변형: `x`의 길이

```
Error using  * 
Incorrect dimensions for matrix multiplication. Check that the number of columns in the first matrix matches the number of rows in the second matrix. To operate on each element of the matrix individually, use TIMES (.*) for elementwise multiplication.
```

- `*`는 행렬곱이다. (1×4)·(1×3)은 앞의 열 수 4와 뒤의 행 수 1이 달라 계산할 수 없다.
- 근거: [4.2.2](../../textbook/ch04/4.2-elementwise-meshgrid.md#422-배열과-배열의-곱셈--vs-) ⚠️ 함정

### Q04-19 [오류] ★★

원본: p.41 `x.*y` (길이 5와 3) → 변형: `x`의 길이

```
Arrays have incompatible sizes for this operation.
```

- `.*`는 원소별 곱이라 두 배열의 크기가 같아야 한다(또는 한쪽이 스칼라). 1×4와 1×3은 짝이 맞지 않는다.
- Q04-18과의 차이: `*`는 "안쪽 차원이 같아야 한다"는 행렬곱 조건, `.*`는 "크기가 같아야 한다"는 원소별 조건으로 실패한다.
- 근거: [4.2.2](../../textbook/ch04/4.2-elementwise-meshgrid.md#422-배열과-배열의-곱셈--vs-)

> **[확인 필요]** 슬라이드(R2022a)는 `Error using` 줄 없이 이 한 줄만 보인다. R2026a에서 앞에 `Error using  .* ` 줄이 붙는지 확인.

### Q04-20 [출력] ★★

```

- `linspace(2,5,4)`는 2부터 5까지 점 4개, 간격 1이라 모두 정수다. 정수 형식으로 찍힌다.
- 근거: [4.2.2](../../textbook/ch04/4.2-elementwise-meshgrid.md#원소별-연산자-모음)

### Q04-21 [변형] ★★★

원본: p.42 `x = 1:5; y = linspace(1,3,5); A = x.*y` → 변형: 길이 3, `linspace(1,2,3)`, 전치 후 행렬곱 추가

```
y =

    1.0000    1.5000    2.0000

A =

     1     3     6

B =

    10

```

- `A`는 원소별 곱 `[1·1, 2·1.5, 3·2] = [1 3 6]`. 결과가 모두 정수라 정수 형식이다.
- `B`는 (1×3)·(3×1) 행렬곱, 즉 내적 `1 + 3 + 6 = 10`이다. `y'`로 전치해 안쪽 차원을 맞췄다.
- 원본처럼 `x.*y`는 "대각선 칸만" 계산할 뿐, `x`와 `y`의 모든 조합(Table 4.1)은 나오지 않는다.

### Q04-22 [출력] ★★

```

     1     2     3
     1     2     3

```

- 결과 크기는 `length(y)`행 × `length(x)`열 = 2×3.
- `new_x`는 `x`를 모든 행에 반복하고, `new_y`는 `y`의 각 값을 행 전체에 채운다.
- 근거: [4.2.3](../../textbook/ch04/4.2-elementwise-meshgrid.md#423-meshgrid--크기가-다른-두-벡터-다루기)

### Q04-23 [코드] ★★★

- 근거: [4.2.3](../../textbook/ch04/4.2-elementwise-meshgrid.md#423-meshgrid--크기가-다른-두-벡터-다루기)
