# 2.4 스칼라·배열 연산

## 스칼라 연산

MATLAB은 두 스칼라 사이의 사칙연산을 다른 프로그램이나 계산기와 거의 동일하게 처리한다.

| 연산 | 연산자 |
| --- | --- |
| 덧셈 | `+` |
| 뺄셈 | `-` |
| 곱셈 | `*` |
| 나눗셈 | `/` |
| 거듭제곱 | `^` |

## 대입 연산자 (Assignment Operator)

- 등호 하나(`=`)는 MATLAB에서 **대입 연산자**다. 계산 결과를 메모리 위치(변수)에 저장하라는 뜻이다.
- `x = 8`은 "x에 8을 대입한다"로 읽어야 한다.
- 대입 연산자는 두 값이 같은지 **비교**하는 `==`(equals 연산자)와 다르다.

```matlab
x = x + 1;   % 대수식이 아니라 대입문이다.
             % "메모리에 저장된 x의 기존 값에 1을 더해서, 그 결과로 x를 다시 저장하라"는 뜻.
```

## 연산자 우선순위 (Order of Operations)

MATLAB은 표준 대수 규칙을 따른다.

1. 괄호 안 — 가장 안쪽부터 바깥쪽 순서로
2. 거듭제곱(`^`)
3. 곱셈·나눗셈 — 왼쪽에서 오른쪽으로
4. 덧셈·뺄셈 — 왼쪽에서 오른쪽으로

### 예제: 원기둥의 겉넓이

원기둥 겉넓이 공식은 `S = 2*pi*r^2 + 2*pi*r*h`이다. 반지름 `r`, 높이 `h`가 주어졌을 때
여러 방식으로 같은 값을 얻을 수 있다.

```matlab
r = 3;
h = 5;

S1 = 2*pi*r^2 + 2*pi*r*h;   % 두 항으로 나눠서 계산
S2 = 2*pi*r*(r + h);        % 공통 인수 r을 묶어서 계산 (더 짧다)
```

두 식 모두 올바른 정답을 낸다 — 문제를 푸는 방법은 여러 가지일 수 있다.

> 실행 파일: [`ex0204a_order_of_operations.m`](../../example/ch02/ex0204a_order_of_operations.m)

### ⚠️ 함정: 괄호를 잘못 놓으면

```matlab
S_wrong = 2*pi*r*r + h;   % h에 2*pi*r을 곱하는 걸 깜빡함 -> 틀린 결과
```

또한 MATLAB은 일반 수학 표기와 달리 **괄호 앞의 곱셈 기호를 생략할 수 없다.**

```matlab
r(r+h)     % 오류! r을 배열 인덱싱/함수 호출로 해석한다
r*(r+h)    % 올바른 표현
```

### 힌트

- 괄호를 더 넣는다고 손해볼 것은 없다. 헷갈리면 괄호를 추가하라.
- 코드는 항상 왼쪽에서 오른쪽으로 읽힌다는 것을 기억하라.
- 긴 식은 여러 문장으로 나눴다가 합치는 편이 읽기 쉽다.
- `+`, `-` 앞뒤에는 공백을 두고, `*`, `/` 앞뒤에는 공백을 두지 않는 것이 관례다.
- 줄 끝에 세미콜론(`;`)을 붙이면 Command Window에 출력이 억제된다.
- 세미콜론이나 쉼표로 구분하면 한 줄에 여러 명령을 쓸 수 있다.

## 배열 생성

### 명시적 목록 (Explicit List)

가장 단순한 배열 생성 방법은 숫자를 나열하는 것이다.

```matlab
x = [1 2 3 4];        % 공백 또는 쉼표로 구분 (구분자, delimiter)
y = [1; 2; 3; 4];     % 세미콜론으로 새 행 -> 열벡터
a = [1 2 3 4; 2 3 4 5; 3 4 5 6];   % 2차원 배열
```

### 콜론 연산자로 균일 간격 배열 만들기

```matlab
b = 1:5;      % b = [1 2 3 4 5], 기본 증분은 1
c = 1:2:5;    % 시작:증분:끝 -> [1 3 5]
```

`b = 1:5`와 `b = [1:5]`는 동일하다(대괄호는 생략 가능).

### linspace — 개수를 지정해 균일 간격 배열 만들기

```matlab
d = linspace(1, 10, 3);   % 1과 10 사이를 3개 값으로 균등 분할 -> [1 5.5 10]
```

세 번째 인자(개수)를 생략하면 기본값 **100개**로 채워진다.

### logspace — 로그 간격 배열 만들기

```matlab
e = logspace(1, 3, 3);    % 10^1과 10^3 사이, 3개 값 -> [10 100 1000]
```

첫 번째, 두 번째 인자는 값 자체가 아니라 **10의 거듭제곱 지수**임에 유의하라.
세 번째 인자는 배열의 원소 개수다.

> 실행 파일: [`ex0204b_array_creation.m`](../../example/ch02/ex0204b_array_creation.m)

### ⚠️ 함정

- `linspace(1, 10)`처럼 개수를 생략하면 조용히 100개짜리 배열이 만들어진다. 원하는 개수를
  항상 명시하라.
- `logspace`의 인자는 "값"이 아니라 "지수"다. `logspace(1, 3, 3)`은 1과 3 사이가 아니라
  `10^1`과 `10^3` 사이를 채운다.

## 배열 연산

### 스칼라와 배열의 덧셈·뺄셈

```matlab
a = [1 2 3];
b = a + 5;    % b = [6 7 8], 스칼라가 모든 원소에 더해진다
```

### 배열끼리 덧셈·뺄셈

두 배열을 더하거나 빼면 **대응하는 원소끼리** 연산된다(크기가 같아야 한다).

### 곱셈: `*` vs `.*`

- `*`는 **행렬곱(matrix multiplication)** 규칙을 따른다.
- 원소별(element-by-element) 곱셈을 하려면 `.*`을 써야 한다.

```matlab
a = [1 2 3];
b = [6 7 8];
c = a .* b;    % c = [6 14 24], 원소별 곱셈
```

### ⚠️ 함정: `*`를 잘못 쓰면 오류가 난다

```matlab
a * b   % 오류! 1x3 행렬끼리는 행렬곱 규칙(내적 차원 불일치)으로 곱할 수 없다
```

두 벡터의 크기가 행렬곱 규칙에 맞지 않으면 MATLAB은 크기가 호환되지 않는다는 오류를 낸다.

### 나눗셈과 거듭제곱도 마찬가지

같은 논리가 나눗셈(`/` vs `./`)과 거듭제곱(`^` vs `.^`)에도 적용된다.

```matlab
a ./ b     % 원소별 나눗셈
```

### ⚠️ 함정: 스칼라를 배열로 나눌 때

```matlab
10 / a   % 오류! /는 역행렬을 구하는 연산으로 해석되어 크기가 맞지 않으면 실패한다
10 ./ a  % 올바름: 원소별 나눗셈
```

> 실행 파일: [`ex0204c_array_arithmetic.m`](../../example/ch02/ex0204c_array_arithmetic.m)

### 배열 연산 활용 예제: 각도를 라디안으로 변환

배열 연산을 쓰면 `for`/`while` 반복문 없이 여러 값을 한 번에 계산할 수 있다.

```matlab
degrees = [10 15 70 90];
radians = degrees .* pi ./ 180;   % 또는 degrees * pi / 180 (스칼라이므로 둘 다 가능)
```

`pi` 값은 MATLAB에 이미 내장되어 있다.

## 전치 연산자 (Transpose)

행을 열로, 열을 행으로 바꾸려면 전치 연산자 `'`를 사용한다. 배열들을 더 큰 배열로 합칠 때
유용하다.

```matlab
row = [1 2 3 4];
col = row';    % 4x1 열벡터
```

## 숫자 표시 형식 (Number Display)

- 표시 형식을 바꿔도 계산 자체의 정확도는 바뀌지 않는다 — **보여지는 방식**만 바뀐다.
- 기본 타입인 `double`은 약 16자리 정밀도로 계산된다.
- 매우 작거나 매우 큰 수는 과학적 표기법(scientific notation)으로 표시된다.
- 정수는 소수점 없이 표시된다.
- 소수는 기본적으로 `short` 형식(소수점 4자리)으로 표시된다.

```matlab
format short   % 기본값, 소수점 4자리
pi             % 3.1416

format long    % 소수점 15자리 내외
pi             % 3.141592653589793

format short   % 다시 기본값으로
```

> 실행 파일: [`ex0204c_array_arithmetic.m`](../../example/ch02/ex0204c_array_arithmetic.m)

## ⚠️ 함정

- `*`, `/`, `^`는 행렬 연산, `.*`, `./`, `.^`는 원소별 연산이다. 점(`.`) 하나 빠뜨리면 오류가
  나거나(크기가 안 맞을 때) 전혀 다른 결과가 나온다(정사각 행렬처럼 크기가 우연히 맞을 때).
- `sin(pi)`는 수학적으로는 0이지만 MATLAB에서는 부동소수점 반올림 오차 때문에
  `1.2246e-16`처럼 0에 아주 가까운 작은 값이 나온다. "0이 아니다"라고 놀라지 말 것.
- `format long`으로 바꾼 뒤 `format short`로 되돌리는 것을 잊기 쉽다. 표시 형식은 세션
  전체에 영향을 준다.
