# 2.3 변수 이름 규칙과 데이터 타입

## 2.3.1 변수 사용하기

Command Window를 계산기처럼 쓸 수도 있지만, 값에 **이름**을 붙이는 편이 훨씬 편리하다.
MATLAB은 대부분의 프로그래밍 언어와 비슷한 명명 규칙을 따른다.

- 이름은 반드시 **문자**로 시작해야 한다.
- 길이 제한은 없지만, 처음 **63자**까지만 실제로 사용된다.
- 허용되는 문자는 숫자, 문자, 밑줄(`_`) 뿐이다.

### isvarname으로 이름 검증하기

```matlab
isvarname("cool_beans")   % 1 (true)  - 규칙을 만족
isvarname("cool-beans")   % 0 (false) - 하이픈은 불가
```

`isvarname`은 1(참) 또는 0(거짓)을 반환한다.

### 대소문자 구분

- 이름은 대소문자를 구분한다. `X`와 `x`는 서로 다른 변수다.
- `for`, `while`, `if` 같은 **예약어(reserved keyword)**는 변수 이름으로 쓸 수 없다.
- 예약어 목록은 `iskeyword` 명령으로 확인한다.

### 함수 이름을 변수로 덮어쓰기

MATLAB은 함수 이름을 변수 이름으로 재사용하는 것을 막지 않는다. 예를 들어 내장 함수
`max`가 있음에도 `max = 10;`처럼 변수를 만들 수 있다. **권장되지는 않는다.**

```matlab
max = 10;          % max가 이제 변수를 가리킨다 (Workspace에 나타남)
clear max          % 변수를 삭제해 다시 함수 max로 되돌린다
```

의도치 않게 함수 이름을 변수로 덮어썼다면 `clear <이름>`으로 되돌릴 수 있다.

## 2.3.2 데이터 타입 (Data Types)

MATLAB의 기본 데이터 타입은 **배열(array)**이다.

- 값 하나(스칼라)는 1×1 배열로 저장된다.
- 값의 목록(벡터)은 행 또는 열로 저장된다.
- 값의 표(2차원 배열)는 행과 열로 구성된다.
- MATLAB은 더 높은 차원의 배열도 다룰 수 있다.

"array"와 "matrix"는 흔히 같은 뜻으로 쓰이지만, 엄밀히는 matrix는 행렬 대수 연산에 쓰이는
숫자 배열을 가리킨다. 배열은 저장하는 데이터 종류(class)에 따라 다시 나뉜다.

| 분류 | 설명 | 기본/대표 타입 |
| --- | --- | --- |
| Numeric | 숫자를 저장 | `double` (기본, 배정밀도 부동소수점) |
| Text | 문자 텍스트를 저장 | `char`(문자 배열), `string`(문자열 배열) |
| Logical | 참/거짓 정보를 저장, 조건 판단에 사용 | `logical` |
| 복합 타입 | 한 배열 안에 여러 타입을 섞어 저장 | `table` (초보자에게 가장 유용) |

```matlab
class(3.5)                         % "double"
class('engineer')                  % "char"
class("engineer")                  % "string"
class(5 > 3)                       % "logical"
class(table([1;2], ["A";"B"]))     % "table"
```

> 실행 파일: [`ex0203_naming_and_types.m`](../../example/ch02/ex0203_naming_and_types.m)

> **[보강]** `char`와 `string`은 둘 다 텍스트를 저장하지만, `char`는 문자 하나하나로 이루어진
> 배열(작은따옴표 `'...'`)이고, `string`은 텍스트를 하나의 덩어리로 다루는 타입(큰따옴표
> `"..."`)이다. R2026a 최신 코드에서는 `string`을 기본으로 쓰는 것이 권장된다. 이 챕터의
> 예제들도 텍스트가 필요할 때는 `string`(큰따옴표)을 사용한다.

## ⚠️ 함정

- `isvarname`은 이름이 **문법적으로** 유효한지만 검사한다. 예약어인지까지는 확인해 주지 않으므로
  `iskeyword`와 같이 써야 한다.
- 함수 이름을 변수로 덮어쓰면 그 세션에서는 원래 함수를 호출할 수 없다. 갑자기 `max(...)`,
  `sum(...)` 같은 함수가 "동작하지 않는다"면 같은 이름의 변수를 만든 적이 없는지 의심하라.
- 스칼라 하나만 저장해도 MATLAB 내부에서는 여전히 "배열"이다. "스칼라는 배열이 아니다"라고
  착각하면 나중에 배열 인덱싱·크기 관련 문제에서 혼란스러워진다.
