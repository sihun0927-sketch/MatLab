# 2.1 Getting Started — MATLAB 시작하기

## MATLAB 실행

- MATLAB 설치 절차는 운영체제와 환경에 따라 다르다. 이미 설치되어 있다고 가정한다.
- 바탕화면 아이콘을 더블클릭하거나 시작 메뉴에서 찾아 실행한다.
- 여러 버전이 설치되어 있다면 실행할 버전을 선택하는 화면이 나올 수 있다.

## MATLAB Desktop 구성

MATLAB을 실행하면 **MATLAB Desktop**이 열린다. Desktop은 여러 개의 창(window)으로 구성되며,
기본 화면에는 그중 세 개만 열린다.

기본으로 열리는 창:

| 창 이름 | 역할 |
| --- | --- |
| Command Window | 명령을 입력하고 결과를 바로 확인하는 계산기 같은 창 |
| Workspace | 현재 세션에서 정의한 변수들을 보여주는 창 |
| Current Folder | 현재 작업 디렉터리의 파일 목록을 보여주는 창 |

이 외의 창들(Command History, Document Window, Graphics Window, Edit Window 등)은
필요할 때 자동으로 열린다. 각 창의 자세한 역할은 [2.2 MATLAB Windows](2.2-matlab-windows.md)에서 다룬다.

> **[보강]** 원서 슬라이드는 R2021a Desktop 캡처 화면을 보여주지만, 실제 창 캡처는 버전마다
> 배치가 조금씩 다르고 텍스트로 재현할 수 없으므로 이 노트에서는 창의 역할과 기능만 표로 정리한다.
> R2026a에서도 창 구성 요소 자체는 동일하다.

## ⚠️ 함정

- Desktop의 창 배치는 **Layout** 메뉴에서 자유롭게 바꿀 수 있다. 시험에 "기본 화면에 열리는 창 3개"를
  묻는 문제가 나오면 Command Window / Workspace / Current Folder를 기억해야 한다. Command History나
  Graphics Window는 기본 화면에 없다.
