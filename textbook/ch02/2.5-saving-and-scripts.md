# 2.5 파일 저장·불러오기, 스크립트, Live Script, Section 모드

## 2.5.1 변수 저장하기

Command Window에서 계산한 값을 보존하려면 Workspace의 내용을 파일로 저장해야 한다.

### .mat 파일 (기본 형식)

```matlab
save my_example_file          % Workspace 전체를 현재 폴더에 저장
load my_example_file          % 저장된 Workspace를 다시 불러오기
```

- 기본 저장 형식은 `.mat`(바이너리 파일)이다.
- 이 과정은 **Workspace의 값**만 저장한다 — Command Window에서 그 값을 만든 **명령**은
  저장되지 않는다.

### 선택한 변수만 저장하기

```matlab
save my_example_file A B C   % 지정한 변수만 저장
```

### ASCII(.dat/.txt) 파일 — 다른 프로그램과 호환

`.mat` 파일은 MATLAB 전용이므로, 다른 프로그램에서도 읽을 수 있게 하려면 ASCII 형식으로
저장한다. 확장자는 `.dat` 또는 `.txt`를 직접 붙여야 한다.

```matlab
save my_data.dat tableData -ascii
```

### ⚠️ 함정

- `-ascii` 앞의 하이픈(`-`)과 뒤 사이에는 **공백이 있어야 한다**. `save file var -ascii`처럼
  `-ascii`를 하나의 옵션 토큰으로 띄어 써야 하며, 옵션 자체를 따옴표로 묶거나 붙여 쓰면 오류가
  난다.
- ASCII 파일로 불러온 데이터는 여러 변수로 나뉘지 않고 **파일 이름과 같은 이름의 단일 변수**로
  들어온다. 필요하면 그 배열에서 개별 변수를 다시 잘라내야 한다.

### 변수 불러오기

```matlab
clear, clc
load my_example_file          % .mat 파일: 저장된 이름 그대로 여러 변수가 복원된다
loaded = load('my_data.dat'); % ASCII 파일: 파일 이름으로 된 배열 하나로 들어온다
```

`.mat` 파일은 서로 다른 크기·타입의 변수를 여러 개 저장해도 각자 원래 이름으로 정확히
복원되므로, 여러 변수를 한꺼번에 보관할 때 편리하다. 반면 실험 데이터처럼 표 형태로
자연스럽게 맞아떨어지는 정보는 ASCII 파일에 저장하는 것이 적합하다.

> 실행 파일: [`ex0205_save_load_and_sections.m`](../../example/ch02/ex0205_save_load_and_sections.m)
> (저장소를 더럽히지 않도록 `tempdir`에 저장했다가 삭제한다.)

> **[보강]** 원서는 EXCEL 스프레드시트나 다른 형식의 파일을 **Import Wizard**(Current Folder
> 창에서 파일을 더블클릭해 여는 대화상자)로 불러오는 과정을 캡처 화면으로 보여준다. 이
> 마법사는 데이터를 어떻게 해석할지(구분자, 헤더 행 여부 등) 대화형으로 물어보는 GUI다.
> MATLAB 데스크톱 캡처는 재현하지 않으므로, 코드로 동일한 작업을 하려면 `readtable`,
> `readmatrix` 함수를 사용하면 된다는 점만 기억해 둔다.

## 2.5.2 프로그램 (스크립트와 Live Script)

Command Window에서 계산하는 것은 쉽고 강력하지만, MATLAB을 닫으면 그 계산은 사라진다.
MATLAB은 프로그램을 저장해 재사용할 수 있는 두 가지 편집기를 제공한다.

- 프로그램 이름도 변수 이름 규칙을 따라야 한다: 문자로 시작, 문자/숫자/밑줄만 사용(공백 불가),
  대소문자 구분.

### 스크립트 (Script, M-file)

- 초기 MATLAB 프로그램은 모두 스크립트로 작성되었고 `.m` 확장자 파일(M-file)로 저장되었다.
- 지금 접하는 대부분의 기존 MATLAB 코드는 스크립트로 작성되어 있다.
- 스크립트와 Live Script의 **코드 자체는 동일하다** — 차이는 편집기뿐이다.
- 데스크톱의 실행(Run) 버튼이나 Command Window에서 스크립트 이름을 입력해 실행한다.

```matlab
% ex_temperature_convert.m
%% 섭씨 -> 화씨 변환 스크립트
c = 100;
f = c*9/5 + 32;
disp(f)
```

### 주석 (Comments)

- 프로그램은 나중에 다시 볼 것을 대비해 주석을 충분히 달아두는 것이 좋다.
- 주석 연산자는 퍼센트 기호(`%`)다. `%`로 시작한 줄은 실행되지 않는다.
- 명령 뒤에 같은 줄에 주석을 붙일 수도 있다.

```matlab
a = 5   % 변수 a에 5를 대입
```

### Evaluate Section (섹션 단위 실행)

스크립트 일부를 드래그로 선택한 뒤 우클릭 → **Evaluate Section**을 선택하면 그 부분만 실행할
수 있다. 같은 메뉴에서 섹션 전체를 주석 처리/해제할 수도 있어, 디버깅 중에 유용하다.

### Live Script

- Live Script는 코드와 함께 텍스트, 이미지, 수식, 그리고 프로그램이 만든 그래픽 결과까지
  하나의 문서 안에 담을 수 있는 대화형 프로그램 파일이다.
- 코드는 스크립트 M-file과 완전히 같다.
- 스크립트 편집기 탭에서 파일 이름을 우클릭 → **Open as Live Script**로 변환할 수 있다.
- 툴스트립의 **New Live Script**로 처음부터 새로 만들 수도 있다.
- `.mlx` 확장자로 저장된다.
- Live Script는 `.mlx` 외에도 보고서 등에 넣기 좋은 형식으로 저장할 수 있다: PDF, Word 문서,
  웹 게시용 HTML. **Save As** 메뉴에서 "MATLAB Code file"을 선택하면 다시 `.m` 스크립트로도
  변환할 수 있다.

> **[보강]** 이 저장소의 예제 코드는 전부 `.m` 스크립트로 관리한다(검증 자동화를 위해). Live
> Script(`.mlx`)는 바이너리 포맷이라 diff·grep이 되지 않으므로, 실제 학습·과제에서 Live Script를
> 쓰더라도 같은 코드를 `.m`으로도 한 부 가지고 있으면 버전 관리가 쉬워진다.

## 2.5.3 Section 모드

Section 모드는 스크립트와 Live Script를 여러 섹션으로 나눠 한 번에 하나씩 실행할 수 있게 하는
기능이다. 프로그램을 점진적으로 개발할 때 특히 유용하다.

- 섹션 구분자는 퍼센트 기호 두 개(`%%`) 뒤에 **공백**을 두고 만든다.
- 같은 줄에 이름을 적으면 그 섹션의 이름이 된다.

```matlab
%% Section A: 데이터 준비
temperatures_c = [0 20 37 100];

%% Section B: 단위 변환
temperatures_f = temperatures_c * 9/5 + 32;
```

커서를 어떤 섹션 안에 두면 그 섹션이 노란색으로 강조되어 활성 섹션임을 보여준다. Live
Script에서도 툴스트립의 섹션 구분 아이콘으로 같은 방식으로 섹션을 나눌 수 있으며, **View**
탭에서 출력이 보이는 방식을 조정할 수 있다.

> 실행 파일: [`ex0205_save_load_and_sections.m`](../../example/ch02/ex0205_save_load_and_sections.m)

## ⚠️ 함정

- `%%` 뒤에 공백을 빼먹으면 섹션 구분자가 아니라 그냥 **주석**으로 인식된다.
- `.mat`와 ASCII(`.dat`) 저장은 저장되는 **내용**이 다르다: `.mat`는 여러 변수를 이름 그대로
  복원하고, ASCII는 파일 이름과 같은 단일 변수로 들어온다.
- `save`는 Workspace의 값만 저장한다. 그 값을 만든 명령(코드)까지 남기고 싶다면 스크립트로
  따로 작성해야 한다.

2. 섭씨 온도 배열을 화씨로 변환하는 스크립트를 작성하고, `%%`로 "데이터 준비"와 "변환" 두
   섹션으로 나누시오.
