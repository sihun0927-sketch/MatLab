# 5.1.3 축 크기 조절과 주석 달기

MATLAB은 x·y축 눈금을 알아서 잡는다. 하지만 두 그래프의 축을 맞추거나, 관심 구간만 확대하려면 직접 정해야 한다.

## axis

| 형태 | 하는 일 |
|---|---|
| `axis` | 입력 없이 쓰면 현재 눈금을 **동결**한다 (이후 데이터를 더해도 축이 안 변한다) |
| `axis([xmin xmax ymin ymax])` | 네 값을 담은 배열 하나로 범위를 지정한다 |

배열의 네 값은 순서대로 x축 최솟값, x축 최댓값, y축 최솟값, y축 최댓값이다.

```matlab
plot(x, y, ":ok", x, y*2, "--r", x, y/2, "-b")
axis([0 11 0 300])
```

→ [`example/ch05/ex0501_axis.m`](../../example/ch05/ex0501_axis.m)

![axis](img/ex0501_axis.png)

> **[보강]** 슬라이드 밖 옵션이지만 자주 쓴다.
> - `axis equal` — x축과 y축의 한 칸 길이를 같게 한다. 원을 원으로 그리려면 필수.
> - `axis square` — 그림 영역을 정사각형으로.
> - `axis tight` — 데이터에 딱 맞게 범위를 줄인다.
> - `xlim([0 11])`, `ylim([0 300])` — 한 축만 따로 지정.

> ⚠️ **함정** — `axis`의 입력은 **대괄호로 묶은 배열 하나**다. 대괄호를 빠뜨려 `axis(0, 11, 0, 300)`로 쓰면 더 나쁜 일이 벌어진다. **오류가 나지 않고, 아무 일도 일어나지 않는다.** R2026a에서 확인한 결과다.
>
> ```matlab
> plot(x, y)
> axis(0, 11, 0, 300)     % 오류 없음. 축 범위도 그대로
> axis([0 11 0 300])      % 이렇게 써야 적용된다
> ```
>
> 축이 안 바뀌는데 오류 메시지도 없다면 대괄호부터 확인하라.

## legend와 text

- `legend`는 선마다 이름을 붙여 범례를 만든다. 기본 위치는 오른쪽 위다.
- `text(x, y, txt)`는 그래프 안 임의의 위치에 글상자를 놓는다.

`text`의 좌표는 **축 값 기준**이다. 화면 비율(0~1)이 아니라 데이터 값이다.

```matlab
plot(x, y, ":ok", x, y*2, "--r", x, y/2, "-b")
legend("line 1", "line 2", "line 3", Location="northwest")
text(1, 100, "Label plots with the text command")
axis([0 11 0 300])
title("Example Graph for Chapter 5")
xlabel("My x-axis label")
ylabel("My y-axis label")
```

→ [`example/ch05/ex0501_legendtext.m`](../../example/ch05/ex0501_legendtext.m)

![legend와 text](img/ex0501_legendtext.png)

`Location`으로 범례 위치를 옮긴다: `"northwest"`, `"southeast"`, `"best"`, `"northoutside"` 등.

> ⚠️ **함정** — `legend`의 이름 순서는 **선이 그려진 순서**를 따른다. `hold on`으로 순서를 바꿔 그렸다면 범례 이름도 그 순서에 맞춰야 한다. 선 개수보다 이름을 적게 주면 남은 선은 범례에서 빠진다.

## TeX 문법

제목·축 이름·범례·`text` 문자열 안에서 TeX 명령을 쓸 수 있다.

| 쓰고 싶은 것 | 쓰는 법 | 결과 |
|---|---|---|
| 그리스 문자 | 이름 앞에 역슬래시 `\` | `\alpha \beta \gamma` → α β γ |
| 위 첨자 | 캐럿 `^` | `m/s^2` → m/s² |
| 아래 첨자 | 밑줄 `_` | `g_1` → g₁ |
| 두 글자 이상 묶기 | 중괄호 `{ }` | `A_{max}` → A_max 전체가 아래 첨자 |
| 화살표 | `\leftarrow`, `\rightarrow` | ← → |

```matlab
title("\alpha \beta \gamma")
ylabel("진폭 A_{max} [m/s^2]")
```

여러 줄 제목은 **문자열을 여러 행으로 쌓은 배열**로 넘긴다. 세미콜론으로 행을 나눈다.

```matlab
title(["첫 번째 줄"; "두 번째 줄"])
```

→ [`example/ch05/ex0501_tex.m`](../../example/ch05/ex0501_tex.m)

![TeX 주석](img/ex0501_tex.png)

> ⚠️ **함정** — 중괄호를 빼면 **첫 글자 하나만** 첨자가 된다. `A_max`는 `A` 아래에 `m`만 붙고 `ax`는 그냥 따라 나온다. 반드시 `A_{max}`로 쓴다. 위 첨자 `^`도 같다.

> **[보강]** 글자 그대로 `_`나 `^`를 보이고 싶으면 앞에 역슬래시를 붙여 `\_`, `\^`로 쓰거나, 해당 객체의 `Interpreter` 속성을 `"none"`으로 바꾼다.

## Example 5.2 — 탄도 문제

중력가속도를 보통 g = 9.81 m/s²로 쓰지만 실제로는 상수가 아니다. 위치에 따라 9.8 ~ 9.9 m/s² 사이 값이 쓰인다. 이 차이가 결과를 얼마나 바꾸는가?

발사각 θ, 초기속도 v로 쏜 포탄의 사거리는

```
R = v² / g · sin(2θ)
```

```matlab
g1 = 9.8;                        % m/s^2
g2 = 9.9;                        % m/s^2
v  = 100;                        % m/s
theta = 0:0.05:pi/2;             % rad

R1 = v^2 ./ g1 .* sin(2*theta);  % m
R2 = v^2 ./ g2 .* sin(2*theta);  % m

plot(theta, R1, theta, R2)
title(["Cannon Range Sensitivity"; "To the Value of g"])
xlabel("Cannon Launch Angle, \theta")
ylabel("Range, meters")
legend("g_1 = 9.8 m/s^2", "g_2 = 9.9 m/s^2")
```

→ [`example/ch05/ex0501_ballistics.m`](../../example/ch05/ex0501_ballistics.m)

![탄도 문제](img/ex0501_ballistics.png)

이 예제에서 눈여겨볼 것:

- x축 이름의 `\theta` → 그리스 문자 θ
- 범례의 `g_1`, `g_2` → 아래 첨자
- 범례의 `m/s^2` → 위 첨자
- 제목의 세미콜론 → 두 줄 제목

실행하면 최대 사거리 차이가 **10.30 m**로 나온다. 최대 사거리 약 1020 m에서 1% 남짓이다. g를 소수 둘째 자리까지 따지는 것이 의미 있는지 판단할 근거가 된다.

> ⚠️ **함정** — `v^2 ./ g1 .* sin(2*theta)`에서 `theta`가 벡터이므로 `./`와 `.*`를 써야 한다. `v^2 / g1 * sin(2*theta)`는 `g1`, `v`가 스칼라라 여기서는 우연히 같은 답이 나오지만, 분모가 벡터가 되는 순간 행렬 나눗셈으로 해석되어 엉뚱한 결과를 준다. 처음부터 원소별 연산자를 쓰는 습관을 들여라.
