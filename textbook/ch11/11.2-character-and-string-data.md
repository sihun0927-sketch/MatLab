# 11.2 Character and String Data

텍스트는 MATLAB에 두 가지 형태로 저장된다.

- **character array** (문자 배열, `char`)
- **string array** (문자열 배열, `string`)

string 타입은 **R2016b**에 추가되었고 character array보다 장점이 많다. character array를 쓴 **legacy code(옛 코드)** 가 많이 남아 있지만, 새 프로그램은 대부분 **string을 쓰는 것이 좋다**. MATLAB 함수는 입력으로 char와 string을 모두 받아, 함수 안에서 알맞은 타입으로 바꿔 쓴다.

## 11.2.1 Creating Character and String Arrays

| | character array | string array |
|---|---|---|
| 만드는 따옴표 | **작은따옴표** `'...'` | **큰따옴표** `"..."` |
| 저장 단위 | **문자 하나하나**가 원소 | **텍스트 덩어리 전체**가 원소 하나 |
| 변환 함수 | `char(s)` : string → char | `string(c)` : char → string |

```matlab
H = 'Emanuel';       % 1x7 char
J = "Sarah";         % 1x1 string
K = string(H)        % char -> string
L = char(J)          % string -> char
```
```
K = 
    "Emanuel"
L =
    'Sarah'
```

- Workspace: `H`는 **1×7** char(14 bytes), `J`는 **1×1** string, `L`은 **1×5** char(10 bytes).
- char는 문자 수만큼 원소가 있고, string은 텍스트 하나가 원소 1개다.

> **[보강]** `length('Emanuel')` = 7, `length("Emanuel")` = **1**. string의 글자 수는 `strlength("Sarah")` = 5. char는 문자당 **2 bytes**다.

### 2차원 character array: 이름 목록 저장하기

character array는 문자를 하나씩 저장하고 배열은 **직사각형**이어야 한다. 그래서 행마다 다른 이름을 넣기가 어색하다. 이름마다 글자 수가 다른데 모든 행의 원소 수는 같아야 하기 때문이다. 해결책은 두 가지다.

1. 빈 칸을 **공백으로 채운다(padding)**.
2. character array들을 **cell array**에 담는다.

**방법 1 — `char`로 padding**

```matlab
M = char('Steven','Jasmin','David','Terrell','Maria')
```
```
M =
  5×7 char 배열
    'Steven '
    'Jasmin '
    'David  '
    'Terrell'
    'Maria  '
```

`char` 함수가 배열을 공백으로 **채운다(pad)**. `M`의 모든 행은 원소가 **7개**(가장 긴 `'Terrell'` 기준)이고, 일부는 공백이다.

**방법 2 — cell array of characters**

```matlab
N = {'Steven';'Jasmin';'David';'Terrell';'Maria'}
```
```
N =
  5×1 cell 배열
    {'Steven' }
    {'Jasmin' }
    {'David'  }
    {'Terrell'}
    {'Maria'  }
```

- cell array는 **cell array constructor**, 즉 **중괄호(curly brackets, braces) `{ }`** 로 만든다.
- character array 사이에 **세미콜론**이 필요하다(5×1 열).
- padded character array의 **여분 공백이 생기지 않는다**.

### String array로 이름 저장하기

텍스트를 저장하는 더 효율적인 방법은 string array다.

```matlab
P = ["Steven";"Jasmin";"David";"Terrell";"Maria"]
```
```
P = 
  5×1 string 배열
    "Steven"
    "Jasmin"
    "David"
    "Terrell"
    "Maria"
```

- string 하나는 같은 내용의 char보다 메모리를 **더** 쓴다.
- 그러나 string **배열**은 같은 정보를 담은 **cell array of char**보다 메모리를 **덜** 쓴다.
- 슬라이드 Workspace 값: `M` 5×7 char **70**, `N` 5×1 cell **578**, `P` 5×1 string **366** bytes.

> **[보강]** R2026a 실측은 `M` **70**, `N` **618**, `P` **382** bytes다. `"Sarah"`도 슬라이드는 150, R2026a는 166 bytes. 버전마다 오버헤드가 달라 숫자는 다르지만 **char < string 배열 < cell of char** 순서는 같다.

### 인덱싱

숫자 배열에서 쓰던 인덱싱을 char와 string에도 그대로 쓴다.

```matlab
M(3,:)        % 'David  '   (공백 포함 7글자)
N{3}          % 'David'     (cell 안의 char)
P(3)          % "David"
M(3,1:2)      % 'Da'
```

> **[보강]** string 안의 글자를 꺼내려면 중괄호로 char를 꺼낸 뒤 괄호: `P{3}(1:2)` → `'Da'`. `P(3)(1:2)`는 오류다(`소괄호 '()' 바로 뒤에 소괄호 '()'를 사용하는 것은 허용되지 않습니다.`).

## 11.2.2 Character Encoding Strategies

- 컴퓨터의 모든 정보는 **0과 1의 연속**으로 저장된다.
- 대표적인 부호화(coding) 방식 두 가지:
  - **ASCII** — 대부분의 소형 컴퓨터
  - **EBCDIC** — 많은 메인프레임, 특히 IBM
- 0과 1만 쓰는 체계를 **binary** 또는 **base-2** 체계라 한다.

### Base-2 vs Base-10

입력한 모든 문자는 base-2 값을 가지고, 모든 base-2 수는 base-10 값을 가진다.

**Table 11.2 Binary-to-Decimal Conversions**

| Base 2 (binary) | 1 | 10 | 11 | 100 | 101 | 110 | 111 | 1000 |
|---|---|---|---|---|---|---|---|---|
| **Base 10 (decimal)** | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |

> **[보강]** `dec2bin(8)` → `'1000'`, `bin2dec('1000')` → `8`.

### 문자의 10진 값

- ASCII(또는 EBCDIC) 문자는 이진 표현과 **10진 값(decimal equivalent)** 을 모두 가진다.
- 문자를 **`double`** 로 바꾸면 ASCII 10진 값이 나온다.
- 반대로 double에 **`char`** 를 쓰면 그 10진 값에 해당하는 문자가 나온다.

```matlab
double('a')       % 97
char(98)          % 'b'
```

> **[보강]** 대문자 `'A'` = 65, `'Z'` = 90, 소문자 `'a'` = 97. 대소문자 차이는 **32**. `double('Hello')` → `72 101 108 108 111`.

### 문자와 숫자를 섞어 배열을 만들면 → 전부 char

```matlab
A = ['a', 98]     % 98이 'b'로 바뀐다
```
```
A =
    'ab'
```

`A`는 **1×2 character array**다. 문자와 숫자를 섞으면 MATLAB은 **모든 데이터를 문자로** 바꾼다.

**모든 숫자에 대응하는 문자가 있는 것은 아니다.** 대응 문자가 없으면 결과 char 배열에서 **빈칸이나 네모(□)** 로 보인다. 예를 들어 3에는 출력 가능한 문자가 없다.

```matlab
B = ['a', 3]      % 'a□'  (B도 1x2 char)
```

### 문자와 숫자로 계산하면 → 문자를 10진 값으로

```matlab
C = 'a' + 3       % 97 + 3
```
```
C =
   100
```

수학 연산에 문자와 숫자가 섞이면 MATLAB은 문자를 **10진 값으로 바꿔** 계산한다. `C`는 **double**이다.

### HINT: string과 char에서 `+`는 다르게 동작한다

| 식 | 결과 | 설명 |
|---|---|---|
| `'a' + 3` | `100` (double) | `'a'`를 97로 바꿔 더한다 |
| `"a" + 3` | `"a3"` (string) | 3을 문자열에 **이어 붙인다(concatenate)** |

> **[보강]** R2026a 실측 추가 예:
>
> | 식 | 결과 |
> |---|---|
> | `'abc' + 1` | `98 99 100` |
> | `"abc" + 1` | `"abc1"` |
> | `'ab' + 'cd'` | `196 198` (원소별 덧셈) |
> | `"ab" + "cd"` | `"abcd"` |
> | `['ab','cd']` | `'abcd'` (char 이어 붙이기는 대괄호) |
> | `["ab","cd"]` | 1×2 string 배열 `"ab" "cd"` |
> | `char('a'+1)` | `'b'` |
> | `'A' < 'a'` | `1` (65 < 97) |

## ⚠️ 함정

- **작은따옴표 = char, 큰따옴표 = string.** `'Sarah'`는 1×5, `"Sarah"`는 1×1.
- **char 행렬은 행 길이가 같아야 한다.** `['abc'; 'de']`는 오류 `결합하려는 배열의 차원이 일치하지 않습니다.` (Dimensions of arrays being concatenated are not consistent.) → `char('abc','de')`로 padding하거나 string 배열을 쓴다.
- **padding된 공백은 데이터다.** `M(3,:)`은 `'David  '`(7글자). 비교할 때 `'David'`와 같지 않다.
- **`'a' + 3`은 100, `"a" + 3`은 `"a3"`.** 시험 단골.
- **`'ab' + 'cde'`는 오류.** 원소별 덧셈이라 길이가 같아야 한다(`이 연산에 대해 배열 크기가 호환되지 않습니다.`).
- **숫자와 문자를 대괄호로 섞으면 숫자가 문자로 바뀐다.** `['Score: ', 90]`은 `'Score: Z'`. 숫자를 텍스트로 넣으려면 `num2str(90)`이나 `"Score: " + 90`.
