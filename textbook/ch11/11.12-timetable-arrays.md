# 11.12 Timetable Arrays

- **timetable**은 **타임스탬프(timestamp)가 찍힌 데이터**를 다루도록 설계된 특별한 array다.
- 일반 table의 기능이 **모두** timetable에서도 동작한다. 거기에 더해 **시간 데이터를 조작하는 함수**가 있다.
- MATLAB에는 timetable 실습용 샘플 데이터가 있다.
  - **`indoors`** 는 `.csv` 파일 → **`readtimetable`** 로 불러온다.
  - **`outdoors`** 는 `.mat` 파일 → **`load`** 명령으로 불러온다.
- 불러오면 둘 다 **timetable**로 저장된다. **같은 기간**을 다루지만 **데이터 점의 개수가 다르다**.
- 내용은 **`summary`** 함수나 variable editor로 살펴본다.

```matlab
indoors = readtimetable("indoors.csv");
load outdoors
```

| 변수 | 크기 | 열 |
|---|---|---|
| `indoors` | **60×2** timetable | `Time`, `Humidity`, `AirQuality` |
| `outdoors` | **51×3** timetable | `Time`, `Humidity`, `TemperatureF`, `PressureHg` |

- 첫 열 `Time`은 **행 시간(row times)** 이다. 변수 개수(열 수)에 들어가지 않는다. `indoors`는 `2015-11-15 00:00:24`, `01:13:35`, `02:26:47`, … 처럼 시각이 찍혀 있다.

> **[보강]** **R2026a에는 `indoors.csv`와 `outdoors.mat` 샘플 파일이 들어 있지 않다**(`which indoors.csv` → 찾을 수 없음, 슬라이드는 R2021a). 이 절의 코드는 같은 열 이름의 작은 timetable을 직접 만들어 실행 확인했다.
>
> ```matlab
> Time = datetime(2015,11,15) + minutes([24; 95; 147; 240]);
> indoors = timetable(Time, [36;36;37;37], [80;80;79;82], ...
>     VariableNames=["Humidity","AirQuality"]);
> Time = datetime(2015,11,15) + minutes([10; 120; 200]);
> outdoors = timetable(Time, [49;48.9;48.8], [51.3;51.5;51.5], [29.61;29.61;29.60], ...
>     VariableNames=["Humidity","TemperatureF","PressureHg"]);
> ```
>
> `timetable(시간열, 데이터…)`의 첫 인수가 행 시간이다. 행 시간 열 이름은 그 변수 이름을 따른다(위에서는 `Time`). 다른 이름(`t1`)으로 만들면 `indoors.Time`은 오류다.

## Timetable 동기화: `synchronize`

두 데이터 세트를 하나로 합치려면 **`synchronize`** 함수를 쓴다.

```matlab
combined_data = synchronize(indoors, outdoors);
```

- 결과는 **110×5 timetable**이다(60 + 51 = 111이 아닌 110인 것으로 보아 한 시각만 겹쳤다). 열은 `Humidity_indoors`, `AirQuality`, `Humidity_outdoors`, `TemperatureF`, `PressureHg`.
- 두 배열에 **같은 시각이 (거의) 없어서**, 한쪽에만 있는 시각의 빈칸에는 **`NaN`(not a number)** 이 들어간다.
- 합친 배열 사이에 **공통 시각이 없으니 결측값(missing value)이 매우 많다.**

> **[보강]** 슬라이드는 "none of the times were the same"이라고 했지만 60 + 51 = 111행이어야 하므로 실제로는 한 시각이 겹친 것으로 보인다. 원본 파일이 없어 확인하지 못했다.
>
> 두 timetable에 **같은 이름의 열**(`Humidity`)이 있으면 `_indoors`, `_outdoors`처럼 **원래 변수 이름이 붙는다**. 위의 작은 데이터로 실행하면:
>
> ```
> combined_data =
>   7×5 timetable
>            Time            Humidity_indoors    AirQuality    Humidity_outdoors    TemperatureF    PressureHg
>     ___________________    ________________    __________    _________________    ____________    __________
>     2015-11-15 00:10:00          NaN              NaN                49               51.3          29.61   
>     2015-11-15 00:24:00           36               80               NaN                NaN            NaN   
>     2015-11-15 01:35:00           36               80               NaN                NaN            NaN   
>     2015-11-15 02:00:00          NaN              NaN              48.9               51.5          29.61   
>     ...
> ```
>
> 결측값 개수: `sum(ismissing(combined_data))`.

## 결측값 채우기: 선형 보간

데이터를 합치면서 빠진 정보를 **선형 보간(linear interpolation)** 으로 채우면 좋다.

```matlab
c_d_linear = synchronize(indoors, outdoors, 'union', 'linear');
```

- `'union'`: 두 timetable의 **모든 시각**을 합친다(합집합).
- `'linear'`: 빈 값을 **선형 보간**으로 채운다.
- 이제 **결측값이 없다.** 예: 슬라이드에서 3행의 `Humidity_indoors`는 36과 37 사이의 `36.2297`, `AirQuality`는 `79.7703`으로 채워졌다.

> **[보강]** 작은 데이터 실행 결과: 02:00의 `Humidity_indoors`는 01:35(36)와 02:27(37) 사이를 시간 비율로 나눈 `36.481`. 데이터 범위 **밖**의 시각(00:10의 indoors, 04:00의 outdoors)은 **외삽(extrapolation)** 되어 채워진다(04:00 `Humidity_outdoors` = 48.75). 외삽 값은 믿을 만하지 않으니 주의.

## 한 가지 더: 일정한 간격으로 — `retime`

- 시각을 자세히 보면 몇 분 간격인 것도 있고 **1시간 반**이나 떨어진 것도 있다.
- 데이터 간격을 **고르게** 만들려면 원하는 시각으로 datetime 배열을 직접 정의하거나, **표준 선택지**(hourly 등) 중에서 고른다.
- 두 방법 모두 **`retime`** 함수를 쓴다.
- 예: **정시(on the hour)** 값을 **cubic spline** 추정으로 계산하려면:

```matlab
regular_spacing = retime(c_d_linear, 'hourly', 'spline');
```

- `retime`의 다른 옵션은 MATLAB 문서를 참고한다.

> **[보강]** 작은 데이터 실행 결과: 00:10~04:00 데이터가 `00:00`, `01:00`, `02:00`, `03:00`, `04:00`의 **5×5 timetable**로 바뀐다. 다른 방법 예: `'linear'`(선형), `'previous'`(직전 값 유지). `retime(A, 'hourly', 'previous')`는 계단 모양으로 채운다.
>
> `synchronize`에도 간격 옵션을 바로 줄 수 있다: `synchronize(indoors, outdoors, 'hourly', 'linear')`.

---

## ⚠️ 함정

- **`synchronize` 기본값은 빈칸을 `NaN`으로 둔다.** 채우려면 `'union','linear'`처럼 방법을 지정한다.
- **행 시간 열은 변수 수에 안 들어간다.** 110×5 timetable은 시간 열 + 데이터 5열이다.
- **같은 열 이름은 자동으로 이름이 바뀐다.** `Humidity` → `Humidity_indoors`, `Humidity_outdoors`. 원래 이름으로 접근하면 오류.
- **`'linear'`은 범위 밖을 외삽한다.** 끝 쪽 값은 측정값이 아니다.
- **`readtimetable`은 파일, `load`는 `.mat`.** `indoors.csv`를 `load`로 읽지 않는다.
