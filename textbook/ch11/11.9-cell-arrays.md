# 11.9 Cell Arrays

- **cell array**는 **서로 다른 타입의 데이터**를 한 배열에 저장할 수 있다.
- cell array의 각 원소는 **그 자체가 배열**이다.
- **중괄호(curly brackets, braces) `{ }`** 가 **cell-array constructor**다. 일반 배열 constructor는 대괄호 `[ ]`.
- 흔한 쓰임은 **길이가 다른 character array들**을 저장하는 것(11.2). 그러나 string이 훨씬 효율적이므로 **cell array of characters는 피해야 한다.**
  - 그래도 **legacy code**에 자주 나오므로 동작을 알아야 한다.
  - **table**에서 이름표(labeling)로도 쓰인다.

## Cell array 만들기

데이터 타입이 모두 다른 배열 4개:

```matlab
A = 1:3;                      % 1x3 double
B = 'abcdefg';                % 1x7 char
C = "Good Morning";           % 1x1 string
D = single([1 2 3; 4 5 6]);   % 2x3 single
```

cell-array constructor `{ }`로 하나로 합친다.

```matlab
my_cellarray = {A,B,C,D}
```
```
my_cellarray =
  1×4 cell 배열
    {[1 2 3]}    {'abcdefg'}    {["Good Morning"]}    {2×3 single}
```

Workspace에는 **1×4 cell** 배열로 표시된다(슬라이드 644 bytes).

> **[보강]** 슬라이드(R2022a)는 `Columns 1 through 2`, `{[1 2 3]}  {'abcdefg'}` …처럼 여러 줄로 나눠 표시했다. R2026a는 한 줄로 표시하고 바이트 수는 692다.

## Cell array 인덱싱

- 인덱싱 체계는 다른 배열과 **같다**. **단일 인덱스**나 **행·열 인덱스**를 쓸 수 있다.
- 각 원소가 배열이므로 결과도 **배열 전체**다.
  - **소괄호 `( )`** → **새 cell array**가 나온다.
  - **중괄호 `{ }`** → **원래 배열**이 나온다.

```matlab
my_cellarray(1)       % 1x1 cell
my_cellarray{1}       % 원래 double 배열
```
```
ans =
  1×1 cell 배열
    {[1 2 3]}
ans =
     1     2     3
```

## 원소 안의 특정 원소

cell array에 저장된 배열 안의 **특정 원소**에 접근하려면 **중괄호와 소괄호를 함께** 쓴다.

```matlab
my_cellarray{4}(1,2)
```
```
ans =
  single
     2
```

`{4}`로 2×3 single 배열을 꺼내고, `(1,2)`로 1행 2열 원소를 꺼낸다.

> **[보강]** `my_cellarray{2}(3)` → `'c'` (char 배열의 3번째 문자). `class(my_cellarray(1))` = `'cell'`, `class(my_cellarray{1})` = `'double'`. 빈 cell array는 `cell(2,3)`으로 만든다(원소마다 `0×0 double`).

## `cell2table`, `table2cell`

- 대부분의 용도에서 **table array가 cell array를 대체**했다. **`cell2table`** 로 cell array를 table로 쉽게 바꿀 수 있다.
- 꼭 cell array가 필요하면 **`table2cell`** 을 쓴다.

```matlab
TablefromCell = cell2table(my_cellarray)
```
```
TablefromCell =
  1×4 table
    my_cellarray1    my_cellarray2    my_cellarray3     my_cellarray4
    _____________    _____________    ______________    _____________
     1    2    3      {'abcdefg'}     "Good Morning"    {2×3 single} 
```

열 이름은 **원래 변수 이름 + 번호**(`my_cellarray1`, …)로 자동으로 붙는다.

> **[보강]** 슬라이드 제목은 "celltotable"이지만 함수 이름은 **`cell2table`** (숫자 2)이다. `table2cell(TablefromCell)`은 다시 1×4 cell을 돌려준다.

---

## ⚠️ 함정

- **`( )`는 cell, `{ }`는 내용물.** `my_cellarray(1) + 1`은 오류(`유효하지 않은 데이터형입니다. 인수는 숫자형, 문자형 또는 논리형이어야 합니다.`). `my_cellarray{1} + 1`은 `2 3 4`.
- **안쪽 원소는 `{ }` 다음 `( )`.** `my_cellarray(4)(1,2)`는 오류. 반드시 `my_cellarray{4}(1,2)`.
- **대괄호로는 cell array를 만들 수 없다.** `[A, B]`는 double과 char를 이어 붙이려 해서 문자로 바뀐다(11.2). 서로 다른 타입을 담으려면 `{A, B}`.
- **함수 이름은 `cell2table`.** "celltotable"이 아니다.
