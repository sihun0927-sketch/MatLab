# 11.5 Sparse Arrays

- **double**과 **logical** 배열은 **full array**로도, **sparse array**로도 저장할 수 있다.
- sparse array는 "**드문드문 채워진(sparsely populated)**" 배열이다. 값의 대부분이 **0**이다.
  - 예: **단위 행렬(identity matrix)** 은 sparse array의 대표 예다.
- double sparse 배열을 full 형식으로 저장하면 **모든 값이 8 bytes**를 차지한다(0도 포함).
- sparse 형식은 **0이 아닌 값만 저장하고 그 위치를 기억한다.** 메모리를 크게 아낀다.

## 메모리 비교: `sparse` 함수

100만(1,000×1,000) 원소 단위 행렬을 double로 저장할 때와 sparse로 저장할 때를 비교한다. **`sparse`** 함수는 double 배열을 sparse로 바꾼다.

```matlab
U = eye(1000);
V = sparse(U);
```

| 변수 | Size | Class | Bytes |
|---|---|---|---|
| `U` | 1000×1000 | double | **8,000,000** |
| `V` | 1000×1000 | double (sparse) | **24,008** |

- `U`: 원소 1,000,000개 × 8 bytes.
- `V`: 0이 아닌 값 1,000개만 저장 → 약 **330분의 1**.
- Workspace의 Class 칸에 `V`는 `double …`(sparse 속성)으로 표시된다. 클래스 자체는 여전히 **double**이다.

> **[보강]** R2026a에서도 같은 값(8000000, 24008)이 나왔다. 관련 함수:
>
> ```matlab
> S = sparse([0 0 3; 0 5 0])
> ```
> ```
> S =
>   2×3 희소 double형 행렬 (0이 아닌 요소 2개)
>    (2,2)        5
>    (1,3)        3
> ```
>
> - sparse 배열은 `(행,열) 값` 목록으로 표시된다(열 순서).
> - `full(S)`: 다시 일반 배열로. `nnz(S)`: 0이 아닌 원소 수(2). `issparse(S)`: 1.
> - `class(S)`는 `'double'`. sparse는 클래스가 아니라 **저장 속성**이다.
> - sparse에 연산해도 sparse로 남는다: `S*2`도 sparse.

---

## ⚠️ 함정

- **0이 많을 때만 이득이다.** 0이 거의 없는 행렬을 sparse로 바꾸면 위치 정보까지 저장하므로 오히려 커진다. 작은 `eye(3)`을 sparse로 바꾸면 80 bytes로 full(72 bytes)보다 크다.
- **sparse는 별도 클래스가 아니다.** `class(sparse(eye(3)))`는 `'double'`. 확인은 `issparse`.
- **슬라이드: sparse는 double과 logical.** integer 배열은 sparse로 만들 수 없다: `sparse(int8(eye(3)))` → 오류 `Input matrix must be single, double, or logical.`
- > **[보강]** R2026a에서는 **single sparse도 된다**(`class(sparse(single(eye(3))))` → `'single'`). 오류 메시지에도 single이 들어 있다. 슬라이드(“double and logical”)와 다른 점이다. 시험 답은 슬라이드 기준으로.
