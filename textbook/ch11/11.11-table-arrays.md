# 11.11 Table Arrays

- table array는 **R2013b**에 도입되었고 그 뒤로 꾸준히 확장·개선되었다.
- 앞 장(Chapter 8)에서는 정보를 **표시**하는 데 table을 썼지만, table은 그 이상이다.
- 다른 모든 데이터 타입으로 묶인 정보를 저장할 수 있다.
- **스프레드시트**에 저장된 것 같은 **표 형식(tabular) 데이터**에 특히 유용하다.

## 11.11.1 Creating Tables from Workspace Variables

MATLAB에는 table을 만드는 법을 연습할 **샘플 데이터**가 들어 있다. 기존 배열에서 만들 수도, 데이터 파일에서 만들 수도 있다.

```matlab
load patients
```

다양한 변수가 생기며 **모두 100×1 열 벡터**다.

| 변수 | Class (슬라이드) |
|---|---|
| `Age`, `Diastolic`, `Height`, `Systolic`, `Weight` | double |
| `Gender`, `LastName`, `Location`, `SelfAssessedHealthStatus` | cell |
| `Smoker` | logical |

### table을 만들기 전에 데이터 타입 손보기

1. 이 데이터는 **string 타입이 생기기 전**에 만들어졌다. `LastName`을 **cell array of char에서 string으로** 바꾸면 메모리가 절약된다.
2. `Location`은 데이터를 모은 **장소 목록**이다. **categorical array**로 저장하는 편이 낫다.
3. 마지막으로 `LastName`, `Location`, `Smoker`, `Gender`만 담은 table을 만든다.

```matlab
LastName = string(LastName);
Location = categorical(Location);
T = table(LastName, Location, Smoker, Gender);
```

- `LastName`과 `Location`의 데이터 타입이 바뀌었고(Workspace: `LastName` 100×1 **string**, `Location` 100×1 **categorical**), **100×4 table**이 만들어졌다.
- Workspace에서 `T`를 더블클릭하면 variable editor에서 table 내용을 볼 수 있다.

```matlab
T(1:3,:)
```
```
ans =
  3×4 table
     LastName             Location             Smoker      Gender  
    __________    _________________________    ______    __________
    "Smith"       County General Hospital      true      {'Male'  }
    "Johnson"     VA Hospital                  false     {'Male'  }
    "Williams"    St. Mary's Medical Center    false     {'Female'}
```

- string 열은 따옴표 `"..."`, categorical 열은 따옴표 없이, cell 열은 `{'...'}`로 표시된다.

> **[보강]** 슬라이드의 variable editor 그림은 `Smoker`를 1/0으로 보여 준다. R2026a 명령 창은 logical을 `true`/`false`로 표시한다.

### Table 인덱싱

숫자 배열과 같은 전략으로 **행 번호와 열 번호**를 지정한다. 두 번째 행 환자가 흡연자인지 알려면 **2행 3열**이다.

```matlab
T(2,3)
```
```
ans =
  table
    Smoker
    ______
    false 
```

> **[보강]** `T(2,3)`은 **1×1 table**이다(`class` → `'table'`). 값 자체를 원하면 중괄호 `T{2,3}` 또는 dot 문법 `T.Smoker(2)` → logical `0`. cell array의 `( )` vs `{ }` 구분과 같은 원리다.

### 열 이름: `VariableNames`

열 이름은 자동으로 **workspace 변수 이름**을 따른다. 다른 이름은 `table` 함수의 **`VariableNames`** 속성으로 정한다.

```matlab
names = ["LastName","Hospital","Smoker","Gender"];
T = table(LastName, Location, Smoker, Gender, 'VariableNames', names);
```

- 이름 배열(`names`)은 **cell array of char**여도, **string array**여도 된다.
- 슬라이드: **`VariableNames` 속성 이름은 작은따옴표**여야 한다. character array여야 한다. 함수가 string과 char를 모두 받지 **않는** 몇 안 되는 경우다.

> **[보강]** R2026a 실측:
>
> | 코드 | 결과 |
> |---|---|
> | `table(..., 'VariableNames', names)` | 된다 |
> | `table(..., "VariableNames", names)` | **오류** `모든 테이블 변수는 행 수가 동일해야 합니다.` ("VariableNames"를 데이터 열로 해석) |
> | `table(..., VariableNames=names)` | **된다** (R2021a부터의 Name=Value 문법) |
>
> 즉 큰따옴표 금지는 R2026a에서도 사실이다. 다만 `Name=Value` 문법을 쓰면 따옴표 문제가 사라진다.

### 행 이름: `RowNames`

table의 행에도 이름을 붙일 수 있다.

```matlab
T.Properties.RowNames = T.LastName;
T("Johnson",:)
```
```
ans =
  1×4 table
               LastName      Hospital      Smoker     Gender 
               _________    ___________    ______    ________
    Johnson    "Johnson"    VA Hospital    false     {'Male'}
```

행 이름을 붙이면 **행 이름과 콜론 연산자**로 행을 꺼낼 수 있다.

### 여러 행

다른 MATLAB 배열의 인덱싱 문법에서 **행 번호 자리에 행 이름**을 넣으면 여러 행을 꺼낼 수 있다.

```matlab
T(["Martinez","Bryant"],:)
```
```
ans =
  2×4 table
                 LastName            Hospital            Smoker      Gender  
                __________    _______________________    ______    __________
    Martinez    "Martinez"    County General Hospital    false     {'Male'  }
    Bryant      "Bryant"      County General Hospital    false     {'Female'}
```

### 행·열 이름으로 인덱싱

행 이름과 열 이름으로 table 일부를 꺼낼 수도 있다.

```matlab
T(["Johnson","Garcia"],["Hospital"])
```
```
ans =
  2×1 table
                Hospital  
               ___________
    Johnson    VA Hospital
    Garcia     VA Hospital
```

> **[보강]** 값 하나: `T{"Johnson","Hospital"}` → categorical `VA Hospital`. 조건으로 행 고르기(Chapter 8의 logical indexing): `T(T.Smoker, :)`는 흡연자 행만. 열 추가는 dot 문법: `T.Age = Age;` 후 `T(T.Smoker & T.Age > 45, :)`. 없는 행 이름은 오류 `'Nobody'은(는) 인식할 수 없는 테이블 행 이름입니다.`

## 11.11.2 Creating Table Arrays from Data Files

- MATLAB은 여러 종류의 데이터 파일에서 표 데이터를 table로 가져오는 함수를 제공한다.
  - **Excel** 같은 스프레드시트
  - **`.csv`** 같은 텍스트 파일
  - **`.txt`** 파일
  - **`.dat`** 파일
- 핵심 조건은 데이터가 **직사각형(rectangular)** 이어야 한다는 것.
- 이 함수들은 **헤더 정보를 무시**하고, 각 열에 저장된 정보의 **타입을 판단**해 알맞은 데이터 타입을 정한다.
- 예: 숫자 → **double**, 텍스트 → **string 또는 cell array of char**.

### 예제 데이터: `patients.dat`와 `readtable`

- 앞 슬라이드의 데이터는 `.mat` 파일에 이미 MATLAB 형식으로 저장되어 있었다.
- 같은 정보가 **`patients.dat`** 에도 있다. import wizard로 불러오거나 **`readtable`** 로 자동으로 불러올 수 있다.
- Workspace는 table의 내용을 **간략히**만 보여 준다(`T2` 100×10 table).
- **`summary`** 함수가 더 자세히 보여 준다:
  - 각 열의 **이름**
  - 각 열의 **데이터 타입**
  - 몇 가지 **통계 정보**

```matlab
T2 = readtable("patients.dat");
summary(T2)
```

슬라이드(R2022a) 출력 일부:

```
Variables:
    LastName: 100×1 cell array of character vectors
    Gender: 100×1 cell array of character vectors
    Age: 100×1 double
        Values:
            Min          25
            Median       39
            Max          50
    Location: 100×1 cell array of character vectors
    Height: 100×1 double
        Values:
            Min          60
            Median       67
            Max          72
    ...
```

> **[보강]** R2026a의 `summary`는 형식이 바뀌어 변수 목록 뒤에 **통계 표**(`NumMissing`, `Min`, `Median`, `Max`, `Mean`, `Std`)를 한꺼번에 보여 준다. 예: `Age` → NumMissing 0, Min 25, Median 39, Max 50, Mean 38.28, Std 7.2154. 텍스트 열 이름 설명도 한국어(`문자형 벡터로 구성된 셀형 배열`)로 나온다.

### 데이터 타입 바꾸기

일부 정보는 바꾸고 싶은 데이터 타입으로 저장되어 있다. 이미 `T2` 안에 있으므로 **dot 문법**으로 열에 접근해 바꾼다.

```matlab
T2 = readtable("patients.dat");
T2.LastName = string(T2.LastName);
T2.Gender = categorical(T2.Gender);
T2.Location = categorical(T2.Location);
T2.Smoker = logical(T2.Smoker);
T2.SelfAssessedHealthStatus = categorical(T2.SelfAssessedHealthStatus);
```

> **[보강]** `readtable`은 `Smoker`(0/1)를 **double**로 읽는다(R2026a 실측 `class(T2.Smoker)` → `'double'`). 그래서 `logical`로 바꾸는 줄이 필요하다. 바꾼 뒤 `summary(T2(:,["Gender","Smoker"]))` → `Gender: categorical (2개 범주)`, `Smoker: logical (34 true)`.

### `uiimport`와 import wizard

- `readtable`은 파일의 데이터를 **자동으로** table로 바꾼다.
- **`uiimport`** 는 **import wizard**를 열어 사용자가 직접 결정하게 한다:
  - table을 만들기 전에 **데이터 타입**을 정하기
  - **열 머리글(column heading)** 이름 정하기
- 이 결정은 **저장**해 두었다가 비슷한 파일을 자동으로 처리할 수 있다.

import wizard 화면에서:

- 각 열 머리글의 **드롭다운 메뉴**로 열마다 다른 데이터 타입을 고른다.
- wizard는 이미 텍스트 열에 cell array of char 대신 **string**을 골라 두었다.
- `Location`, `Gender`, `SelfAssessedHealthStatus`에는 **categorical**을 골라 두었다.
- 흥미롭게도 **logical은 선택지에 없다.** 그래서 `Smoker`를 logical로 바꿀 수 없고, categorical로는 바꿀 수 있다.
- `Location` 열 이름을 **`Hospital`** 로, `SelfAssessedHealthStatus`를 **`SAHS`** 로 바꾼다.

변경을 마치면:

- 열 머리글을 **뺀 데이터(2행 이하)** 를 선택하고 **Import Selection**을 눌러 가져온다.
- 파일 이름이 `patients.dat`이므로 workspace에 **`patients`** 라는 배열로 나타난다.
- Import Selection 메뉴에서 **Generate Function**을 고르면 지금까지 한 선택을 담은 **함수가 생성**된다. 이 함수로 이후 데이터 세트의 처리를 자동화할 수 있다(메뉴에는 Import Data, Generate Live Script, Generate Script도 있다).

> **[보강]** import wizard는 GUI라 `-batch`에서 실행하지 않았다. `uiimport("patients.dat")`로 연다.

## ⚠️ 함정

- **`T(2,3)`은 table, `T{2,3}`은 값.** 계산에 쓰려면 중괄호나 `T.Smoker(2)`.
- **`"VariableNames"`(큰따옴표)는 오류.** 슬라이드 규칙: 작은따옴표. R2026a에서는 `VariableNames=names`도 된다.
- **행 이름은 텍스트여야 하고 중복될 수 없다.** 성(LastName)이 겹치는 데이터면 `RowNames`로 쓸 수 없다.
- **`readtable`은 0/1 열을 double로 읽는다.** logical이 필요하면 직접 `logical(...)`.
- **import wizard에는 logical 타입 선택지가 없다.** categorical은 있다.
- **`load patients`는 변수 이름을 덮어쓴다.** 이미 `T`나 `Age`가 있었다면 교체된다.
