# 11.3 Symbolic Data

**symbolic array**는 다음 두 가지를 저장한다.

- **function handle**
- **symbolic variable** (기호 변수)

function handle은 앞 장(Chapter 6)에서 다뤘다. 함수의 **"별명(nickname)"** 이라고 생각하면 된다. symbolic toolbox는 뒤 장에서 자세히 다룬다. symbolic toolbox는 symbolic 데이터로 **기호 대수 계산(symbolic algebraic calculations)** 을 한다.

## `syms`로 symbolic variable 만들기

```matlab
syms x
```

symbolic variable을 조합해 **symbolic equation(기호식)** 을 만들 수 있다.

```matlab
S = x^2-2
```
```
S =
x^2 - 2
```

- `x`에 숫자 값이 없어도 오류가 나지 않는다. `S`는 숫자가 아니라 **식 그 자체**를 저장한다.
- symbolic 객체 여러 개를 모아 **수학식의 배열**을 만들 수 있다.

> **[보강]** 비교: function handle은 **값을 넣어 계산**하는 도구, symbolic variable은 **식을 다루는** 도구다.
>
> ```matlab
> f = @(t) t.^2 - 2;    % function handle
> f([0 1 2])            % -2  -1   2   (숫자 계산)
> class(f)              % 'function_handle'
> ```
>
> symbolic이라면 `solve(S)`로 근 $\pm\sqrt2$를 **기호 그대로** 얻는다(Chapter 12 범위).

> **[보강]** 이 저장소의 R2026a에는 **Symbolic Math Toolbox가 설치되어 있지 않아** `syms x`가 `함수 'syms'은(는) 'char'형 입력 인수에 대해 정의되지 않았습니다.` 오류를 냈다. 위 `S` 출력은 슬라이드 그대로 옮긴 것이고 직접 실행하지 못했다. function handle 예제는 실행해 확인했다.

---

## ⚠️ 함정

- **`syms`는 toolbox 함수다.** Symbolic Math Toolbox가 없으면 `syms`부터 오류다. 기본 MATLAB 기능이 아니다.
- **`syms x` 다음에 `x = 3`을 쓰면** `x`는 숫자 double로 덮어써진다. 그 뒤로 만든 식은 symbolic이 아니다.
- **function handle과 symbolic은 다르다.** `@(x) x^2-2`는 호출해야 값이 나오고, `S = x^2-2`는 식을 저장할 뿐이다.
