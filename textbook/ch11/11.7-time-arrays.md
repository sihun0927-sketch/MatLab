# 11.7 Time Arrays

날짜와 시간 계산은 까다롭다.

- 달마다 날짜 수가 다르다.
- **윤년(leap year)** 이 계산을 복잡하게 만든다.
- 시간은 **100 단위가 아니다**: 60초 = 1분, 60분 = 1시간, 24시간 = 1일.
- **시간대(time zone)** 를 고려해야 한다.
- 거기에 **일광 절약 시간(daylight savings time)** 까지 있다.

다행히 날짜·시간 정보를 저장하는 **표준 형식**이 있다. MATLAB은 날짜·시간을 **`datetime` 배열**에 저장한다. datetime 배열을 만드는 방법은 여러 가지인데, 슬라이드는 간단한 예 하나를 보인다.

## 기간 구하기 (Finding a Duration)

두 날짜 **1990년 2월 1일**과 **2016년 5월 20일**로 datetime 배열을 만들고 두 날짜 사이의 시간 차이를 구한다.

**1단계** — 연, 월, 일을 나타내는 **열 벡터**를 만든다.

```matlab
year = [1990; 2016];
month = [2; 5];
day = [1; 20];
```

**2단계** — **`datetime`** 함수로 연·월·일 벡터를 합친다.

```matlab
X = datetime(year, month, day)
```
```
X = 
  2×1 datetime 배열
   01-Feb-1990
   20-May-2016
```

**3단계** — 두 날짜의 차이는 **`diff`** 함수를 쓰거나, 배열의 두 번째 원소에서 첫 번째 원소를 **빼서** 구한다.

```matlab
Y = diff(X)
Y = X(2) - X(1)
```
```
Y = 
  duration
   230520:00:00
```

결과는 **`duration` 배열**이며 **시간:분:초(hours:minutes:seconds)** 로 표시된다. 230,520시간이다.

> **[보강]** R2026a(한국어 로케일)는 `X`를 `1990-02-01`, `2016-05-20`으로 표시한다. 슬라이드의 `01-Feb-1990`과 형식만 다르고 값은 같다. 표시 형식은 `X.Format = 'dd-MMM-yyyy'`로 바꿀 수 있다(한국어 로케일에서는 `01-2월-1990`처럼 월 이름이 한국어).

> **[보강]** duration을 다른 단위로: `days(Y)` → **9605**일, `hours(Y)` → 230520. 연·월·일로 나누려면 `between(X(1), X(2))` → `26y 3mo 19d`(calendarDuration). 날짜에 기간을 더할 수도 있다: `X(1) + days(100)` → 1990-05-12.

## datetime으로 데이터 시각화하기: Denver 기후 데이터

datetime 배열은 데이터를 **분석하고 그래프로 그릴 때** 특히 쓸모 있다.

**Table 11.3 Denver Temperature Data for 2015** — 미국 National Weather Service가 2015년 Denver 국제공항에서 모은 월별 요약 데이터.

| Month | Extreme High for the Month (°F) |
|---|---|
| 20150101 | 75 |
| 20150201 | 73.9 |
| 20150301 | 81 |
| 20150401 | 79 |
| 20150501 | 84.9 |
| 20150601 | 93.9 |
| 20150701 | 97 |
| 20150801 | 98.1 |
| 20150901 | 91.9 |
| 20151001 | 87.1 |
| 20151101 | 75 |
| 20151201 | 69.1 |

- 첫 열은 데이터를 모은 **달**이다. 앞 네 자리가 **연**, 다음 두 자리가 **월**, 마지막 두 자리가 **일**이다.

### Excel에서 가져오기 (Import Wizard)

- 데이터는 스프레드시트 `Denver_Climate_Data_2015.xlsx`에서 뽑았다. National Weather Service가 정보를 모으는 모든 지점에 비슷한 자료가 있다.
- MATLAB 안에서 Excel 파일을 **더블클릭**하면 **import wizard**가 열린다.
- 가져올 두 열 **DATE**와 **EMXT**를 선택한다.
- 두 열의 데이터 타입은 **Number (double)**. Output Type은 **Column vectors**.
- 페이지 위쪽의 **Import Selection** 버튼을 누른다.

> **[보강]** 원본 xlsx 파일은 없으므로, 아래 코드는 Table 11.3 값을 직접 입력해 같은 변수(`DATE`, `EMXT`, 12×1 double)를 만들었다.
>
> ```matlab
> DATE = [20150101;20150201;20150301;20150401;20150501;20150601; ...
>         20150701;20150801;20150901;20151001;20151101;20151201];
> EMXT = [75;73.9;81;79;84.9;93.9;97;98.1;91.9;87.1;75;69.1];
> ```

### double로 그리면 눈금을 읽기 어렵다

```matlab
bar(DATE, EMXT)
```

`DATE`가 **double**로 저장되어 있으면 막대 그래프 x축 눈금이 `2.015010`, `2.015020`, … 에 **`×10^7`** 이 붙은 형태로 나온다. 날짜를 **숫자로** 표현하므로 해석하기 어렵다.

### `datetime`으로 바꿔서 그리기

**`datetime`** 함수로 `DATE`를 double에서 datetime 데이터로 바꾼다.

```matlab
date = datetime(DATE, 'ConvertFrom', 'yyyymmdd')
bar(date, EMXT)
```
```
date = 
  12×1 datetime 배열
   01-Jan-2015
   01-Feb-2015
   ...
   01-Dec-2015
```

이제 x축 눈금이 `Jan 2015`, `Feb 2015`, … 처럼 **표준 날짜 표기**로 나온다.

> **[보강]** R2026a 문법: `datetime(DATE, ConvertFrom="yyyymmdd")`. 결과가 같다(`isequal` → 1). 확인: `datetime` 축은 `DatetimeRuler`, double 축은 `NumericRuler`에 `Exponent` 7.
>
> `'yyyymmdd'`는 **ConvertFrom 전용 키워드**(숫자 20150101 같은 형식)다. 텍스트를 읽는 `InputFormat`에서는 월이 대문자 `MM`이다: `datetime(string(DATE), InputFormat="yyyyMMdd")`. 소문자 `mm`은 **분(minute)** 이다.

### Orlando 데이터: 두 방법 비교

Orlando 강수량(precipitation) 데이터도 같은 방식으로 가져와 double 그대로 그리거나 datetime으로 바꿔 그릴 수 있다.

```matlab
tiledlayout("flow")
nexttile
plot(Date, Precip)                                   % double
date = datetime(Date, 'ConvertFrom', 'YYYYMMDD');
nexttile
plot(date, Precip)                                   % datetime
```

- 데이터는 364×1(`Date` double, `Precip` double).
- 위 그래프(double): x축이 `2.015`, `2.01502`, … `×10^7`이고, 월 경계(예: 20150131 → 20150201)에서 x값이 **크게 건너뛰어** 간격이 고르지 않다.
- 아래 그래프(datetime): x축이 `Jan`, `Feb`, … `Dec`, `Jan 2015`이고 날짜 간격이 **실제 시간에 비례**한다.

> **[보강]** Orlando 데이터 파일은 없어 위 코드는 실행하지 못했다(Denver 코드는 실행 확인). 슬라이드는 `'YYYYMMDD'`(대문자)를 썼는데, ConvertFrom 키워드는 대소문자를 가리지 않아 Denver 예의 `'yyyymmdd'`와 같다.

## ⚠️ 함정

- **`year`, `month`, `day` 변수가 함수를 가린다.** 슬라이드처럼 `month = [2;5]`를 만든 뒤 `month(date(i))`를 쓰면 함수가 아니라 **변수 인덱싱**이 되어 오류 `datetime 유형의 값은 인덱스로 사용할 수 없습니다.` (R2026a 실측). 슬라이드 예제를 그대로 따라 한 뒤 날짜 함수를 쓸 때 주의. 다른 이름(`yr`, `mo`, `dy`)을 쓰거나 `clear month`.
- **`date`도 내장 함수 이름이다.** 슬라이드는 `date`를 변수 이름으로 쓴다. 그 뒤로 `date` 함수(오늘 날짜 텍스트)는 가려진다.
- **datetime의 차이는 숫자가 아니라 `duration`.** `X(2)-X(1)`을 일 수로 쓰려면 `days(...)`.
- **연·월·일은 열 벡터 3개로 따로.** `datetime([1990 2 1])`처럼 한 행으로 넣는 것도 되지만, 슬라이드 방식은 `datetime(year, month, day)`.
- **ConvertFrom `'yyyymmdd'` vs InputFormat `'yyyyMMdd'`.** 형식 문자열에서 `mm`은 분, `MM`은 월.
