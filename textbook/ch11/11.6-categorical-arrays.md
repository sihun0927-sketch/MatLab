# 11.6 Categorical Arrays

**categorical array**는 **유한한 범주(category) 목록** 중 하나의 값을 저장한다.

- logical 배열과 비슷하다. logical 원소는 "true" 아니면 "false"뿐이다.
- categorical 배열의 원소는 **사용자가 정한 값 목록** 중 하나여야 한다.
- categorical 배열은 관련 정보를 담은 **table의 일부**로 자주 쓰인다(11.11).
- **`categorical`** 함수에 **string 배열** 또는 **cell array of character arrays**를 넣어 만든다.

## 만들기

```matlab
W = categorical(["A","C","B","D","E","D","B","A"])         % string 배열로
W = categorical({'A','C','B','D','E','D','B','A'})         % cell array of char로
```
```
W = 
  1×8 categorical 배열
     A      C      B      D      E      D      B      A 
```

두 방법의 결과는 같다(`isequal` → 1). 표시에 따옴표가 없다는 점에 주목한다. 텍스트가 아니라 **범주 이름**이기 때문이다.

## 범주 목록: `categories`

```matlab
categories(W)
```
```
ans =
  5×1 cell 배열
    {'A'}
    {'B'}
    {'C'}
    {'D'}
    {'E'}
```

- 결과는 **cell array**(5×1)다.
- 중복 없이 **정렬된** 범주 목록이 나온다.

## 범주로 데이터 고르기: `find`

`find`에 categorical 배열을 쓰면 범주를 기준으로 데이터를 골라낼 수 있다. 다음은 `W`에서 `'A'`와 같은 원소를 찾는다.

```matlab
find(W=='A')
```
```
ans =
     1     8
```

> **[보강]** 비교 대상은 `'A'`(char)든 `"A"`(string)든 된다. 범주별 개수는 `countcats(W)` → `2 2 1 2 1`(A, B, C, D, E 순). `summary(W)`도 범주별 개수를 보여 준다.
>
> categorical은 숫자가 아니므로 산술이 안 된다: `W + 1` → 오류 `유효하지 않은 데이터형입니다. 인수는 숫자형, 문자형 또는 논리형이어야 합니다.`

> **[보강]** 왜 쓰는가? 같은 텍스트가 반복되는 데이터(병원 이름, 성별, 등급)를 string으로 저장하면 매번 텍스트 전체를 저장한다. categorical은 범주 목록을 한 번 저장하고 각 원소는 번호만 가진다. 11.11의 `patients` 예제에서 `Location`(cell, 15,008 bytes)을 categorical로 바꾸면 크게 줄어든다(슬라이드 Workspace: 532 bytes).

---

## ⚠️ 함정

- **`categories`의 결과는 cell array다.** categorical이 아니다.
- **대소문자를 구분한다.** `g = categorical(["low","high"]); find(g == "Low")` → 빈 배열 `1×0`. 오류도 경고도 없다.
- **`categories`는 정렬된 순서.** 입력 순서(A C B D E)가 아니라 A B C D E.
- **산술 불가.** `W + 1` 오류. 숫자로 계산할 데이터는 categorical로 만들지 않는다.
