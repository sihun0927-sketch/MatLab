# 3.3 기초 수학 함수

기초 수학 함수는 네 묶음이다. 일반 계산(로그·지수·절댓값), 반올림, 이산수학, 그리고 그 한계다.
이 절의 함수는 모두 스칼라와 배열 입력을 다 받는다.

## 3.3.1 일반 계산 (Table 3.1)

| 함수 | 뜻 | 예 |
|------|-----|-----|
| `abs(x)` | 절댓값 | `abs(-3)` → `3` |
| `sqrt(x)` | 제곱근 | `sqrt(85)` → `9.2195` |
| `nthroot(x,n)` | 실수 n제곱근 | `nthroot(-2,3)` → `-1.2599` |
| `sign(x)` | 부호. 음수 `-1`, 0은 `0`, 양수 `1` | `sign(-8)` → `-1` |
| `rem(x,y)` | `x/y`의 나머지 | `rem(25,4)` → `1` |
| `exp(x)` | e의 x제곱 | `exp(10)` → `2.2026e+04` |
| `log(x)` | **자연로그** ln(x) | `log(10)` → `2.3026` |
| `log10(x)` | 상용로그 | `log10(10)` → `1` |
| `log2(x)` | 밑이 2인 로그 | `log2(8)` → `3` |

전체 코드: [`ex0303_common_math.m`](../../example/ch03/ex0303_common_math.m)

```matlab
x = [-8 -3 0 4 85];

disp("abs(x)   = " + join(string(abs(x)), "  "))
disp("sign(x)  = " + join(string(sign(x)), "  "))
fprintf("sqrt(85)      = %.4f\n", sqrt(85))

% nthroot 는 실수 n제곱근을 준다. ^(1/3) 과 결과가 다르다.
fprintf("nthroot(-2,3) = %.4f\n", nthroot(-2,3))
z = (-2)^(1/3);
fprintf("(-2)^(1/3)    = %.4f %+.4fi  (복소수)\n", real(z), imag(z))

% 지수와 로그
fprintf("exp(10)       = %.4e\n", exp(10))
fprintf("log(10)       = %.4f   (자연로그 ln)\n", log(10))
fprintf("log10(10)     = %.4f\n", log10(10))
fprintf("log2(8)       = %.4f\n", log2(8))
```

`ex0303_common_math.m` 실행 결과 (일부 생략):
```text
abs(x)   = 8  3  0  4  85
sign(x)  = -1  -1  0  1  1
sqrt(85)      = 9.2195
nthroot(-2,3) = -1.2599
(-2)^(1/3)    = 0.6300 +1.0911i  (복소수)
exp(10)       = 2.2026e+04
log(10)       = 2.3026   (자연로그 ln)
log10(10)     = 1.0000
log2(8)       = 3.0000
```

⚠️ **함정 — `log`는 상용로그가 아니다**
수학 교과서에서 log는 보통 밑이 10이지만, **모든 프로그래밍 언어에서 `log`는 자연로그**다.
상용로그는 `log10`을 써야 한다. 신입 사용자가 가장 많이 틀리는 지점이다.

⚠️ **함정 — `nthroot(-2,3)`와 `(-2)^(1/3)`은 다른 답을 준다**
둘 다 수학적으로는 -2의 세제곱근이지만, `^`는 복소수 근 중 편각이 가장 작은 주근(principal root)을
반환해 `0.6300 + 1.0911i`가 나온다. 실수 근이 필요하면 `nthroot`를 쓴다.

⚠️ **함정 — `exp(3)`은 e³, `3e5`는 3×10⁵**
지수 함수와 과학적 표기법의 `e`는 아무 관계가 없다. `5e3`은 5000이지 e의 5제곱이 아니다.

> **[보강] `rem`과 `mod`의 차이.** 슬라이드에는 `rem`만 나오지만 시험에 자주 같이 나온다.
> 양수끼리는 같고, 음수가 끼면 갈린다. `rem`은 몫을 0쪽으로 자르고(`fix`), `mod`는 음의 무한대쪽으로
> 자른다(`floor`). 그래서 `rem(-25,4) = -1`, `mod(-25,4) = 3`이다. 결과의 부호는 `rem`은 피제수를,
> `mod`는 제수를 따른다.

> **[보강] 임의 밑의 로그.** MATLAB에는 밑을 입력받는 범용 로그 함수가 없다. 밑변환 공식으로 직접 쓴다.
> `log_3(81) = log(81)/log(3) = 4`.

## 3.3.2 반올림 함수 (Table 3.2)

사과가 개당 0.52달러이고 5달러가 있다면 몇 개를 살 수 있는가?
`5/0.52 = 9.6154`지만 사과를 조각내 살 수는 없고 가게가 반올림해주지도 않는다. **내림**해야 한다.
이때 쓰는 함수가 `fix`다.

| 함수 | 뜻 | `8.6` | `-8.6` |
|------|-----|------|-------|
| `round(x)` | 가장 가까운 정수 | `9` | `-9` |
| `round(x,N)` | 소수점 N자리까지 | `round(8.6436,3)` → `8.644` | |
| `fix(x)` | **0 방향으로** 버림 | `8` | `-8` |
| `floor(x)` | **-∞ 방향으로** 버림 | `8` | `-9` |
| `ceil(x)` | **+∞ 방향으로** 올림 | `9` | `-8` |

전체 코드: [`ex0303_rounding.m`](../../example/ch03/ex0303_rounding.m)

```matlab
money = 5.00;
price = 0.52;
count = money/price;
fprintf("money/price = %.4f -> 살 수 있는 개수 = %d\n", count, fix(count))

fprintf("round(8.6436,3) = %.4f\n", round(8.6436,3))
fprintf("fix(-8.6)=%g 이지만 floor(-8.6)=%g\n", fix(-8.6), floor(-8.6))
```

`ex0303_rounding.m` 전체 실행 결과:
```text
money/price = 9.6154 -> 살 수 있는 개수 = 9
       x      8.6     -8.6
   round        9       -9
     fix        8       -8
   floor        8       -9
    ceil        9       -8
round(8.6436,3) = 8.6440
fix(-8.6)=-8 이지만 floor(-8.6)=-9
```

⚠️ **함정 — 양수에서는 `fix`와 `floor`가 같아 보인다**
`fix(8.6)`과 `floor(8.6)`은 둘 다 8이다. 차이는 음수에서만 드러난다.
`fix(-8.6) = -8`, `floor(-8.6) = -9`. 시험에서 반올림 함수를 물으면 **거의 항상 음수 예제**로 나온다.

## 3.3.3 이산수학 (Table 3.3)

이산수학은 정수의 수학이다. 이 함수들은 **정수 스칼라 입력**을 전제한다.

| 함수 | 뜻 | 예 |
|------|-----|-----|
| `factor(x)` | 소인수분해 | `factor(12)` → `2 2 3` |
| `gcd(x,y)` | 최대공약수 | `gcd(10,15)` → `5` |
| `lcm(x,y)` | 최소공배수 | `lcm(2,5)` → `10` |
| `rats(x)` | 실수를 분수 문자열로 | `rats(1.5)` → `3/2` |
| `factorial(x)` | 계승 x! | `factorial(6)` → `720` |
| `nchoosek(n,k)` | 조합 nCk | `nchoosek(10,3)` → `120` |
| `primes(x)` | x 이하의 소수 전부 | `primes(10)` → `2 3 5 7` |
| `isprime(x)` | 소수면 1, 아니면 0 | `isprime(7)` → `1` |

전체 코드: [`ex0303_discrete.m`](../../example/ch03/ex0303_discrete.m)

### rats — 실수를 분수로 보기

`rats`는 주어진 부동소수점 수에 가장 가까운 **분수 근삿값**을 만들어 준다.

```matlab
disp("rats(1.5)      = " + strtrim(rats(1.5)))
disp("rats(1/3)      = " + strtrim(rats(1/3)))
disp("rats(pi)       = " + strtrim(rats(pi)) + "   <- 정확한 값이 아니라 근삿값")
```

위 세 줄의 출력 (`ex0303_discrete.m`의 일부):
```text
rats(1.5)      = 3/2
rats(1/3)      = 1/3
rats(pi)       = 355/113   <- 정확한 값이 아니라 근삿값
```

⚠️ **함정 — `rats`가 돌려주는 것은 숫자가 아니라 문자 배열이다**
`class(rats(1.5))`는 `char`다. `rats(1.5) + 1`은 3/2에 1을 더한 값이 아니라 문자 코드의 덧셈이 된다.
계산이 아니라 **표시**에만 쓴다. 또 `rats(pi)`의 `355/113`은 π의 근삿값이지 정확한 값이 아니다.
3.5절의 `format rat`도 같은 성격으로, 화면 표시만 바꾸고 저장된 값은 double 그대로다.

### 팩토리얼과 조합론

팩토리얼은 1부터 주어진 수까지 모두 곱한 값이다. 3! = 3×2×1 = 6.
카드 5장을 나열하는 경우의 수는 첫 장에 5가지, 다음에 4가지 … 이므로 5! = 120이다.
이런 계산을 **조합론(combinatorics)** 이라 한다.

- **순열(permutation)**: 순서가 **중요할 때**의 부분집합 수. n!/(n−k)!
- **조합(combination)**: 순서가 **중요하지 않을 때**의 부분집합 수. n!/((n−k)!k!)

MATLAB에는 **nPk를 세어 주는 함수가 없다.** `nchoosek`은 조합 수를 주고, `perms`는
순열의 개수가 아니라 순열 전체를 나열한다. nPk는 정의식으로 계산한다.

```matlab
n = 5; k = 2;
fprintf("5P2 = %d,  5C2 = %d\n", factorial(n)/factorial(n-k), nchoosek(n,k))
% 5P2 = 20,  5C2 = 10
```

### factorial의 한계 — 시험 포인트

팩토리얼은 아주 빨리 커진다. double로 표현할 수 있는 마지막 값은 **170!** 이고,
171!은 `Inf`가 된다.

전체 코드: [`ex0303_factorial_limit.m`](../../example/ch03/ex0303_factorial_limit.m)

```matlab
fprintf("factorial(170) = %.4e\n", factorial(170))
fprintf("factorial(171) = %g\n", factorial(171))

fprintf("nchoosek(200,2) = %d\n", nchoosek(200,2))
bad = factorial(200)/(factorial(198)*factorial(2));
fprintf("factorial(200)/(factorial(198)*factorial(2)) = %g\n", bad)
```

`ex0303_factorial_limit.m` 실행 결과 (일부 생략):
```text
factorial(170) = 7.2574e+306
factorial(171) = Inf   <- 오버플로로 Inf
nchoosek(200,2) = 19900
factorial(200)/(factorial(198)*factorial(2)) = NaN
```

200명 중 2명으로 팀을 만드는 경우의 수는 19900이다. 그런데 정의식 `200!/(198!·2!)`로 계산하면
`Inf/Inf`가 되어 **`NaN`** 이 나온다. `nchoosek`은 팩토리얼을 실제로 계산하지 않고 약분해가며
누적 곱을 취하므로, 풀 크기가 170을 넘어도 답을 준다.

⚠️ **함정 — `!`는 MATLAB 연산자가 아니다**
수학에서 `5!`라고 쓰지만 MATLAB에서 `5!`는 문법 오류다. 반드시 `factorial(5)`를 쓴다.
(MATLAB에서 `!`는 운영체제 명령을 실행하는 접두사다.)
