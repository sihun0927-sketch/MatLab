# 3.1 내장 함수 사용과 도움말

## 왜 내장 함수인가

공학 계산은 대부분 이미 이름이 붙은 수학 연산의 조합이다. 지수·로그, 반올림, 소인수분해와 팩토리얼,
삼각함수, 자료 분석, 난수 생성, 복소수 연산이 그것이다. MATLAB은 이 계산들을 전부 **내장 함수(built-in
function)** 로 제공하므로, 직접 구현할 필요가 없다.

MATLAB은 C로 작성되었고, 함수 이름 상당수를 C·Fortran·Python·Java와 공유한다. `sqrt`, `sin`, `exp`처럼
다른 언어에서 쓰던 이름이 대부분 그대로 통한다.

## 함수의 세 가지 구성요소

모든 함수는 **이름(name) · 입력(input) · 출력(output)** 으로 이루어진다.

```matlab
sin(a)
% └┬┘ └┬┘
%  │   └── 입력(input), 인수(argument). 괄호 안에 넣는다.
%  └────── 이름(name)
```

출력을 변수에 대입하지 않으면 결과는 기본 변수 `ans`에 저장된다.

### 스칼라와 배열

MATLAB 함수의 큰 장점은 인수가 **스칼라여도 배열이어도 동작한다**는 점이다.
스칼라를 넣으면 스칼라가, 배열을 넣으면 같은 크기의 배열이 돌아온다.

```matlab
a = 5;
b = [1 2 3];
sin(a)    % 스칼라 하나
sin(b)    % 1x3 배열
```

### 입력이 여러 개인 함수

`rem`(remainder, 나머지)은 피제수와 제수 두 개를 받는다.

```matlab
rem(10,3)     % ans = 1
```

### 출력이 여러 개인 함수

`size`는 배열 하나를 받아 `[행 열]` 배열을 돌려준다. 출력을 하나로 받으면 그 배열이 통째로 오고,
좌변을 대괄호로 묶으면 값마다 이름을 붙일 수 있다.

```matlab
d = [1 2 3; 4 5 6];
f = size(d)              % f = [2 3]
[rows, cols] = size(d)   % rows = 2, cols = 3
```

전체 코드: [`ex0301_function_io.m`](../../example/ch03/ex0301_function_io.m)

```matlab
% ex0301_function_io.m
clear; clc

a = 5;
b = [1 2 3];
disp("sin(a) = " + sin(a))
disp("sin(b) = " + join(string(sin(b)), "  "))

fprintf("rem(10,3) = %g\n", rem(10,3))

d = [1 2 3; 4 5 6];
f = size(d);
disp("f = " + join(string(f), "  "))

[rows, cols] = size(d);
fprintf("rows = %d, cols = %d\n", rows, cols)

sqrt(85);
fprintf("ans = %.4f\n", ans)
```

실행 결과:

```text
sin(a) = -0.95892
sin(b) = 0.84147  0.9093  0.14112
rem(10,3) = 1
f = 2  3
rows = 2, cols = 3
ans = 9.2195
```

## 도움말: help, doc, 스크린 팁

함수 사용법을 확인하는 방법은 세 가지다.

| 방법 | 설명 |
|------|------|
| `help 함수명` | 명령창에 요약 도움말을 출력한다. 간단하지만 예제가 적다. |
| `doc 함수명` | HTML 문서 창을 연다. 예제·수식·관련 함수까지 전부 있다. F1 키 또는 툴스트립의 Help와 같다. |
| 스크린 팁 | 편집기/명령창에 함수 이름을 타이핑하면 호출 형식과 도움말 링크가 자동으로 뜬다. |

> **[보강]** `which 함수명`은 그 이름이 실제로 **어느 파일에서 오는지**를 알려준다.
> 변수가 함수를 가려버린 경우(3.9절) 원인을 찾는 가장 빠른 방법이다.
> `which -all 함수명`을 쓰면 같은 이름을 가진 정의를 전부 나열한다.

```matlab
help nthroot
which nthroot
% which -all rem
```

전체 코드: [`ex0301_help.m`](../../example/ch03/ex0301_help.m)

⚠️ **함정 — `help`와 `doc`는 다르다**
`help`는 명령창 텍스트, `doc`는 브라우저 문서다. 시험에서 "HTML 기반 문서를 여는 명령"을 묻는다면
답은 `doc`다. 그리고 `doc`는 창을 띄우므로 `-batch` 모드 스크립트 안에서는 쓰지 않는다.

⚠️ **함정 — 출력이 여러 개인 함수를 하나로 받으면 첫 번째만 오는 게 아니다**
`f = size(d)`는 `f = 2`가 아니라 `f = [2 3]`이다. `size`는 "첫 출력이 행 개수"인 함수가 아니라
"첫 출력이 크기 벡터"인 함수다. 반면 `[a,b] = max(x)`처럼 출력 개수에 따라 **내용 자체가 달라지는**
함수도 있다(3.5절). 헷갈리면 `help`로 호출 형식을 확인한다.
