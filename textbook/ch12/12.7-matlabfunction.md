# 12.7 Converting Symbolic Expressions to Anonymous Functions

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. `matlabFunction` 자체는 이 PC에서 실행하지 못했다. 그 **결과물인 anonymous function**은 toolbox 없이도 동작하므로, 슬라이드에 찍힌 function handle을 그대로 입력해 R2026a에서 실행·확인했다([README](README.md#실행-환경-메모)).

- 수학 식을 **먼저 기호로 계산**한 뒤, 그 결과를 **전통적인 MATLAB 함수**에서 쓰면 편리한 경우가 많다.
- 이를 위해 **`matlabFunction`** 함수가 **symbolic expression을 anonymous function으로 변환**한다.

```matlab
syms x
y = cos(x);
dy = diff(y)
```
```
dy =
-sin(x)
```
```matlab
f = matlabFunction(dy)
```
```
f =
  function_handle with value:
    @(x)-sin(x)
```

- `dy`는 symbolic expression(Class `sym`)이다.
- `f`는 **`function_handle`**(Workspace에 32 bytes)이다. Chapter 6에서 배운 anonymous function과 같은 종류다.

## symbolic function에도 쓴다

- **symbolic function**도 숫자 MATLAB 함수로 변환할 수 있다.
- anonymous function은 **다른 MATLAB 함수와 똑같이** 쓸 수 있다.

```matlab
syms x
y(x)=(exp(-x)-1)/x;
dy=diff(y)
```
```
dy(x) =
- exp(-x)/x - (exp(-x) - 1)/x^2
```
```matlab
g=matlabFunction(dy)
```
```
g =
  function_handle with value:
    @(x)-exp(-x)./x-1.0./x.^2.*(exp(-x)-1.0)
```

- `y`와 `dy`는 **symfun**, `x`는 sym, `g`는 **function_handle**이다.
- 변환된 식을 보면 `/`가 **`./`** 로, `^`가 **`.^`** 로, `*`가 **`.*`** 로 바뀌었다. 숫자 `1`은 `1.0`으로 적혔다. **array 연산자**로 바뀌었으므로 `g`에 배열을 넣을 수 있다.

> **[보강]** 확인: 몫의 미분으로 $\dfrac{d}{dx}\left[\dfrac{e^{-x}-1}{x}\right] = \dfrac{-e^{-x}}{x} - \dfrac{e^{-x}-1}{x^2}$.

## Symbolic 함수와 Numeric 함수의 차이

같은 값 5를 넣어 본다.

```matlab
dy(5)
```
```
ans =
1/25 - (6*exp(-5))/25
```

**`dy`는 symbolic function**이고 **symbolic 결과**를 돌려준다. `exp(-5)`를 계산하지 않고 정확한 식으로 남긴다.

```matlab
g(5)
```
```
ans =
    0.0384
```

**`g`는 numeric function**이고 **numeric(double) 결과**를 돌려준다. Workspace의 `ans`가 double이 된다.

| | `dy` | `g` |
|---|---|---|
| 만드는 법 | `dy = diff(y)` | `g = matlabFunction(dy)` |
| Class | `symfun` | `function_handle` |
| `(5)`의 결과 | `1/25 - (6*exp(-5))/25` | `0.0384` |
| 결과의 Class | `sym` | `double` |
| 화면 표시 | 들여쓰기 없음 | 들여쓰기 있음 |

> **[보강]** 확인: $-\dfrac{e^{-5}}{5} - \dfrac{e^{-5}-1}{25} = \dfrac{1}{25} - \dfrac{6e^{-5}}{25} \approx 0.04 - 0.0016 = 0.0384$. `double(dy(5))`로 바꿔도 `0.0384`다.

> **[보강]** 슬라이드에 찍힌 `g`를 R2026a에 그대로 입력해 실행한 결과. 한국어 로케일이라 `function_handle with value:`가 `다음 값을 갖는 function_handle:`로 나온다.
>
> ```matlab
> g = @(x)-exp(-x)./x-1.0./x.^2.*(exp(-x)-1.0)
> g(5)
> g([1 2 3])
> g(0)
> ```
> ```
> g =
>   다음 값을 갖는 function_handle:
>     @(x)-exp(-x)./x-1.0./x.^2.*(exp(-x)-1.0)
> ans =
>     0.0384
> ans =
>     0.2642    0.1485    0.0890
> ans =
>    NaN
> ```
>
> - `g([1 2 3])`: array 연산자 덕분에 **배열 입력**이 된다. `./` 대신 `/`를 쓴 `@(x) -exp(-x)/x - 1.0/x^2*(exp(-x)-1.0)`에 `[1 2 3]`을 넣으면 `^` 때문에 오류가 난다(실행 확인).
> - `g(0)`: 0으로 나누어 **NaN**이 나온다. 숫자 함수는 식을 그대로 계산할 뿐이다.

> **[보강]** 기호 계산과 숫자 계산을 잇는 전형적인 흐름:
>
> ```matlab
> syms x
> dy = diff(x*sin(x));          % 기호로 미분: sin(x) + x*cos(x)
> k = matlabFunction(dy);       % 숫자 함수로 변환
> k([0 pi/2 pi])                % 배열에 대해 계산
> fplot(k,[0,2*pi])             % 숫자 함수로 그리기
> ```
>
> `k`에 해당하는 `@(x) sin(x) + x.*cos(x)`를 R2026a에서 실행하면 `k([0 pi/2 pi])`는 `0 1.0000 -3.1416`이다.

> **[보강]** symbolic 결과를 숫자로 바꾸는 세 가지 방법 비교:
>
> | 방법 | 코드 | 쓰는 때 |
> |---|---|---|
> | `double` | `double(dy(5))` | **값 하나**를 숫자로 |
> | `subs` + `double` | `double(subs(expr,x,1:5))` | expression에 값 몇 개 대입 |
> | `matlabFunction` | `g = matlabFunction(dy); g(1:5)` | **반복 계산**, 다른 MATLAB 함수(`fplot`, `integral`, `fzero` …)에 넘길 때 |

## ⚠️ 함정

- **`dy(5)`와 `g(5)`는 Class가 다르다.** `dy(5)`는 sym(`1/25 - (6*exp(-5))/25`), `g(5)`는 double(`0.0384`). 둘의 **값은 같다.**
- **이름 철자.** `matlabFunction`은 **F가 대문자**다. `matlabfunction`은 다른 이름이다.
- **변환된 함수는 array 연산자를 쓴다.** `./`, `.^`, `.*`로 바뀐 것은 오류가 아니다. 배열 입력을 받기 위한 것이다.
- **`matlabFunction`은 원본을 바꾸지 않는다.** `dy`는 symbolic으로 남고, `g`가 새로 생긴다.
- **anonymous function은 단순화하지 않는다.** `g(0)`은 NaN이다. 극한이 필요한 계산은 symbolic 쪽에서 한다.
- **`function_handle`은 `diff`, `int`, `solve`에 넣을 수 없다.** 그 함수들은 symbolic 입력이 필요하다. 기호 계산을 **먼저 끝낸 뒤** `matlabFunction`으로 바꾼다.
- **방향은 symbolic → numeric이다.** `matlabFunction`은 symbolic expression/function을 anonymous function으로 바꾼다.
