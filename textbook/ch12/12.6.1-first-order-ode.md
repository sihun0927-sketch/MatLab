# 12.6 Differential Equations — 12.6.1 First-Order Differential Equations

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. `dsolve`는 Symbolic Math Toolbox 함수라 이 PC에서 실행하지 못했다. `[보강]`의 해는 수학적으로 검증했다([README](README.md#실행-환경-메모)).

## 12.6 Differential Equations

**미분방정식(differential equation)** 은 **종속 변수(dependent variable)** 와, 그것을 **독립 변수(independent variable)** 로 미분한 **도함수**를 함께 담고 있다. 예:

$$\frac{dy}{dt} = y$$

는 미분방정식이다.

- **y**가 종속 변수
- **t**가 독립 변수

독립 변수와 종속 변수에 어떤 기호든 쓸 수 있지만, MATLAB에서 상미분방정식(ordinary differential equation)의 **기본 독립 변수는 t**다. (대부분의 상미분방정식 표기에서도 보통 t를 쓴다.)

### Background

간단한 식을 보자.

$$y = e^t$$

y를 t로 미분하면

$$\frac{dy}{dt} = e^t$$

이다. $e^t$ 가 곧 y이므로, 이 식은 **미분방정식**으로 표현할 수 있다.

$$\frac{dy}{dt} = y$$

### Solutions to Differential Equations

- 미분방정식의 **해(solution)** 는 **y를 t로 나타낸 식**이다.
- 미분방정식에는 보통 **해가 여러 개** 있다.
- 다음 **함수 족(family of functions)** 은 모두 같은 미분방정식 $dy/dt = y$ 로 표현된다.

$$y = C_1 e^t$$

- 관심 있는 특정 식 하나는 **초기 조건(initial condition)** 을 지정해 정한다.
- 예를 들어 $y(0) = 1$ 이면 $C_1 = 1$ 이다.

### Another Example

조금 더 복잡한 함수:

$$y = t^2$$

y를 t로 미분하면

$$\frac{dy}{dt} = 2t$$

이다. 이 식은 다음처럼 쓸 수 있다.

$$\frac{dy}{dt} = \frac{2t^2}{t} = \frac{2y}{t}$$

즉 $y = t^2$ 은 미분방정식 $dy/dt = 2y/t$ 의 **한 해**다.

### Solving Differential Equations

- 미분방정식에는 **해가 여러 개** 있다.
- 미분방정식을 **푼다**는 것은 **종속 변수(예에서 y)를 독립 변수(예에서 t)로 나타내는** 것이다.
- symbolic toolbox 함수 **`dsolve`** 가 미분방정식을 푼다. 즉 **y를 t에 대해** 푼다.

## 12.6.1 First-Order Differential Equations

- `dsolve` 함수는 **symbolic function으로 표현한 미분방정식**을 입력으로 받는다.
- 종속 변수를 `y`, 독립 변수를 `t`로 이름 지으면, 결과(해)는 **y가 t의 함수**인 식이다.

### `dsolve`의 입력 만들기

**첫 단계**는 y 함수를 위한 **symbolic variable을 정의**하는 것이다.

```matlab
syms y(t)
```

**다음으로** 미분방정식을 정의한다. 예로 다음 식을 쓴다.

$$\frac{dy}{dt} = \frac{2y}{t}$$

### 1차 미분방정식 풀기

`eqn`이라는 변수(어떤 유효한 이름이든 된다)를 정의하고, **`diff` 함수**로 y(t)의 도함수를 나타낸다.

```matlab
syms y(t)
eqn = diff(y(t),t)==2*y(t)/t
```
```
eqn =
diff(y(t), t) == (2*y(t))/t
```

- `diff(y(t),t)`가 $dy/dt$ 다. y(t)가 무엇인지 아직 모르므로 MATLAB은 미분을 계산하지 않고 **`diff(y(t), t)` 그대로** 둔다.
- 방정식이므로 **`==`**.
- Workspace에는 `y`(symfun), `t`(sym), `eqn`이 생긴다.

### Function Notation 또는 Function Handle

정의에서 **함수 표기(function notation, `y(t)`)** 를 써도 되고 **함수 이름만(`y`)** 써도 된다. 슬라이드는 뒤쪽을 "function handle"이라고 부른다. **결과는 같다.**

```matlab
eqn = diff(y,t)==2*y/t
```
```
eqn(t) =
diff(y(t), t) == (2*y(t))/t
```

> **[보강]** 두 경우의 차이는 화면 첫 줄뿐이다. `y(t)`로 쓰면 `eqn =`, `y`만 쓰면 `eqn(t) =`(eqn 자체가 t의 symbolic function이 된다). 방정식 내용은 같다. 슬라이드가 말하는 "function handle"은 Chapter 6의 `@` function handle이 아니라 **인수 `(t)`를 떼고 쓴 함수 이름 `y`** 를 가리킨다.

### `dsolve`로 풀기

이 미분방정식에는 **해가 무한히 많다.**

```matlab
dsolve(eqn)
```
```
ans =
C1*t^2
```

`dsolve` 함수가 `eqn` 변수를 입력으로 받아 미분방정식의 **해를 반환**한다. **`C1`** 은 임의의 상수다.

> **[보강]** 확인: $y = C_1 t^2$ 이면 $dy/dt = 2C_1 t = 2(C_1 t^2)/t = 2y/t$. 앞의 Another Example에서 본 $y = t^2$ 은 $C_1 = 1$ 인 경우다.

### 방정식을 직접 넣기

방정식을 `dsolve`에 **직접** 넣어도 같은 결과다.

```matlab
syms y(t)
dsolve(diff(y,t)==2*y/t)
```
```
ans =
C1*t^2
```

종속 변수(여기서는 `y`)는 **반드시 함수 표기로 선언**해야 한다(`syms y(t)`).

## Boundary Conditions (경계 조건)

- 미분방정식은 **경계 조건(boundary condition)을 지정하지 않으면** 해가 하나로 정해지지 않는다.
- 상수 **`C1`** 은 **무한히 많은 값**을 가질 수 있다.
- `dsolve`는 **둘째 입력**에 경계 조건을 **방정식으로** 받는다.
- 경계 조건은 **별도의 방정식으로 정의해 이름을 붙여도** 되고, `dsolve` 안에서 **직접 정의해도** 된다.

### 경계 조건 지정하기

```matlab
syms y(t)
eqn = diff(y,t)==2*y/t;
dsolve(eqn)
```
```
ans =
C1*t^2
```

경계 조건을 `dsolve` 안에 직접:

```matlab
dsolve(eqn,y(-1)==1)
```
```
ans =
t^2
```

경계 조건에 이름을 붙여서:

```matlab
cond = y(-1)==1
```
```
cond =
y(-1) == 1
```
```matlab
dsolve(eqn,cond)
```
```
ans =
t^2
```

- 경계 조건 $y(-1) = 1$ 을 주자 `C1`이 사라지고 **해가 하나(`t^2`)** 로 정해졌다.
- 경계 조건도 방정식이므로 **`==`** 를 쓴다.

> **[보강]** 확인: $y = C_1 t^2$ 에 t = −1, y = 1을 넣으면 $C_1 (-1)^2 = 1 \Rightarrow C_1 = 1$.

> **[보강]** 이 절 Background의 미분방정식 $dy/dt = y$ 를 `dsolve`로 풀면:
>
> ```matlab
> syms y(t)
> dsolve(diff(y,t) == y)             % C1*exp(t)
> dsolve(diff(y,t) == y, y(0) == 1)  % exp(t)
> ```
>
> 슬라이드가 손으로 구한 $y = C_1 e^t$, 그리고 $y(0) = 1$ 일 때 $C_1 = 1$ 과 같다.

> **[보강]** `solve`와 `dsolve` 비교:
>
> | | `solve` ([12.2.1](12.2.1-solve.md)) | `dsolve` |
> |---|---|---|
> | 푸는 대상 | 대수 방정식 | **미분**방정식 |
> | 미지수 | 변수(`syms x`) | **함수**(`syms y(t)`) |
> | 답 | 값 또는 식 (`3`, `-(c + b*x)/x^2`) | **t의 식** (`C1*t^2`) |
> | 추가 입력 | 풀 변수 | **경계 조건** |
> | 임의 상수 | 없음 | `C1`, `C2`, … |

## ⚠️ 함정

- **`syms y(t)`로 선언해야 한다.** `syms y t`로 선언하면 `y`는 t와 무관한 독립 기호라서 `diff(y,t)`가 **0**이 된다. 방정식이 `0 == 2*y/t`로 바뀌어 미분방정식이 아니게 된다.
- **미분방정식에도 `==`.** `eqn = diff(y,t) = 2*y/t`는 오류다.
- **경계 조건이 없으면 `C1`이 남는다.** `C1*t^2`은 오류가 아니라 **일반해**다. 특정 해를 원하면 둘째 입력에 조건을 준다.
- **경계 조건은 `y(-1)==1` 꼴이다.** "t = −1일 때 y = 1"을 뜻한다. `y(-1)`은 인덱싱이 아니라 **함수 y에 t = −1을 넣은 값**이다.
- **`diff`의 두 얼굴.** 여기서 `diff(y,t)`는 계산할 수 없는 도함수를 **기호로 남겨** 방정식을 만드는 데 쓴다. [12.5.1](12.5.1-differentiation.md)처럼 바로 계산되는 경우와 다르다.
- **기본 독립 변수는 t다.** `solve`·`diff`·`int`의 기본 변수가 x인 것과 다르다.
- **`eqn =` 과 `eqn(t) =`.** `y(t)`로 썼느냐 `y`로 썼느냐에 따라 화면 첫 줄이 다르다. 둘 다 `dsolve`에 넣을 수 있고 결과가 같다.
- > **[보강]** **옛 문법.** 오래된 자료의 `dsolve('Dy = 2*y/t')`, `dsolve('Dy = y','y(0) = 1')`처럼 **문자열과 `D` 표기**를 쓰는 방식은 구문법이다. 슬라이드처럼 `syms y(t)`, `diff`, `==`를 쓴다.
