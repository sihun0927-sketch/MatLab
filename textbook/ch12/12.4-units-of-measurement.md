# 12.4 Units of Measurement

> **[보강]** 이 절의 MATLAB 출력은 슬라이드(R2022a) 화면 그대로다. `symunit`은 Symbolic Math Toolbox 함수라 이 PC에서 실행하지 못했다. 분수 값은 손계산과 R2026a 숫자 계산으로 검산했다([README](README.md#실행-환경-메모)).

- 엔지니어가 계산할 때 가장 중요한 일 가운데 하나가 **단위(units of measurement)를 추적**하는 것이다.
- 컴퓨터 계산에서는 단위를 **놓치기 쉽다.** symbolic toolbox는 **변수에 단위를 붙이는** 방법을 제공한다.
- 이 단위는 **다른 대수 기호처럼** 동작한다. 그래서 다음을 할 수 있다.
  - **일관성 확인**(check for consistency)
  - **단위 변환**(unit conversions)
  - 중요한 **물리 상수**를 직접 입력하지 않고 계산에 포함

## Workspace에 단위 추가하기 — `symunit`

단위를 계산에 넣는 첫 단계는 **`symunit`을 Workspace에 추가**하는 것이다. 여기서는 이름을 임의로 `u`라고 지었다.

```matlab
u = symunit
```
```
u = 
  symbolicUnitsCollection with units:

     ampere: [A]
     kelvin: [K]
   kilogram: [kg]
      meter: [m]
       mole: [mol]
     second: [s]
    candela: [cd]
  Show all units.
```

- Workspace에 `u`가 **1×1 `symbolicUnitsCollection`** 으로 생긴다.
- 표시된 7개는 측정 체계를 정의하는 **7개 기본 단위(base units)** 다. 여기서는 **SI**(Système International) 체계다.

| 기본 단위 | 기호 | 양 |
|---|---|---|
| ampere | `[A]` | 전류 |
| kelvin | `[K]` | 온도 |
| kilogram | `[kg]` | 질량 |
| meter | `[m]` | 길이 |
| mole | `[mol]` | 물질량 |
| second | `[s]` | 시간 |
| candela | `[cd]` | 광도 |

- 그러나 **생각할 수 있는 거의 모든 단위**를 쓸 수 있다. 화면의 **Show all units** 링크를 누르면 목록이 나온다.

## 변수에 단위 붙이기

단위는 structure array에서 쓰던 **dot 표기법**으로 지정한다.

```matlab
distance1 = 5*u.m
```
```
distance1 =
5*[m]
```

- 숫자에 `u.단위이름`을 **곱한다.**
- 결과는 **sym**이고, 단위는 **대괄호 `[m]`** 로 표시된다.

### 단위 이름을 추측하면 될 수도 있다

```matlab
distance2 = 10*u.feet
```
```
Error using  . 
Undefined unit 'feet'. Did you mean:
'femtoA', 'femtoC', 'femtoF'? For
details, see Units List.
```

단위 이름을 **추측해서 맞을 때도 많지만**, 더 나은 방법은 **tab expansion** 기능이다.

### Tab Expansion

1. 코드를 평소처럼 입력하다가 **단위를 입력하기 직전에 멈추고 Tab 키**를 누른다. (예: `distance2 = 10*u.` 까지 입력하고 Tab)
2. 가능한 **모든 단위를 나열한 팝업 창**이 뜬다. (슬라이드 화면에는 `fS`, `fs`, `fsr`, `fSt`, `fSv`, `fT`, `ft`, `ft_US` 등이 보인다.)
3. 원하는 것을 **더블클릭**해 고른다.

피트는 `feet`이 아니라 **`ft`** 다.

```matlab
distance2 = 10*u.ft
```
```
distance2 =
10*[ft]
```

## Mixed Units — 단위는 자동으로 단순화되지 않는다

```matlab
ratio = distance1/distance2
```
```
ratio =
(1/2)*([m]/[ft])
```

수학 연산을 해도 **단위는 자동으로 단순화되지 않는다.** 5 m ÷ 10 ft가 `(1/2)*([m]/[ft])`로 남는다.

### `simplify`

```matlab
ratio = simplify(ratio)
```
```
ratio =
625/381
```
```matlab
ratio = double(ratio)
```
```
ratio =
    1.6404
```

- **`simplify`** 를 쓰면 단위가 정리된다. 결과는 **여전히 symbolic**이다(분수 `625/381`).
- **`double`** 이 답을 **숫자 결과**로 바꾼다. Workspace에서 `ratio`의 Class가 `sym`에서 **`double`** 로 바뀐다.

> **[보강]** 검산: 1 ft = 0.3048 m (정확한 정의값). $\dfrac{5\ \text{m}}{10\ \text{ft}} = \dfrac{5}{10 \times 0.3048} = \dfrac{625}{381} \approx 1.6404$. 길이 ÷ 길이라 단위가 사라진 **무차원** 값이다. symbolic 계산은 변환 계수를 **정확한 분수**로 다룬다.

## Unit Conversions — 미터와 피트 합치기

더 복잡한 예:

```matlab
u = symunit;
distance1 = 5*u.m;
distance2 = 10*u.ft;
distance3 = 15*u.m;
velocity = 10*u.m/u.sec;
time = 15*u.sec;
total = velocity*time + distance1 + distance3 + distance2
```
```
total =
10*[ft] + 170*[m]
```

단위가 **자동으로 결합되고 약분되었다.**

- `velocity*time` = 10 m/s × 15 s = 150 m (초가 **약분**되었다)
- 150 m + 5 m + 15 m = **170 m** (같은 단위끼리 **합쳐졌다**)
- 10 ft는 단위가 달라 **따로 남았다**

### 결과 — `simplify`

```matlab
total = simplify(total)
```
```
total =
(216310/381)*[ft]
```

- `simplify`가 **두 길이 항을 합친다.**
- 어느 단위로 단순화할지는 **MATLAB이 고른다.** 여기서는 **feet**다.

### `unitConvert` 함수

결과를 **원하는 단위**로 바꾸려면 **`unitConvert`** 함수를 쓴다.

```matlab
total = unitConvert(total,u.m)
```
```
total =
(21631/125)*[m]
```

`unitConvert(식, 목표단위)`.

> **[보강]** 검산: 10 ft = 3.048 m. 170 + 3.048 = **173.048 m** = 21631/125. 피트로는 173.048 ÷ 0.3048 = 567.74… ft = 216310/381.

## Separating Units — `separateUnits`

**`separateUnits`** 함수로 계산된 **숫자 값과 단위를 분리**할 수 있다. 그런 다음 변수를 **double로 변환**해 다른 계산에 쓴다.

```matlab
[total_value,total_unit] = separateUnits(total)
```
```
total_value =
21631/125
total_unit =
[m]
```
```matlab
total_value = double(total_value)
```
```
total_value =
  173.0480
```

- 출력이 **두 개**다. 첫째가 값, 둘째가 단위.
- `total_value`는 분리 직후에는 아직 **sym**(분수)이다. `double`을 거쳐야 숫자가 된다.

## Temperatures — 온도

`unitConvert`는 매우 유용하지만 **온도에 쓸 때는 주의**가 필요하다.

- 입력한 온도 값은 실제 온도가 아니라 **온도 차(temperature difference)** 라고 **가정**한다.

```matlab
u = symunit;
delta_T_C = 5*u.Celsius;
delta_T_K = unitConvert(delta_T_C,u.K)
```
```
delta_T_K =
5*[K]
```

**5 °C의 변화는 5 K의 변화와 같다.** (눈금 간격이 같기 때문이다.)

### Temperatures — Absolute

**실제 측정한 온도**를 한 눈금에서 다른 눈금으로 바꾸려면, 함수 입력에서 값을 (차이 형식이 아니라) **absolute로 지정**해야 한다.

```matlab
u = symunit;
T_C = 5*u.Celsius;
T_K = unitConvert(T_C,u.K,"Temperature","Absolute")
```
```
T_K =
(5563/20)*[K]
```
```matlab
[T_K_value,T_K_unit] = separateUnits(T_K)
```
```
T_K_value =
5563/20
T_K_unit =
[K]
```
```matlab
double(T_K_value)
```
```
ans =
  278.1500
```

**5 °C의 온도는 278.15 K의 온도와 같다.**

> **[보강]** 두 경우 비교:
>
> | 뜻 | 코드 | 결과 |
> |---|---|---|
> | 온도 **차** 5 °C (기본) | `unitConvert(5*u.Celsius, u.K)` | `5*[K]` |
> | **실제 온도** 5 °C | `unitConvert(5*u.Celsius, u.K, "Temperature", "Absolute")` | `(5563/20)*[K]` = 278.15 K |
>
> 5 + 273.15 = 278.15 = 5563/20.

> **[보강]** 이 절의 함수 정리:
>
> | 함수 | 하는 일 | 결과의 Class |
> |---|---|---|
> | `u = symunit` | 단위 모음을 Workspace에 만든다 | `symbolicUnitsCollection` |
> | `5*u.m` | 값에 단위를 붙인다 | `sym` |
> | `simplify(식)` | 단위를 정리한다(목표 단위는 MATLAB이 선택) | `sym` |
> | `unitConvert(식, u.m)` | **지정한 단위**로 변환한다 | `sym` |
> | `[v, un] = separateUnits(식)` | 값과 단위를 분리한다 | 둘 다 `sym` |
> | `double(v)` | 숫자로 바꾼다 | `double` |

---

## ⚠️ 함정

- **`symunit`을 먼저 실행해야 한다.** `u = symunit` 없이 `5*u.m`을 쓰면 `u`가 없다는 오류다. `u`는 **임의로 지은 이름**이다(다른 이름도 된다).
- **단위 이름을 추측하면 틀릴 수 있다.** `u.feet`은 오류(`Undefined unit 'feet'`)다. 피트는 **`u.ft`**. 확실하지 않으면 `u.`까지 치고 **Tab**.
- **단위는 자동으로 단순화되지 않는다.** `distance1/distance2`는 `(1/2)*([m]/[ft])`로 남는다. `simplify`나 `unitConvert`를 써야 한다. (같은 단위끼리 더하기, 곱에서 약분되는 것은 자동이다: `170*[m]`.)
- **`simplify`는 목표 단위를 내가 정할 수 없다.** 슬라이드 예에서는 feet로 정리되었다. 원하는 단위가 있으면 **`unitConvert`**.
- **단위가 붙은 값은 symbolic이다.** 숫자 계산에 쓰려면 `separateUnits` → `double` 두 단계를 거친다. 단위가 붙은 채로는 `double`로 바꿀 수 없다.
- **`separateUnits`는 출력이 두 개다.** `[값, 단위] = separateUnits(...)`.
- **온도는 기본이 "차이"다.** `unitConvert(5*u.Celsius, u.K)`는 278.15가 아니라 **`5*[K]`** 다. 실제 온도는 `"Temperature","Absolute"`를 붙인다.
- **결과가 분수로 나온다.** `(21631/125)*[m]`은 173.048 m다. 소수로 보려면 값을 분리해 `double`.
