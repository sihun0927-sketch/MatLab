# 12.2.3 Substitution and Symbolic Functions

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. symbolic 코드는 이 PC에서 실행하지 못했다([README](README.md#실행-환경-메모)).

symbolic expression을 정의하고 나면 거기에 **값(보통 숫자)을 대입(substitute)** 하고 싶을 때가 많다. 방법은 두 가지다.

- **`subs` 함수**를 쓴다.
- expression을 **symbolic function으로 변환**한다.

어느 것을 쓸지:

- `subs`는 대입을 **한 번만** 하거나 **더 큰 과정의 일부**로 할 때 주로 쓴다.
- 대입을 **반복해서** 한다면 **symbolic function**을 쓴다.

## `subs` 함수

`subs`는 입력 **세 개**가 필요하다.

1. **고칠 expression**
2. **바꿀 변수**
3. **새로 넣을 변수**(또는 값)

```matlab
syms x a b c
e4 = a*x^2 + b*x + c
```
```
e4 =
a*x^2 + b*x + c
```
```matlab
syms y
e5 = subs(e4,x,y)
```
```
e5 =
a*y^2 + b*y + c
```

`e4`의 `x`를 `y`로 바꾼 새 expression이 `e5`에 저장된다.

### 숫자 대입

숫자를 대입할 때도 **같은 절차**다.

```matlab
subs(e4,x,3)
```
```
ans =
9*a + 3*b + c
```

### 원래 expression은 바뀌지 않는다

**원래 expression은 바뀌지 않는다.** 새 expression이 `subs`의 **결과로 반환**되고, 사용자가 지정한 이름에 저장된다. 위 예에서는 이름을 주지 않았으므로 `ans`에 저장되었다.

```matlab
e4
```
```
e4 =
a*x^2 + b*x + c
```

### 여러 변수를 한꺼번에

여러 개를 대입하려면 **변수들과 대입할 값들을 각각 배열로** 나열한다.

```matlab
e6 = subs(e4,[a,b,c],[1,2,3])
```
```
e6 =
x^2 + 2*x + 3
```

`a → 1`, `b → 2`, `c → 3`으로 **같은 위치끼리** 짝지어 대입된다.

### 배열 입력

변수 자리에 **숫자 배열**을 대입할 수 있다. **결과가 여러 개** 나온다.

```matlab
numbers = 1:5;
subs(e6,x,numbers)
```
```
ans =
[6, 11, 18, 27, 38]
```

- `ans`는 **1×5 sym** 배열이다.
- symbolic 행 벡터는 **대괄호와 쉼표**로 표시된다. 숫자 배열(`6 11 18 27 38`)의 표시와 다르다.

> **[보강]** 확인: $x^2 + 2x + 3$ 에 x = 1, 2, 3, 4, 5 → 6, 11, 18, 27, 38. 숫자 배열로 바꾸려면 `double(ans)`.

## Symbolic Function 만들기 — `symfun`

**`symfun`** 함수는 변수에 저장된 **기존 expression**을 코드를 **다시 입력하지 않고** symbolic function으로 변환한다. 입력은 두 개다.

1. **symbolic expression**
2. **변수 이름의 배열**

```matlab
syms x y
e7 = x^2 + y^2;
g = symfun(e7,[x,y])
```
```
g(x, y) =
x^2 + y^2
```
```matlab
g(2,3)
```
```
ans =
13
```

- Workspace에서 `g`의 Class는 **`symfun`**, `e7`·`x`·`y`·`ans`는 `sym`이다.
- `g(2,3)`의 결과 `13`도 **symbolic**이다(2² + 3² = 13).

> **[보강]** symbolic function을 만드는 세 가지 방법 비교:
>
> | 방법 | 코드 | 쓰는 때 |
> |---|---|---|
> | `syms`로 선언 후 정의 | `syms fun(x,z)` → `fun(x,z) = 2*x^2+4*z` | 처음부터 함수로 만들 때 ([12.1](12.1-symbolic-algebra.md)) |
> | 한 단계 정의 | `f(x) = x^2 + 2` (x가 이미 symbolic) | 변수가 이미 있을 때 |
> | `symfun` | `g = symfun(e7,[x,y])` | **이미 만든 expression**을 함수로 바꿀 때 |
>
> `subs`와 symbolic function의 차이:
>
> ```matlab
> subs(e7,[x,y],[2,3])    % 13   (매번 변수 목록을 적어야 한다)
> g(2,3)                  % 13   (함수 호출처럼 값만 적는다)
> ```

---

## ⚠️ 함정

- **`subs`는 원본을 바꾸지 않는다.** `subs(e4,x,3)`만 쓰면 결과는 `ans`에 들어가고 `e4`는 그대로다. 저장하려면 `e6 = subs(...)`처럼 **이름을 준다.**
- **입력 순서.** `subs(식, 바꿀 변수, 새 값)`. 둘째와 셋째를 뒤집으면 안 된다.
- **여러 개 대입은 배열 두 개의 위치가 맞아야 한다.** `subs(e4,[a,b,c],[1,2,3])`에서 `a`↔1, `b`↔2, `c`↔3. 개수가 다르면 안 된다.
- **대입 결과도 symbolic이다.** `subs(e6,x,1:5)`의 `[6, 11, 18, 27, 38]`은 sym 배열이다. `plot` 등에 쓰려면 `double`.
- **일부만 대입하면 나머지 기호는 남는다.** `subs(e4,x,3)` → `9*a + 3*b + c`. 오류가 아니다.
- **`symfun`의 둘째 입력이 인수 순서를 정한다.** `symfun(e7,[x,y])`면 `g(2,3)`은 x=2, y=3. `[y,x]`로 주면 `g(2,3)`은 y=2, x=3이다.
- **expression에 괄호로 값을 넣을 수 없다.** `e7(2,3)`은 함수 호출이 아니라 인덱싱이다. 값을 넣으려면 `subs`를 쓰거나 `symfun`으로 함수로 만든다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다.

1. 다음 코드의 각 출력과 마지막에 `f`에 저장된 식을 쓰시오.
   ```matlab
   syms x
   f = x^2 + 3*x;
   subs(f,x,2)
   subs(f,x,[0 1 2])
   f
   ```
2. `e4 = a*x^2 + b*x + c`에서 a = 1, b = −3, c = 2, x = 4를 **한 번의 `subs` 호출로** 대입하는 코드를 쓰고 결과를 쓰시오. 결과를 double로 바꾸는 코드도 쓰시오.
3. 다음 코드에서 `h(1,2)`와 `k(1,2)`의 값을 각각 구하시오.
   ```matlab
   syms x y
   e = x*y + y^2;
   h = symfun(e,[x,y]);
   k = symfun(e,[y,x]);
   ```
