# 12.1.2 Manipulating Symbolic Expressions and Equations

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. `[보강]` 블록의 출력은 직접 실행하지 못했고 수학적으로만 확인했다([README](README.md#실행-환경-메모)).

- **equation**은 무언가와 **같다고 놓은 것**(`==`가 있다)이고, **expression**(function 포함)은 그렇지 않다.
- 대부분의 경우 **단순한 symbolic expression**이나 **symbolic function 형태의 expression**을 다루게 된다.
- symbolic object를 다루는 MATLAB 함수는 **대부분** equation과 expression **둘 다**에 쓸 수 있다. **전부는 아니다.**

## Simplification Functions

무엇이 "단순한(simple)" 식인지는 **언제나 분명하지는 않다.**

### 만들 때 자동으로 항을 합친다

```matlab
syms a
z = a+2*a+(a-3)^2-(a^2+2*a+1)
```
```
z =
a + (a - 3)^2 - a^2 - 1
```

`z`를 만들 때 MATLAB이 **자동으로 항을 합쳤다**(`a + 2*a − 2*a` → `a`). 그러나 `(a − 3)^2`은 전개하지 않았다.

### `simplify` 함수

`simplify`는 MATLAB에 내장된 단순화 규칙으로 expression이나 equation의 **각 부분을 단순화**한다.

```matlab
simplify(z)
```
```
ans =
8 - 5*a
```

> **[보강]** 확인: $a + (a-3)^2 - a^2 - 1 = a + a^2 - 6a + 9 - a^2 - 1 = 8 - 5a$.

### symbolic function에도 쓴다

```matlab
syms f2(x)
f2(x) = (x-2)*(x+2)
```
```
f2(x) =
(x - 2)*(x + 2)
```
```matlab
simplify(f2(x))
```
```
ans =
x^2 - 4
```

**symbolic function은 symbolic expression의 한 종류**이므로 같은 함수가 그대로 동작한다.

### symbolic equation에도 쓴다

```matlab
w = x^3-1 == (x-3)*(x+3)
```
```
w =
x^3 - 1 == (x - 3)*(x + 3)
```
```matlab
simplify(w)
```
```
ans =
x^3 + 8 == x^2
```

> **[보강]** 확인: 우변을 전개하면 $x^2 - 9$. $x^3 - 1 = x^2 - 9$ 의 양변에 9를 더하면 $x^3 + 8 = x^2$. `simplify`는 방정식을 **풀지 않는다.** 양변을 정리할 뿐이다. 푸는 것은 `solve`다([12.2.1](12.2.1-solve.md)).

## Other Simplification Strategies

`simplify`는 MATLAB에서 **가장 일반적인(general)** 단순화 방법이다. 그 밖의 함수:

| 함수 | 하는 일 |
|---|---|
| `expand` | expression이나 equation의 모든 부분을 **곱해서 전개**한다 |
| `factor` | expression이나 equation을 **인수분해**한다 |
| `collect` | **동류항을 모은다** |
| `combine` | **거듭제곱의 곱을 하나의 거듭제곱으로** 다시 쓴다 |
| `numden` | expression의 **분자(numerator)와 분모(denominator)** 를 둘 다 구한다. **equation에는 쓸 수 없다** |

> **[보강]** 슬라이드에는 이 함수들의 실행 예가 없다. 아래는 각 함수가 무엇을 하는지 보여 주는 예다. 결과는 수학적으로 확인한 것이고, **MATLAB이 항을 적는 순서는 다를 수 있다.**
>
> ```matlab
> syms x y z
> expand((x + 3)^2)                     % x^2 + 6*x + 9
> factor(x^2 - 9)                       % [x - 3, x + 3]   (인수들의 벡터)
> collect(x^2*y + y*x - x^2 - 2*x, x)   % (y - 1)*x^2 + (y - 2)*x
> combine(x^y*x^z)                      % x^(y + z)
> [n, d] = numden(x/y + y/x)            % n = x^2 + y^2,  d = x*y
> ```
>
> - `expand`와 `factor`는 **서로 반대** 방향이다. `expand((x-2)*(x+2))` → `x^2 - 4`, `factor(x^2 - 4)` → `[x - 2, x + 2]`.
> - `factor`는 곱의 형태가 아니라 **인수를 나열한 벡터**를 돌려준다.
> - `collect(식, x)`는 둘째 인수로 **어느 변수 기준으로** 모을지 정한다.
> - `numden`은 출력이 **두 개**다. `[n, d] = numden(...)`처럼 받는다. 먼저 통분해서 하나의 분수로 만든 뒤 분자·분모를 돌려준다.

> **[보강]** 이 절 도입부의 식을 세 방법으로 다뤄 보면:
>
> ```matlab
> syms x
> y = 2*(x + 3)^2/(x^2 + 6*x + 9);
> simplify(y)              % 2            (x = -3에서 정의 안 됨 정보가 사라진다)
> expand(2*(x + 3)^2)      % 2*x^2 + 12*x + 18   (분자만 전개)
> factor(x^2 + 6*x + 9)    % [x + 3, x + 3]      (분모만 인수분해)
> ```

## ⚠️ 함정

- **"단순하다"는 주관적이다.** `(x-2)*(x+2)`와 `x^2 - 4` 중 어느 쪽이 단순한지는 쓰임에 따라 다르다. `simplify`의 결과가 내가 원하는 형태가 아닐 수 있다. 그럴 때 `expand`, `factor`, `collect`로 **방향을 정해** 준다.
- **MATLAB은 식을 만들 때 이미 일부를 정리한다.** `a+2*a+(a-3)^2-(a^2+2*a+1)`을 입력해도 화면에는 `a + (a - 3)^2 - a^2 - 1`이 나온다. 입력한 그대로 저장되지 않는다. 그렇다고 **완전히 단순화하지는 않는다.**
- **`simplify`는 원본을 바꾸지 않는다.** `simplify(z)`의 결과는 `ans`에 들어간다. `z`를 바꾸려면 `z = simplify(z)`.
- **`simplify`는 방정식을 풀지 않는다.** `simplify(w)`는 `x^3 + 8 == x^2`를 돌려줄 뿐 x 값을 구하지 않는다.
- **`numden`은 equation에 쓸 수 없다.** expression 전용이다. 슬라이드가 "대부분의 함수가 둘 다에 동작하지만 전부는 아니다"라고 한 예가 이것이다.
- **`factor`는 overloaded 함수다.** symbolic 입력이면 인수분해, **숫자 입력이면 소인수분해**다. toolbox가 없는 R2026a에서 `factor(12)`는 `2 2 3`을 돌려준다(실행 확인).
- **단순화하면 정보를 잃을 수 있다.** `2*(x+3)^2/(x^2+6*x+9)`를 `2`로 줄이면 x = −3에서 정의되지 않는다는 사실이 사라진다.

1. `syms x` 다음에 실행한 각 명령의 결과를 예측하시오.
   ```matlab
   simplify((x^2 - 1)/(x - 1))
   simplify(sin(x)^2 + cos(x)^2)
   expand((x - 1)*(x + 4))
   ```
2. `syms a; z = a+2*a+(a-3)^2-(a^2+2*a+1)`을 실행하면 화면에 `a + (a - 3)^2 - a^2 - 1`이 나온다. (a) 입력과 다르게 나오는 이유를 쓰시오. (b) `simplify(z)`의 결과를 쓰시오. (c) `z`의 값은 `simplify(z)` 뒤에 바뀌는가?
3. 표의 다섯 함수(`expand`, `factor`, `collect`, `combine`, `numden`) 중 (a) equation에 쓸 수 없는 것, (b) 출력을 두 개 받는 것, (c) `(x+2)^3`을 `x^3 + 6*x^2 + 12*x + 8`로 바꾸는 것을 각각 고르시오.
