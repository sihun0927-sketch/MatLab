# 12.5.2 Integration

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. symbolic 코드는 이 PC에서 실행하지 못했다. 숫자 검산(`integral`)만 R2026a에서 실행했다([README](README.md#실행-환경-메모)).

- 적분(integration)은 **미분의 반대**라고 생각할 수 있다. **역도함수(antiderivative)** 라고도 부른다.
- 흔히 **곡선 아래의 넓이(area under a curve)** 로 시각화한다.
- 예: 피스톤–실린더 장치(piston–cylinder device)가 위아래로 움직이며 하는 **일(work)** 은 상태 1과 상태 2 사이에서 **P dV를 적분**해 구한다.

$$W = \int_1^2 P\,dV$$

- 이 문제가 어려운지 쉬운지는 **P가 V에 따라 어떻게 변하는지**에 달려 있다.
  - **dV가 0이면** 일이 없다(W = 0).
  - **P가 일정하면** $W = P\,\Delta V$.
  - 그 밖의 관계에서는 적분이 더 복잡해진다.

### Pressure-Volume Work (Figure 12.12)

- (a) 피스톤–실린더 장치: 실린더 안에 기체(gas)가 있고 피스톤이 움직인다.
- (b) 피스톤–실린더 장치가 하는 일은 **압력–부피 곡선(Pressure-Volume curve) 아래의 넓이**다. 그림의 예는 **압력이 일정**하다(100 psia, 부피 1 → 4 cm³). 빗금 친 직사각형이 **moving boundary work**다.

> **[보강]** 압력이 일정한 그림의 경우 넓이는 직사각형이다: $W = P\,\Delta V = 100 \times (4 - 1) = 300$ (psia·cm³). symbolic으로는 `syms V; int(sym(100),V,1,4)` → `300`.

## `int` 함수

- symbolic toolbox의 **`int`** 함수로 매우 복잡한 함수도 쉽게 적분할 수 있다.
- `int`는 **symbolic expression** 또는 **symbolic function**을 입력으로 받는다.

### 부정적분 (Indefinite Integral)

**부정적분**(적분 구간을 지정하지 않은 적분)은 **입력 하나**만 있으면 된다.

```matlab
syms x
y = x^3 + sin(x)
```
```
y =
sin(x) + x^3
```
```matlab
int(y)
```
```
ans =
x^4/4 - cos(x)
```

### 기본 적분 변수 (Default Integration Variable)

**기본 적분 변수는 x**, 또는 **알파벳 순서로 x에 가장 가까운 변수**다.

변수를 t로 바꿔도 결과가 같다. 식에 **변수가 하나뿐**이기 때문이다.

```matlab
syms t
y = t^3 + sin(t)
```
```
y =
sin(t) + t^3
```
```matlab
int(y)
```
```
ans =
t^4/4 - cos(t)
```

변수가 **두 개**인 식은 **기본적으로 x에 대해** 적분된다.

```matlab
syms x t
y = x^3 +sin(t)
```
```
y =
x^3 + sin(t)
```
```matlab
int(y)
```
```
ans =
x^4/4 + sin(t)*x
```

`sin(t)`는 x와 무관하므로 **상수 취급**되어 `sin(t)*x`가 되었다.

### 적분 변수 지정

적분 변수를 지정하려면 **둘째 입력**에 넣는다.

```matlab
int(y,t)
```
```
ans =
t*x^3 - cos(t)
```

이 코드는 **t를 적분 변수로** 지정한다. 이번에는 `x^3`이 상수 취급되어 `t*x^3`이 되었다.

### 정적분 (Definite Integral)

**정적분**은 **두 점(구간의 양 끝, bounds) 사이**에서 계산한다. 적분 구간은 **둘째와 셋째 입력**에 넣는다.

```matlab
syms x
y = x^2
```
```
y =
x^2
```
```matlab
int(y,2,3)
```
```
ans =
19/3
```

> **[보강]** 확인: $\displaystyle\int_2^3 x^2\,dx = \left[\frac{x^3}{3}\right]_2^3 = \frac{27 - 8}{3} = \frac{19}{3}$. 숫자로는 6.3333. R2026a의 수치 적분 `integral(@(x) x.^2, 2, 3)`도 `6.3333`을 준다.

### 변수가 여러 개인 정적분

**적분 변수와 구간을 모두** 지정하려면 전부 **함수 입력으로 나열**한다.

```matlab
syms x z
y = sin(x)+cos(z);
int(y,z,2,3)
```
```
ans =
sin(3) - sin(2) + sin(x)
```

이 코드는 **z를 적분 변수**(integration parameter)로 지정한다.

> **[보강]** 확인: $\displaystyle\int_2^3 (\sin x + \cos z)\,dz = \sin x\cdot(3-2) + [\sin z]_2^3 = \sin x + \sin 3 - \sin 2$.

### 구간이 symbolic인 정적분

구간은 **숫자**일 수도 있고 **symbolic**일 수도 있다.

```matlab
syms b c
int(y,z,b,c)
```
```
ans =
sin(c) - sin(b) - sin(x)*(b - c)
```

> **[보강]** `int`의 입력 형태 정리:
>
> | 호출 | 뜻 | 슬라이드 예 |
> |---|---|---|
> | `int(y)` | 부정적분, 기본 변수 | `x^4/4 - cos(x)` |
> | `int(y,t)` | 부정적분, 변수 t | `t*x^3 - cos(t)` |
> | `int(y,2,3)` | 정적분, 기본 변수, 2 → 3 | `19/3` |
> | `int(y,z,2,3)` | 정적분, 변수 z, 2 → 3 | `sin(3) - sin(2) + sin(x)` |
> | `int(y,z,b,c)` | 정적분, 기호 구간 | `sin(c) - sin(b) - sin(x)*(b - c)` |
>
> `diff`와 나란히 놓으면:
>
> | | 기본 변수 | 변수 지정 | 추가 입력 |
> |---|---|---|---|
> | `diff` | `diff(y)` | `diff(y,z)` | `diff(y,z,2)` — **차수** |
> | `int` | `int(y)` | `int(y,z)` | `int(y,z,a,b)` — **구간** |

> **[보강]** 피스톤 예를 압력이 변하는 경우로 넓히면, 등온 과정에서 $P = 100/V$ 라 할 때
>
> ```matlab
> syms V
> W = int(100/V, V, 1, 4)
> ```
>
> 수학적 답은 $100\ln 4 = 200\ln 2 \approx 138.63$ 이다(MATLAB은 `ln`을 `log`로 쓴다). R2026a의 수치 적분 `integral(@(V) 100./V, 1, 4)`는 `138.6294`를 준다. 압력이 일정할 때(300)보다 작다.

## ⚠️ 함정

- **적분 상수 `+ C`가 없다.** `int(y)`는 `x^4/4 - cos(x)`만 돌려준다. 수학 답안에서는 `+ C`를 붙여야 하지만 **MATLAB 출력에는 없다.**
- **기본 변수는 x(또는 x에 가장 가까운 글자)다.** `y = x^3 + sin(t)`에서 `int(y)`는 x로 적분한다. t로 적분하려면 `int(y,t)`.
- **입력 순서.** `int(식, 변수, 아래끝, 위끝)`. 변수를 생략하면 `int(식, 아래끝, 위끝)`. `int(y,2,3)`의 2, 3은 구간이다(`diff(y,2)`의 2가 차수인 것과 다르다).
- **다른 변수는 상수 취급.** `int(x^3 + sin(t))`의 `sin(t)*x`는 오타가 아니다.
- **정적분 결과도 symbolic이다.** `19/3`은 분수 그대로다. `sin(3) - sin(2) + sin(x)`의 `sin(3)`도 계산하지 않고 남긴다. 숫자는 `double`.
- **`int`와 `integral`은 다르다.** `int`는 **symbolic**(해석적), `integral`은 function handle을 받는 **수치** 적분이다.
- **`int`는 정수 타입이 아니다.** Chapter 11의 `int8`, `int16`…과 이름이 비슷하지만 무관하다. `int`는 integrate다.
- **MATLAB이 식을 적는 순서는 입력 순서와 다르다.** `x^3 + sin(x)`를 입력하면 `sin(x) + x^3`으로 표시된다. 같은 식이다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다.

1. `syms x` 다음 각 정적분의 결과를 쓰시오.
   ```matlab
   int(x^2, 0, 3)
   int(sin(x), 0, pi)
   ```
2. `syms x t; y = x^2*t`일 때 다음 결과를 수식으로 쓰시오(MATLAB의 표시 순서는 달라도 된다).
   ```matlab
   int(y)
   int(y,t)
   int(y,t,0,2)
   ```
3. `int(y)`와 `int(y,2,3)`의 차이, `int`와 `integral`의 차이를 각각 한 문장으로 설명하시오. 그리고 `syms x; int(x^3 + sin(x))`의 MATLAB 출력에 수학 답안과 비교해 빠져 있는 것을 쓰시오.
