# 12.2 Solving Expressions and Equations — 12.2.1 The `solve` Function

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. symbolic 코드는 이 PC에서 실행하지 못했다. 숫자 검산(`roots`)만 R2026a에서 실행했다([README](README.md#실행-환경-메모)).

symbolic toolbox에서 매우 유용한 함수가 **`solve`** 다. 다음에 쓸 수 있다.

- expression의 **근(root)** 을 구한다.
- 변수가 하나일 때 **수치 답**을 구한다.
- 미지수에 대해 **기호로(symbolically)** 푼다.

`solve`는 **연립방정식(systems of equations)** 도 푼다. 선형(linear)과 비선형(nonlinear) 모두 가능하다([12.2.2](12.2.2-systems-of-equations.md)).

## 12.2.1 `solve` 함수

**expression**에 `solve`를 쓰면, 그 expression을 **0과 같다고 놓고** 근을 구한다.

```matlab
syms x
E1 = x-3
```
```
E1 =
x - 3
```
```matlab
solve(E1)
```
```
ans =
3
```

`x - 3 = 0`의 해 `3`이다.

### expression 이름 또는 식을 직접

`solve`에는 **expression 이름**을 줄 수도 있고, 괄호 안에서 **symbolic expression을 직접** 만들 수도 있다.

```matlab
syms x
solve(x^2-9)
```
```
ans =
-3
 3
```

결과가 숫자처럼 보이지만 `ans`는 **2×1 symbolic 배열**이다(Workspace: `ans` 2×1 `sym`).

### 변수가 여러 개인 식

변수가 둘 이상인 symbolic expression도 바로 풀 수 있다.

```matlab
syms x a b c
solve(a*x^2+b*x+c)
```
```
ans =
-(b + (b^2 - 4*a*c)^(1/2))/(2*a)
-(b - (b^2 - 4*a*c)^(1/2))/(2*a)
```

- MATLAB은 **x를 우선해서(preferentially)** 푼다.
- 식에 **x가 없으면** 알파벳 순서로 **x에 가장 가까운 변수**를 찾는다.
- 결과는 근의 공식이다. 제곱근은 `sqrt`가 아니라 **`^(1/2)`** 로 표시된다.

### x가 아닌 변수에 대해 풀기

다른 변수에 대해 풀려면 **둘째 입력(second field)** 에 그 변수를 넣는다.

```matlab
solve(a*x^2+b*x+c, a)
```
```
ans =
-(c + b*x)/x^2
```

> **[보강]** 확인: $ax^2 + bx + c = 0 \Rightarrow a = -(bx + c)/x^2$.

## 방정식(equation) 풀기

방정식을 푸는 전략은 두 가지다.

1. **우변을 좌변에서 빼서** 방정식을 단순한 expression으로 바꾼다.
2. 방정식을 **그대로** `solve`에 넣는다. 이때 등호 연산자 **`==`** 를 써야 한다.

다음 방정식을 보자.

$$5x^2 + 6x + 3 = 10$$

첫째 전략으로는 다음이 된다.

$$5x^2 + 6x - 7 = 0$$

### 전략 1: 단순한 expression으로

```matlab
syms x
solve(5*x^2+6*x-7)
```
```
ans =
- (2*11^(1/2))/5 - 3/5
  (2*11^(1/2))/5 - 3/5
```

모든 항을 한쪽으로 모아 풀었다. MATLAB이 그 expression을 **자동으로 0과 같다고** 놓는다.

### 전략 2: equation으로

```matlab
e2 = 5*x^2+6*x+3 == 10
```
```
e2 =
5*x^2 + 6*x + 3 == 10
```
```matlab
solve(e2)
```
```
ans =
- (2*11^(1/2))/5 - 3/5
  (2*11^(1/2))/5 - 3/5
```

방정식을 **미리 정의해 이름을 붙여도** 되고, `solve(5*x^2+6*x+3 == 10)`처럼 **직접 넣어도** 된다.

### 두 방법의 결과

두 방법의 결과는 같다. 결과는 **분수를 써서 가능한 한 단순하게** 표현된다(소수로 바꾸지 않는다).

> **[보강]** 근의 공식으로 확인: $x = \dfrac{-6 \pm \sqrt{36 + 140}}{10} = \dfrac{-6 \pm 4\sqrt{11}}{10} = -\dfrac{3}{5} \pm \dfrac{2\sqrt{11}}{5}$.

### double로 변환

결과를 **double-precision floating point 숫자**로 바꾸려면 **`double`** 함수를 쓴다.

```matlab
double(ans)
```
```
ans =
   -1.9266
    0.7266
```

변환 뒤 Workspace에서 `ans`는 2×1 **double**(16 bytes)이 된다. 출력이 **들여써진** 것도 달라진 점이다.

> **[보강]** toolbox 없이 같은 근을 숫자로 구하려면 다항식 계수를 `roots`에 넣는다. R2026a에서 실행한 결과가 슬라이드와 일치한다.
>
> ```matlab
> r = roots([5 6 -7])
> ```
> ```
> r =
>    -1.9266
>     0.7266
> ```
>
> `roots`는 **다항식만**, **숫자 계수만** 다룬다. `solve`는 기호 계수(`a`, `b`, `c`)와 다항식이 아닌 식도 다룬다.

> **[보강]** `solve` 사용법 요약(슬라이드 HINT가 말하는 교재 Table 12.2는 슬라이드에 실려 있지 않다. 아래 표는 이 장 슬라이드의 예를 모은 것이다).
>
> | 호출 | 뜻 | 결과 |
> |---|---|---|
> | `solve(E1)` | expression = 0 을 기본 변수(x)로 푼다 | `3` |
> | `solve(x^2-9)` | 식을 직접 넣는다 | `-3`, `3` (2×1 sym) |
> | `solve(a*x^2+b*x+c)` | 변수가 여러 개면 x로 푼다 | 근의 공식 |
> | `solve(a*x^2+b*x+c, a)` | 둘째 입력의 변수로 푼다 | `-(c + b*x)/x^2` |
> | `solve(e2)` 또는 `solve(5*x^2+6*x+3 == 10)` | equation을 푼다 | 분수·`^(1/2)` 꼴 |
> | `double(solve(...))` | 숫자로 바꾼다 | `-1.9266`, `0.7266` |
> | `answer = solve(one,two,three)` | 연립방정식 → **structure** | `answer.x` … |
> | `[X,Y,Z] = solve(one,two,three)` | 연립방정식 → 변수 각각(알파벳 순) | `X`, `Y`, `Z` |

> **[보강]** 도입부의 식 재배열을 `solve`로 하면:
>
> ```matlab
> syms k k0 Q R T
> solve(k == k0*exp(-Q/(R*T)), T)
> ```
>
> 수학적 답은 $T = Q/(R\ln(k_0/k))$ 다. MATLAB은 `ln`을 `log`로 쓰고, `-Q/(R*log(k/k0))`처럼 **부호와 로그 안의 분수를 뒤집은 같은 식**으로 보여 줄 수 있다. 둘째 입력 `T`를 빼면 MATLAB이 기본 변수를 고르므로, x가 없는 식에서는 **풀 변수를 꼭 명시**한다.

## ⚠️ 함정

- **expression을 넣으면 `= 0`이 숨어 있다.** `solve(5*x^2+6*x+3)`은 `5x²+6x+3 = 0`을 푼다. `= 10`을 풀려면 `-7`로 옮기거나 `== 10`을 쓴다.
- **`solve` 안에 `=`를 쓴다.** `solve(5*x^2+6*x+3 = 10)`은 오류다. 방정식의 등호는 **`==`**. 괄호 안의 `=`는 R2026a에서 실행 전에 걸러진다(메시지: `'=' 연산자는 사용할 수 없습니다. 값이 같은지 비교하려면 '=='를 사용하십시오. …`).
- **결과는 symbolic이다.** `-3`, `3`처럼 숫자로 보여도 `sym`이다. 숫자 계산이나 `fprintf`에 쓰려면 `double`로 바꾼다.
- **근이 둘이면 결과는 2×1 배열이다.** 스칼라가 아니다. 하나만 쓰려면 `r = solve(...); r(1)`.
- **기본 변수는 x다.** `solve(a*x^2+b*x+c)`는 a, b, c가 아니라 **x**에 대해 푼다. 다른 변수로 풀려면 둘째 입력에 적는다.
- **제곱근 표기.** `11^(1/2)`는 √11이다. 답안에 MATLAB 출력을 쓸 때 `sqrt(11)`로 쓰지 않는다.
- **분수 그대로 나온다.** `0.7266`이 아니라 `(2*11^(1/2))/5 - 3/5`가 나온다. symbolic 계산은 **정확한 값**을 유지한다.
- > **[보강]** **옛 문법.** 오래된 자료에는 `solve('x^2-9')`, `solve('5*x^2+6*x+3=10')`처럼 **문자열**을 넣는 코드가 있다. 최신 버전에서는 문자 입력을 지원하지 않는다. `syms`로 변수를 선언하고 식을 직접 쓴다.
