# 12.2.2 Solving Systems of Equations

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. symbolic 코드는 이 PC에서 실행하지 못했다. 행렬 풀이(`A\B`)만 R2026a에서 실행했다([README](README.md#실행-환경-메모)).

- `solve` 함수는 **연립방정식**도 푼다.
- `solve`의 기본 결과는 **structure array**다(Chapter 11에서 다뤘다).
- 개별 답에 접근하려면 **dot 문법**을 쓴다.

## Structure Array 결과

```matlab
syms x y z
one = 3*x + 2*y - z == 10;
two = -x + 3*y + 2*z == 5;
three = x - y - z == -1;
answer = solve(one,two,three)
```
```
answer = 
  struct with fields:

    x: -2
    y: 5
    z: -6
```

각 답은 field 이름으로 꺼낸다.

```matlab
answer.x
```
```
ans =
-2
```
```matlab
answer.y
```
```
ans =
5
```
```matlab
answer.z
```
```
ans =
-6
```

- Workspace에서 `answer`는 **1×1 struct**(528 bytes)다.
- `answer.x`로 꺼낸 값은 **1×1 sym**이다. 숫자처럼 보여도 symbolic이다.

> **[보강]** 확인: $3(-2) + 2(5) - (-6) = 10$, $-(-2) + 3(5) + 2(-6) = 5$, $(-2) - 5 - (-6) = -1$.

## Structure Array 건너뛰기

결과를 structure array 없이 받으려면 **개별 변수에 이름을 지정**한다.

```matlab
[X,Y,Z] = solve(one,two,three)
```
```
X =
-2
Y =
5
Z =
-6
```

- 결과는 **알파벳 순서로** 대입된다. 예를 들어 식에 쓰인 변수가 `q`, `x`, `p`라면 결과는 **`p`, `q`, `x` 순서**로 반환된다.
- 이것은 **까다로운(tricky) 방법**이다. 결과가 반환되는 순서가 알파벳 순서라서 **기대한 순서와 다를 수 있다.**

> **[보강]** 순서를 직접 정하려면 풀 변수를 명시한다. 방정식과 변수를 각각 벡터로 묶는다.
>
> ```matlab
> [xs, ys, zs] = solve([one, two, three], [x, y, z])
> ```
>
> 이렇게 하면 출력이 `[x, y, z]`에 적은 순서로 나온다. 순서가 헷갈릴 때는 structure로 받아 **field 이름으로** 꺼내는 편이 가장 안전하다.

## Matrix Algebra vs. `solve` (HINT)

여러 방정식에 `solve`를 쓰는 것은 선형대수 기법과 비교해 **장점과 단점**이 모두 있다.

- 일반적으로, **행렬로 풀 수 있는 문제**라면 **행렬 풀이가 컴퓨터 시간을 덜 쓴다.**
- 그러나 선형대수는 **1차 다항식(first-order polynomials)** 으로 제한된다.
- `solve`는 **더 오래 걸릴 수 있지만**, **비선형 문제**와 **symbolic variable이 있는 문제**를 풀 수 있다.
- (교재의 Table 12.2가 `solve`의 쓰임을 정리한다. 슬라이드에는 표가 없다. [12.2.1의 요약표](12.2.1-solve.md) 참고.)

> **[보강]** 같은 연립방정식을 Chapter 10의 left division으로 푼 결과(R2026a에서 실행).
>
> ```matlab
> A = [3 2 -1; -1 3 2; 1 -1 -1];
> B = [10; 5; -1];
> X = A\B
> ```
> ```
> X =
>    -2.0000
>     5.0000
>    -6.0000
> ```
>
> | | `A\B` (Chapter 10) | `solve` (Chapter 12) |
> |---|---|---|
> | 입력 | 계수 행렬 `A`, 상수 벡터 `B` | symbolic equation들 |
> | 결과 | **double** 열 벡터 (`-2.0000`) | **struct**(field는 sym, `-2`) |
> | 속도 | 빠르다 | 느릴 수 있다 |
> | 비선형 | 불가 | 가능 |
> | 기호 계수 | 불가 | 가능 |
>
> `A\B`의 `-2.0000`은 부동소수점 계산 결과이고, `solve`의 `-2`는 정확한 값이다.

> **[보강]** 비선형 연립방정식의 예. 원 $x^2 + y^2 = 25$ 와 직선 $y = x + 1$ 의 교점:
>
> ```matlab
> syms x y
> s = solve(x^2 + y^2 == 25, y == x + 1);
> s.x
> s.y
> ```
>
> 해는 $(x, y) = (3, 4)$ 와 $(-4, -3)$ 두 쌍이다. `s.x`와 `s.y`는 각각 **2×1 sym**이고 같은 행끼리 한 쌍이다. 행렬(`A\B`)로는 풀 수 없다. (두 쌍이 나열되는 순서는 직접 실행해 확인하지 못했다.)

## ⚠️ 함정

- **기본 결과는 structure다.** `answer`를 숫자 벡터처럼 `answer(1)`로 쓰면 원하는 값이 아니다. `answer.x`처럼 **field 이름**으로 꺼낸다.
- **`[X,Y,Z] = solve(...)`의 순서는 알파벳 순이다.** 내가 쓴 변수 이름 순서가 아니다. 변수가 `q`, `x`, `p`면 `[A,B,C] = solve(...)`의 `A`는 `p`, `B`는 `q`, `C`는 `x`다.
- **출력 변수 개수.** 미지수가 3개인데 `[X,Y] = solve(...)`처럼 2개만 받으면 안 된다. 하나로 받거나(structure) 미지수 개수만큼 받는다.
- **방정식마다 `==`.** `one = 3*x + 2*y - z = 10`은 오류다.
- **세미콜론.** 슬라이드는 `one`, `two`, `three` 정의 끝에 `;`를 붙여 출력을 숨겼다. `answer = solve(...)`에는 붙이지 않아 결과가 보인다.
- **field 값도 symbolic이다.** `answer.x + 1`은 sym 계산이다. 숫자가 필요하면 `double(answer.x)`.
- **행렬 풀이가 가능하면 행렬이 빠르다.** 선형이고 숫자 계수뿐이면 `A\B`를 쓴다. `solve`는 비선형이거나 기호가 있을 때 쓴다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다.

1. 다음 연립방정식을 `solve`로 풀어 structure `s`에 저장하고, x 값과 y 값을 꺼내는 코드를 쓰시오. 결과도 쓰시오.
   $$2x + y = 7, \qquad x - y = 2$$
2. 변수 `q`, `x`, `p`를 쓰는 방정식 세 개 `e1`, `e2`, `e3`가 있다. `[A, B, C] = solve(e1, e2, e3)`를 실행하면 `A`, `B`, `C`에 각각 어느 변수의 해가 들어가는가? 이 방법이 "tricky"한 이유를 쓰시오.
3. 다음 중 `A\B`로 풀 수 **없고** `solve`로는 풀 수 있는 것을 모두 고르고 이유를 쓰시오.
   (a) $3x + 2y = 10,\ x - y = 1$ (b) $x^2 + y = 5,\ x + y = 3$ (c) $ax + y = 1,\ x - y = b$ (a, b는 기호)
