# 12.1 Symbolic Algebra — 12.1.1 Creating Symbolic Objects

> **[보강]** 이 절의 MATLAB 출력은 슬라이드(R2022a) 화면 그대로다. 이 PC의 R2026a에는 Symbolic Math Toolbox가 없어 직접 실행하지 못했다([README](README.md#실행-환경-메모)).

## 왜 기호(symbolic)로 계산하는가

- symbolic mathematics는 수학, 공학, 과학 수업에서 늘 쓴다.
- 변수에 **값을 대입하기 전에 식을 기호 상태로 먼저 정리**하는 편이 좋을 때가 많다.

언뜻 복잡해 보이는 식:

$$y = \frac{2(x+3)^2}{x^2+6x+9}$$

분자를 전개하면

$$y = \frac{2(x^2+6x+9)}{x^2+6x+9}$$

이고, 약분하면 $y = 2$ 다.

### 단순화하면 정보를 잃는다

- 이 단순화를 **할 수도 있고 하지 않을 수도 있다.** 단순화하면 **정보 일부를 잃기** 때문이다.
- $x = -3$ 이면 $x + 3 = 0$ 이 되어 $y$ 는 **정의되지 않는다(undefined)**.

$$y = \frac{2(-3+3)^2}{(-3+3)^2} = \frac{2\cdot 0}{0} = \text{undefined}$$

- MATLAB의 symbolic algebra 기능은 이 단순화를 **해 줄 수도 있고**, **분자와 분모를 따로** 다루게 해 줄 수도 있다.

> **[보강]** 단순화한 식 `y = 2`만 보면 "x = −3에서 정의되지 않는다"는 사실이 사라진다. 그래서 `simplify`를 바로 쓰지 않고 `numden`으로 분자·분모를 따로 꺼내 확인하는 방법도 배운다([12.1.2](12.1.2-manipulating-expressions.md)).
>
> 숫자 계산으로 확인한 결과(R2026a에서 실행). x = −3에서는 0/0이라 **NaN**이 나온다.
>
> ```matlab
> x = 3;  y = 2*(x+3)^2/(x^2+6*x+9)    % y = 2
> x = -3; y = 2*(x+3)^2/(x^2+6*x+9)    % y = NaN
> ```

### 식 재배열(Rearranging Equations)

또 하나 자주 하는 일은 **다른 변수에 대해 풀도록 식을 재배열**하는 것이다. 예:

$$k = k_0\, e^{-Q/(RT)}$$

$T$ 를 좌변에 오도록 정리하려면 대수 계산이 조금 필요하다. MATLAB이 대신 해 줄 수 있다.

$$T = \frac{Q}{R\,\ln(k_0/k)}$$

> **[보강]** 유도: 양변을 $k_0$ 로 나누고 자연로그를 취하면 $\ln(k/k_0) = -Q/(RT)$. 따라서 $T = -Q/(R\ln(k/k_0)) = Q/(R\ln(k_0/k))$. MATLAB으로는 `solve(k == k0*exp(-Q/(R*T)), T)` 로 푼다([12.2.1](12.2.1-solve.md)). MATLAB은 자연로그를 `log`로 적는다.

## 12.1.1 Symbolic 객체 만들기

식을 풀기 전에 먼저 **symbolic object**를 만들어야 한다. MATLAB의 symbolic object에는 여러 종류가 있다.

| 종류 | 예 | 특징 |
|---|---|---|
| **simple variable** (단순 변수) | `syms x` | 글자 하나 |
| **expression** (식) | `y = 2*(x+3)^2/(x^2+6*x+9)` | 등호(`==`)가 없다 |
| **function** (함수, expression의 한 종류) | `fun(x,z) = 2*x^2+4*z` | 값을 넣어 호출할 수 있다 |
| **equation** (방정식) | `ideal_gas_law = P*V == R*Temp*n` | `==`로 양변을 잇는다 |

### `sym` vs. `syms`

단순 symbolic variable은 두 가지 방법으로 만든다.

```matlab
x = sym('x')
```

또는

```matlab
syms x
```

- 두 방법 모두 **문자 `'x'`를 symbolic variable `x`와 같게** 만든다.
- **첫째 방법**: `sym` 명령으로 문자 `'x'`에 symbolic 데이터 타입을 주고, 대입 연산자 `=`로 메모리 위치 `x`에 대입한다. (두 단계)
- **둘째 방법**: 두 작업을 **한 문장**으로 끝낸다.
- 대부분의 프로그래머에게 둘째 방법이 더 간단하다. **`syms`를 기본으로 쓴다.**

> **[보강]** `syms`는 **여러 변수를 공백으로 구분**해 한 번에 만든다(`syms a b`, `syms x y z`). **쉼표를 쓰지 않는다.** `sym`은 함수라서 `x = sym('x')`처럼 대입해야 하고, 변수 이름과 기호 이름을 다르게 줄 수도 있다(`p = sym('x')`이면 변수 `p`에 기호 `x`가 들어간다).

### Symbolic Expressions

이미 있는 symbolic variable을 **조합**해 식 전체를 나타내는 symbolic object를 만든다.

```matlab
syms x
y = 2*(x + 3)^2/(x^2 + 6*x + 9)
```
```
y =
(2*(x + 3)^2)/(x^2 + 6*x + 9)
```

- symbolic expression을 만들 때 **array 연산자(`.*`, `./`, `.^`)를 쓸 필요가 없다.**
- Workspace를 보면 `x`와 `y` **둘 다 1×1 symbolic variable**(Class `sym`, 8 bytes)이다. `y`에는 식이 통째로 들어 있지만 크기는 1×1이다.
- MATLAB은 symbolic 결과를 **들여쓰지 않는다**. 숫자 결과는 들여써서 보여 주는 것과 다르다.

> **[보강]** 들여쓰기 차이는 "이 값이 숫자인가 symbolic인가"를 화면만 보고 구별하는 단서다.
>
> ```
> >> a = 34          >> b = sym(34)
> a =                b =
>     34             34
> ```
>
> 왼쪽(double)은 들여쓰고 오른쪽(sym)은 줄 맨 앞에 붙는다.

### Symbolic Functions

symbolic function도 비슷하게 만든다.

1. `syms`로 **함수 이름과 입력**을 정의한다.
2. 그다음 **함수 자체**를 정의한다.

```matlab
syms fun(x,z)
fun(x,z) = 2*x^2 + 4*z
```
```
fun(x, z) =
2*x^2 + 4*z
```

- 함수 이름은 `fun`이고 **입력 두 개** `x`, `z`가 필요하다.
- `x`와 `z`도 **symbolic variable**이다. Workspace에 `fun`, `x`, `z` 세 개가 생긴다(`fun`의 Class는 `symfun`, `x`·`z`는 `sym`).

### Symbolic function의 결과

- symbolic function의 입력은 **숫자**, **숫자를 저장한 변수**, **symbolic variable** 모두 가능하다.
- 결과는 **숫자처럼 보여도 언제나 symbolic**이다.

```matlab
fun(3,4)
```
```
ans =
34
```

`fun(3,4)`의 결과 `34`는 숫자처럼 보이지만 Workspace에서 `ans`는 **1×1 sym**이다. (2·3² + 4·4 = 34. 들여쓰기가 없는 것도 단서다.)

symbolic variable을 입력으로 줄 수도 있다.

```matlab
syms a b
fun(a,b)
```
```
ans =
2*a^2 + 4*b
```

`a`와 `b`는 **`syms` 명령 하나로 동시에** 만들었다.

### 한 단계로 함수 만들기 (HINT)

함수에 쓰는 symbolic variable이 **이미 정의되어 있으면** `syms` 정의 단계를 건너뛰고 함수만 정의하면 된다. 예를 들어 `x`가 이미 symbolic variable이면

```matlab
f(x) = x^2 + 2
```

가 symbolic function `f`를 **한 단계로** 만든다.

### Symbolic Equations

**방정식 전체**에도 이름을 붙일 수 있다.

```matlab
syms P V n R Temp
ideal_gas_law = P*V == R*Temp*n
```
```
ideal_gas_law =
P*V == R*Temp*n
```

- 방정식 정의에는 대입 연산자 `=`가 아니라 **`==` 연산자**를 쓴다.
- `ideal_gas_law`도 Workspace에서는 1×1 `sym`이다.

### 정리: 식 전체를 저장하는 세 가지 방법

이 절에서 식 전체를 저장하는 symbolic object를 만드는 방법 세 가지를 다뤘다.

1. **식(expression)에 이름을 붙였다.**
   ```matlab
   k = k0*exp(-Q/(R*T))
   ```
2. **함수(function)를 만들었다.** 독립 변수에 다른 값을 대입할 수 있다. 함수는 expression의 한 종류다.
   ```matlab
   fun(x,z) = 2*x^2 + 4*z
   ```
3. **방정식(equation) 전체를 정의하고 이름을 붙였다.** 방정식의 각 변(side)은 별개의 expression이고, 등호 연산자 `==`로 연결된다.
   ```matlab
   ideal_gas_law = P*V == R*Temp*n
   ```

> **[보강]** 세 가지를 구별하는 기준:
>
> | | 왼쪽 | 가운데 | 값 대입 방법 |
> |---|---|---|---|
> | expression | `k` (이름만) | `=` 한 번 | `subs(k, T, 300)` |
> | function | `fun(x,z)` (이름 + 입력) | `=` 한 번 | `fun(3,4)` |
> | equation | `ideal_gas_law` (이름만) | `=` 한 번 + **`==`** 한 번 | `subs(...)` |
>
> expression `k`에 `k(300)`처럼 쓰면 함수 호출이 아니라 **배열 인덱싱**이다. `k`는 1×1이므로 `k(300)`은 인덱스 초과 오류다. 값을 넣으려면 `subs`를 쓰거나 function으로 만든다([12.2.3](12.2.3-substitution-and-symfun.md)).

## ⚠️ 함정

- **`=`와 `==`를 혼동한다.** `=`는 **대입**(이름 붙이기), `==`는 **방정식의 등호**다. `ideal_gas_law = P*V == R*Temp*n`에는 둘 다 한 번씩 나온다. `P*V = R*Temp*n`은 오류다(R2026a 메시지: `'=' 연산자를 잘못 사용했습니다. '='를 사용하여 변수에 값을 대입하고 '=='를 사용하여 값이 같은지 비교하십시오.`).
- **숫자처럼 보여도 symbolic이다.** `fun(3,4)`의 `34`는 `sym`이다. `class(ans)`로 확인하고, 숫자가 필요하면 `double(ans)`로 바꾼다. 화면에서는 **들여쓰기가 없으면 symbolic**이다.
- **`syms` 없이 식부터 쓴다.** `y = 2*(x+3)^2`를 `syms x` 없이 실행하면 `x`가 정의되지 않았다는 오류가 난다. `x`에 숫자가 들어 있으면 오류 없이 **숫자 계산**이 되어 버린다.
- **`syms x` 뒤에 `x = 3`.** `x`가 double로 덮어써진다. 이후 식은 symbolic이 아니다. 값을 넣고 싶으면 `subs`를 쓴다.
- **`syms a, b`처럼 쉼표를 쓴다.** `syms`는 공백으로 구분한다.
- **array 연산자를 꼭 써야 한다고 생각한다.** symbolic variable은 1×1이므로 `*`, `/`, `^`로 충분하다. (`.*`를 써도 오류는 아니다.)
- **Symbolic Math Toolbox는 add-on이다.** professional 버전에서는 **선택 사항**이고 **student 버전에는 기본 포함**이다. toolbox가 없으면 `syms`부터 `정의되지 않았습니다` 오류다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다.

1. 다음을 실행한 뒤 Workspace에 생기는 변수 이름과 각 변수의 Class를 쓰시오. 그리고 `fun(1,2)`의 결과와 그 Class를 쓰시오.
   ```matlab
   syms fun(x,z)
   fun(x,z) = 2*x^2 + 4*z;
   r = fun(1,2)
   ```
2. 다음 각 줄이 만드는 것이 expression, function, equation 중 무엇인지 쓰시오. (모든 글자는 이미 `syms`로 선언했다고 가정한다.)
   ```matlab
   A = pi*r^2
   g(t) = 5*t^2 + 3
   E1 = m*c^2 == E
   ```
3. 다음 코드에서 잘못된 줄 두 곳을 찾아 고치시오.
   ```matlab
   syms P, V, n, R, T
   gas = P*V = n*R*T
   ```
