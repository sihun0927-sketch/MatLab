# 8.5.4 `switch/case`

## 언제 쓰는가

- `switch/case`는 **한 변수의 값에 따라** 여러 프로그래밍 경로 중 하나를 고를 때 흔히 쓴다.
- `if/elseif/else`와 비슷하다. **`switch/case`로 할 수 있는 일은 전부 `if/elseif/else`로도 할 수 있다.**
- 기준은 **스칼라(숫자)** 이거나 **문자열**일 수 있다.

```matlab
switch variable
    case option 1
        code to be executed if variable is equal to option 1
    case option 2
        code to be executed if variable is equal to option 2
    case option n
        code to be executed if variable is equal to option n
    otherwise
        code to be executed if variable is not equal to any of the options
end
```

> **[보강]** `if`와 달리 `case`에는 부등호가 들어가지 않는다. **같은가**만 본다.

---

## 예제 ① — 도시 이름 (string 입력)

[`example/ch08/ex0854_switch_city.m`](../../example/ch08/ex0854_switch_city.m):

```matlab
city = input("Enter the name of a city in double quotes: ")

switch city
    case "Boston"
        disp("$345")
    case "Denver"
        disp("$150")
    case "Honolulu"
        disp("Stay home and study")
    otherwise
        disp("Not on file")
end
```
```
Enter the name of a city in double quotes: "Honolulu"
city = 
    "Honolulu"
Stay home and study
```

사용자가 큰따옴표까지 쳤으므로 `city`는 string이다(7.1).

---

## 예제 ② — `input(..., "s")`로 받으면 char

사용자가 따옴표 없이 바로 글자를 치게 하는 `input`의 형식(`"s"` 옵션)을 쓰면, 받은 글자는 **character array로 저장된다**. 그래서 슬라이드는 "각 `case`의 값도 string이 아니라 **character array로** 써야 한다"고 말한다.

```matlab
city = input("Enter the name of a city: ", "s")

switch city
    case 'Boston'
        disp('$345')
    case 'Denver'
        disp('$150')
    case 'Honolulu'
        disp('Stay home and study')
    otherwise
        disp('Not on file')
end
```
```
Enter the name of a city: Denver
city =
    'Denver'
$150
```

Workspace에서 `city`는 `1×6 char`다.

> **[보강]** **R2026a에서는 char와 string을 섞어도 맞는다.** 슬라이드의 주장과 달리, `switch`는 문자열을 비교할 때 `strcmp`처럼 **내용**만 보므로 char 변수가 string `case`에, string 변수가 char `case`에 그대로 맞는다.
>
> ```matlab
> switch 'Denver'             % char
>     case "Denver"           % string
>         disp("char 'Denver' 가 string case ""Denver"" 에 맞았다")
> end
> ```
> ```
> char 'Denver' 가 string case "Denver" 에 맞았다
> ```
>
> 그래도 시험에서 "`'s'` 옵션으로 받은 값의 자료형"을 물으면 답은 **char**다(7.1). 그리고 한 프로그램 안에서는 한쪽으로 통일하는 편이 읽기 좋다.

## `otherwise`

`otherwise` 부분은 **선택**이다. 그러나 사용자가 `case` 목록에 없는 값을 입력할 가능성이 **전혀 없다고 확신할 때가 아니면** 넣는 것이 좋다. 없으면 목록 밖의 값이 들어왔을 때 아무 일도 일어나지 않고 조용히 넘어간다.

> **[보강]** `case`는 대소문자와 철자가 **정확히** 같아야 맞는다. `"denver"`는 `"Denver"`와 다르다. 사용자 입력을 받는다면 `switch lower(city)`처럼 한쪽으로 맞춘 뒤 비교하고, `case`도 소문자로 쓴다.
>
> ```
> "denver" 는 "Denver" 와 다르다 → otherwise
> ```

---

> **[보강]** 숫자 `switch`에서 **여러 값을 한 `case`에** 묶으려면 중괄호(cell array)로 쓴다. `case [1, 7]`처럼 대괄호로 쓰면 "변수가 배열 `[1 7]`과 같은가"가 되어 맞지 않는다.
>
> ```matlab
> day = 6;
> switch day
>     case {1, 7}
>         disp("주말")
>     case {2, 3, 4, 5, 6}
>         disp("평일")
>     otherwise
>         disp("1~7 이 아니다")
> end
> ```
> ```
> 평일
> ```
>
> 문자열도 `case {"Boston", "Cambridge"}`처럼 묶을 수 있다. C와 달리 MATLAB의 `switch`는 **fall-through가 없다**. 맞은 `case` 하나만 실행하고 끝나므로 `break`가 필요 없다.

---

## ⚠️ 함정

- **`case`에는 부등호를 쓸 수 없다.** `case age < 18`은 "변수가 `age < 18`의 결과(0 또는 1)와 같은가"가 되어 엉뚱하게 동작한다. 범위는 `if/elseif`.
- **여러 값은 `{ }`로 묶는다.** `[ ]`로 묶으면 맞지 않는다.
- **대소문자·공백까지 정확히 같아야 한다.** `"Denver "`(끝에 공백)도 다르다. `strtrim`, `lower`로 정리한 뒤 비교.
- **`otherwise`가 없으면 목록 밖 입력은 조용히 무시된다.** 오류도 메시지도 없다.
- **`input(..., "s")`의 결과는 char.** R2026a의 `switch`는 char/string을 섞어도 맞지만, `==`로 비교하면 char는 길이가 다를 때 오류가 난다.
- **fall-through가 없다.** C의 습관대로 `break`를 쓰면 `switch`가 아니라 바깥 loop를 빠져나간다.

1. 월(1~12)을 받아 그 달의 날짜 수를 출력하시오. 31일인 달과 30일인 달은 각각 `case` 하나로 묶고, 2월은 윤년(4로 나뉘고, 100으로 나뉘면 400으로도 나뉘어야 함)을 판정하시오. 1~12가 아니면 `NaN`.
2. 길이 3을 `"km"`, `"mi"`, `"ft"` 단위에서 미터로 바꾸는 `switch`를 쓰시오. 단위가 `'km'`(char), `"MI"`, `'Ft'`, `"yard"`처럼 섞여 들어와도 동작하게 하고, 모르는 단위는 `error`로 알리시오.
