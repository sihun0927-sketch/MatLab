# 8.5 Selection Structures / 8.5.1 Simple `if`

## 8.5 들어가기 — `if`는 언제 필요한가

- **대부분의 경우** `find`나 logical indexing을 `if` 대신 쓸 수 있고, **그렇게 해야 한다**.
- 그러나 어떤 상황에서는 `if`가 꼭 필요하다.
- `if` 구조는 세 가지다.
  - simple `if` (8.5.1)
  - `if/else` (8.5.2)
  - `if/elseif/else` (8.5.3)
- 셋 다 배열에도 쓸 수 있지만 **스칼라에 쓸 때 가장 쓸모 있다**.

> **[보강]** "언제 `if`가 꼭 필요한가"의 기준: **실행할 명령 자체가 달라질 때**다. 값만 다르게 고르는 일(이 원소는 "Sick", 저 원소는 "Well")은 logical indexing으로 충분하다. 반면 "입력이 잘못됐으면 계산을 하지 말고 메시지를 띄운다", "사용자가 고른 메뉴에 따라 다른 계산을 한다"처럼 **실행 경로**가 갈리면 `if`나 `switch`를 쓴다.

## 8.5.1 Simple `if`

```matlab
if comparison
    statements
end
```

- comparison(논리식)이 **참**이면 `if`와 `end` 사이의 statements를 실행한다.
- **거짓**이면 곧바로 `end` 다음 문장으로 건너뛴다.
- `if` 안의 문장은 읽기 쉽게 **들여쓰기**하는 것이 좋은 습관이다.
- MATLAB은 공백을 무시한다. 들여쓰기를 하든 안 하든 프로그램은 똑같이 돈다.

> **[보강]** MATLAB 편집기는 `if`를 치고 Enter를 누르면 알아서 들여쓰고, `end`를 치면 내어 쓴다. 엉킨 들여쓰기는 `Ctrl+I`(Smart Indent)로 한 번에 정리된다.

### 예제 — `G < 50`

[`example/ch08/ex0851_simple_if.m`](../../example/ch08/ex0851_simple_if.m):

```matlab
G = input("Enter a value for G ");

if G < 50
    disp("G is a small value equal to:")
    disp(G);
end
```

**5를 넣으면** — `G < 50`이 참이므로 `if` 안의 두 줄이 실행된다.

```
Enter a value for G 5
G is a small value equal to:
     5
```

**70을 넣으면** — 비교가 거짓이므로 `if` 안을 건너뛴다. command window에 아무 메시지도 나오지 않는다.

```
Enter a value for G 70
```

> **[보강]** `input`은 `-batch`에서 쓸 수 없으므로 예제 파일은 `usejava('desktop')`으로 갈라 배치 실행에서는 `G = 5`를 직접 넣는다(7.1). 데스크톱에서 돌리면 진짜로 묻는다.

### 배열을 넣으면?

**`[5 25 75]`를 넣으면** — 이번에도 아무것도 출력되지 않는다.

```
Enter a value for G [5 25 75]
```

배열 비교는 **모든 원소가 참일 때만** 참이다. 세 번째 원소 75가 50보다 크므로 비교 전체가 거짓이 되고, `if` 안은 건너뛴다.

```matlab
G = [5 25 75];
G < 50                  % 1 1 0
all(G < 50)             % 0 → if 는 이 값을 본다
any(G < 50)             % 1 → 하나라도 작으면 실행하고 싶다면 any 를 써야 한다
```

같은 `if`에 입력 세 개를 넣어 비교하면 이렇다.

```
G = 5          → if 안을 실행했다
G = 70         → 건너뛰었다
G = [5 25 75]  → 건너뛰었다
```

> **[보강]** 배열 조건에 `if`를 쓰면 의도가 모호해진다. "전부"를 원하면 `if all(...)`, "하나라도"를 원하면 `if any(...)`라고 **명시**하는 편이 읽는 사람에게 친절하다. 원소마다 다른 일을 하려면 `if`가 아니라 logical indexing(8.4)이다.

---

## ⚠️ 함정

- **배열 조건은 "모든 원소가 참"일 때만 참.** `if [5 25 75] < 50`은 거짓이다. 하나라도 거짓이면 통째로 건너뛴다.
- **빈 배열은 거짓.** `if []`는 아무것도 실행하지 않는다. `find`가 빈 배열을 돌려준 결과로 `if`를 쓰면 조용히 건너뛴다.
- **`NaN`과 `""`는 참/거짓으로 바꿀 수 없다.** `if NaN`, `if ""`는 오류다(R2026a: `NaN 값을 논리형으로 변환할 수 없습니다.`).
- **글자도 참이 된다.** `if 'abc'`는 각 글자의 코드가 0이 아니므로 참이다. `if x == 'yes'`처럼 char를 `==`로 비교하면 길이가 다를 때 오류가 난다. 문자열 비교는 `strcmp` 또는 string의 `==`.
- **`end`를 빼먹으면** 파일 끝까지가 `if` 안으로 잡히거나 구문 오류가 난다. 편집기의 코드 접기 표시(`⊟`)로 짝을 확인한다.
- **들여쓰기는 의미가 없다.** Python과 달리 MATLAB은 `end`가 블록을 닫는다. 들여쓰기만 맞추고 `end` 위치가 틀리면 그대로 틀린 프로그램이다.
