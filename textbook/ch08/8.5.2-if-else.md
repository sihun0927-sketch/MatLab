# 8.5.2 `if/else`

## simple `if`와 무엇이 다른가

- simple `if`는
  - 조건이 참이면 문장들을 **실행**하고,
  - 거짓이면 그 문장들을 **건너뛴다**.
- `else` 절이 있으면
  - 비교가 참이면 한 묶음의 문장을 실행하고,
  - 거짓이면 **다른 묶음**을 **실행**한다.
- **`else` 줄에는 비교식이 없다!** `else` 아래는 `if`의 비교가 거짓일 때만 실행된다.

```matlab
if comparison
    statements (참일 때)
else
    statements (거짓일 때)
end
```

---

## 예제 — 음수에는 `log`를 쓰지 않는다

[`example/ch08/ex0852_if_else.m`](../../example/ch08/ex0852_if_else.m):

```matlab
x = input("Enter a value of x: ")

if x > 0
    y = log(x)
else
    disp("The input to the log function must be positive")
end
```

**5를 넣으면** — 비교가 참이므로 `if`와 `else` 사이(`y = log(x)`)가 실행되고 `else` 쪽은 건너뛴다.

```
Enter a value of x: 5
x =
     5
y =
    1.6094
```

**−1을 넣으면** — 비교가 거짓이므로 `log` 줄은 건너뛰고 `else`와 `end` 사이가 실행된다.

```
Enter a value of x: -1
x =
    -1
The input to the log function must be positive
```

**`else` 줄에는 절대 비교식을 쓰지 않는다.**

> **[보강]** 쓰면 어떻게 되는가? R2026a는 오류를 내지 않는다. `else x <= 0`의 `x <= 0`을 **조건이 아니라 `else` 블록의 첫 문장**으로 읽어 실행한다. 그래서 `x = -1`이면 `ans = logical 1`이 찍힌 뒤 `else` 블록이 실행되고, `x = 5`면 조건과 무관하게 `if` 쪽만 실행된다. 결과가 "맞아 보여서" 더 위험하다. Code Analyzer가 "가독성을 높이기 위해 이 명령문 앞에 새 줄, 세미콜론, 쉼표 중 하나를 삽입해 보십시오"라는 경고로만 알려 준다.

### 배열을 넣으면?

슬라이드의 질문: "`x`에 음수가 섞인 배열을 넣으면 어떻게 될까?"

```matlab
x = [5 -1 2];
if x > 0
    y = log(x)
else
    disp("x = " + mat2str(x) + " → else 실행 (모든 원소가 양수가 아니다)")
end
```
```
x = [5 -1 2] → else 실행 (모든 원소가 양수가 아니다)
```

8.5.1과 같은 규칙이다. **원소 하나라도 거짓이면 비교 전체가 거짓**이므로, 양수인 5와 2도 `log`를 계산받지 못하고 `else`로 간다.

> **[보강]** 양수인 원소만 `log`를 구하려면 `if`가 아니라 logical indexing을 쓴다.
>
> ```matlab
> y = NaN(size(x));
> ok = x > 0;
> y(ok) = log(x(ok))          % 1.6094  NaN  0.6931
> ```

> **[보강]** 검사하지 않으면 어떻게 되는가? MATLAB의 `log`는 음수에도 **오류를 내지 않고 복소수**를 돌려준다. `log(-1)`은 `0 + 3.1416i`다. 그래서 이 `if/else`는 "오류를 막는" 코드가 아니라 "엉뚱한 복소수 결과를 막는" 코드다. `sqrt(-9)`도 `0 + 3i`다.

## HINT — `beep`

MATLAB에는 컴퓨터가 "삑" 소리를 내게 하는 `beep` 함수가 있다. 사용자에게 오류를 알릴 때 쓸 수 있다. 예를 들어 `if/else`의 오류 메시지 쪽에 넣는다.

[`example/ch08/ex0852_beep_error.m`](../../example/ch08/ex0852_beep_error.m):

```matlab
x = -3;
if x > 0
    y = log(x);
else
    beep
    disp("The input to the log function must be positive")
end
disp("beep 다음 줄도 실행된다")
```

이 코드는 `error` 함수를 흉내 낸다. 차이는 하나다. **`error`는 프로그램을 중단시키고**, 위 코드는 command window에 메시지만 보내고 **계속 간다**.

```matlab
if x > 0
    y = log(x);
else
    error("The input to the log function must be positive")
end
disp("이 줄은 실행되지 않는다")
```

슬라이드는 "두 코드를 모두 MATLAB에서 돌려 동작을 관찰해 보라"고 한다.

| | 메시지 | 소리 | 뒤의 코드 |
|---|---|---|---|
| `beep` + `disp` | 검은 글씨 | 남 | **계속 실행** |
| `error` | 빨간 글씨 + "오류:" | 남(설정에 따라) | **중단** |

> **[보강]** `beep`은 `-batch`에서도 오류 없이 실행된다(소리만 나지 않을 수 있다). `beep off`로 소리를 끌 수 있다. `error`로 멈춘 프로그램은 `try/catch`로 잡을 수 있다(7.5). 예제 파일은 `error` 쪽을 `try`로 감싸 다음 줄까지 실행되게 했다.

## ⚠️ 함정

- **`else` 줄에 조건을 쓰지 말 것.** `else x < 0`은 조건이 아니라 `else` 블록의 첫 문장이 된다. 조건이 필요하면 `elseif`(8.5.3).
- **배열은 "전부 참"일 때만 `if` 쪽.** 원소 하나만 음수여도 모든 원소가 `else`로 간다.
- **`log`, `sqrt`는 음수에 오류를 내지 않는다.** 복소수가 조용히 나온다. 검사는 직접 해야 한다.
- **`beep` + `disp`는 프로그램을 멈추지 않는다.** 뒤의 계산이 `y`를 쓴다면 `y`가 정의되지 않아 엉뚱한 곳에서 오류가 난다. 멈춰야 하면 `error`.
- **`if`와 `else` 양쪽에서 같은 변수를 정의해 두자.** 한쪽에서만 `y`를 만들면 다른 쪽을 탄 뒤 `y`를 쓸 때 "인식할 수 없는 함수 또는 변수" 오류가 난다.
