# 13.6 Solving Differential Equations Numerically

> **[보강]** 이 절의 코드와 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 기준이다. 이 장은 R2026a에서 다시 실행하지 않았다([README](README.md#실행-환경-메모)). 슬라이드에 없는 수치는 SciPy로 계산했고 그때마다 밝혔다.

- MATLAB에는 다음 꼴의 **상미분방정식(ordinary differential equation, ODE)** 을 푸는 함수군이 있다.

$$\frac{dy}{dt} = f(t, y)$$

- **1계 미분방정식의 연립(system)** 도 이 함수들로 풀 수 있다.
- **고계(higher-order)** 미분방정식도 풀 수 있지만, **1계 미분방정식의 연립으로 다시 써야(reformulate)** 한다.
- solver는 크게 **두 부류**다.
  - **초깃값 문제(initial value problem)** 를 푸는 것
  - 일반적인 **경계값 문제(boundary value problem)** 를 푸는 것 → [13.6.4](13.6.4-boundary-value-problems.md)

## Initial Value Solvers

- 대부분의 미분방정식 solver는 **초기 시각에서의 해의 값**을 알아야 한다(시간이 독립 변수라고 가정).
- 모든 초깃값 문제를 **같은 기법**으로 풀 수 있는 것은 아니므로, MATLAB에는 **다양한** 미분방정식 solver가 있다.
- 이 solver들은 **모두 형식(format)이 같다.**
- 그래서 **함수 이름만 바꾸면** 다른 기법을 쉽게 시도할 수 있다.

### MATLAB ODE Solvers

| Solver | Problem Type |
|---|---|
| `ode45` | Nonstiff differential equations |
| `ode23` | Nonstiff differential equations |
| `ode78` | Nonstiff differential equations |
| `ode89` | Nonstiff differential equations |
| `ode113` | Nonstiff differential equations |
| `ode15s` | Stiff differential equations |
| `ode23s` | Stiff differential equations |
| `ode23t` | Moderately stiff differential equations |
| `ode23tb` | Stiff differential equations |
| `ode15i` | Fully implicit differential equations |

> **[보강]** **stiff**(경직)한 문제는 해 안에 아주 빠르게 변하는 성분과 느리게 변하는 성분이 섞여 있어, nonstiff solver로는 step을 극히 작게 잡아야 해서 매우 느려지는 문제다. `ode45`가 너무 오래 걸리면 `ode15s`로 바꿔 본다. 외우는 요령: 이름 끝에 **s, t, tb**가 붙으면 stiff 계열, `ode15i`의 **i**는 implicit.

### ODE solvers

- 각 solver에는 **최소한 다음 세 입력**이 필요하다.
  1. 미분방정식에 대한 **function handle**. 독립 변수(t)와 종속 변수(y)로 표현한다. **t와 y 둘 다, 이 순서로** 지정해야 한다. **식에 나타나지 않더라도** 그렇다.
  2. 관심 있는 **시간 구간(time span)**. 배열로 저장한다.
  3. 연립의 **각 방정식에 대한 초기 조건(initial condition)**. 배열로 저장한다.
- solver는 모두 **t 값과 y 값의 배열**을 돌려준다.
- 결과 배열 `[t,y]`를 **지정하지 않으면**, 결과의 **그래프**를 그린다.
- 아래 예제는 디버깅 기능으로 코드를 **한 줄씩 실행(stepping)** 하며 보인 것이다.

풀 문제:

$$\frac{dy}{dt} = 2t, \qquad y(-1) = 1, \qquad -1 \le t \le 1$$

```matlab
clear,clc
dydt = @(t,y) 2*t;
tspan = [-1,1];
y0 = 1;
[t,y] = ode45(dydt,tspan,y0)
ode45(dydt,tspan,y0)
```

#### First define a function for the ODE in terms of t and y

```matlab
dydt = @(t,y) 2*t;
```

이 함수는 **t에만 의존**하지만, 정의에 **t와 y가 모두** 변수로 들어 있다. 뒤에서 ode solver가 그렇게 **요구**하기 때문이다. (Workspace: `dydt` — `1x1 function_handle`)

#### Next define a time span

```matlab
tspan = [-1,1];
```

time span은 **값이 둘인 배열**이다. ODE를 풀 구간의 **초기 시각과 최종 시각**이다(시간이 독립 변수라고 가정). (Workspace: `tspan` — `1x2 double`)

#### Define the initial condition

```matlab
y0 = 1;
```

초기 조건은 **초기 시각에서의 종속 변수 값**이다. 이 경우 초기 시각이 −1이므로 **y(−1) = 1**이다.

#### Implement the solver

```matlab
[t,y] = ode45(dydt,tspan,y0)
```

방정식이나 연립방정식이 어떻게 거동하는지 **모르겠다면, 처음에는 `ode45`나 `ode23`** 을 시도한다. 둘 다 **Runge-Kutta** 기법을 쓴다.

#### Results

`t`와 `y`를 지정하면 결과는 독립 변수와 종속 변수의 **벡터**다. Workspace에 `t`와 `y`가 각각 **`45x1 double`** 로 생긴다.

```
t =
   -1.0000
   -0.9749
     ...
   -0.7995
   -0.7495
   -0.6995
   -0.6495
     ...
```

> **[보강]** 읽을 점:
>
> - 결과는 **열벡터**다(45×1). `tspan`이나 `y0`를 행으로 줘도 그렇다.
> - `tspan`에 값을 **둘만** 줬는데 점이 45개다. solver가 오차를 보고 **step 크기를 스스로** 정한다. 그래서 t의 간격이 일정하지 않다(처음 −1 → −0.9749는 0.025, 뒤에서는 0.05).
> - 해석적 해: $y = t^2 + C$, $y(-1) = 1$ 에서 $C = 0$, 즉 $y = t^2$. 그래프가 포물선인 이유다.

#### Automatic Figure Creation

```matlab
ode45(dydt,tspan,y0)
```

출력을 지정하지 **않고** `ode45`를 실행하면 미분방정식의 해를 나타내는 **figure**가 만들어진다. 앞 줄에서 만든 `t`, `y` 배열을 `plot`으로 그려도 **같은 그래프**가 나온다. 슬라이드 그림: (−1, 1)에서 시작해 (0, 0)으로 내려갔다가 (1, 1)로 올라가는 포물선, 각 계산점에 ○ 표시.

> **[보강]** `plot(t,y,"-o")`가 자동 그래프와 같은 모양이다.

## 13.6.1 Function Handle Input

- 위 예제에서 anonymous function의 이름은 **function handle**로 저장했다.
- 미분방정식의 정의는 **별도의 M-file이나 MLX-file**로 저장할 수도 있고, **프로그램의 끝**에 저장할 수도 있다.
  - 이 경우 **`@` 기호**로 그 함수에 대한 function handle을 정의해야 한다.
- **연립방정식**은 별도의 함수로 저장하고 function handle을 쓰는 편이 대개 더 쉽다.
- 연립방정식을 나타내는 함수의 출력은 **1계 도함수 값들의 열벡터(column vector)** 여야 한다.

### Systems of Equations

- x와 y가 종속 변수, t가 독립 변수인 미분방정식 2개의 연립을 생각하자.

$$\frac{dy}{dt} = x, \qquad \frac{dx}{dt} = -y$$

- 종속 변수를 $y_1$, $y_2$ 로 써서 똑같이 나타낼 수 있다.

$$\frac{dy_1}{dt} = y_2, \qquad \frac{dy_2}{dt} = -y_1$$

- ode solver 함수는 종속 변수에 대해 **입력 하나**를 기대하지만 그것이 **배열**일 수 있다. 이 경우 MATLAB 함수 안에서 `y(1)`, `y(2)`로 정의된 배열이 된다.

### Solving a System of Two ODE's

```matlab
clear,clc,clf

ode45(@twofuns,[-1,1],[1,1])

function dy=twofuns(t,y)
dy(1) = y(2);
dy(2) = -y(1);
dy=[dy(1); dy(2)];
end
```

- 연립방정식은 **프로그램의 끝**에 정의했다.
- 함수는 **`@` 기호로 지정한 function handle**로 호출한다.
- **`dy`가 열벡터**로 정의된 것에 주목한다(`dy=[dy(1); dy(2)];`).

### Two initial conditions are required

- 연립에 방정식이 **둘**이므로 초기 조건도 **둘**(`[1,1]`) 필요하다.
- solver의 출력을 정의하지 않았으므로 결과는 **그래프**다.

### Two plot lines are generated

그래프에 선이 **둘** 생긴다. **`y(1)` vs time**: 1에서 시작해 약 1.41까지 올라갔다가 0.49로 내려온다. **`y(2)` vs time**: 1에서 시작해 −1.33까지 계속 내려간다.

원래 연립방정식의 표기로 `y(1)`은 **y**, `y(2)`는 **x**에 해당한다.

> **[보강]** 출력을 받으면 `y`는 **열이 둘인 행렬**이다. 첫째 열이 `y(1)`, 둘째 열이 `y(2)`.
>
> ```matlab
> [t,y] = ode45(@twofuns,[-1,1],[1,1]);
> size(y)                 % [n, 2]
> plot(t, y(:,1), t, y(:,2))
> legend("y(1)", "y(2)")
> ```
>
> 최종값(SciPy로 계산): `y(end,:)` ≈ `0.4932 -1.3254`. 해석적 해 $y_1(1) = \cos 2 + \sin 2$, $y_2(1) = \cos 2 - \sin 2$ 와 일치한다.

### M-files and MLX-files

- 함수를 current directory의 **M-file이나 MLX-file**로 저장해도 **같은 구문**을 쓴다.
- 함수에 대한 function handle을 **변수에 배정**해서 쓸 수도 있다. 예:

```matlab
some_fun = @twofuns
```

> **[보강]** 그 뒤에는 `ode45(some_fun,[-1,1],[1,1])`처럼 **`@` 없이** 쓴다. `some_fun`이 이미 handle이기 때문이다. anonymous function `dydt = @(t,y) 2*t;`를 `ode45(dydt,…)`로 넘길 때 `@`를 다시 붙이지 않는 것과 같다.

## 13.6.3 Solving Higher-Order Differential Equations

- ode 계열 함수(`ode45`, `ode23` 등)는 **1계 미분방정식 하나** 또는 **1계 미분방정식의 연립**을 풀 수 있다.
- **고계** 미분방정식도, 간단한 **치환(substitution)** 으로 1계 미분방정식의 연립으로 바꾸면 풀 수 있다.
- 간단한 2계 미분방정식으로 시작한다.

$$\frac{d^2y}{dt^2} + \frac{dy}{dt} = y + t$$

### Reformulating a Second Order Differential Equation

- y를 $y_1$ 로 이름을 바꾸고 새 변수 $y_2$ 를 도입해 연립방정식으로 다시 쓴다.

$$y_2 = \frac{dy_1}{dt}$$

- 그러면 다음이 성립한다.

$$\frac{dy_2}{dt} = \frac{d^2y_1}{dt^2}$$

### One Second Order Equation Becomes Two First Order Equations

- 원래 식에 대입하면

$$\frac{d^2y}{dt^2} + \frac{dy}{dt} = y + t \quad\longrightarrow\quad \frac{dy_2}{dt} + \frac{dy_1}{dt} = y_1 + t$$

- 원래 방정식 하나를 **방정식 둘**로 바꾼 것이다.

$$y_2 = \frac{dy_1}{dt} \qquad\text{and}\qquad \frac{dy_2}{dt} + \frac{dy_1}{dt} = y_1 + t$$

- 정리하면 ode solver에 쓸 수 있는 연립방정식이 된다.

$$\frac{dy_1}{dt} = y_2 \qquad\text{and}\qquad \frac{dy_2}{dt} = y_1 + t - \frac{dy_1}{dt}$$

### Results from the Evaluation of a Second Order Differential Equation

```matlab
clear,clc
ode45(@twoeq,[-1,1],[0,0])

function dydt = twoeq(t,y)
dydt(1) = y(2);
dydt(2) = y(1) + t - dydt(1);
dydt = dydt';
end
```

- 연립에 방정식이 둘이므로 초기 조건이 **둘(0과 0)** 필요하다. 즉 $y(-1) = 0$, $y'(-1) = 0$.
- solver의 출력을 정의하지 않았으므로 결과는 **그래프**다.
- time span은 **−1부터 +1**까지다.

슬라이드 그림: 두 선 모두 0에서 시작한다. `y(1)`(y)은 계속 내려가 t = 1에서 약 −0.48, `y(2)`(dy/dt)는 약 −0.35까지 내려갔다가 다시 올라와 t = 1에서 0 근처다.

> **[보강]** 코드 읽기:
>
> - `dydt(1) = y(2);` 다음 `dydt(2) = …`로 원소를 하나씩 채우면 `dydt`는 **행벡터**가 된다. 그래서 마지막 줄 `dydt = dydt';`로 **전치**해 열벡터로 만든다. 앞 예제의 `dy=[dy(1); dy(2)];`와 방법만 다르고 목적은 같다.
> - `dydt(2)` 식의 `- dydt(1)`은 `- y(2)`와 같다. 바로 윗줄에서 `dydt(1) = y(2)`로 정했기 때문이다.
> - 초기 조건 `[0,0]`의 순서는 `[y, dy/dt]`, 즉 `y` 배열의 순서와 같다.

### A more complicated example

- **5계** 미분방정식을 생각하자.

$$a\frac{d^5y}{dt^5} + b\frac{d^4y}{dt^4} + c\frac{d^3y}{dt^3} + d\frac{d^2y}{dt^2} + e\frac{dy}{dt} + f = 0$$

- 변수 y와 **모든 도함수**로 이루어진 배열 `y`를 만든다.

| 배열 원소 | 뜻 |
|---|---|
| `y(1)` | $y$ |
| `y(2)` | $dy/dt$ |
| `y(3)` | $d^2y/dt^2$ |
| `y(4)` | $d^3y/dt^3$ |
| `y(5)` | $d^4y/dt^4$ |

### Create a dydt array

- 이제 `y` 배열을 바탕으로, **앞의 4개 방정식**에 대해 새 배열 `dydt`를 정의하는 함수를 만든다.
- `dydt(5)`는 **원래 방정식을 최고계 도함수에 대해 푼다.**

$$\frac{d^5y}{dt^5} = \frac{-b\dfrac{d^4y}{dt^4} - c\dfrac{d^3y}{dt^3} - d\dfrac{d^2y}{dt^2} - e\dfrac{dy}{dt} - f}{a}$$

| `dydt` 원소 | 값 |
|---|---|
| `dydt(1)` | `y(2)` |
| `dydt(2)` | `y(3)` |
| `dydt(3)` | `y(4)` |
| `dydt(4)` | `y(5)` |
| `dydt(5)` | `(-b*y(5) - c*y(4) - d*y(3) - e*y(2) - f)/a` |

### A 5th order ODE decomposes to 5 First order Differential Equations

```matlab
clear,clc
tspan = [0,10];
init_cond = [0,1,5,0,0];
ode45(@fiveth_order,tspan,init_cond)

function dydt = fiveth_order(t,y)
a = 1; b=1; c=1.5; d=12; e=5; f=3;
dydt(1) = y(2);
dydt(2) = y(3);
dydt(3) = y(4);
dydt(4) = y(5);
dydt(5) = (-b*y(5) - c*y(4) - d*y(3) -e*y(2)-f)/a;
dydt = dydt'; % converts the result to a column
end
```

- **초기 조건이 5개** 필요하다(`init_cond = [0,1,5,0,0]`: $y(0)=0$, $y'(0)=1$, $y''(0)=5$, $y'''(0)=0$, $y^{(4)}(0)=0$).
- **결과는 열벡터여야 한다.**

### Five Plot Lines are Generated

- 5계 미분방정식이 1계 미분방정식 **5개의 연립**으로 분해되므로 결과 그래프에 **선이 5개** 나온다(슬라이드 그림: t = 0~10, 세로축 ×10⁴ 규모로 진동이 커진다). 각 선은 다음에 해당한다.
  - $y$
  - $dy/dt$
  - $d^2y/dt^2$
  - $d^3y/dt^3$
  - $d^4y/dt^4$

> **[보강]** 원래 구하려던 해 y만 그리려면 출력을 받아 **첫째 열**만 쓴다.
>
> ```matlab
> [t,y] = ode45(@fiveth_order,tspan,init_cond);
> plot(t, y(:,1))
> ```

### The function can also be stored as an anonymous function

```matlab
a = 1; b=2; c=1.5; d=12; e=5; f=3;
dydt = @(t,y) [y(2);
    y(3);
    y(4);
    y(5);
    (-b*y(5) - c*y(4) - d*y(3) -e*y(2)-f)/a];
```

함수가 **원소 5개의 배열**을 돌려주고, **열벡터로 구성**된 것에 주목한다(원소 사이가 **세미콜론**).

> **[보강]** 이 슬라이드에서는 `b=2`다(앞의 함수 버전은 `b=1`). anonymous function은 **정의하는 순간**의 `a`~`f` 값을 저장한다. 정의한 뒤에 `b`를 바꿔도 `dydt`는 바뀌지 않는다. 계수는 handle보다 **먼저** 정의해야 한다.

> **[보강]** **n계 ODE를 1계 연립으로 바꾸는 절차**(시험 서술형 단골):
>
> 1. $y_1 = y$, $y_2 = y'$, …, $y_n = y^{(n-1)}$ 로 둔다.
> 2. 앞의 n − 1개 식은 자동이다: $y_1' = y_2$, $y_2' = y_3$, …, $y_{n-1}' = y_n$.
> 3. 마지막 식 $y_n'$ 은 **원래 방정식을 최고계 도함수에 대해 풀어서** 쓴다.
> 4. 함수는 `[y(2); y(3); …; 마지막 식]`의 **열벡터**를 돌려준다.
> 5. 초기 조건은 **n개**: `[y(t0), y'(t0), …]`.

> **[보강]** R2023b부터는 `ode` 객체로도 풀 수 있다(슬라이드 범위 밖, 미실행).
>
> ```matlab
> F = ode(ODEFcn=@(t,y) 2*t, InitialTime=-1, InitialValue=1);
> S = solve(F,-1,1);
> plot(S.Time, S.Solution, "-o")
> ```
>
> 시험 범위는 슬라이드의 `ode45(fun,tspan,y0)` 구문이다.

## ⚠️ 함정

- **함수는 반드시 `(t,y)` 두 입력, 이 순서.** 식에 y가 없어도 `@(t,y) 2*t`다. `@(t) 2*t`는 solver가 입력 2개로 호출하므로 "입력 인수가 너무 많다"는 오류가 난다. `@(y,t)`로 순서를 바꾸면 오류 없이 **다른 방정식**을 푼다.
- **연립의 함수 출력은 열벡터.** `[y(2), -y(1)]`(쉼표, 행벡터)는 "열벡터를 반환해야 한다"는 오류다. `[y(2); -y(1)]` 또는 마지막에 `dydt = dydt';`.
- **초기 조건의 개수 = 방정식의 개수.** 2계 → 2개, 5계 → 5개. 개수가 다르면 차원 불일치 오류다.
- **초기 조건은 `tspan(1)`에서의 값이다.** `tspan = [-1,1]`, `y0 = 1`은 y(0) = 1이 아니라 **y(−1) = 1**이다.
- **이름이 있는 함수에는 `@`를 붙인다.** `ode45(twofuns,…)`는 `twofuns`를 인수 없이 **호출**하려다 오류가 난다. `ode45(@twofuns,…)`. 반대로 이미 handle인 변수(`dydt`, `some_fun`)에는 `@`를 붙이지 않는다.
- **출력을 안 받으면 그래프, 받으면 배열.** `ode45(…)`는 figure를 만들고 값은 주지 않는다. 값이 필요하면 `[t,y] = ode45(…)`.
- **연립의 `y`는 행렬이다.** `[t,y] = ode45(@twofuns,…)`에서 `y`는 n×2. `y(1)`은 "첫 번째 변수 전체"가 아니라 **원소 하나**다. 변수별로는 `y(:,1)`, `y(:,2)`.
- **함수 안의 `y(1)`과 결과의 `y(:,1)`은 다르다.** 함수 안에서 `y`는 한 시각의 상태(원소 n개), 결과에서 `y`는 모든 시각의 상태(행이 시각).
- **결과 t의 간격은 일정하지 않다.** 원하는 시각에서의 값이 필요하면 `tspan = -1:0.1:1`처럼 **3개 이상의 값**을 주면 그 시각들에서만 결과를 돌려준다.
- **스크립트 끝의 local function.** 책의 규칙은 "함수 정의는 스크립트의 맨 끝"이다. 그리고 함수 이름은 스크립트 파일 이름과 달라야 한다.
- **`clear` 뒤에 계수를 정의하지 않고 anonymous function을 만들면 오류는 실행 때 난다.** `a`~`f`가 없는 상태로 handle을 만들면 정의는 되지만 호출할 때 정의되지 않은 변수 오류가 난다.
- **symbolic `dsolve`와 구분.** `dsolve`는 해의 **식**을, `ode45`는 해의 **숫자 표**를 준다. `ode45`에는 반드시 초기 조건과 구간이 필요하다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다.

1. $\dfrac{dy}{dt} = -2y$, $y(0) = 5$ 를 $0 \le t \le 2$ 에서 `ode45`로 풀어 `t`, `y`를 얻고 그래프를 그리는 코드를 쓰시오. 해석적 해 $y = 5e^{-2t}$ 로 y(2)의 참값을 구하시오.
2. $\dfrac{d^2y}{dt^2} + 3\dfrac{dy}{dt} + 2y = 0$, $y(0) = 1$, $y'(0) = 0$ 을 $0 \le t \le 2$ 에서 푼다.
   - (a) 1계 연립방정식으로 다시 쓰시오.
   - (b) 스크립트 끝의 local function을 쓰는 코드를 쓰시오. y만 그래프로 그릴 것.
   - (c) 같은 함수를 anonymous function으로 쓰시오.
3. 다음 각 코드의 문제점을 쓰시오.
   ```matlab
   % (a)
   ode45(@(t) 2*t, [-1,1], 1)
   % (b)
   f = @(t,y) [y(2), -y(1)];
   ode45(f, [-1,1], [1,1])
   % (c)
   ode45(@twoeq, [-1,1], 0)      % twoeq는 본문의 2계 방정식 함수
   ```
