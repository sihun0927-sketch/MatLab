- **초깃값 문제(initial value problem)** 는 일반적인 **경계값 문제(boundary value problem)** 범주의 **특수한 경우**다.
  - 초깃값 문제에서는 종속 변수의 **시작 값**을 안다.
- 더 일반적인 경계값 문제에서는 종속 변수의 값을 **어떤 점**에서 알고 있으며, 그 점이 **꼭 초기 점은 아니다.**

> **[보강]** 앞 절의 2계 방정식으로 비교하면:
>
> | | 초깃값 문제 ([13.6.3](13.6-solving-odes.md#1363-solving-higher-order-differential-equations)) | 경계값 문제 (이 절) |
> |---|---|---|
> | 아는 것 | $y(-1) = 0$, $y'(-1) = 0$ (**같은 점**에서 둘) | $y(-1) = 0$, $y(1) = 3$ (**서로 다른 점**에서 하나씩) |
> | 모르는 것 | — | $y'(-1)$ |
> | solver | `ode45` | `bvp4c` |

## The `bvp4c` function input

- **`bvp4c`** 함수는 **초기 조건을 꼭 알지 못해도** 상미분방정식을 푼다. **입력 3개**가 필요하다.
  1. 풀려는 ODE 또는 ODE 연립에 대한 **function handle**.
  2. 알려진 경계 조건과 그 점에서의 예측값을 바탕으로 **residual 값(오차)** 을 계산하는 또 다른 함수에 대한 **function handle**.
  3. 초기 조건에 대한 **추측(guess)의 집합**.

### The ode function input

- `bvp4c`의 **첫째 입력**은 풀려는 미분방정식(들)을 기술하는 함수에 대한 function handle이다.
- **ode solver 함수군에서 쓰는 것과 형식이 같다.**
  - anonymous function, M-file, MLX-file, 또는 프로그램 끝의 `function` 구문으로 저장할 수 있다.
  - 관심 있는 도함수(들)의 식을 담아야 하고, **결과는 열벡터**여야 한다.

미분방정식 2개의 연립 예($y'' + y' = y + t$ 를 다시 쓴 것):

```matlab
function dydt = twoeq(t,y)
dydt(1) = y(2);
dydt(2) = y(1) + t  - dydt(1);
dydt = dydt';
end
```

### Boundary Condition Residuals

- `bvp4c`의 **둘째 입력**은, 연립방정식을 정의하기에 **충분한 수의 경계 조건**에 대해 **residual을 계산**하는 함수의 function handle이다.
  - 방정식 **하나**에는 경계 조건 **하나**
  - 방정식 **둘**에는 경계 조건 **둘** …
  - 이것들이 **초기 조건일 필요는 없다.**
- 미분방정식을 풀기 위해, 모든 종속 변수의 **초깃값을 추측**한다. 그다음 풀이 과정에서 프로그램은 **계산된 경계값**을 **실제 값**과 비교해 얼마나 잘했는지 확인한다.
  - 추측은 `bvp4c`의 **셋째 입력**이다.

### Boundary Condition Function

- 계산된 경계값과 실제 경계값의 **차이**를 **residual**이라고 한다.
- **반복 과정(iterative process)** 이 residual이 **0에 가까워질 때까지** 되풀이된다. 0에 가까워지면 해가 맞다는 뜻이다.
  - 이 풀이 과정을 **유한 차분법(finite difference approach)** 이라고 한다.
- 경계 조건 함수는, **올바른 경계 조건이 계산되면 함수값이 0**이 되도록 만든다.
- 예. 다음 경계 조건을 생각하자.
  - **t = −1일 때 y = 0**, 그리고
  - **t = 1일 때 y = 3**
- 프로그램은 y와 dy/dt **둘 다**의 초기 추측을 바탕으로 연립방정식을 푼 뒤, t = −1과 t = +1에서 결과가 얼마나 가까운지 확인한다(즉 t = −1에서 y = 0인지, t = +1에서 y = 3인지).

### Boundary Condition Input

```matlab
function residual=bc(y_initial, y_final)
residual(1) = y_initial(1) + 0;
residual(2) = y_final(1) - 3;
residual = residual';
end
```

- `bc`의 입력은 **배열 둘**이다. 이 예에서는 `y_initial`과 `y_final`이라고 불렀다.
- 각 배열은 문제에 쓰인 **종속 변수들**로 이루어진다(보통 y, dydt 등). 즉 **`y_initial(1)`은 y의 초깃값**이고 **`y_initial(2)`는 dydt의 초깃값**이다.
- `y_initial(1) = 0`, `y_final(1) = 3`인 값으로 `bc`를 실행하면 결과는 **0으로 이루어진 열**이다. 다른 결과가 나오면 프로그램이 `y_initial`과 `y_final`을 잘못 계산한 것이고, 초기 조건에 대한 추측을 **갱신**해야 한다.

> **[보강]** residual을 만드는 규칙은 "**(계산된 값) − (알려진 값)**"이다.
>
> | 경계 조건 | residual |
> |---|---|
> | $y(-1) = 0$ (왼쪽 끝의 y) | `y_initial(1) - 0` |
> | $y(1) = 3$ (오른쪽 끝의 y) | `y_final(1) - 3` |
> | $y'(1) = 3$ (오른쪽 끝의 dy/dt) | `y_final(2) - 3` |
>
> 슬라이드의 `y_initial(1) + 0`은 `y_initial(1) - 0`과 같은 값이다. 0이 아닌 값이면 반드시 **뺀다.** 여기서 "initial", "final"은 구간의 **왼쪽 끝**과 **오른쪽 끝**이라는 뜻이다.

### Initial Solution Estimates

- `bvp4c`의 **셋째 입력**은 문제의 해에 대한 **추정값의 mesh**로, 계산의 **출발점**으로 쓰인다.
- MATLAB은 이 mesh를 만드는 보조 함수 **`bvpinit`** 을 제공한다. 결과는 **structure array**로 저장된다.
- 입력은 둘이다. **독립 변수에 대응하는 값의 배열**, 그리고 ode 연립방정식에 정의된 **각 변수의 초기 추정값**.

### Initial Solution - Example

- mesh가 특별히 **촘촘할 필요는 없고**, 초기 추측이 특별히 **정확할 필요도 없다.**
- 예를 들어 지금 문제에는 다음이면 충분하다.

```matlab
initial_guess = bvpinit(-1:.5:1, [0, -1])
```

- `-1:.5:1` — **mesh**를 지정한다.
- `[0, -1]` — **모든 t 값에서** y = 0, dydt = −1이라는 초기 추정을 지정한다.
- 이 추정이 `bc` 함수 계산의 **첫 번째 근사**로 쓰인다.

### `bvpinit`

```matlab
initial_guess = bvpinit(-1:.5:1, [0, -1])
```
```
initial_guess =
  struct with fields:

    solver: 'bvpinit'
         x: [-1 -0.5000 0 0.5000 1]
         y: [2×5 double]
     yinit: [0 -1]
```

- `bvpinit`의 결과는 **structure array**다.
  - **`x`** 는 독립 변수 값의 mesh다. MATLAB은 이 함수에서 독립 변수를 **x라고 부르지만 실제로는 t**다.
  - **`y`** 는 y와 dydt를 나타내는 배열이다.
  - **`yinit`** 은 모든 t 값에서의 y와 dydt의 초깃값을 나타내는 배열이다.

> **[보강]** `initial_guess.y`가 **2×5**인 이유: **행이 변수**(y, dydt로 2개), **열이 mesh 점**(5개)이다. 첫째 행은 전부 0, 둘째 행은 전부 −1이다. `ode45`의 결과(행이 시각)와 **방향이 반대**다.

## Solving the Boundary Value Problem

```matlab
clear,clc
initial_guess = bvpinit(-1:.5:1, [0, -1]);
bvp4c(@twoeq, @bc, initial_guess)

function dydt = twoeq(t,y)
dydt(1) = y(2);
dydt(2) = y(1) + t  - dydt(1);
dydt = dydt';
end

function residual=bc(y_initial, y_final)
residual(1) = y_initial(1) + 0;
residual(2) = y_final(1) - 3;
residual = residual';
end
```
```
ans =
  struct with fields:

    solver: 'bvp4c'
         x: [-1 -0.7500 -0.5000 -0.2500 -0.1250 0 0.2500 … ]
         y: [2×9 double]
        yp: [2×9 double]
     stats: [1×1 struct]
```

결과는 **structure array**다. `x`가 독립 변수이고, `y` 값의 배열이 ODE 연립방정식의 해에 대응한다.

> **[보강]** 읽을 점:
>
> - mesh가 5점(`-1:.5:1`)에서 **9점**으로 늘었다. `bvp4c`가 필요한 곳에 점을 추가한다(−0.75, −0.25, −0.125 등).
> - `y`는 2×9: **첫째 행이 y, 둘째 행이 dydt**. `yp`는 그 도함수(`twoeq`의 값), `stats`는 풀이 통계다.
> - 결과를 쓰려면 변수에 받는 것이 낫다: `sol = bvp4c(@twoeq, @bc, initial_guess);` → `sol.x`, `sol.y(1,:)`.

### Visualizing the Solution With a Plot

```matlab
plot(ans.x,ans.y, '-o')
```

슬라이드 그림 "A Boundary Value Problem"(x축 "x-axis - the independent variable, usually time or distance", y축 "y-axis - the dependent variables"): 선이 둘이다. **y**는 (−1, 0)에서 시작해 (1, 3)으로 올라간다(**두 경계 조건을 만족**). **dydt**는 약 2.3에서 시작해 약 1.15까지 내려갔다가 약 2.2로 올라간다.

```matlab
sol = bvp4c(@twoeq, @bc, initial_guess);
plot(sol.x, sol.y, "-o")
title("A Boundary Value Problem")
xlabel("x-axis - the independent variable, usually time or distance")
ylabel("y-axis - the dependent variables")
legend("y", "dydt", Location="southeast")
```

> **[보강]** 해의 값(SciPy `solve_bvp`로 계산):
>
> | t | −1 | −0.5 | 0 | 0.5 | 1 |
> |---|---|---|---|---|---|
> | y | 0 | 0.847 | 1.435 | 2.084 | 3 |
> | dydt | 2.286 | 1.296 | 1.156 | 1.505 | 2.219 |
>
> `bvp4c`가 찾아낸 것은 결국 **몰랐던 초기 기울기 y'(−1) ≈ 2.286**이다. 이 값을 초기 조건으로 `ode45(@twoeq,[-1,1],[0,2.286])`을 풀면 같은 해가 나온다.

> **[보강]** `plot(ans.x, ans.y, '-o')`가 선 둘을 그리는 이유: `ans.y`가 2×9 행렬이고 `ans.x`가 길이 9인 벡터라서, `plot`이 길이가 맞는 방향(행)마다 선을 하나씩 그린다.

> **[보강]** **`bvp4c` 풀이 절차 정리**
>
> 1. 고계 ODE를 1계 연립으로 다시 쓰고 함수로 만든다(`ode45` 때와 같다, 열벡터).
> 2. 경계 조건마다 residual 식 하나를 쓰는 `bc(y_initial, y_final)`을 만든다(열벡터, 개수 = 방정식 수).
> 3. `bvpinit(mesh, [변수별 추측])`으로 초기 추정 structure를 만든다.
> 4. `sol = bvp4c(@odefun, @bc, initial_guess)`.
> 5. `sol.x`, `sol.y(1,:)`로 결과를 쓴다.

## 13.6.5 Partial Differential Equations

- MATLAB에는 제한적인 **편미분방정식(partial differential equation) solver**인 **`pdepe`** 가 있다.
- 더 자세한 정보는 MATLAB **help** 기능을 참고한다.

```matlab
doc pdepe
```

> **[보강]** `pdepe`는 공간 변수 **하나**와 시간에 대한 포물형·타원형 PDE(예: 1차원 열전도)를 푼다. 더 일반적인 PDE에는 별도 제품인 Partial Differential Equation Toolbox가 필요하다.

## ⚠️ 함정

- **`bvp4c`의 입력은 3개, 순서는 (ODE 함수, 경계 조건 함수, 초기 추정).** `ode45`의 (함수, tspan, y0)와 다르다. `tspan`을 따로 주지 않는다. 구간은 `bvpinit`의 mesh가 정한다.
- **`bvp4c`의 결과는 `[t,y]`가 아니라 structure다.** `[t,y] = bvp4c(…)`는 오류다. `sol.x`, `sol.y`로 꺼낸다.
- **독립 변수의 필드 이름은 `x`다.** 문제에서 t라고 불러도 `sol.t`는 없다.
- **`sol.y`는 행이 변수다.** y는 `sol.y(1,:)`, dydt는 `sol.y(2,:)`. `ode45` 결과의 `y(:,1)`과 방향이 반대다.
- **`bc`의 입력은 배열 둘이다.** `y_initial(2)`는 "둘째 시각의 y"가 아니라 **왼쪽 끝에서의 dydt**다.
- **residual은 0이 되도록 쓴다.** y(1) = 3이면 `y_final(1) - 3`. `y_final(1) = 3`이나 `y_final(1) == 3`으로 쓰지 않는다.
- **`bc`의 결과도 열벡터.** ODE 함수와 마찬가지로 `residual = residual';`가 필요하다.
- **경계 조건의 개수 = 1계 방정식의 개수.** 2계 ODE 하나 → 1계 방정식 2개 → 경계 조건 2개.
- **`bvpinit`의 둘째 입력은 변수마다 하나.** `[0, -1]`은 "t = 0과 t = −1"이 아니라 "y의 추측 0, dydt의 추측 −1"이다. 모든 mesh 점에 같은 값이 쓰인다.
- **초기 추측은 경계 조건이 아니다.** 추측 dydt = −1은 실제 해(1.2~2.3)와 많이 다르지만 답은 구해진다. 다만 비선형 문제에서는 추측에 따라 수렴하지 않거나 다른 해로 갈 수 있다.
- **`ans`에 의존하지 않는다.** 슬라이드처럼 `plot(ans.x, ans.y)`를 쓰면 그 사이에 다른 계산을 하나만 해도 `ans`가 덮어써진다.
- **`pdepe`는 "limited" solver다.** 모든 PDE를 푸는 함수가 아니다.
