# 13.3 Using the Interactive Fitting Tools

> **[보강]** 이 절은 MATLAB 창(figure 메뉴, 대화상자) 조작이 중심이다. 슬라이드(R2022a)의 화면 캡처는 재현하지 않고 텍스트로 설명한다. 이 장은 R2026a에서 다시 실행하지 않았다([README](README.md#실행-환경-메모)).

- MATLAB에는 **Command Window를 쓰지 않고** 그래프에 주석을 달 수 있는 **대화형 플로팅 도구(interactive plotting tools)** 가 있다.
- 다음도 포함되어 있다.
  - **기본 curve fitting**
  - **더 복잡한 curve fitting**
  - **통계 도구(statistical tools)**

## 13.3.1 Basic Fitting Tools

- basic fitting 도구를 쓰려면 **먼저 figure를 만든다.**
- 아래 명령은 샘플 데이터 그래프를 만든다.

```matlab
x = 0:5;
y = [0, 20, 60, 68, 77, 110];
plot(x,y,'o')
axis([-1,7,-20,120])
```

- curve-fitting 도구를 켜려면 figure의 메뉴 바에서 **Tools → Basic Fitting**을 선택한다.
- **Basic Fitting 창이 새 창으로** 열린다.

### Basic Fitting 창

슬라이드 화면("Figure 1: Basic Fitting")의 구성:

| 영역 | 내용 |
|---|---|
| **Data** | 적합할 데이터 선택(`data1`), "Center and scale x-axis data" 체크박스 |
| **TYPES OF FIT** | Linear, Quadratic, Cubic, Spline interpolant, 4th degree polynomial, 5th degree polynomial, … (체크박스. 여러 개를 동시에 고를 수 있다) |
| **FIT RESULTS** | 적합 결과(식, 계수) |
| **ERROR ESTIMATION (RESIDUALS)** | Plot Style(None, 막대 등), Plot Location(Subplot 등), "Norm of residuals" |
| **INTERPOLATE / EXTRAPOLATE DATA** | `X =` 칸에 값이나 MATLAB 식을 넣어 그 점에서 적합값을 계산, "Plot evaluated data" |

슬라이드에서는 **Linear**와 **Cubic**을 체크했다.

### Display Options

Linear와 Cubic을 고르고 식 표시와 residual 그래프를 켠 결과(슬라이드 그림 "Some Data"):

- 위 그래프: 데이터(`data1`)와 **linear**, **cubic** 적합선, 그리고 그래프 위에 표시된 식

```
Linear:  y = 20.83*x + 3.762
Cubic:   y = 1.102*x^3 - 9.317*x^2 + 41.19*x - 3.056
```

- 아래 그래프("residuals"): 각 x에서 두 모델의 **residual을 막대그래프**로 나란히 표시한다. x = 2에서 linear의 residual이 약 +15로 가장 크다.

> **[보강]** Basic Fitting이 계산하는 것은 `polyfit`과 같다. 같은 결과를 코드로 얻으면:
>
> ```matlab
> x = 0:5;
> y = [0, 20, 60, 68, 77, 110];
> c1 = polyfit(x,y,1)
> c3 = polyfit(x,y,3)
> ```
> ```
> c1 =
>    20.8286    3.7619
> c3 =
>     1.1019   -9.3175   41.1918   -3.0556
> ```
>
> 대화형 도구는 **빠르게 여러 모델을 비교**할 때 좋고, 코드는 **재현**할 수 있다는 점이 좋다. residual 그래프도 직접 그릴 수 있다.
>
> ```matlab
> r1 = y - polyval(c1,x);
> r3 = y - polyval(c3,x);
>
> tiledlayout(2,1)
> nexttile
> new_x = -1:0.1:7;
> plot(x, y, "o", new_x, polyval(c1,new_x), new_x, polyval(c3,new_x))
> axis([-1,7,-20,120]), title("Some Data"), legend("data1","linear","cubic")
> nexttile
> bar(x, [r1', r3']), title("residuals")
> ```

[^subplot]

[^subplot]: 구문법: `subplot(2,1,1)`, `subplot(2,1,2)`.

### Data Statistics

슬라이드 13.3.2 옆의 화면("Figure 1: Data Statistics")은 figure 메뉴 **Tools → Data Statistics** 창이다. 그래프에 그려진 데이터의 통계를 X, Y 각각 보여 주고, 체크하면 그래프 위에 표시한다. **Save to Workspace…** 버튼으로 값을 저장할 수 있다.

| | X | Y |
|---|---|---|
| min | 0 | 0 |
| max | 5 | 110 |
| mean | 2.5 | 55.83 |
| median | 2.5 | 64 |
| mode | 0 | 0 |
| std | 1.871 | 39.87 |
| range | 5 | 110 |

> **[보강]** 같은 값을 주는 함수: `min`, `max`, `mean`, `median`, `mode`, `std`, `range`(= `max - min`; `range` 함수는 Statistics and Machine Learning Toolbox에 있으므로 기본 MATLAB에서는 `max(y) - min(y)`로 쓴다). 값이 모두 한 번씩만 나오면 `mode`는 **가장 작은 값**을 돌려준다(여기서 0).

## 13.3.2 Curve Fitting Toolbox

- basic fitting 유틸리티 외에도 MATLAB에는 전문적인 **통계·데이터 적합** 작업을 돕는 **toolbox**들이 있다.
- **Curve Fitting Toolbox**는 **다항식 이외의 곡선**으로도 적합할 수 있는 **앱(app)** 을 제공한다.
- **별도 판매**되지만 **student edition에는 기본 포함**되어 있어 널리 쓸 수 있다.

> **[보강]** 앱은 APPS 탭의 **Curve Fitter**(옛 이름 Curve Fitting, 명령 `cftool`→`curveFitter`)다. 지수, 거듭제곱, Fourier, Gaussian, 사용자 정의 식 등을 고를 수 있다. 이 PC에 설치되어 있는지는 확인하지 않았다(`ver`로 확인).

## ⚠️ 함정

- **figure가 먼저 있어야 한다.** Basic Fitting은 Command Window 메뉴가 아니라 **figure 창의 Tools 메뉴**에 있다. 그래프를 그리지 않으면 메뉴 자체가 없다.
- **Basic Fitting ≠ Curve Fitting Toolbox.** Basic Fitting은 **기본 MATLAB**에 있고 다항식·spline만 된다. Curve Fitting Toolbox는 **별도 제품**(student edition 포함)이고 다항식 이외의 식도 된다.
- **Basic Fitting의 Linear는 `polyfit(x,y,1)`이다.** 원점 통과 옵션은 없다([13.2.2](13.2-curve-fitting.md#1322-linear-regression-through-zero)).
- **그래프의 식은 유효숫자 4자리로 표시된다.** `20.83`은 실제 `20.8286`의 반올림이다. 계산에 다시 쓸 때는 `polyfit` 결과를 쓴다.
- **"Spline interpolant"는 회귀가 아니다.** 모든 점을 지나는 보간이므로 residual이 0이다.
- **대화형으로 한 작업은 스크립트에 남지 않는다.** 다시 실행하면 사라진다. 재현이 필요하면 `polyfit`/`polyval` 코드로 남긴다.
