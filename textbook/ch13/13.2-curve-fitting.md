# 13.2 Curve Fitting

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. 이 장은 R2026a에서 다시 실행하지 않았다([README](README.md#실행-환경-메모)).

- 보간 기법으로 측정한 x 값 **사이**의 y 값을 찾을 수 있지만, 실험 데이터를 **수학 함수** $y = f(x)$ 로 모델링하는 편이 더 편리할 때가 많다.
- 그러면 독립 변수의 알려진 값으로부터 종속 변수의 **어떤 값이든** 계산할 수 있다.
- x와 y 사이의 **근본 관계를 이해**하고 있다면 그 원리에 기반해 식을 정할 수 있다.

### Empirical Equations

- 종속 변수와 독립 변수의 관계를 **이해하지 못하는** 경우가 많고, 그때는 **경험식(empirical equation)** 이 필요하다.
  - 경험식은 어떤 거동이 **왜** 일어나는지에 대한 이론과 관련이 없다. 한 매개변수가 다른 매개변수에 따라 **어떻게** 변하는지를 잘 예측할 뿐이다.
- MATLAB에는 데이터를 모델링하는 **내장 curve-fitting 함수**가 있다.
- 이 모델들은 **데이터가 존재하는 영역에서만** 유효하다는 점을 기억해야 한다.
- y가 x에 따라 왜 그렇게 변하는지 모른다면, data-fitting 식이 **데이터 범위 밖에서도** 통할지 예측할 수 없다.

## 13.2.1 Linear Regression

- 데이터를 모델링하는 **가장 단순한 방법은 직선**이다.
- 예제 데이터를 보자.
  - 데이터 점들 사이로 직선을 **그려 넣어** 거동의 대략적인 모델을 얻을 수 있다.
  - 이 과정을 **"eyeballing it"**(눈대중)이라고 부르기도 한다. 계산은 하지 않았지만 잘 맞아 보인다는 뜻이다.

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
plot(x,y,'o',MarkerSize=10,MarkerFaceColor='b')
axis([-1,6,-1,16])
grid on
title("Curve Fitting Example")
xlabel("x"), ylabel("y")
```

### Residuals

- 위 그림은 **데이터 점만** 보이도록 지정해 만들었다.
- 슬라이드 그림의 빨간 직선은 **계산 없이** 그은 것이다((0, 15)와 (5, 0)을 지난다).
- 이 직선의 적합 품질(quality of the fit)을 다른 추정과 **비교**하려면, **실제 y 값**과 추정으로 **계산한 값**의 차이를 구한다.
- 이 차이, 즉 실제값과 예측값 사이의 오차를 **잔차(residual)** 라고 한다.

### Linear Regression

- **linear regression**(선형 회귀) 기법은 **최소제곱 적합(least squares fit)** 이라는 접근으로, 서로 다른 식이 데이터를 얼마나 잘 모델링하는지 비교한다.
- 실제값과 계산값의 차이(residual)를 **제곱해서 모두 더한다.** 양의 편차와 음의 편차가 **서로 상쇄되지 않는다**는 장점이 있다.
- **잔차 제곱합(sum of the squares of the residuals)이 가장 작은** 모델이 **'best fit'** 이다.

> **[보강]** 눈대중 직선 $y = -3x + 15$ 의 잔차 제곱합을 계산해 보면:
>
> ```matlab
> x = 0:5;
> y = [15, 10, 9, 6, 2, 0];
> y_eye = -3*x + 15;
> residual = y - y_eye
> sum_of_squares = sum(residual.^2)
> ```
> ```
> residual =
>      0    -2     0     0    -1     0
> sum_of_squares =
>      5
> ```

### The `polyfit` function

- MATLAB에서 linear regression은 **`polyfit`** 함수로 한다. `polyfit`은 데이터를 모델링하는 **다항식의 계수**를 돌려준다.
- `polyfit`에는 **입력 세 개**가 필요하다.
  - **x 값 벡터**, **y 값 벡터**, 그리고
  - 데이터에 맞출 다항식의 **차수(order)** 를 나타내는 정수.
- 직선은 **1차 다항식**이므로 `polyfit`에 **1**을 넣으면 linear regression이다.

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
coef = polyfit(x,y,1)
```
```
coef =
   -2.9143   14.2857
```

$$y = -2.9143x + 14.2857$$

> **[보강]** 슬라이드의 강조 상자에는 `y = −2.914x + 14.2857`로 적혀 있다(기울기의 끝자리 3이 빠졌다). 화면 출력은 `-2.9143`이다.

### Linear Regression Using Polyfit

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
coef = polyfit(x,y,1)
best_y = -2.9143*x + 14.2857;
plot(x,y,'o',x,best_y,'-')
title("Best Fit Using Linear Regression")
xlabel("x"), ylabel("y")
```

이 그림의 직선은 `polyfit`이 linear regression 기법으로 만든 **계수**를 써서 그렸다.

> **[보강]** 슬라이드는 계수를 **손으로 다시 타이핑**했다(`-2.9143*x+14.2857`). 반올림된 값을 옮겨 적는 것보다 `best_y = coef(1)*x + coef(2);` 또는 `polyval(coef,x)`([13.2.4](#1324-the-polyval-function))가 정확하고 안전하다.

### Comparison of the Eyeballed and 'Best Fit' Models

슬라이드 그림 "Linear Model of Some Data": (a) "Eyeballed" Data Fit, (b) First Order Linear Regression Fit. 각 점에서 직선까지의 화살표가 **Deviation from Model**(residual)이다. (a)는 직선이 점 4개를 지나지만 두 점에서 크게 벗어나고, (b)는 모든 점에서 조금씩 벗어난다.

> **[보강]** 두 모델의 잔차 제곱합:
>
> | 모델 | residual | 제곱합 |
> |---|---|---|
> | eyeballed $y=-3x+15$ | 0, −2, 0, 0, −1, 0 | **5** |
> | `polyfit` $y=-2.9143x+14.2857$ | 0.7143, −1.3714, 0.5429, 0.4571, −0.6286, 0.2857 | **3.3714** |
>
> 점을 많이 지나는 직선이 best fit인 것은 아니다. 기준은 **제곱합**이다.

## 13.2.2 Linear Regression Through Zero

- 시스템의 **물리**에 근거해, 수학 모델이 **원점을 지나야 한다**는 것을 아는 경우가 있다.

$$y = ax + b, \qquad b = 0$$

- 이런 식에서는 x가 0일 때 y도 0이다.
- **`polyfit`에는 적합을 영점으로 강제하는 옵션이 없다.** 그래서 다른 전략이 필요하다.

### Using Left Division to Implement Linear Regression

- **왼쪽 나눗셈 연산자 `\`** 는 앞 장에서 소개했다.
- 연립 일차방정식을 푸는 데 **Gaussian elimination**을 쓴다.
- 연립방정식이 **과결정(over specified)**, 즉 **방정식이 변수보다 많으면**, 왼쪽 나눗셈 연산자는 `polyfit`과 같은 **최소제곱 적합 전략**을 쓴다.
- 다음 풍속(wind velocity)과 그 결과로 생기는 힘(force) 데이터를 보자.

| Wind Velocity, x | Resulting Force, y |
|---|---|
| **0** | **0** |
| 10 | 24 |
| 20 | 38 |
| 30 | 64 |
| 40 | 82 |
| 50 | 90 |

결과 모델은 **바람이 불지 않을 때 힘 0**을 예측해야 한다.

### Result with `polyfit`

- `polyfit`을 쓰면 결과는 **원점을 지나지 않는** 직선이다.

```matlab
x = 0:10:50;
y = [0, 24, 38, 64, 82, 90];
a = polyfit(x,y,1)
```
```
a =
    1.8571    3.2381
```

$$y = a(1)\cdot x + a(2) = 1.8571x + 3.2381$$

### Result with Left Division

- 왼쪽 나눗셈으로 모델이 원점을 지나게 하려면 **x와 y를 열벡터로** 써야 한다.

```matlab
a = x'\y'
```
```
a =
    1.9455
```

$$y = a(1)\cdot x = 1.9455x$$

이 모델은 잔차 제곱합 기준으로는 `polyfit`의 선형 모델만큼 **"좋지" 않지만**, 물리 시스템에 대해 **우리가 아는 것**에 비추어 보면 **더 나은 모델**이다.

> **[보강]** `x'\y'`가 뜻하는 것: 미지수는 a 하나, 방정식은 6개인 연립방정식 $x_i\,a = y_i$ 를 최소제곱으로 푼다. 답은 $a = \dfrac{\sum x_i y_i}{\sum x_i^2} = \dfrac{10700}{5500} = 1.9455$.
>
> | 모델 | 잔차 제곱합 | x = 0에서 예측 |
> |---|---|---|
> | `polyfit` $1.8571x + 3.2381$ | 103.62 | 3.2381 (바람이 없는데 힘이 있다) |
> | left division $1.9455x$ | 123.64 | 0 |

### Comparison of Polyfit and Left Division Results

슬라이드 그림 "Wind Tunnel Results": Data(점), Polyfit Results(점선), Left-division Results(실선). 실선은 원점에서 출발하고, 점선은 y절편 3.24에서 출발한다.

```matlab
x = 0:10:50;
y = [0, 24, 38, 64, 82, 90];
a_poly = polyfit(x,y,1);
a_zero = x'\y';

plot(x, y, "o", x, polyval(a_poly,x), "--", x, a_zero*x, "-", MarkerFaceColor="b")
title("Wind Tunnel Results")
xlabel("Wind Velocity"), ylabel("Resulting Force")
legend("Data", "Polyfit Results", "Left-division Results", Location="northwest")
```

> **[보강]** 원점을 지나는 **2차식** $y = a_1x^2 + a_2x$ 도 같은 방법으로 맞춘다. 열을 하나 더 쌓으면 된다.
>
> ```matlab
> a = [x'.^2, x'] \ y'
> ```
> ```
> a =
>    -0.0108
>     2.3876
> ```

## 13.2.3 Polynomial Regression

- regression 기법으로 분석할 수 있는 식이 **직선만은 아니다.**
- **Taylor 정리**에 따르면 매끄러운 함수는 무엇이든 **다항식으로 근사**할 수 있다. 그래서 데이터를 다음 꼴의 **고차 다항식**으로 맞추는 것이 흔한 접근이다.

$$y = a_1x^n + a_2x^{n-1} + a_3x^{n-2} + \cdots + a_nx + a_{n+1}$$

- **polynomial regression**은 `polyfit` 함수를 써서, 계산값과 데이터의 편차(residual)의 **제곱합을 최소화**하는 best fit을 구한다.

### Second Order Polynomial Fit

- 2차 다항식 적합은 **셋째 입력에 2**를 넣는다.

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
a = polyfit(x,y,2)
```
```
a =
    0.0536   -3.1821   14.4643
```

결과는 다음 식에 대응한다.

$$y = a(1)\cdot x^2 + a(2)\cdot x + a(3) = 0.0536x^2 - 3.1821x + 14.4643$$

> **[보강]** 슬라이드의 둘째 식은 `y = 0.0536x² − 3.1821 + 14.4643`로, **−3.1821 뒤의 x가 빠져 있다**(오타). 위가 옳은 식이다.

### Higher Order Polynomials

- 더 높은 차수의 적합은 셋째 입력에 **그 차수**를 넣는다.
- 엔지니어·과학자로서 자신이 한 모델링은 **스스로 평가**해야 한다.
- 모델링하는 과정의 **물리**에 대해 아는 것, 그리고 측정의 **정확도와 재현성**을 고려해야 한다.

> **[보강]** 같은 데이터(점 6개)를 차수별로 맞춘 결과:
>
> | 차수 | `polyfit` 결과 | 잔차 제곱합 |
> |---|---|---|
> | 1 | `-2.9143 14.2857` | 3.3714 |
> | 2 | `0.0536 -3.1821 14.4643` | 3.2643 |
> | 3 | `-0.0648 0.5397 -4.0701 14.6587` | 2.9921 |
> | 4 | `0.1875 -1.9398 6.2986 -9.4272 14.9802` | 0.0992 |
> | 5 | `-0.0417 0.7083 -4.2083 10.2917 -11.7500 15.0000` | 0 |
>
> 차수를 올리면 제곱합은 **항상 줄어든다.** 점 6개에 5차식(계수 6개)을 쓰면 모든 점을 **정확히** 지나 제곱합이 0이다. 그렇다고 좋은 모델은 아니다. 측정 오차까지 따라가고(overfitting), 데이터 범위 밖에서 급격히 발산한다. 3차 모델은 x = 8에서 −16.5를 예측한다.

## 13.2.4 The `polyval` Function

- `polyfit` 함수는 regression 기준으로 데이터에 가장 잘 맞는 **다항식의 계수**를 돌려준다.
- **`polyval`** 함수는 `polyfit`의 결과와 **독립 변수 값 배열**을 받아, 대응하는 **종속 변수 값**을 계산한다.
- `polyfit`이 돌려준 계수를 **어떤 순서로** 써야 하는지 헷갈릴 수 있을 때 특히 유용하다.
- 보통 `polyval`의 입력으로 **값이 많은 배열**을 써서, 그리는 그래프가 **매끄럽게** 나오게 한다.

### Using `polyval` and `polyfit` Together

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
a = polyfit(x,y,3);
new_x = 0:0.1:5;
new_y = polyval(a,new_x);
plot(x,y,'o',new_x,new_y,'-')
title("Third Order Fit")
xlabel("x"), ylabel("y")
```

Workspace에는 `a`가 `1x4 double`(값 `[-0.0648, 0.5397, ...]`), `new_x`, `new_y`가 `1x51 double`로 보인다.

> **[보강]** `polyval(a,x)`는 `a(1)*x.^3 + a(2)*x.^2 + a(3)*x + a(4)`와 같다. 한 줄로 쓸 수도 있다: `new_y = polyval(polyfit(x,y,3), new_x);`

## ⚠️ 함정

- **`polyfit`의 셋째 입력은 차수다.** 계수 개수는 **차수 + 1**이다. `polyfit(x,y,1)` → 2개, `polyfit(x,y,2)` → 3개.
- **계수는 높은 차수부터다.** `coef(1)`이 기울기, `coef(2)`가 y절편이다. `coef(1) + coef(2)*x`로 쓰면 틀린다. 헷갈리면 `polyval`을 쓴다.
- **`polyval(계수, x)` 순서.** `polyval(x, a)`로 바꿔 쓰면 x를 계수로 해석해 엉뚱한 값이 나오고 오류는 없다.
- **`polyfit`으로는 원점을 지나게 할 수 없다.** `x'\y'`를 쓴다.
- **left division은 열벡터로.** 행벡터 그대로 `x\y`를 쓰면 스칼라가 아니라 **6×6 행렬**이 나온다(오류가 아니다). `x'\y'`처럼 둘 다 전치한다.
- **`\`와 `/`를 혼동하지 않는다.** `x'/y'`는 다른 계산이다.
- **제곱합이 작다고 더 좋은 모델은 아니다.** 원점을 지나야 하는 물리 시스템에서는 제곱합이 더 큰 $1.9455x$ 가 더 나은 모델이다. 차수를 올리면 제곱합은 무조건 줄어든다.
- **모델은 데이터가 있는 영역에서만 유효하다.** 경험식으로 범위 밖을 예측하지 않는다.
- **차수 n에는 점이 n + 1개 이상 필요하다.** 점보다 계수가 많으면 `polyfit`이 경고(다항식이 유일하지 않음)를 낸다.
- **잔차 제곱합은 `sum(r.^2)`.** `sum(r)^2`나 `r^2`가 아니다. 그냥 `sum(r)`은 양·음이 상쇄된다.
- **interpolation과 regression은 다르다.** 보간 곡선은 모든 측정점을 **지나고**, 회귀 곡선은 대개 **지나지 않는다.**
