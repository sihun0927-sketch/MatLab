## 13.1

### 1. 손으로 하는 `interp1`

```matlab
x = 0:5; y = [15, 10, 9, 6, 2, 0];
interp1(x,y,2.5)                    % 7.5000
interp1(x,y,[0.5, 4.2])             % 12.5000    1.6000
interp1(x,y,6)                      % NaN
interp1(x,y,6,'linear','extrap')    % -2
```

- 2.5: x = 2(y = 9)와 3(y = 6)의 가운데 → (9 + 6)/2 = **7.5**
- 0.5: (15 + 10)/2 = **12.5**. 4.2: 2 + (0 − 2)(4.2 − 4) = 2 − 0.4 = **1.6**
- 6: 데이터 범위(0~5) **밖**이므로 **NaN**(오류가 아니다)
- 외삽: 마지막 선분의 기울기 −2를 연장 → 0 + (−2)(1) = **−2**

### 2. 물의 밀도

```matlab
T   = 0:20:100;
rho = [999.8, 998.2, 992.2, 983.2, 971.8, 958.4];
rho_lin = interp1(T, rho, 50)             % 987.7000
rho_spl = interp1(T, rho, 50, "spline")   % 988.0250
```

(a) 50은 40(992.2)과 60(983.2)의 가운데 → (992.2 + 983.2)/2 = **987.7 kg/m³**

(b) spline은 **988.025 kg/m³**. 밀도 곡선이 위로 볼록해서 현(직선)보다 곡선이 위에 있다.

### 3. 2차원 보간

```matlab
x = 1:4;
y = 2:2:6;
z = [  7  15   22   30
      54 109  164  218
     403 807 1210 1614];

% (a) interp1 두 번
new_z  = interp1(y, z, 5)          % 228.5000  458.0000  687.0000  916.0000
new_z2 = interp1(x, new_z, 2.5)    % 572.5000

% (b) interp2 한 번
interp2(x, y, z, 2.5, 5)           % 572.5000
```

- Step 1 (y = 5, y = 4와 6의 가운데): (54 + 403)/2 = 228.5, (109 + 807)/2 = 458, (164 + 1210)/2 = 687, (218 + 1614)/2 = 916
- Step 2 (x = 2.5, x = 2와 3의 가운데): (458 + 687)/2 = **572.5**
- `interp2`의 입력 순서는 `(x, y, z, 새 x, 새 y)`다. `interp2(x,y,z,5,2.5)`로 쓰면 x = 5가 범위(1~4) 밖이라 NaN이다.

## 13.2

### 1. 잔차 제곱합

```matlab
x = 0:5; y = [15, 10, 9, 6, 2, 0];

% (a) eyeballed
r_eye  = y - (-3*x + 15);
ss_eye = sum(r_eye.^2)             % 5

% (b) polyfit
coef   = polyfit(x,y,1);
r_fit  = y - polyval(coef,x);
ss_fit = sum(r_fit.^2)             % 3.3714
```

(a) 눈대중 직선의 값은 15, 12, 9, 6, 3, 0. residual은 0, −2, 0, 0, −1, 0 → 0 + 4 + 0 + 0 + 1 + 0 = **5**

(b) **3.3714**. `polyfit`의 직선이 제곱합이 더 작다(best fit).

### 2. 2차 적합

(a)

```matlab
a = polyfit(x,y,2);
y_25 = a(1)*2.5^2 + a(2)*2.5 + a(3)     % 6.8438
```

계수는 **높은 차수부터**다. 0.0536 × 6.25 − 3.1821 × 2.5 + 14.4643 ≈ 6.84. (`polyval(a,2.5)`와 같다.)

(b) 5차 다항식은 계수가 6개여서 점 6개를 **모두 정확히 지나는** 다항식이 하나 정해지므로 residual이 전부 0이다(회귀가 아니라 보간이 된다).

### 3. 원점을 지나는 회귀

```matlab
x = 0:10:50; y = [0, 24, 38, 64, 82, 90];
a = x'\y'                % 1.9455
```

(a) `a = x'\y'`. 손 계산: Σxy = 240 + 760 + 1920 + 3280 + 4500 = 10700, Σx² = 100 + 400 + 900 + 1600 + 2500 = 5500 → 10700/5500 = **1.9455**

(b)

- `polyfit` 모델: 1.8571 × 25 + 3.2381 = **49.67**
- 원점 통과 모델: 1.9455 × 25 = **48.64**

(c) 오류 없이 **6×6 행렬**이 나온다. 1×6 행벡터 `x`에 대한 `x\y`는 미지수 6개, 방정식 1개인 연립의 해(6×1)를 `y`의 열마다 구하기 때문이다. 스칼라 기울기를 얻으려면 **열벡터**(`x'\y'`)로 써야 한다.

## 13.3

### 1. Basic Fitting 여는 법

1. `plot`으로 **figure를 만든다**(반드시 먼저).
2. figure 창의 메뉴 바에서 **Tools → Basic Fitting**을 선택한다.
3. 새 창으로 열린 Basic Fitting 창의 TYPES OF FIT에서 모델(Linear, Cubic 등)을 체크한다.

창을 열기 전에 **데이터가 그려진 figure**가 있어야 한다.

### 2. Linear 결과를 코드로

```matlab
x = 0:5;
y = [0, 20, 60, 68, 77, 110];
c1 = polyfit(x,y,1)             % 20.8286    3.7619
r1 = y - polyval(c1,x)          % -3.7619  -4.5905  14.5810  1.7524  -10.0762  2.0952
ss = sum(r1.^2)                 % 356.8190
```

`20.8286`, `3.7619`를 유효숫자 4자리로 반올림한 것이 그래프의 `y = 20.83*x + 3.762`다. residual은 x = 2에서 +14.58로 가장 크다(슬라이드 residual 막대그래프와 일치).

### 3. Basic Fitting vs Curve Fitting Toolbox

- **제공 방식**: Basic Fitting은 기본 MATLAB의 figure 메뉴에 들어 있다. Curve Fitting Toolbox는 **별도 판매**되는 제품이다(student edition에는 기본 포함).
- **모델 종류**: Basic Fitting은 다항식(과 spline 보간)만 된다. Curve Fitting Toolbox의 앱은 **다항식 이외의 곡선**으로도 적합할 수 있다.

## 13.4

### 1. 간격이 일정하지 않은 데이터

```matlab
x = [0, 1, 3, 6]; y = [2, 4, 10, 13];
diff(y)                 % 2     6     3
diff(y)./diff(x)        % 2     3     1
gradient(y,x)           % 2.0000    2.6667    1.8000    1.0000
```

- `diff(x)` = `1 2 3`이므로 기울기는 2/1, 6/2, 3/3 = **2, 3, 1**
- `gradient`: 첫째 = forward = 2. 둘째 = (10 − 2)/(3 − 0) = **2.6667**. 셋째 = (13 − 4)/(6 − 1) = **1.8**. 마지막 = backward = 1.

> **[보강]** 안쪽 점의 값은 본문의 central difference 식 $\dfrac{y_{i+1}-y_{i-1}}{x_{i+1}-x_{i-1}}$ 로 계산했다(MATLAB `gradient`의 정의). NumPy의 `gradient`는 간격이 다를 때 다른 가중식을 쓰므로(2.3333, 2.2) 검산 도구로 쓰지 않았다. 이 답은 R2026a에서 실행해 확인하지 않았다.

### 2. 위치 → 속도

```matlab
t = 0:2:8; d = [0, 7, 18, 33, 52];
fd = diff(d)./diff(t)       % 3.5000    5.5000    7.5000    9.5000
g  = gradient(d,t)          % 3.5000    4.5000    6.5000    8.5000    9.5000
g1 = gradient(d)            % 7     9    13    17    19
```

(a) `diff(d)` = 7, 11, 15, 19, 간격 2 → **3.5, 5.5, 7.5, 9.5** (t = 0, 2, 4, 6에 배정)

(b) 양 끝은 forward/backward(3.5, 9.5), 안쪽은 central: (18 − 0)/4 = 4.5, (33 − 7)/4 = 6.5, (52 − 18)/4 = 8.5

(c) `gradient(d)`는 간격을 **1로 가정**하므로 값이 전부 **2배**(7, 9, 13, 17, 19)다. 실제 간격이 2초이므로 틀린 속도다.

### 3. `diff`의 길이

(a) **10개**(입력 11개보다 하나 적다).

(b) `x`는 11개, `fd`는 10개라 벡터 길이가 달라 오류다.

```matlab
plot(x(1:end-1), fd)        % forward difference: 구간의 첫째 점에 배정
```

(c) backward difference는 구간의 **마지막** 점에 배정하므로 첫 원소(0.1)는 **x = 0.1**에서의 도함수 근사다. (forward로 해석하면 x = 0에서의 근사. 참값은 2x이므로 각각 0.2, 0이고, 0.1은 그 가운데다.)

## 13.5

### 1. 속도 → 거리

```matlab
t = 0:2:10; v = [0, 4, 9, 13, 15, 16];
distance = trapz(t,v)       % 98
wrong    = trapz(v)         % 49
```

(a) 간격이 2로 일정하므로 2 × ((0 + 16)/2 + 4 + 9 + 13 + 15) = 2 × 49 = **98 m**

(b) `trapz(v)`는 **49**. x를 주지 않으면 간격을 1로 가정하기 때문에 실제(간격 2)의 절반이 된다.

### 2. `integral` vs `trapz`

```matlab
I1 = integral(@sin, 0, pi)          % 2.0000

x  = linspace(0,pi,11);
I2 = trapz(x, sin(x))               % 1.9835
```

`integral`이 더 가깝다. `integral`은 허용 오차(상대 1e-6)를 만족할 때까지 구간을 **자동으로** 나누지만, `trapz`는 주어진 11개 점을 **직선으로 이은** 넓이만 계산한다. sin은 이 구간에서 위로 볼록해서 사다리꼴이 곡선 아래에 놓이므로 과소평가(1.9835)한다. 점을 101개로 늘리면 1.9998이다.

### 3. 오류 고치기

```matlab
integral(@(x) x.^2 + 1, 0, 3)             % 12.0000
integral(@(x) x.^2 + 1, 0, 3)             % 12.0000
integral2(@(x,y) x.*y, 0, 2, 0, 1)        % 1.0000
```

- 첫째: `x^2` → `integral`은 x를 **벡터**로 넣어 호출하므로 `^`는 행렬 거듭제곱 오류다. **`.^`** 로 고친다.
- 둘째: 첫 입력이 function handle이 아니다(`x`가 정의되어 있지 않으면 그 오류가 먼저, 정의되어 있어도 숫자 배열은 받지 않는다). **`@(x)`** 를 붙인다.
- 셋째: `integral2`의 함수는 **인수 2개** `@(x,y)`를 받아야 한다. `@(x)`만 있으면 `y`가 정의되지 않았거나 입력 인수가 너무 많다는 오류다.

검산: $\int_0^3 (x^2 + 1)\,dx = 9 + 3 = 12$.

## 13.6

### 1. 1계 ODE

```matlab
dydt  = @(t,y) -2*y;
tspan = [0,2];
y0    = 5;
[t,y] = ode45(dydt,tspan,y0);
plot(t,y,"-o")
xlabel("t"), ylabel("y")
y(end)                      % 약 0.0916
```

참값: $y(2) = 5e^{-4} = 0.0916$. 이 식은 t에 의존하지 않지만 `@(t,y)`로 **둘 다** 써야 한다.

### 2. 2계 ODE

(a) $y_1 = y$, $y_2 = dy/dt$ 로 두면

$$\frac{dy_1}{dt} = y_2, \qquad \frac{dy_2}{dt} = -3y_2 - 2y_1$$

초기 조건은 `[1, 0]`.

(b)

```matlab
clear,clc
[t,y] = ode45(@damped,[0,2],[1,0]);
plot(t, y(:,1))
xlabel("t"), ylabel("y")

function dydt = damped(t,y)
dydt(1) = y(2);
dydt(2) = -3*y(2) - 2*y(1);
dydt = dydt';
end
```

(c)

```matlab
damped = @(t,y) [y(2); -3*y(2) - 2*y(1)];
[t,y] = ode45(damped,[0,2],[1,0]);      % handle 변수이므로 @를 다시 붙이지 않는다
```

검산: 해석적 해는 $y = 2e^{-t} - e^{-2t}$, $y(2) = 0.2524$ (SciPy 수치해 0.2524와 일치).

---

> ⛔ **시험 범위 밖 끝 ↑** 여기부터 다시 시험 범위다.

---

### 3. 문제점 찾기

- (a) 함수가 `t` **하나만** 받는다. solver는 `(t,y)` 두 입력으로 호출하므로 "입력 인수가 너무 많다"는 오류가 난다. → `@(t,y) 2*t`
- (b) 함수가 **행벡터**(`[y(2), -y(1)]`, 쉼표)를 돌려준다. 연립의 출력은 **열벡터**여야 한다. → `@(t,y) [y(2); -y(1)]`

## 13.6.4

### 1. `bvp4c` 스크립트

```matlab
clear,clc
initial_guess = bvpinit(linspace(0,pi/2,5), [0, 0]);
sol = bvp4c(@shm, @bc, initial_guess);

plot(sol.x, sol.y(1,:), "-o")
xlabel("t"), ylabel("y")

function dydt = shm(t,y)
dydt(1) = y(2);
dydt(2) = -y(1);
dydt = dydt';
end

function residual = bc(y_initial, y_final)
residual(1) = y_initial(1) - 0;
residual(2) = y_final(1) - 2;
residual = residual';
end
```

참값: $y(\pi/4) = 2\sin(\pi/4) = \sqrt2 = 1.4142$. `bvp4c`가 찾는 초기 기울기는 $y'(0) = 2$다(SciPy `solve_bvp`: y(π/4) = 1.4142, y'(0) = 2.0000).

### 2. 경계 조건 바꾸기

```matlab
function residual = bc(y_initial, y_final)
residual(1) = y_initial(1) - 1;     % y(-1) = 1
residual(2) = y_final(2) - 3;       % y'(1) = 3  → 둘째 원소(dydt)
residual = residual';
end
```

y의 조건은 **첫째 원소**, dy/dt의 조건은 **둘째 원소**를 쓴다. 0이 아닌 값은 **뺀다.**

### 3. `bvpinit`의 결과

(a) 추측값이 3개(`[2, 0, 5]`)이므로 **1계 방정식 3개**(예: 3계 ODE 하나).

(b) **`3 5`**. 행이 변수(3개), 열이 mesh 점(`0:0.25:1`은 5개).

(c) **`5 5 5 5 5`**. 셋째 변수의 추측 5가 모든 mesh 점에 쓰인다.
