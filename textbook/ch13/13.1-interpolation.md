# 13.1 Interpolation

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. 이 장은 R2026a에서 다시 실행하지 않았다([README](README.md#실행-환경-메모)).

- 무언가를 측정할 때 **가능한 모든 점에서 데이터를 모으지는 않는다.**
- **보간(interpolation)** 기법을 쓰면 **측정하지 않은** 독립 변수 x 값에서 종속 변수 y 값을 **추정**할 수 있다.
- 가장 흔한 보간 기법 두 가지는 다음과 같고, 둘 다 MATLAB이 지원한다.
  - **linear interpolation** (선형 보간)
  - **cubic spline interpolation** (3차 스플라인 보간)

## 13.1.1 Linear Interpolation

- 알려진 두 점 사이의 데이터 점을 추정하는 **가장 흔한 방법**이 linear interpolation이다.
- 두 점 사이의 함수가 **직선(straight line)** 이라고 가정한다.
- 점들이 **서로 가까울수록** 근사가 **더 정확**하다.

슬라이드 그림: (a) 두 점 (1, 2), (5, 10)을 이은 직선 위에서 중간 점을 읽는다. (b) 측정 데이터 6개를 선분으로 잇고, 선분 위에서 보간한 점(interpolated points)을 읽는다.

> **[보강]** 두 점 $(x_1, y_1)$, $(x_2, y_2)$ 사이의 선형 보간식:
>
> $$y = y_1 + \frac{y_2 - y_1}{x_2 - x_1}(x - x_1)$$
>
> 손으로 계산하는 시험 문제는 이 식 하나로 푼다.

### HINT (슬라이드)

- **외삽(extrapolate)은 가능하지만 현명한 경우가 드물다.** 데이터를 모은 영역 밖에서도 같은 패턴이 이어진다고 가정하고 싶겠지만, 그 가정은 **큰 오차**로 이어질 수 있다.
- 함수 이름 `interp1`의 **마지막 글자는 숫자 1**이다. 글꼴에 따라 소문자 엘(l)처럼 보일 수 있다.

### The `interp1` function

- MATLAB에서 linear interpolation은 **`interp1`** 함수로 한다.
- **한 번** 보간하려면 입력은 **x 데이터, y 데이터, 그리고 y를 추정하고 싶은 새 x 값**이다.
- **여러 번** 동시에 보간하려면 **셋째 입력에 x 값의 벡터**를 쓴다.

#### Scalar 입력

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
interp1(x,y,3.5)
```
```
ans =
     4
```

`interp1`은 종속 변수 y의 새 값을 보간한다. **기본 전략은 linear interpolation**이다.

> **[보강]** 손 검산: x = 3과 4 사이, y는 6과 2. $6 + \frac{2-6}{4-3}(3.5-3) = 6 - 2 = 4$.

#### Array 입력

셋째 입력에 독립 변수 값의 **배열**을 넣으면 종속 변수 값 여러 개를 한 번에 추정한다.

```matlab
new_x = 0:0.2:5;
new_y = interp1(x,y,new_x)
```
```
new_y =
  Columns 1 through 5
   15.0000   14.0000   13.0000   12.0000   11.0000
  Columns 6 through 10
   10.0000    9.8000    9.6000    9.4000    9.2000
  Columns 11 through 15
    9.0000    8.4000    7.8000    7.2000    6.6000
  Columns 16 through 20
    6.0000    5.2000    4.4000    3.6000    2.8000
  Columns 21 through 25
    2.0000    1.6000    1.2000    0.8000    0.4000
  Column 26
         0
```

결과는 종속 변수를 나타내는 **값의 배열**이다(여기서는 `new_y`). Workspace에는 `new_x`, `new_y`가 `1x26 double`, `x`, `y`가 `1x6 double`로 보인다.

#### Graphing the results

- 위 linear interpolation 결과를 원래 데이터와 **같은 그래프**에 그린다.
- 모든 결과가 원래 점들 사이의 **직선 위**에 놓인다.

```matlab
plot(x, y, "-o", new_x, new_y, "o")
legend("Measured Data", "Interpolated Data")
title("(a) Linear Interpolation"), xlabel("x-axis"), ylabel("y-axis")
axis([-1, 6, -1, 16])
```

- `interp1`의 방식을 linear interpolation으로 **명시**하려면 **넷째 입력**에 적는다.

```matlab
interp1(x,y,3.5, "linear")
```
```
ans =
     4
```

## 13.1.2 Cubic Spline Interpolation

- 데이터 점을 직선으로 잇는 것은 가장 **단순**하지만, 중간값을 추정하는 **최선의 방법은 아닐 수 있다.**
- `interp1`에 들어 있는 **cubic spline interpolation** 기법으로 **더 매끄러운 곡선**을 만들 수 있다.
- 이 방식은 **3차 다항식(third-order polynomial)** 을 쓰므로, 데이터의 거동을 모델링하려면 **데이터 점이 최소 4개** 필요하다.
- cubic spline interpolation은 **넷째 입력**에 지정한다.

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
interp1(x,y,3.5,"spline")
```
```
ans =
    3.9417
```

cubic spline 기법으로 x 값 배열의 **모든 원소**에 대해 새 y 값을 추정할 수 있다.

```matlab
new_x = 0:0.2:5;
new_y = interp1(x,y,new_x,"spline")
```
```
new_y =
  Columns 1 through 5
   15.0000   13.3088   12.0251   11.0869   10.4325
  Columns 6 through 10
   10.0000    9.7275    9.5531    9.4149    9.2512
  Columns 11 through 15
    9.0000    8.6133    8.0987    7.4773    6.7707
  Columns 16 through 20
    6.0000    5.1872    4.3563    3.5317    2.7381
  Columns 21 through 25
    2.0000    1.3419    0.7883    0.3637    0.0928
  Column 26
         0
```

> **[보강]** 슬라이드 화면은 5열 일부가 설명 상자에 가려져 있다. 가려진 값(10.4325, 9.2512, 6.7707, 2.7381, 0.0928)은 같은 not-a-knot cubic spline을 SciPy로 계산해 채웠다. 보이는 값은 슬라이드와 전부 일치한다.

### Comparison Between Linear and Cubic Spline Estimates

슬라이드 그림 "Measured and Interpolated Data": (a) Linear Interpolation — 보간점이 측정점 사이의 **꺾인 선분** 위에 있다. (b) Spline Interpolation — 보간점이 측정점을 **모두 지나는 매끄러운 곡선** 위에 있다. 두 그림 모두 측정점(measured points)에서는 값이 같다.

```matlab
new_lin = interp1(x, y, new_x);
new_spl = interp1(x, y, new_x, "spline");

tiledlayout(1,2)
nexttile
plot(x, y, "-o", new_x, new_lin, "o"), title("(a) Linear Interpolation")
nexttile
plot(x, y, "-o", new_x, new_spl, "-o"), title("(b) Spline Interpolation")
```

[^subplot]

[^subplot]: 구문법: `subplot(1,2,1)`, `subplot(1,2,2)`.

> **[보강]** `interp1`의 넷째 입력(method)으로 자주 쓰는 것:
>
> | method | 뜻 | 필요한 점 수 |
> |---|---|---|
> | `"linear"` | 선형 보간 (**기본값**) | 2 |
> | `"nearest"` | 가장 가까운 점의 값 | 2 |
> | `"spline"` | cubic spline (not-a-knot) | 4 |
> | `"pchip"` | shape-preserving piecewise cubic. `"cubic"`은 같은 것의 옛 이름 | 4 |
> | `"makima"` | modified Akima cubic | 2 |
>
> 같은 데이터에서 `interp1(x,y,3.5,"pchip")`는 3.9048이다(spline 3.9417, linear 4).

## 13.1.3 Extrapolation

- **좋은 생각인 경우는 드물지만**, `interp1`에 입력 두 개(**모델링 방식**과 **외삽하라는 지시**)를 더해 데이터를 **외삽(extrapolate)** 할 수 있다.

```matlab
x = 0:5;
y = [15, 10, 9, 6, 2, 0];
y_new = interp1(x,y, 6, 'linear','extrap')
```
```
y_new =
    -2
```

### Extrapolation Results

- **모델링 전략을 바꾸면 결과가 크게 달라질 수 있다.**

```matlab
y_new = interp1(x,y,6,'spline','extrap')
```
```
y_new =
    3.0667
```

같은 x = 6에서 linear는 **−2**, spline은 **3.0667**이다. 데이터가 없는 영역이므로 어느 쪽이 맞는지 알 수 없다.

> **[보강]** linear 외삽은 마지막 선분(4,2)–(5,0)의 기울기 −2를 그대로 연장한다: 0 + (−2)(6−5) = −2.

> **[보강]** 슬라이드는 작은따옴표 `'linear','extrap'`로 썼다. 큰따옴표 `"linear","extrap"`도 같다. 외삽 대신 **범위 밖 값을 상수로** 정하려면 다섯째 입력에 숫자를 쓴다: `interp1(x,y,6,"linear",0)` → `0`.

## 13.1.4 Multidimensional Interpolation

- 두 독립 변수 x, y에 의존하는 데이터 z가 아래 표처럼 있다고 하자.
- 표에 **없는** x, y 값에서 z를 구하려면 `interp1`로 **이중 선형 보간(double linear interpolation)** 을 해야 한다.
- **y = 3, x = 1.5**에서 z를 구해 보자.

| | x = 1 | x = 2 | x = 3 | x = 4 |
|---|---|---|---|---|
| **y = 2** | 7 | 15 | 22 | 30 |
| **y = 4** | 54 | 109 | 164 | 218 |
| **y = 6** | 403 | 807 | 1,210 | 1,614 |

### Use `interp1` twice

한 가지 방법:

- `interp1`로 **y = 3에서, 주어진 모든 x 값**의 z를 구한다.
- 그 새 표에서 **x = 1.5**로 두 번째 보간을 한다.

```matlab
y = 2:2:6;
x = 1:4;
z = [  7  15   22   30
      54 109  164  218
     403 807 1210 1614];
new_z = interp1(y,z,3)
```
```
new_z =
   30.5000   62.0000   93.0000  124.0000
```
```matlab
new_z2 = interp1(x,new_z,1.5)
```
```
new_z2 =
   46.2500
```

### Visualizing the Double Interpolation

**Step 1** — 먼저 **y를 원하는 값으로 고정**하고 보간한다(y = 3 행이 새로 생긴다).

| | x = 1 | x = 2 | x = 3 | x = 4 |
|---|---|---|---|---|
| y = 2 | 7 | 15 | 22 | 30 |
| **y = 3** | **30.5** | **62.0** | **93.0** | **124** |
| y = 4 | 54 | 109 | 164 | 218 |
| y = 6 | 403 | 807 | 1,210 | 1,614 |

**Step 2** — 그다음 **원하는 x 값**으로 두 번째 보간을 한다.

| | x = 1 | **x = 1.5** | x = 2 | x = 3 | x = 4 |
|---|---|---|---|---|---|
| **y = 3** | 30.5 | **46.25** | 62.0 | 93.0 | 124 |

> **[보강]** `interp1(y,z,3)`에서 `z`가 **행렬**이면 `interp1`은 **열마다** 보간한다. 그래서 첫째 입력은 z의 **행**에 대응하는 `y`(길이 3)여야 한다. 손 검산: (7+54)/2 = 30.5, (15+109)/2 = 62, … 그리고 (30.5+62)/2 = 46.25.

### Using `interp2`

- MATLAB에는 2차원 선형 보간 함수 **`interp2`** 가 있어 이 문제를 **한 번에** 푼다.

```matlab
x = 1:4;
y = 2:2:6;
z = [  7  15   22   30
      54 109  164  218
     403 807 1210 1614];
interp2(x,y,z,1.5,3)
```
```
ans =
   46.2500
```

### Higher Dimensions

- 3차원 보간 함수 **`interp3`** 이 있다.
- 더 높은 차원의 보간은 **`interpn`** 함수로 한다.
- 모든 보간 함수는 **기본이 linear interpolation**이지만, cubic spline을 포함해 MATLAB 라이브러리의 **다른 전략도 받는다.**

> **[보강]** 예: `interp2(x,y,z,1.5,3,"spline")`. 단 spline은 각 방향에 점이 4개 이상 필요한데 위 표는 y 방향이 3개뿐이라 이 표에서는 쓸 수 없다.

## ⚠️ 함정

- **`interp1`의 끝은 숫자 1이다.** `interpl`(엘)로 치면 정의되지 않은 함수 오류다.
- **입력 순서는 (x 데이터, y 데이터, 새 x).** 결과는 새 **y**다. y로부터 x를 거꾸로 찾으려면 `interp1(y,x,new_y)`처럼 순서를 바꾼다(y가 단조일 때만).
- **범위 밖은 NaN이다.** `interp1(x,y,6)`은 오류가 아니라 `NaN`이다(linear 기본). 외삽하려면 method와 `'extrap'` **둘 다** 써야 한다: `interp1(x,y,6,'linear','extrap')`.
- **`"spline"`은 범위 밖에서도 값을 낸다.** `interp1(x,y,6,"spline")`은 `'extrap'` 없이도 3.0667이다(`"spline"`, `"pchip"`, `"makima"`는 외삽이 기본 동작). NaN이 안 나왔다고 믿을 만한 값인 것은 아니다.
- **외삽 결과는 method에 따라 딴판이다.** x = 6에서 linear −2, spline 3.0667. 힘이나 길이가 음수가 되는 등 물리적으로 말이 안 되는 값도 나온다.
- **cubic spline은 점이 4개 이상 필요하다.** 3차 다항식이기 때문이다.
- **spline은 측정점을 정확히 지난다.** 측정점에서는 linear와 spline의 값이 같고, **사이**에서만 다르다(3.5에서 4 vs 3.9417).
- **`interp2(x,y,z,xq,yq)`에서 x는 z의 열, y는 z의 행이다.** `size(z)`는 `[length(y), length(x)]`여야 한다. 위 예는 3×4, y가 3개, x가 4개다.
- **`interp1(y,z,3)`의 첫 입력은 y다.** 행렬 z는 열 방향으로 보간되므로 x(길이 4)를 넣으면 길이가 맞지 않아 오류다.
- **x 데이터는 값이 서로 달라야 한다.** 같은 x가 두 번 나오면 `interp1`은 오류를 낸다.
