# 13.5 Numerical Integration

> **[보강]** 이 절의 MATLAB 출력 중 슬라이드에 있는 것은 슬라이드(R2022a) 화면 그대로다. 이 장은 R2026a에서 다시 실행하지 않았다([README](README.md#실행-환경-메모)).

- 적분은 흔히 **곡선 아래의 넓이**를 구하는 것으로 생각한다. 이 기법을 **quadrature**(구적법)라고 부르기도 한다.
- MATLAB은 quadrature를 이용한 수치 적분에 **두 가지 접근**을 제공한다. **무엇을 알고 있느냐**에 따라 고른다.
  - 종속·독립 변수의 **순서쌍 집합(데이터)** 을 알고 있다면: **trapezoid rule**(사다리꼴 공식)이 최선이고, **`trapz`** 함수로 구현되어 있다.
  - 종속 변수를 독립 변수로 정의하는 **함수** $y = f(x)$ 를 알고 있다면: **`integral`** 함수가 맞는 선택이다. 관심 영역을 나눌 **구간 수를 자동으로** 고른다.

> **[보강]** 슬라이드 본문에는 "implemented with the **trap** function"이라고 적혀 있지만 함수 이름은 **`trapz`** 다(바로 다음 슬라이드에는 `trapz`로 나온다).

## The Trapezoid Rule

- trapezoid rule은 곡선 아래 넓이를 **직사각형으로 쪼갠 뒤**, 모든 직사각형의 기여를 **더해서** 근사한다.
- 이것을 **trapezoid rule**이라고 부르는 이유는, 그 직사각형이 이웃한 원소 사이에 그린 **사다리꼴과 넓이가 같기** 때문이다.
- MATLAB의 내장 함수 **`trapz`** 가 같은 결과를 주며, 구문은 다음과 같다.

```matlab
trapz(x,y)
```

슬라이드 그림 "(a) Trapezoid Rule": 샘플 데이터(x = 0:5, y = 15, 10, 9, 6, 2, 0)를 이은 선 아래에, 구간마다 **높이가 양 끝 y의 평균**인 노란 직사각형 5개(높이 12.5, 9.5, 7.5, 4, 1)가 그려져 있다.

> **[보강]** 식과 손 계산:
>
> $$\int_{x_1}^{x_n} y\,dx \approx \sum_{i=1}^{n-1} \frac{y_i + y_{i+1}}{2}\,(x_{i+1} - x_i)$$
>
> ```matlab
> x = 0:5;
> y = [15, 10, 9, 6, 2, 0];
> avg_y = (y(1:end-1) + y(2:end))/2      % 각 직사각형의 높이
> area = sum(diff(x).*avg_y)
> trapz(x,y)
> ```
> ```
> avg_y =
>    12.5000    9.5000    7.5000    4.0000    1.0000
> area =
>    34.5000
> ans =
>    34.5000
> ```
>
> 12.5 + 9.5 + 7.5 + 4 + 1 = 34.5. 간격이 일정할 때는 $\Delta x\left(\dfrac{y_1 + y_n}{2} + y_2 + \cdots + y_{n-1}\right)$ 로 계산하면 빠르다: $1 \times (7.5 + 10 + 9 + 6 + 2) = 34.5$.

> **[보강]** 누적 넓이가 필요하면 `cumtrapz(x,y)`를 쓴다. 위 데이터에서는 `0 12.5 22 29.5 33.5 34.5`(입력과 같은 길이, 첫 원소 0).

## The `integral` Function

- 종속·독립 변수를 잇는 **함수**를 알고 있으면 `integral` 함수로 적분을 구한다.
- **첫째 입력에 function handle**을 넣어야 하고, **마지막 두 입력**이 **적분 구간(limits of integration)** 이다.
- `integral` 함수는 **1×10⁻⁶ 이내**로 정확한 답을 돌려준다.

```matlab
f = @(x) x.^2;
result = integral(f,0,1)
```
```
result =
    0.3333
```

> **[보강]** 참값은 $\int_0^1 x^2\,dx = \tfrac13$. 같은 적분을 `trapz`로 하면 점의 개수에 따라 달라진다.
>
> | 방법 | 결과 |
> |---|---|
> | `x = linspace(0,1,6); trapz(x,x.^2)` | 0.3400 |
> | `x = linspace(0,1,11); trapz(x,x.^2)` | 0.3350 |
> | `x = linspace(0,1,101); trapz(x,x.^2)` | 0.3334 (0.33335) |
> | `integral(@(x) x.^2,0,1)` | 0.3333 |

> **[보강]** "1×10⁻⁶"의 정확한 뜻: `integral`의 기본 허용 오차는 **상대 오차 `RelTol` = 1e-6**, 절대 오차 `AbsTol` = 1e-10이다. 바꾸려면 `integral(f,0,1,RelTol=1e-10)`. 구간 끝에 `Inf`도 쓸 수 있다: `integral(@(x) exp(-x.^2),-Inf,Inf)` → `1.7725`($\sqrt{\pi}$).

> **[보강]** function handle을 변수에 담지 않고 바로 써도 된다. 이미 있는 함수는 `@`만 붙인다.
>
> ```matlab
> integral(@(x) exp(-x.^2), 0, 1)     % 0.7468
> integral(@sin, 0, pi)               % 2.0000
> ```

## Double and Triple Integrals

- **`integral2`**, **`integral3`** 함수는 `integral`과 매우 비슷하며 각각 **이중 적분**, **삼중 적분**을 푼다.
- 이 기법들의 원리는 **수치해석(numerical methods) 교재**에서 더 알아볼 수 있다.

> **[보강]** 입력 순서는 `integral2(fun, xmin, xmax, ymin, ymax)`, `integral3(fun, xmin, xmax, ymin, ymax, zmin, zmax)`다.
>
> ```matlab
> integral2(@(x,y) x.*y, 0, 2, 0, 1)          % x: 0~2, y: 0~1  →  1.0000
> integral2(@(x,y) x.^2 + y.^2, 0, 1, 0, 1)   % 0.6667
> ```
>
> 검산: $\int_0^1\!\!\int_0^2 xy\,dx\,dy = \left[\tfrac{x^2}{2}\right]_0^2\left[\tfrac{y^2}{2}\right]_0^1 = 2 \times \tfrac12 = 1$.

> **[보강]** 수치 적분과 symbolic 적분 비교:
>
> | | `trapz` | `integral` | `int` (Chapter 12) |
> |---|---|---|---|
> | 입력 | 데이터 벡터 x, y | function handle, 구간 | symbolic 식 |
> | 구간 분할 | 데이터 점 그대로 | 자동 | 해당 없음(해석적) |
> | 결과 | double 근삿값 | double 근삿값 | sym 정확한 식/값 |
> | 부정적분 | 불가 | 불가 | 가능 |

## ⚠️ 함정

- **`trapz(x,y)`는 x가 먼저다.** `gradient(y,x)`와 **반대**다.
- **`trapz(y)`는 간격을 1로 가정한다.** `t = 0:2:10`인 데이터에서 `trapz(v)`는 `trapz(t,v)`의 절반이다. 오류가 없으니 더 위험하다.
- **`trapz`에 function handle을 넣을 수 없고, `integral`에 데이터 벡터를 넣을 수 없다.** 데이터 → `trapz`, 함수 → `integral`.
- **`integral`의 함수는 벡터 입력을 받아야 한다.** `@(x) x^2`는 오류다(`integral`은 x를 벡터로 넣어 호출한다). `.^`, `.*`, `./`를 쓴다.
- **상수 함수 `@(x) 5`도 오류다.** 출력 크기가 입력과 달라진다. `@(x) 5*ones(size(x))`로 쓴다.
- **`integral(f,0,1)`의 `f`는 handle이다.** `integral(f(x),0,1)`이나 `integral(x.^2,0,1)`은 틀리다.
- **`trapz`의 정확도는 점의 개수에 달려 있다.** 점이 6개면 x²의 적분이 0.34다. 위로 볼록한 곡선은 과소평가, 아래로 볼록한 곡선은 과대평가한다.
- **`integral` ≠ `int`.** `int`는 symbolic(Symbolic Math Toolbox), `integral`은 수치다. `integral`은 부정적분을 못 한다.
- **`integral2`의 구간 순서는 x 먼저, y 나중이다.** 함수는 `@(x,y)`로 **인수 두 개**를 받아야 한다.
- **x축 아래 넓이는 음수로 더해진다.** `integral(@sin,0,2*pi)`는 0(근사)이다. 넓이의 합을 원하면 `abs`를 씌운다.
