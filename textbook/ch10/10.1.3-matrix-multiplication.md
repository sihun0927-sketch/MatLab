# 10.1.3 Matrix Multiplication

## 각 원소가 dot product

행렬 곱의 결과는 **각 원소가 dot product인 배열**이다. 연산자는 별표 **`*`** 다.

$$
C_{i,j} = \sum_{k=1}^{n} A_{i,k} B_{k,j}
$$

쉽게 말해 **C의 (i, j) 원소 = A의 i번째 행 · B의 j번째 열**이다.

```matlab
A = [2 1 0;
     1 3 2];        % 2×3
B = [1 4;
     2 0;
     3 1];          % 3×2
C = A*B             % 2×2
```
```
C =
     4     8
    13     6
```

## 행 하나, 열 하나를 꺼내 확인하기

슬라이드는 행 하나와 열 하나를 꺼내 `dot`으로 계산하고, 결과가 C의 해당 원소와 같음을 보인다.

```matlab
A_row2 = A(2,:)             % 1 3 2
B_col1 = B(:,1)             % 1; 2; 3
dot(A_row2, B_col1)         % 13  = C(2,1)
```

$1\cdot1 + 3\cdot2 + 2\cdot3 = 13$. C의 2행 1열 값과 같다.

> 슬라이드 예: `A = [1 2 3; 4 5 6]`, `B = [10 20 30; 40 50 60; 70 80 90]` → `C = A*B = [300 360 420; 660 810 960]`. `dot(A(1,:), B(:,1))` = **300** = `C(1,1)`.

---

## 열 수 = 행 수

행렬 곱은 dot product의 연속이므로 **A의 열 수가 B의 행 수와 같아야** 한다.

- A가 **m × n**이면 B는 **n × p**여야 하고, 결과는 **m × p**다.
- 차원을 나란히 써 보면 **안쪽 두 숫자가 같아야** 한다.

$$
(m \times \underbrace{n)\,(n}_{\text{같아야}} \times p) \;\to\; m \times p
$$

위 예에서 (2×**3**)(**3**×2) → 2×2.

---

## 비가환 (not commutative)

행렬 곱은 일반적으로 **교환법칙이 성립하지 않는다**: $A \times B \ne B \times A$.

차원이 안 맞으면 아예 계산이 안 된다. 2×3 `A`를 자기 자신과 곱해 보면:

```matlab
A*A
```
```
행렬 곱셈의 차원이 잘못되었습니다. 첫 번째 행렬의 열 개수가 두 번째 행렬의 행 개수와 일치하는지 확인하십시오. 행렬의 각 요소에 대해 개별적으로 연산을 수행하려면 요소별 곱셈 연산에 TIMES(.*)를 사용하십시오.
```

> 영어 원문(슬라이드 p.18): `Error using *` / `Incorrect dimensions for matrix multiplication. Check that the number of columns in the first matrix matches the number of rows in the second matrix. To operate on each element of the matrix individually, use TIMES (.*) for elementwise multiplication.`

위의 `A`(2×3), `B`(3×2)는 양쪽 다 되지만 크기부터 다르다.

```matlab
D = B*A             % 3×3, C(2×2)와 전혀 다름
```
```
D =
     6    13     8
     4     2     0
     7     6     2
```

### 정사각 행렬은 더 위험하다

정사각 행렬은 **두 순서 모두 정당한 결과가 나오는데 답이 다르다.** 오류가 안 나서 실수를 알아채기 어렵다. 문제를 이해하고 **계산 순서를 정확히** 세워야 한다.

```matlab
P = [1 2; 3 4];
Q = [0 1; 1 0];
P*Q                 % [2 1; 4 3]   열을 맞바꿈
Q*P                 % [3 4; 1 2]   행을 맞바꿈
P.*Q                % [0 2; 3 0]   원소별 곱 — 또 다른 답
```

---

## ⚠️ 함정

- **`*`와 `.*`는 완전히 다른 연산.** `*`는 행렬 곱(행·열 dot product), `.*`는 같은 자리끼리 곱. 오류 메시지가 `.*`를 권하더라도, 원하는 것이 행렬 곱이면 차원을 다시 봐야 한다.
- **정사각 행렬은 `A*B`와 `B*A`가 모두 실행된다.** 오류가 없다고 맞는 게 아니다.
- **스칼라 곱은 예외**: `3*A`와 `A*3`은 같다(원소별).
- 결과 크기는 **바깥 두 숫자**(m × p).
