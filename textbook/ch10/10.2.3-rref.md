# 10.2.3 Reduced Row Echelon Function

## Gauss-Jordan elimination

**reduced row echelon**(기약 행 사다리꼴) 함수는 **Gauss-Jordan elimination** 기법으로 연립방정식을 푼다. MATLAB 함수는 **`rref`** 다.

슬라이드 설명:

- 이 기법은 해가 **수렴할 때까지 반복(iterating)** 하는 수치 해법이다.
- 일부 큰 문제에서는 Gaussian elimination보다 효율적일 수 있다.

> **[보강]** 이 설명은 정확하지 않다. Gauss-Jordan elimination은 Gaussian elimination처럼 **정해진 횟수의 행 연산으로 끝나는 직접법(direct method)** 이다. "수렴할 때까지 반복"하는 방법(Jacobi, Gauss-Seidel 같은 반복법)이 아니다. 차이는 Gaussian elimination이 위삼각(upper triangular)까지만 소거하고 뒤에서부터 대입하는 반면, Gauss-Jordan은 **피벗 위아래를 모두 0으로** 만들어 왼쪽 부분을 단위 행렬로 바꾼다는 것이다. 연산량은 Gauss-Jordan이 더 많아서 `A\B`보다 느린 것이 보통이다. 시험에서 슬라이드 문장을 그대로 물으면 슬라이드대로 답하되, 이 차이를 알아 두자.

## 확장 행렬(expanded matrix)을 입력으로

`rref`는 **계수 행렬과 결과 행렬을 이어 붙인 확장 행렬**을 입력으로 받는다. 10.2.2와 같은 시스템을 풀어 보자.

$$
\begin{aligned}
3x + 2y + 5z &= 22 \\
4x + 5y - 2z &= 8 \\
x + y + z &= 6
\end{aligned}
$$

먼저 A와 B를 **가로로 이어 붙인다.**

```matlab
A = [3 2 5; 4 5 -2; 1 1 1];
B = [22; 8; 6];
C = [A, B]
```
```
C =
     3     2     5    22
     4     5    -2     8
     1     1     1     6
```

그리고 `rref`를 쓴다.

```matlab
R = rref(C)
```
```
R =
     1     0     0     1
     0     1     0     2
     0     0     1     3
```

왼쪽 3×3이 **단위 행렬**이 되었다. 각 행은 이제 이렇게 읽는다.

$$
1x + 0y + 0z = 1,\quad 0x + 1y + 0z = 2,\quad 0x + 0y + 1z = 3
$$

즉 해는 $x = 1, y = 2, z = 3$이고, 결과 행렬의 **마지막 열**에 있다.

> **[보강]** 슬라이드 p.54는 "The X values are in the final **row** of the answer matrix"라고 적었지만 **마지막 열(column)** 이 맞다. 슬라이드 그림에서 빨간 동그라미로 둘러싼 것도 세로로 놓인 `1 2 3`, 즉 넷째 열이다. 마지막 행은 `0 0 1 3`이다.
>
> 해만 꺼내려면:
>
> ```matlab
> X = R(:, end)       % [1; 2; 3]
> ```

---

> **[보강]** `rref`는 해가 하나가 아닐 때도 정보를 준다.
>
> ```matlab
> rref([1 1 2; 2 2 5])        % [1 1 0; 0 0 1]   → 0 = 1, 해 없음
> rref([1 1 2; 2 2 4])        % [1 1 2; 0 0 0]   → x + y = 2, 해 무수히 많음
> ```
>
> 마지막 열을 제외한 부분이 모두 0인데 마지막 열이 0이 아닌 행(`0 0 1`)은 $0 = 1$이라는 뜻이라 **해가 없다**(inconsistent). 행 전체가 0인 행은 식 하나가 다른 식에 종속이라는 뜻이고, 남은 식보다 미지수가 많으면 **해가 무수히 많다**. under-defined 시스템(10.2.2)에 `rref`를 쓰면 `\`처럼 변수를 0으로 두는 대신 관계식을 보여 준다.
>
> ```matlab
> rref([3 2 5 22; 4 5 -2 8])
> ```
> ```
> ans =
>     1.0000         0    4.1429   13.4286
>          0    1.0000   -3.7143   -9.1429
> ```
>
> $x = 13.4286 - 4.1429z$, $y = -9.1429 + 3.7143z$. z를 0으로 두면 $x = 13.43, y = -9.14$로, `\`의 답(x = 0)과 다른 해가 나온다. 둘 다 맞는 해다.

---

## ⚠️ 함정

- **해는 마지막 "열".** 슬라이드 문장("final row")을 그대로 외우면 틀린다.
- **`[A, B]`(가로, 쉼표)로 붙인다.** `[A; B]`(세로, 세미콜론)는 차원 오류이거나 엉뚱한 행렬이 된다.
- **B는 열 벡터여야** `[A, B]`가 n×(n+1)이 된다. 행 벡터면 "결합하려는 배열의 차원이 일치하지 않습니다" 오류.
- **`rref`의 출력은 해 벡터가 아니라 행렬**이다. 해는 `R(:, end)`로 꺼낸다.
- 왼쪽이 단위 행렬이 **아니면** 해가 유일하지 않다(해 없음 또는 무수히 많음).
