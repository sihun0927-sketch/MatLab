# 10.1.4 Matrix Powers

## `A^2`는 `A*A`

행렬을 거듭제곱하는 것은 **행렬을 자기 자신과 그 횟수만큼 행렬 곱하는 것**이다.

- $A^2$ = `A*A`
- $A^3$ = `A*A*A`
- 자기 자신과 곱하려면 (n×n)(n×n)이어야 하므로 **정사각 행렬만** 거듭제곱할 수 있다.

```matlab
P = [1 2; 3 4];
P^2             % [7 10; 15 22]
P*P             % 같음
P^3             % [37 54; 81 118]
P.^2            % [1 4; 9 16]   ← 원소별 제곱, 전혀 다름
```

> **[보강]** 정사각이 아닌 행렬에 `^`를 쓰면 오류가 난다.
>
> ```matlab
> A = [2 1 0; 1 3 2];
> A^2
> ```
> ```
> 차원이 정확하지 않아 행렬을 거듭제곱할 수 없습니다. 행렬이 정사각 행렬이고 지수 값이 스칼라인지 확인하십시오. 행렬의 각 요소에 대해 개별적으로 연산을 수행하려면 요소별 거듭제곱 연산에 POWER(.^)를 사용하십시오.
> ```
>
> 벡터 `x = [1 2 3]`도 1×3이라 `x^2`는 같은 오류다. 각 원소의 제곱이 목적이면 `x.^2`.

## 비정수 거듭제곱

슬라이드 요약(p.58): **"행렬을 정수가 아닌 지수로 거듭제곱하면 결과는 복소수 행렬이다."**

```matlab
P^0.5
```
```
ans =
   0.5537 + 0.4644i   0.8070 - 0.2124i
   1.2104 - 0.3186i   1.7641 + 0.1458i
```

> **[보강]** R2026a에서 확인하면 **항상** 복소수인 것은 아니다. `P = [1 2; 3 4]`는 고유값 중 하나가 음수(−0.37)라서 복소수가 되지만, 고유값이 모두 양수인 행렬은 실수 결과가 나온다.
>
> ```matlab
> S = [4 0; 0 9];  S^0.5        % [2 0; 0 3]
> T = [2 1; 1 2];  T^0.5        % [1.3660 0.3660; 0.3660 1.3660]
> ```
>
> `A^0.5`는 `X*X = A`를 만족하는 행렬 `X`(행렬 제곱근, `sqrtm(A)`와 같다)이고, 원소별 제곱근 `A.^0.5` = `sqrt(A)`와 다르다. 시험에서 "결과가 복소수"라고 쓴다면 "**그럴 수 있다**"가 정확하다.

---

## ⚠️ 함정

- **`A^2` vs `A.^2`.** 2장의 array 연산에서 `.`을 빼먹으면 정사각 행렬일 때 오류 없이 행렬 곱이 된다. 원소별 제곱을 원했다면 조용히 틀린다.
- **비정사각 행렬은 `^` 불가.** 벡터도 마찬가지.
- **`A^-1`은 역행렬**(10.1.5), `A.^-1`은 원소별 역수 `1./A`.
- 지수가 정수가 아니면 결과가 복소수일 수 있다.
