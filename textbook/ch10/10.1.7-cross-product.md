# 10.1.7 Cross Products

## dot product와의 차이

**cross product**는 **vector product**라고도 한다.

- dot product의 결과는 **스칼라**다.
- cross product의 결과는 **벡터**다.

cross product로 나온 벡터는 **두 입력 벡터가 만드는 평면에 항상 수직(normal)** 이다. 이 성질을 **직교성(orthogonality)** 이라고 한다.

## 벡터 표기

3차원 공간에서 방향과 크기를 함께 나타내는 두 벡터(힘이 대표적이다)를 생각하자.

$$
\vec A = A_x\vec i + A_y\vec j + A_z\vec k, \qquad \vec B = B_x\vec i + B_y\vec j + B_z\vec k
$$

- $A_x, A_y, A_z$와 $B_x, B_y, B_z$는 각각 x, y, z 방향 성분의 크기다.
- $\vec i, \vec j, \vec k$는 x, y, z 방향의 **단위 벡터**다.

## 정의

$$
\vec A \times \vec B = (A_yB_z - A_zB_y)\vec i + (A_zB_x - A_xB_z)\vec j + (A_xB_y - A_yB_x)\vec k
$$

> **[보강]** 외우기 쉬운 형태는 행렬식이다(슬라이드 요약 p.60: "cross product는 단위 벡터와 두 입력 벡터로 이루어진 행렬의 행렬식으로 볼 수 있다").
>
> $$
> \vec A \times \vec B = \det\begin{bmatrix} \vec i & \vec j & \vec k \\ A_x & A_y & A_z \\ B_x & B_y & B_z \end{bmatrix}
> $$

## `cross` 함수

- 입력 두 개: A 벡터와 B 벡터.
- 각 벡터는 **원소가 3개**여야 한다. 3차원 공간의 성분이기 때문이다.
- 어떤 방향(x, y, z)의 성분이 없으면 **0**을 넣는다.

슬라이드 예: $\vec A = 1\vec i + 2\vec j + 3\vec k$, $\vec B = 4\vec i + 5\vec j + 6\vec k$

```matlab
A = [1 2 3];
B = [4 5 6];
C = cross(A, B)
```
```
C =
    -3     6    -3
```

즉 $\vec C = -3\vec i + 6\vec j - 3\vec k$.

손 계산: $(2\cdot6 - 3\cdot5) = -3$, $(3\cdot4 - 1\cdot6) = 6$, $(1\cdot5 - 2\cdot4) = -3$.

> **[보강]** 직교성 확인 — 결과 벡터와 각 입력 벡터의 dot product는 0이다.
>
> ```matlab
> dot(C, A)       % 0
> dot(C, B)       % 0
> ```
>
> 단위 벡터로 확인하면 $\vec i \times \vec j = \vec k$: `cross([1 0 0], [0 1 0])` → `[0 0 1]`.

## 순서가 중요하다

cross product는 **교환법칙이 성립하지 않는다.** `cross(A,B)`는 `cross(B,A)`와 **부호가 반대**다.

```matlab
cross(B, A)
```
```
ans =
     3    -6     3
```

즉 $\vec C = +3\vec i - 6\vec j + 3\vec k$.

---

## ⚠️ 함정

- **`cross(A,B) = -cross(B,A)`.** 순서를 바꾸면 방향이 뒤집힌다. 토크 $\vec M = \vec r \times \vec F$는 반드시 r이 먼저.
- **2차원 벡터는 0을 채워 3원소로.** `cross([1 2], [3 4])`는 오류다.
  ```
  외적을 구하려면 A와 B의 차원의 길이는 3이어야 합니다.
  (A and B must be of length 3 in the dimension in which the cross product is taken.)
  ```
  `cross([1 2 0], [3 4 0])`으로 쓴다.
- **dot은 스칼라, cross는 벡터.** `dot([1 2 3],[4 5 6])` = 32, `cross([1 2 3],[4 5 6])` = `[-3 6 -3]`.
- > **[보강]** 직교성 확인을 소수 벡터로 하면 0 대신 `-4.4409e-16` 같은 반올림 오차가 나올 수 있다.
