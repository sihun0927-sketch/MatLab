# 10.2.2 Matrix Left Division

## Gaussian elimination

연립방정식을 푸는 더 나은 기법은 **Gaussian elimination**(가우스 소거법)이다. 변수를 체계적으로 소거해 **미지수가 하나만 남을 때까지** 줄인 다음, **거꾸로 대입(back substitution)** 해서 모든 미지수를 구한다.

MATLAB에서는 **left division 연산자 `\`** 가 이것을 한다. $AX = B$를 풀려면

$$
X = A \backslash B
$$

라고만 쓰면 된다.

```matlab
A = [2 1 -1; 1 -1 2; 3 2 1];
B = [-3; 9; 2];
X = A\B
```
```
X =
    1.0000
   -2.0000
    3.0000
```

10.2.1의 `inv(A)*B`와 같은 답이다.

> 슬라이드 예: `A = [3 2 -1; -1 3 2; 1 -1 -1]`, `B = [10; 5; -1]` → `X = A\B = [-2; 5; -6]`.

> **[보강]** 읽는 법: `A\B`는 "A로 B를 **왼쪽에서** 나눈다", 즉 $A^{-1}B$다. 슬래시 방향이 A 쪽으로 기울었다고 기억하자. 반대 방향 **`B/A`(right division)** 는 $BA^{-1}$로, $XA = B$(X가 왼쪽에 있는 식)를 푼다.
>
> ```matlab
> P = [1 2; 3 4];
> P\[5; 6]            % [-4; 4.5]   P*X = [5;6]
> [5 6]/P             % [-1 2]      X*P = [5 6]
> ```

## 다시 기본 예제 — 3식 3미지수

이후 over/under-defined 예제가 모두 이 시스템에서 출발한다.

$$
\begin{aligned}
3x + 2y + 5z &= 22 \\
4x + 5y - 2z &= 8 \\
x + y + z &= 6
\end{aligned}
$$

```matlab
A = [3 2 5; 4 5 -2; 1 1 1];
B = [22; 8; 6];
X = A\B
```
```
X =
     1
     2
     3
```

**독립인 식 3개, 미지수 3개**라서 해가 하나로 정해진다. 연립방정식을 풀려면 **독립인 식의 개수 = 미지수 개수**가 필요하다.

## Over-defined와 under-defined

MATLAB의 left division은 **over-defined**(식이 미지수보다 많음)나 **under-defined**(식이 미지수보다 적음) 시스템도 푼다.

### Over-defined — 일관된(consistent) 식

위 시스템에 넷째 식 $2x - 4y - 7z = -27$을 더하자. 미지수 3개를 정하는 데는 3개면 충분하므로 **over-defined**다.

```matlab
A4 = [A; 2 -4 -7];          % 4×3
B4 = [B; -27];              % 4×1
X4 = A4\B4
```
```
X4 =
    1.0000
    2.0000
    3.0000
```

**같은 결과**다. 넷째 식이 $(1, 2, 3)$을 만족하기 때문이다($2 - 8 - 21 = -27$). 이런 식들을 **consistent**하다고 한다.

### Over-defined — 일관되지 않은(inconsistent) 식

식이 일관되지 않으면 어떻게 될까? **계수(A)나 결과(B)가 측정 데이터에서 온 경우** 흔히 생긴다. 이때 MATLAB은 **least squares(최소제곱)** 방법으로 푼다(원서 뒷장에서 자세히 다룬다).

`B(4)`만 −27에서 **−28**로 바꾼다.

```matlab
B4b = [B; -28];
X = A4\B4b
```
```
X =
    0.8618
    2.1234
    3.0328
```

4개 식이 서로 맞지 않아 결과가 `[1; 2; 3]`이 **아니다.**

### Least squares는 B의 편차를 최소화한다

계산한 X로 B를 되돌려 구해 실제 B와 비교한다.

```matlab
Best_B = A4*X
Difference = B4b - Best_B
```
```
Best_B =
   21.9962
    7.9982
    6.0180
  -27.9997
Difference =
    0.0038
    0.0018
   -0.0180
   -0.0003
```

least squares는 **계산한 B 값과 실제 B 값의 차이**를 최소화한다. 네 식 중 어느 것도 정확히 맞지 않지만, 전체적으로 가장 적게 어긋나는 X를 고른 것이다.

> **[보강]** 정확히는 차이의 **제곱합** $\sum (B_i - \hat B_i)^2$을 최소화한다(그래서 "least **squares**"). 슬라이드는 "absolute value of the difference"라고 표현했지만, 최소화되는 것은 절댓값의 합이 아니라 제곱의 합이다. 여기서 `norm(Difference)` = 0.0185.

> **[보강]** 공학에서 가장 흔한 over-defined 문제는 **직선 맞춤(curve fitting)** 이다. 측정점 4개로 $y = mx + b$의 m, b(미지수 2개)를 구하는 것이 식 4개, 미지수 2개인 시스템이다(연습문제 2).

### Under-defined — 식이 미지수보다 적다

식이 미지수보다 적으면 해가 무수히 많다. MATLAB은 **변수 몇 개를 0으로 두어** 식 개수와 변수 개수를 같게 만든 다음 푼다.

$$
\begin{aligned}
3x + 2y + 5z &= 22 \\
4x + 5y - 2z &= 8
\end{aligned}
$$

```matlab
A2 = [3 2 5; 4 5 -2];
B2 = [22; 8];
X2 = A2\B2
A2*X2               % 확인
```
```
X2 =
         0
    2.8966
    3.2414
ans =
   22.0000
    8.0000
```

슬라이드 설명: MATLAB은 **첫 번째 변수를 0**으로 놓아 문제를 식 2개, 미지수 2개로 줄여 푼다.

> **[보강]** R2026a에서 이 예제는 슬라이드와 똑같이 x = 0이 나온다. 하지만 **"항상 첫 변수"는 아니다.** `\`는 열 피벗팅(column pivoting) QR로 어떤 변수를 0으로 둘지 고른다.
>
> ```matlab
> [1 2 3; 4 5 6]\[6; 15]          % [1.5; 0; 1.5]   ← 둘째 변수가 0
> [1 1 1; 1 -1 0]\[6; 0]          % [3; 3; 0]       ← 셋째 변수가 0
> ```
>
> 공통점은 "0이 아닌 값이 최대 rank(A)개인 해(basic solution)"라는 것이다. 위 예제들은 경고 없이 실행된다. 모든 해 중 **크기(norm)가 가장 작은 해**가 필요하면 `pinv(A)*B` 또는 `lsqminnorm(A, B)`를 쓴다: `pinv(A2)*B2` = `[1.8148; 1.2695; 2.8033]`. 시험 답안에는 슬라이드 설명("변수 일부를 0으로 둔다")을 쓰면 된다.

---

## ⚠️ 함정

- **`A\B`와 `B/A`를 헷갈리지 말 것.** `A\B` = $A^{-1}B$, `B/A` = $BA^{-1}$. 열 벡터 B에 `B/A`를 쓰면 "행렬의 차원이 일치해야 합니다" 오류가 난다.
- **`\`는 over-defined에서도 오류를 내지 않는다.** 일관되지 않은 식이면 조용히 least squares 답을 준다. 답이 맞는지는 `A*X - B`로 직접 확인해야 한다.
- **under-defined의 답은 여러 해 중 하나**일 뿐이다. "유일한 해"라고 쓰면 틀린다.
- **singular 정사각 시스템**(`[1 2; 2 4]\[3; 6]`)은 "특이 행렬" 경고와 함께 `NaN`/`Inf`가 나온다.
