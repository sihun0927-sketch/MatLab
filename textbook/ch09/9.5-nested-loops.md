# 9.5 Nested Loops

loop 안에 다른 loop를 넣는(**nest**) 것이 유용할 때가 많다.

예로 `max` 함수의 결과를 흉내 내 보자. `max`는 **각 열의 최댓값**을 돌려준다. 이것을 중첩 loop로 구한 뒤, 배열 **전체**의 최댓값까지 찾는다.

```matlab
x = [3 9 2;
     8 1 6;
     5 7 4];
max(x)                              % 비교용: 내장 함수
```
```
ans =
     8     9     6
```

```matlab
[rows, cols] = size(x);
maximum = zeros(1, cols);           % 사전할당 (9.6)
for k = 1:cols                      % 바깥 loop: 열
    maximum(k) = x(1, k);           % 그 열의 첫 원소를 일단 최댓값으로
    for j = 1:rows                  % 안쪽 loop: 행
        if x(j, k) > maximum(k)
            maximum(k) = x(j, k);   % 더 큰 값을 만나면 교체
        end
    end
end
maximum
```
```
maximum =
     8     9     6
```

- 바깥 loop의 pass **한 번**마다 안쪽 loop가 **처음부터 끝까지** 돈다. 비교 횟수는 `cols × rows = 9`번.
- 안쪽 loop의 index(`j`)와 바깥 loop의 index(`k`)는 **다른 변수**여야 한다.

> 슬라이드 원본은 `4×4` 배열로, `%%` 섹션 두 개(① `max(x)`, ② 중첩 loop)로 나누어 보여 준다. 원본 코드는 사전할당 없이 `maximum(k)`를 하나씩 늘린다.

### 전체 최댓값

각 열의 최댓값 중에서 다시 최댓값을 찾는다.

```matlab
overall = maximum(1);
for k = 2:cols
    if maximum(k) > overall
        overall = maximum(k);
    end
end
overall                             % 9
```

> **[보강]** 내장 함수로는 둘 다 한 줄이다.
>
> ```matlab
> max(max(x))          % 9 — 열별 최댓값의 최댓값
> max(x, [], "all")    % 9 — 전체에서 바로
> ```
>
> 8장 HINT의 말처럼, 중첩 loop는 이해하기 어렵고 logic error의 단골 원인이다. 내장 함수나 vectorization으로 피할 수 있으면 피한다. 여기서 중첩 loop를 쓰는 것은 **원리를 보이기 위해서**다.

---

## ⚠️ 함정

- **안쪽·바깥 index에 같은 변수**를 쓰면 안쪽 loop가 바깥 index를 덮어쓴다. `for`는 다음 pass에 index를 다시 대입하므로 오류는 안 나지만, 안쪽에서 쓰는 바깥 index 값이 틀어진다.
- **최댓값 초기값을 0으로** 두면 음수만 있는 열에서 틀린다(답이 0). **그 열의 첫 원소**로 초기화하는 이유다.
- **행·열 순서 혼동.** `x(j, k)`에서 `j`가 행, `k`가 열이다. `size`가 돌려주는 순서도 `[rows, cols]`.
- **`break`는 안쪽 loop만** 끝낸다(9.3).

   ```matlab
   end
   ```
