# 9.3 `break`와 `continue`

- **`break`**: `for` loop나 `while` loop를 **도중에 끝낸다.**
- **`continue`**: `break`와 비슷하지만 loop를 끝내지 않고, **이번 pass만 그만두고 다음 pass로** 건너뛴다.

두 명령 모두 보통 **`if`와 함께** 쓴다.

---

## `break` 예제

양수를 최대 3번(슬라이드는 4번) 입력받아 자연로그를 출력한다. 음수가 들어오면 메시지를 내고 프로그램을 끝낸다.

```matlab
n = 0;                                          % 2행: 카운터, loop 밖
while n < 3                                     % 3행
    n = n + 1;                                  % 4행
    a = input("Enter a value greater than 0: ");% 6행
    if a <= 0                                   % 7행
        disp("You must enter a positive number")
        disp("This program will terminate")
        break                                   % 10행
    end
    disp("The natural log of that number is")
    disp(log(a))
end                                             % 14행
```

`2`, `-5`를 입력한 경우:

```
Enter a value greater than 0: 2
The natural log of that number is
    0.6931
Enter a value greater than 0: -5
You must enter a positive number
This program will terminate
```

`-5` 뒤로는 더 묻지 않는다. loop가 `n = 2`에서 끝났기 때문이다(`n < 3`이 아직 참인데도).

### Debugger로 한 줄씩 따라가기 (슬라이드 p.16~22)

슬라이드는 이 예제를 **debugger**로 한 줄씩 실행해 보여 준다.

1. 2행 줄 번호 옆을 클릭해 **breakpoint**(빨간 표시)를 걸고 **Run**을 누른다. 코드는 2행에서 **멈춘다**(pause). 이때 Editor 툴바의 Run 자리에 **Continue, Step, Step In, Step Out, Stop** 버튼이 나타나고, command window 프롬프트가 `K>>`로 바뀐다.
2. 2행에서 카운터 `n`이 loop **밖**에서 0으로 정해진다. 이제 **Step** 아이콘으로 한 줄씩 실행할 수 있다.
3. 각 단계에서 무엇이 일어나는지:

| 단계 | 실행한 줄 | 일어나는 일 | Workspace |
|---|---|---|---|
| 1 | 3행 `while n < 4` | `n = 0`이므로 참 → loop에 들어감 | `n = 0` |
| 2 | 4~6행 (Step 반복) | `n` 증가, `input`에서 값을 기다림. `-5` 입력 | `a = -5`, `n = 1` |
| 3 | 7행 `if a <= 0` | 참 → 7행 바로 아래 묶음(`disp` 두 개와 `break`)으로 | |
| 4 | 10행 `break` | **loop를 뛰쳐나가 14행 `end`로** | |
| 5 | (가정) 양수였다면 | `if`가 거짓 → 상자 안 묶음(메시지·`break`) 전체를 건너뜀. `n`이 4가 될 때까지 계속 반복 | |

Workspace 창에서 `a`와 `n`의 값이 단계마다 바뀌는 것을 볼 수 있다. 이것이 debugger를 쓰는 이유다.

> **[보강]** 단축키: Step = `F10`, Step In = `F11`, Continue = `F5`. 키보드로 `dbstop`, `dbstep`, `dbcont`, `dbquit` 명령으로도 같은 일을 할 수 있다.

## `continue` 예제

`break` 자리에 `continue`를 넣고 메시지를 바꿨다. 음수가 들어와도 프로그램을 끝내지 않고, **이번 pass만** 그만두고 `while` 문으로 돌아간다.

```matlab
n = 0;
while n < 3
    n = n + 1;
    a = input("Enter a value greater than 0: ");
    if a <= 0
        disp("You must enter a positive number")
        disp("Try again")
        continue
    end
    disp("The natural log of that number is")
    disp(log(a))
end
```

`2`, `-5`, `3`을 입력한 경우:

```
Enter a value greater than 0: 2
The natural log of that number is
    0.6931
Enter a value greater than 0: -5
You must enter a positive number
Try again
Enter a value greater than 0: 3
The natural log of that number is
    1.0986
```

- `-5`인 pass에서는 `continue` 아래의 `log` 출력 두 줄이 **건너뛰어진다.**
- 하지만 `n`은 이미 증가했으므로, 잘못된 입력도 **3번 중 한 번으로 센다.** 입력 기회가 줄어든다.

| | `break` | `continue` |
|---|---|---|
| 이번 pass의 나머지 | 건너뜀 | 건너뜀 |
| 다음 pass | **없음** — loop 종료 | **있음** — 기준 검사로 돌아감 |
| 이후 실행 위치 | loop의 `end` 다음 줄 | loop의 첫 줄(`while` 검사 / `for`의 다음 index) |

> **[보강]** R2026a에서 `-batch`는 `input`을 못 쓰므로 `vals = [2, -5, 3]; a = vals(n);`으로 바꿔 위 출력을 확인했다.

## ⚠️ 함정

- **`break`는 가장 안쪽 loop 하나만** 빠져나온다. 중첩 loop 전체를 끝내지 않는다(9.5 연습 참고).

  ```matlab
  for i = 1:3
      for j = 1:3
          if j == 2, break, end
          fprintf("(%d,%d) ", i, j)
      end
  end
  % (1,1) (2,1) (3,1)  ← 바깥 loop는 3번 다 돈다
  ```
- **`break`는 `if`를 빠져나오는 명령이 아니다.** `if` 안에 있어도 그 `if`를 감싼 **loop**를 끝낸다.
- **`continue` 앞에 갱신이 있어야 한다.** `while`에서 `n = n + 1`을 `continue` **뒤**에 두면, 건너뛰는 pass에서 `n`이 안 바뀌어 무한 루프가 된다.
- **loop 밖의 `break`는 오류**다. R2026a 메시지: `BREAK 문이 루프 외부에 나타났습니다. 대신 RETURN을 사용하십시오.`
