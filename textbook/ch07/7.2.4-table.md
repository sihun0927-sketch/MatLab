# 7.2.4 출력 (4) — `table`

## 왜 필요한가

`disp`와 `fprintf`로 형식 있는 출력을 만들 수는 있지만, **열마다 자료형이 다른 표**를 만들기는 번거롭다. 이름은 글자이고 중력가속도는 숫자인 표를 `fprintf`로 찍으려면 형식 문자열과 배열 쌓기를 매번 손으로 맞춰야 한다.

`table`은 **서로 다른 자료형의 열을 한 변수에 담는** 새 자료형이다. 원래는 자료를 다루는 도구지만, 출력 수단으로도 매우 편하다.

---

## 만들기

입력은 **모두 열 벡터**여야 한다.

[`example/ch07/ex0724_table_basics.m`](../../example/ch07/ex0724_table_basics.m):

```matlab
p = ["Earth"; "Moon"];        % string 열 벡터
g = [9.81; 1.62];             % double 열 벡터
d = 0.5 * g * 100^2;          % 100 초 동안 낙하한 거리

table(p, g, d)
```
```
ans =

  2×3 table

       p        g        d  
    _______    ____    _____

    "Earth"    9.81    49050
    "Moon"     1.62     8100
```

**변수 이름이 그대로 열 이름이 된다.** `p`, `g`, `d`처럼 짧은 이름을 쓰고 있었다면 표가 읽히지 않는다.

---

## 열 이름 지정 — `VariableNames`

```matlab
table(p, g, d, 'VariableNames', ["Planet", "Gravity", "Distance"])
```
```
    Planet     Gravity    Distance
    _______    _______    ________

    "Earth"     9.81       49050  
    "Moon"      1.62        8100  
```

`'VariableNames'`는 **작은따옴표**로 써야 한다. 이것은 MATLAB에서 아직 작은따옴표를 고수해야 하는 몇 안 되는 자리 중 하나다.

큰따옴표로 쓰면 MATLAB이 그것을 옵션 이름이 아니라 **데이터 열 하나**로 받아들인다.

```
큰따옴표를 쓰면: 모든 테이블 변수는 행 수가 동일해야 합니다.
```

> **[보강]** 슬라이드는 "MATLAB이 적절한 알림과 함께 오류를 낸다"고 하지만, R2026a의 실제 메시지는 위와 같이 **행 수가 다르다**는 쪽이다. `"VariableNames"`가 1행짜리 데이터 열로 해석되어 2행짜리 `p`, `g`와 맞지 않는 것이다. 원인을 알면 메시지가 납득이 간다.

### 이름을 미리 배열에 담아 두기

```matlab
ColNames = ["Planet", "Gravity (m/s^2)", "Distance (m)"];
T = table(p, g, d, 'VariableNames', ColNames);
```

같은 이름을 여러 표에 쓸 때 편하다.

---

## `ans =` 줄 없애기 — `disp`로 감싸기

세미콜론 없이 `table(...)`을 쓰면 `ans =`와 `2×3 table` 머리글이 같이 나온다. 결과만 보여 주고 싶으면 `disp`로 감싼다.

```matlab
disp(table(p, g, d, 'VariableNames', ["Planet", "Gravity", "Distance"]))
```
```
    Planet     Gravity    Distance
    _______    _______    ________

    "Earth"     9.81       49050  
    "Moon"      1.62        8100  
```

---

## 표를 변수에 담아 쓰기

[`example/ch07/ex0724_table_colnames.m`](../../example/ch07/ex0724_table_colnames.m)

표도 다른 배열처럼 이름을 붙여 workspace에 둘 수 있다. 그러면 자료처럼 다룰 수 있다.

```matlab
T = table(p, g, d, 'VariableNames', ColNames);

size(T)       % [3 3]   (행 3, 변수 3)
height(T)     % 3
width(T)      % 3
T.Planet      % 열 하나 꺼내기
T{:,2}        % 2 번째 열의 값만 (double 배열)
T(T.Gravity > 3, :)      % 조건에 맞는 행만
T.Ratio = g / 9.81;      % 열 추가
sortrows(T, "Total", "descend")    % 정렬
summary(T)    % 열별 통계
```

| 쓰기 | 뜻 |
|---|---|
| `T.이름` | 그 열의 값 (원래 자료형 그대로) |
| `T.("이름")` | 같은 것. 이름에 공백·한글·괄호가 있을 때 |
| `T(행, 열)` | 부분 **표** (여전히 table) |
| `T{행, 열}` | 부분 **값** (중괄호면 내용물) |

> **[보강]** 점 표기 `T.총점`은 **쓸 수 없다**. MATLAB 식별자는 ASCII 글자로 시작해야 해서 한글 열 이름은 파싱 단계에서 거부된다. 공백이나 괄호가 든 이름도 마찬가지다. 전부 `T.("총점")`, `T.("Temp (degC)")` 형태로 접근해야 한다. 열 이름 자체는 한글이어도 아무 문제가 없다.

### 표에 설명 붙이기

```matlab
T.Properties.VariableUnits = ["", "degC", "kPa"];
T.Properties.VariableDescriptions = ["시료 번호", "측정 온도", "측정 압력"];
T.Properties.Description = "측정 자료";
T.Properties.RowNames = cellstr(T.Sample);   % 행 이름을 붙이면 T("S3", :) 가 된다
```

## Variable Editor

workspace 창에서 변수 이름을 더블클릭하면 **Variable Editor**가 열려 표를 스프레드시트처럼 보고 고칠 수 있다. 100행짜리 표를 command window로 보는 것보다 훨씬 낫다. 명령으로 여는 것은 `openvar('T')`다.

> **[보강]** `openvar`는 데스크톱에서만 동작한다. `-batch`에서는 `usejava('desktop')`으로 걸러야 한다.

---

## ⚠️ 함정

- **입력은 열 벡터여야 한다.** 행 벡터를 주면 **오류가 나지 않는다**. 대신 행이 1개뿐이고 각 변수가 `1×n`짜리 한 칸인 엉뚱한 표가 만들어진다. `size(T)`로 행 수를 확인할 것.
- **`'VariableNames'`는 작은따옴표.** 큰따옴표를 쓰면 데이터 열로 오해받아 행 수 오류가 난다.
- **변수 이름이 열 이름이 된다.** `p`, `g` 같은 이름을 쓰고 있었다면 `VariableNames`를 꼭 줄 것.
- **`T(1,2)`와 `T{1,2}`는 다르다.** 소괄호는 작은 표를, 중괄호는 값을 준다.
- **한글·공백·괄호가 든 열 이름은 `T.("...")`로만 접근된다.**
- **`disp(table(...))`로 감싸야 `ans =`가 사라진다.**
