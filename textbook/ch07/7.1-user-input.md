# 7.1 사용자 입력 — `input`

## 프로그래머와 사용자가 다른 사람이 되는 순간

6장까지는 프로그램을 쓰는 사람과 돌리는 사람이 같았다. command window를 계산기처럼 쓰거나, 편집창에서 짧은 프로그램을 쓰고 직접 돌렸다. 값을 바꾸고 싶으면 코드를 고치면 그만이었다.

7장부터는 **프로그램을 쓰는 사람과 돌리는 사람이 다를 수 있다**고 가정한다. 그러면 비슷한 문제를 풀 때마다 코드를 고쳐 쓸 수는 없으므로, 프로그램이 돌아가는 중에 값을 받고 결과를 보여 주는 수단이 필요하다. MATLAB이 주는 수단은 이렇다.

| 방향 | 함수 |
|---|---|
| 사용자 → 프로그램 | `input`, `ginput` |
| 프로그램 → 사용자 | `disp`, `fprintf`, `sprintf`, `table` |
| 파일 ↔ 프로그램 | `readtable`, `writetable`, `audioread`, `uiimport` |

프로그램을 담는 그릇은 두 가지다.

- **script**(`.m`): 평범한 텍스트 파일. 명령을 차례로 적는다.
- **live script**(`.mlx`): 코드와 서식 있는 글, 수식, 그림, 실행 결과를 한 문서에 담는다. `.m`과 달리 텍스트 파일이 아니라서 git diff가 잘 보이지 않는다.

이 장의 내용은 둘 중 어느 쪽에서도 똑같이 동작한다.

## `input`의 기본형

```matlab
z = input("Enter a value ")
```

하는 일은 세 단계다.

1. 따옴표 안의 글(prompt)을 command window에 띄운다.
2. 사용자가 Enter를 칠 때까지 **프로그램을 멈춘다**.
3. 사용자가 친 것을 **MATLAB 코드처럼 해석**해서 그 값을 `z`에 넣는다.

3번이 핵심이다. `input`은 "글자를 받는" 함수가 아니라 "식을 받아 계산해 주는" 함수다. 그래서 사용자가 `2+3`이라고 치면 `5`가 들어가고, `pi/2`라고 치면 `1.5708`이 들어간다.

[`example/ch07/ex0701_input_types.m`](../../example/ch07/ex0701_input_types.m):

```matlab
z = input("Enter a value ");                    % 5
x = input("Enter an array in brackets ");       % [1, 2, 3; 4, 5, 6]
y = input("Enter your name in double quotes "); % "Holly"
w = input("Enter your name in single quotes "); % 'Maria'
```

```
이름   크기       클래스
z    [1 1]    double
x    [2 3]    double
y    [1 1]    string
w    [1 5]    char
```

네 번 모두 같은 `input`인데 자료형이 넷 다 다르다. **`input`은 자료형을 정하지 않는다. 사용자가 친 모양이 자료형을 정한다.** 배열을 넣고 싶으면 평소 MATLAB에서 배열을 만들듯 대괄호와 쉼표·세미콜론을 그대로 치면 된다.

> **[보강]** `input`은 키보드를 기다리므로 `matlab -batch`에서는 아예 쓸 수 없다. R2026a에서 시도하면 "사용자 입력값을 읽기 위해서는 ... 이 플랫폼에서는 그렇게 동작할 수 없습니다"라는 오류가 난다. 이 저장소의 예제는 `usejava('desktop')`으로 환경을 보고 갈라, 배치 실행에서는 입력했을 값을 직접 넣는다. 데스크톱에서 돌리면 진짜로 물어본다.
>
> ```matlab
> if usejava('desktop')
>     z = input("Enter a value ");
> else
>     z = 5;   % -batch 에서는 input 을 쓸 수 없다
> end
> ```

## char 배열과 string은 크기가 다르다

이 장에서 가장 자주 나오는 시험 포인트다.

```matlab
w = 'Maria'    % char   → 1x5
y = "Holly"    % string → 1x1
```

둘 다 글자 다섯 개인데 크기가 다르다.

- **char 배열**은 글자 하나가 원소 하나다. `'Maria'`는 원소 다섯 개짜리 `1x5` 배열이다.
- **string**은 문자열 하나가 원소 하나다. `"Holly"`는 글자가 몇이든 `1x1`이다.

그래서 길이를 재는 함수도 다르다.

```matlab
numel('Maria')      % 5
numel("Holly")      % 1    ← 문자열이 하나라는 뜻
strlength("Holly")  % 5    ← 글자 수를 원하면 이쪽
```

> **[보강]** `length`는 "가장 긴 차원의 크기"라 `length("Holly")`도 1이다. 글자 수를 세려면 `strlength`뿐이다. `size`, `numel`, `length`가 전부 1을 돌려주는데 글자는 다섯 개인 상황이 string을 처음 쓸 때의 혼란 지점이다.

## `input(prompt, "s")` — 따옴표 없이 글자 받기

따옴표를 꼬박꼬박 치게 하는 것은 불친절하다. 두 번째 인수에 `"s"`를 주면 사용자가 친 글자를 **그대로** 받는다.

```matlab
p = input("Enter your name - no need to include quotes ", "s")
```

[`example/ch07/ex0701_input_s.m`](../../example/ch07/ex0701_input_s.m):

```
p = Lin
class(p) = char   ← "s" 를 줬는데도 string 이 아니라 char
size(p)  = [1 3]
```

**이름이 `"s"`(string)인데 돌아오는 것은 char 배열이다.** string이라는 자료형이 생기기 한참 전, 글자들의 나열을 그냥 "string"이라고 부르던 시절에 만들어진 옵션이라 이름이 그렇게 굳었다. string으로 쓰고 싶으면 `string(p)`로 직접 바꿔야 한다.

`"s"` 없이 받는데 사용자가 따옴표를 빠뜨리면 이렇게 된다.

```
따옴표 없이 Lin 을 입력했다면: 'Lin'은(는) 인식할 수 없는 함수 또는 변수입니다.
```

MATLAB이 `Lin`을 변수나 함수 이름으로 해석하려 들기 때문이다.

> **[보강]** char 배열이냐 string이냐는 취향 문제에 가깝다. 다만 `"s"`로 받은 **숫자**는 숫자가 아니라 글자라는 점은 취향 문제가 아니다.
>
> ```matlab
> age = input("나이? ", "s");   % '42'
> age + 1                        % [53 51]  ← ASCII 코드에 1 을 더했다
> str2double(age) + 1            % 43       ← 이렇게 바꿔 써야 한다
> ```

## ⚠️ 함정

- **`input`은 `-batch`에서 못 쓴다.** 자동 채점이나 배치 실행을 염두에 둔 코드라면 입력을 함수 인수로 받도록 설계하고, `input`은 맨 바깥 스크립트에만 두는 편이 안전하다.
- **`'s'` 옵션은 string이 아니라 char를 준다.** 이름에 속지 말 것.
- **`numel("Holly")`는 5가 아니라 1이다.** 글자 수는 `strlength`.
- **`input`은 친 것을 코드로 해석한다.** 사용자가 `clear`라고 치면 그대로 실행된다. 신뢰할 수 없는 입력에 `input`을 쓰면 안 되는 이유다(`"s"` 옵션은 해석하지 않으므로 이 문제가 없다).
- **그냥 Enter를 누르면 `[]`(빈 배열)이 돌아온다.** 오류가 아니라 빈 값이므로, 뒤에서 `isempty`로 확인해 기본값을 채워 주는 코드가 필요하다.
- **prompt 끝에 공백을 넣어 두자.** `input("값? ")`처럼 써야 사용자가 치는 글자가 물음표에 달라붙지 않는다.

## 연습문제

1. 반지름을 입력받아 원의 넓이와 둘레를 소수점 아래 네 자리까지 출력하는 스크립트를 쓰시오. 입력이 양수인 스칼라가 아니면 `error`로 멈추게 하시오.
2. 사용자가 `'Hong'`, `"Hong"`, (`"s"` 옵션으로) `Hong`을 쳤을 때 돌아오는 세 값의 클래스·크기·글자 수를 표로 출력하시오. `isequal`로 비교하면 어떤 결과가 나오는지도 확인하시오.
3. 벡터를 입력받아 개수·합계·평균·최댓값(과 그 위치)·최솟값·표준편차를 출력하시오. 사용자가 그냥 Enter를 누르면 기본값 `[4 8 15 16 23 42]`를 쓰도록 하시오.
