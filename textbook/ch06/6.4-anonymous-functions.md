# 6.4 Anonymous function과 function handle

## anonymous function

파일을 만들지 않고 **한 줄로 그 자리에서** 정의하는 함수다. command window나 스크립트에서 만들고, workspace가 비워지면 함께 사라진다.

```matlab
ln = @(x) log(x)
```

| 부분 | 의미 |
|---|---|
| `@` | "이것은 함수다"라고 MATLAB에 알리는 기호 |
| `(x)` | 입력 목록. 바로 뒤에 괄호로 나열 |
| `log(x)` | 함수의 본체. **식 하나**만 쓸 수 있다 |

만들어진 `ln`은 **변수처럼** workspace에 올라가며, 클래스(자료형)는 `function_handle`이다.

[`example/ch06/ex0604_anonymous.m`](../../example/ch06/ex0604_anonymous.m):

```matlab
ln  = @(x) log(x);
hyp = @(a, b) sqrt(a.^2 + b.^2);   % 입력 여러 개
always7 = @() 7;                    % 입력 없음
```

```
ln(exp(2)) = 2
벡터도 그대로: [0 1 2]
class(ln) = function_handle
isa(ln, 'function_handle') = 1
hyp(3, 4) = 5
always7() = 7
```

일반 함수처럼 쓸 수 있고, 벡터를 넣으면 원소별로 계산된다(본체를 `.^`, `.*`로 써야 한다).

## 값은 만들어질 때 복사되어 박제된다

이것이 anonymous function의 가장 중요한 성질이다. 정의할 때 쓰인 바깥 변수의 **그 순간의 값**이 함수 안에 복사되어 들어간다. 나중에 바깥 변수를 바꿔도 함수는 옛날 값을 계속 쓴다.

```matlab
a = 2;
f = @(x) a*x;
a = 100;            % 나중에 a 를 바꿔도
f(3)                % → 6.  여전히 a=2 로 계산한다
```

`clear a`로 지워도 `f`는 멀쩡히 동작한다. 무엇이 박제됐는지는 `functions(f)`로 들여다볼 수 있다([`sol0604_2.m`](../../example/ch06/sol0604_2.m)에서는 같은 실험을 변수 `k`로 한다).

```
f 가 붙잡고 있는 변수:
    k: 2
```

식 자체는 `func2str`로 확인한다.

```
f 의 정의: @(x)a*x
```

> **[보강]** 최신 값을 쓰고 싶다면 그 변수를 입력 인수로 받도록 만들어야 한다: `g = @(x, a) a*x`.

## function handle — 이미 있는 함수에 별명 붙이기

`@` 뒤에 **괄호 없이 함수 이름만** 쓰면 그 함수를 가리키는 handle이 된다.

```matlab
g = @mypoly;        % 괄호 없음
g(2)                % → 22, mypoly(2) 와 같다
```

`@mypoly`(handle)와 `mypoly(2)`(호출)는 전혀 다르다. 전자는 함수 자체를, 후자는 계산 결과를 준다.

handle은 내장 함수에도 붙일 수 있고(`@sin`, `@sqrt`), local function에도 붙일 수 있다. 6.2에서 본 것처럼 local function의 handle은 **파일 밖으로 넘겨도 동작한다**.

## 입력 일부를 미리 고정해 두기

입력이 많은 함수를 쓰는데 매번 하나만 바뀐다면, 나머지를 미리 묶어 새 함수를 만들 수 있다.

[`example/ch06/ex0604_partial.m`](../../example/ch06/ex0604_partial.m):

```matlab
a = 5; b = 10; c = 15; d = 20;      % 매번 똑같이 들어가는 "어려운 부분"

new_fun = @(x) complicated(a, b, c, d, x);
```

```
new_fun(1) = 50
new_fun(2) = 130
new_fun(3) = 290
new_fun(4) = 560
new_fun 의 정의: @(x)complicated(a,b,c,d,x)
```

`a`~`d`는 만드는 시점의 값으로 박제되고, 앞으로는 `x` 하나만 넘기면 된다. 6.5의 function function(`fzero`, `fminbnd` 등)은 **입력이 하나인 함수**를 요구하는 경우가 많아, 이 기법이 자주 쓰인다.

## .mat 파일로 저장하고 불러오기

anonymous function은 변수이므로 `save`/`load`가 그대로 통한다.

[`example/ch06/ex0604_save_load.m`](../../example/ch06/ex0604_save_load.m):

```matlab
drag = @(v, k) k * v.^2;
ln   = @(x) log(x);

save(matfile, 'drag', 'ln');
clear drag ln
load(matfile);
drag(10, 0.5)       % → 50
```

```
clear 후 exist('drag', 'var') = 0
load 후  exist('drag', 'var') = 1
drag(10, 0.5) = 50
ln(exp(3))    = 3
```

`S = load(파일)`처럼 구조체로 받으면 무엇이 들어있었는지 `fieldnames(S)`로 확인할 수 있어 더 안전하다.

> 구문법: R2006b 이전에는 같은 일을 `f = inline('x.^2')`으로 했다. `inline`은 폐기(deprecated)되었으니 anonymous function을 쓴다. `fplot('sin(x)')`처럼 식을 문자열로 넘기는 형태도 같은 이유로 더 이상 쓰지 않는다.

## ⚠️ 함정

- **`@` 뒤 괄호의 유무**: `@mypoly`는 handle, `@(x) mypoly(x)`도 handle(한 겹 감싼 것), `mypoly(2)`는 호출 결과. `f = mypoly`처럼 `@` 없이 쓰면 인수 없이 호출한 결과가 들어간다.
- **본체에는 식 하나만 쓸 수 있다.** `if`, `for`, 여러 줄은 불가능하다. 필요하면 local function으로 만든다.
- **박제 성질을 잊으면 결과가 틀린다.** 루프 안에서 `f{k} = @(x) k*x`를 만들면 각 handle이 그때그때의 `k`를 따로 붙잡으므로 의도대로 동작한다. 반대로 루프 밖 변수를 나중에 바꿔봐야 이미 만든 handle에는 반영되지 않는다.
- **원소별 연산 점을 빠뜨리기**: `@(x) x^2`에 벡터를 넣으면 행렬 거듭제곱이 되어 오류가 난다. `@(x) x.^2`로 써야 한다.
- **workspace를 지우면 사라진다.** 계속 쓰려면 `.mat`으로 저장하거나 아예 함수 파일로 만든다.
- **`save`로 저장된 anonymous function은 박제된 변수까지 함께 저장된다.** 파일이 예상보다 클 수 있고, 저장 당시의 값이 그대로 되살아난다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다. 시험 대비용으로 추가한 것이다.

1. 도를 라디안으로 바꾸는 `deg2radf`, 원의 둘레를 구하는 `circ`, 두 점 사이 거리를 구하는 `dist2`를 각각 anonymous function으로 만들어라. `whos`로 세 변수의 클래스가 `function_handle`인지 확인하고, `func2str`로 정의를 출력하라.
2. `k = 2`일 때 `f = @(x) k*x`를 만든 뒤 `k`를 10으로 바꾸고, 다시 `k`를 지워라. 각 단계에서 `f(10)`이 어떻게 나오는지 확인하고, `functions(f)`로 실제로 무엇이 저장되어 있는지 보여라. 최신 `k`를 쓰려면 어떻게 고쳐야 하는지도 보여라.
3. `parabola = @(x) x.^2 - 4`와 정규분포 밀도 `gauss = @(x, mu, s) ...`를 `.mat` 파일에 저장하고, `clear` 후 구조체로 `load`해 다시 호출하라. `fieldnames`로 무엇이 저장됐는지 확인하라.
