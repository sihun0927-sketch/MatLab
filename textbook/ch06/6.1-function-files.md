# 6.1 함수 파일 작성 (Creating Function Files)

MATLAB은 함수를 중심으로 만들어진 언어다. `sin(x)`를 쓸 때 우리는 사인값을 어떻게 계산하는지 알 필요가 없다. 각도를 넣으면 결과가 나온다. 자주 하는 계산을 이렇게 포장해 두면 같은 코드를 다시 쓰지 않아도 된다. 내장 함수만 쓰는 게 아니라 **직접 함수를 만들 수 있다**는 것이 이 장의 내용이다.

## 6.1.1 함수의 구조와 문법

내장 함수든 사용자 정의 함수든 구조는 같다. **이름**, **사용자가 주는 입력**, **계산된 출력** 세 가지다.

함수 파일은 반드시 **function definition line**(함수 정의줄)으로 시작한다.

```matlab
function result = calculation(a)
%        ^^^^^^   ^^^^^^^^^^^ ^
%        출력 변수   함수 이름   입력 변수
```

정의줄에 들어가는 네 가지:

| 요소 | 설명 |
|---|---|
| `function` | 이 파일이 함수임을 알리는 키워드. 반드시 맨 앞 |
| 출력 변수 | 반환할 값을 담을 변수 이름. 여러 개면 `[a, b]` |
| 함수 이름 | 호출할 때 쓰는 이름. **파일 이름과 같아야 한다** |
| 입력 변수 | 괄호 안에 쉼표로 나열 |

출력 변수, 함수 이름, 입력 변수의 이름은 프로그래머가 마음대로 정한다. 함수 이름은 변수 이름 규칙(영문자로 시작, 영문자·숫자·언더스코어만)을 그대로 따른다.

### 함수를 어디에 두는가

MATLAB이 함수를 찾을 수 있으려면 셋 중 하나여야 한다.

1. **현재 폴더(current folder)에 있는 별도 파일** — `mypoly.m`처럼 함수 이름과 같은 이름의 파일
2. **search path 위의 폴더에 있는 별도 파일** — 6.3에서 다룬다
3. **호출하는 스크립트/라이브 스크립트의 맨 끝** — 이 경우 그 파일 안에서만 쓸 수 있고, **local function**이라 부른다

파일은 스크립트(`.m`, M-file)로도 라이브 스크립트(`.mlx`, MLX-file)로도 저장할 수 있다. 이 저장소는 전부 `.m`을 쓴다.

### 별도 파일로 저장한 함수

[`example/ch06/mypoly.m`](../../example/ch06/mypoly.m):

```matlab
function output = mypoly(x)
% MYPOLY  다항식 5x^3 - 4x^2 + 2x - 6 의 값을 계산한다.
%   output = MYPOLY(x) 는 x 의 각 원소에 대해 다항식 값을 원소별로 계산한다.
%   x 는 스칼라, 벡터, 행렬 모두 가능하다.
%
%   예: mypoly(2) 는 22 를 반환한다.
%
%   참고: POLYVAL, MYPOLY 는 내장 함수 POLY 와 다른 함수다.

if nargin == 0
    x = 0:0.5:2;   % [보강] 인수 없이 실행해도 되도록 넣은 기본값
end

output = 5*x.^3 - 4*x.^2 + 2*x - 6;
end
```

- 파일 이름은 반드시 `mypoly.m`이다. 파일 이름과 함수 이름이 다르면 **파일 이름 쪽이 이긴다**.
- 마지막 줄의 `end`는 별도 파일에서는 **필수가 아니지만** 쓰는 것이 좋은 습관이다. 한 파일에 함수가 여러 개면 필수다.
- 거듭제곱을 `.^`로 쓴 덕분에 벡터·행렬을 그대로 넣을 수 있다.

> **[보강]** 이 저장소의 독립 함수 파일에는 `if nargin == 0` 기본값 블록이 들어 있다. 파일을 그냥 실행해도 오류 없이 돌아가게 하려고 넣은 것이며, 교재 원본에는 없다. `nargin`은 6.1.5에서 다룬다.

저장한 뒤에는 command window에서도, 다른 프로그램에서도 호출할 수 있다.
[`example/ch06/ex0601_first_function.m`](../../example/ch06/ex0601_first_function.m):

```matlab
x = 0:0.5:2;
y = mypoly(x);
```

실행 결과:

```
x =
         0    0.5000    1.0000    1.5000    2.0000
mypoly(x) =
   -6.0000   -5.3750   -3.0000    4.8750   22.0000
mypoly(2) = 22
mypoly([1 2; 3 4]) =
    -3    22
    99   258
```

### 프로그램 안에 함수를 넣는 경우 (local function)

함수를 한 프로그램에서만 쓸 거라면 굳이 파일을 따로 만들 필요가 없다. 스크립트 **맨 끝**에 적으면 된다. 코드 조각이 한곳에 모여 모듈식 프로그래밍에 유리하다.

규칙 두 가지:
- 함수는 **파일 끝**에 두어야 한다(실행 코드보다 뒤).
- 각 함수를 **`end`로 닫아야 한다**.

[`example/ch06/ex0601_local_function.m`](../../example/ch06/ex0601_local_function.m):

```matlab
d = [0.1 0.25 0.5 1.0 2.0];    % 입자 지름 (mm)
c = grain_class(d);

for k = 1:numel(d)
    fprintf('%5.2f mm → %s\n', d(k), c(k));
end

% ---- 여기서부터 local function. 반드시 파일 끝에 두고 end 로 닫는다 ----
function label = grain_class(dia)
% GRAIN_CLASS  입자 지름(mm)을 모래/자갈 등급 문자열로 바꾼다.
label = strings(size(dia));
label(dia < 0.25)               = "fine sand";
label(dia >= 0.25 & dia < 0.5)  = "medium sand";
label(dia >= 0.5  & dia < 2.0)  = "coarse sand";
label(dia >= 2.0)               = "gravel";
end
```

```
 0.10 mm → fine sand
 0.25 mm → medium sand
 0.50 mm → coarse sand
 1.00 mm → coarse sand
 2.00 mm → gravel
```

`grain_class`는 command window에서도, 다른 프로그램에서도 **호출할 수 없다**. 그래서 local function이라 부른다.

## 6.1.2 주석과 help (H1 line)

함수 안의 주석 중 **함수 정의줄 바로 다음에 이어지는 주석 블록**은 특별한 역할을 한다. `help 함수이름`을 쳤을 때 출력되는 내용이 바로 이 블록이다.

- 주석 블록의 **첫 줄**을 **H1 line**이라 부른다. `lookfor`로 검색할 때, 그리고 폴더 목차를 볼 때 그 함수의 한 줄 요약으로 쓰인다.
- `help 이름`으로 조회되는 것은 **파일로 저장된 함수**다. 스크립트나 다른 파일 안의 local function은 이름만으로는 찾지 못하고 `help 파일이름>함수이름` 형태로 불러야 한다.
- 관례상 H1 line은 `% 함수이름(대문자)  한 줄 설명` 형식으로 쓴다.
- 주석 블록 중간에 **주석이 아닌 줄**(빈 줄 포함)이 끼면 `help`는 거기서 끊긴다.

[`example/ch06/ex0612_help_h1.m`](../../example/ch06/ex0612_help_h1.m):

```matlab
help mypoly

h1 = string(help('mypoly')).splitlines();
disp(h1(1))            % H1 line 만 뽑기
```

```
  MYPOLY  다항식 5x^3 - 4x^2 + 2x - 6 의 값을 계산한다.
    output = MYPOLY(x) 는 x 의 각 원소에 대해 다항식 값을 원소별로 계산한다.
    x 는 스칼라, 벡터, 행렬 모두 가능하다.

    예: mypoly(2) 는 22 를 반환한다.

    참고: POLYVAL, MYPOLY 는 내장 함수 POLY 와 다른 함수다.
```

> **[보강]** `help`는 문자열로도 받을 수 있어(`s = help('mypoly')`), 위처럼 H1 line만 뽑아 쓸 수 있다. 여러 함수의 H1 line을 모으면 그대로 toolbox 목차가 된다(6.3 연습문제 1).

## ⚠️ 함정

- **파일 이름 ≠ 함수 이름**: `mypoly.m`에 `function y = polynomial(x)`라고 써두면, 호출할 때 쓰는 이름은 **파일 이름인 `mypoly`**다. 함수 정의줄의 이름은 무시된다. 경고도 없이 헷갈리므로 둘을 반드시 맞춘다.
- **기존 함수 이름 덮어쓰기**: 교재 예제처럼 함수를 `poly.m`으로 저장하면 MATLAB 내장 `poly`(특성다항식)를 가려버린다(shadowing). 여기서는 `mypoly`로 이름을 피했다. `which -all 이름`으로 충돌을 확인할 수 있다.
- **local function을 파일 앞에 두면** 그 파일은 스크립트가 아니라 **함수 파일**이 된다. 함수 정의가 먼저 나오는 순간 앞의 코드는 실행되지 않는다. local function은 반드시 뒤에.
- **`.^`를 `^`로 잘못 쓰면** 벡터 입력에서 "행렬 거듭제곱"이 되어 정사각행렬이 아니라는 오류가 난다. 원소별 연산에는 언제나 점(`.`)을 붙인다.
- **한 파일에 함수가 둘 이상이면 모두 `end`로 닫아야 한다.** 하나라도 빠지면 파싱 오류가 난다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다. 시험 대비용으로 추가한 것이다.

1. 화씨(°F)를 켈빈(K)으로 바꾸는 함수 `f2k`를 작성하라. `K = (F-32)*5/9 + 273.15`이며, 벡터 입력도 처리되어야 한다. `[-40 32 98.6 212]`에 적용해 표로 출력하라.
2. 운동에너지 `E = 0.5*m*v^2`을 계산하는 함수 `kinetic_energy(m, v)`를 작성하되, H1 line을 포함한 도움말 블록을 제대로 달아라. `help`로 확인하고, H1 line만 따로 뽑아 출력하라.
3. 체질량지수 BMI = 질량/키²를 계산하는 local function `bmi`와, BMI를 "저체중/정상/과체중/비만" 문자열로 바꾸는 local function `bmi_class`를 한 스크립트 안에 작성하라. 네 사람의 데이터를 넣어 결과를 출력하라.
