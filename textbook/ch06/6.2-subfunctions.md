# 6.2 Subfunction (local function)

여러 함수를 한 파일에 모아 두는 것을 **subfunction**이라 한다. 이미 6.1에서 스크립트 끝에 함수를 붙여 써봤는데, 그것이 바로 subfunction이다.

## 6.2.1 primary function과 subfunction

**함수 파일**(맨 위가 `function`으로 시작하는 파일)에서는 구조가 이렇다.

| 구분 | 설명 |
|---|---|
| **primary function** | 파일의 **첫 번째** 함수. 파일 이름과 이름이 같아야 한다. 바깥에서 호출할 수 있는 유일한 함수 |
| **subfunction** | primary 뒤에 오는 나머지 함수들. 이름은 자유. **그 파일 안에서만** 보인다 |

`my_function.m`에 저장한다면 primary function은 반드시 `my_function`이어야 한다. subfunction은 아무 이름이나 써도 된다.

**스크립트 파일**에서도 마찬가지다. 스크립트 본문이 primary 역할을 하고, 파일 끝의 함수들이 subfunction이 된다.

subfunction은 바깥에서 볼 수 없기 때문에 **local function**이라고도 부른다. 이것이 장점이자 단점이다.

- 장점: 코드를 잘게 나눠 primary 쪽을 읽기 쉽게 만들 수 있다. 이름 충돌 걱정이 없다.
- 단점: 다른 프로그램에서 재사용할 수 없다. 재사용하려면 별도 파일로 빼야 한다.

## 예제

[`example/ch06/ex0602_subfunctions.m`](../../example/ch06/ex0602_subfunctions.m):

```matlab
r = [1 2 3];
h = [10 5 2];

for k = 1:numel(r)
    fprintf('r=%g h=%g → 겉넓이 %8.3f, 부피 %8.3f\n', ...
        r(k), h(k), cyl_area(r(k), h(k)), cyl_volume(r(k), h(k)));
end

% ---- primary 역할: 위의 스크립트 본문 / 아래는 subfunction ----
function A = cyl_area(r, h)
% CYL_AREA  원기둥의 전체 겉넓이
A = 2*base_area(r) + 2*pi*r.*h;
end

function V = cyl_volume(r, h)
% CYL_VOLUME  원기둥의 부피
V = base_area(r) .* h;
end

function A = base_area(r)
% BASE_AREA  밑면(원)의 넓이 — 위 두 subfunction 이 공유한다
A = pi * r.^2;
end
```

```
r=1 h=10 → 겉넓이   69.115, 부피   31.416
r=2 h=5  → 겉넓이   87.965, 부피   62.832
r=3 h=2  → 겉넓이   94.248, 부피   56.549
가장 부피가 큰 원기둥의 부피: 62.832
```

주목할 점:

- **subfunction끼리 서로 호출할 수 있다.** `cyl_area`와 `cyl_volume`이 둘 다 `base_area`를 쓴다. 공통 계산을 한 곳에 모아두는 것이 subfunction의 전형적인 용도다.
- 함수를 나열하는 **순서는 자유**다. `base_area`가 맨 뒤에 있어도 앞의 함수들이 호출할 수 있다.
- 각 함수는 `end`로 닫아야 한다.

편집기에서는 각 함수 옆에 회색 대괄호가 표시되고, `+`/`−`를 눌러 내용을 접거나 펼 수 있다. MATLAB은 이 기능을 **folding**이라 부른다.

## 바깥에서는 보이지 않는다

[`example/ch06/sol0602_2.m`](../../example/ch06/sol0602_2.m)에서 확인한 내용:

```
같은 파일 안에서는 호출된다: secret_double(21) = 42
다른 파일에서 호출 → 오류: 함수 'secret_double'이(가) ... 정의되지 않았습니다.
call_by_name('mypoly', 2) = 22
handle 로 넘기면 동작: 42
```

- 다른 파일에서 이름으로 찾으면 없다.
- 그러나 **같은 파일 안에서 만든 function handle**(`@secret_double`)은 밖으로 넘겨도 동작한다. handle은 이름이 아니라 함수 자체를 가리키기 때문이다(6.4).

> **[보강]** `str2func('secret_double')`은 "그 코드가 놓인 파일에서 보이는 것"을 찾는다. 같은 파일 안에서 쓰면 local function을 찾아내지만, 다른 파일에서 쓰면 찾지 못한다. 문자열로 함수를 찾는 코드가 파일을 옮기면 갑자기 깨지는 이유가 이것이다.

## ⚠️ 함정

- **파일 이름은 primary function 이름과 같아야 한다.** subfunction 이름을 파일 이름으로 쓰면 그 함수는 호출되지 않는다.
- **subfunction을 바깥에서 부르려다 "인식할 수 없는 함수" 오류**를 만나면, 별도 파일로 빼거나 handle을 반환받아야 한다.
- **스크립트에서는 함수 정의가 실행 코드보다 뒤에 와야 한다.** 앞에 두면 그 파일은 함수 파일로 해석되어 스크립트 본문이 실행되지 않는다.
- **subfunction 이름이 내장 함수와 겹치면 파일 안에서는 subfunction이 이긴다.** `sum`이라는 subfunction을 만들면 그 파일 안의 모든 `sum` 호출이 그쪽으로 간다. 내장 함수 이름은 피한다.
- **`end` 누락**: 한 파일에 함수가 둘 이상이면 모두 `end`가 필요하다. 하나만 빠져도 전체 파싱이 깨진다.

## 연습문제

1. 세 변의 길이를 담은 벡터를 받아 둘레를 구하는 subfunction `perimeter`와, 헤론의 공식으로 넓이를 구하는 subfunction `heron_area`를 한 파일에 작성하라. `heron_area`는 `perimeter`를 호출해 반둘레를 구해야 한다. `[3 4 5]`, `[6 8 10]`, `[2 3 4]` 세 삼각형에 적용하라.
2. local function `secret_double`을 만들고, ① 같은 파일에서는 호출되지만 ② 다른 파일(`call_by_name.m`)에서 이름으로 찾으면 오류가 나고 ③ function handle로 넘기면 동작한다는 세 가지를 모두 보여라.
