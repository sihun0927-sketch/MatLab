# 6.1.5 입력·출력 개수 다루기 (nargin, nargout, varargin, varargout)

함수가 몇 개의 입력을 받고 몇 개의 출력을 내는지 알아야 할 때가 있다. MATLAB은 `nargin`과 `nargout` 두 함수를 제공한다. **쓰는 위치에 따라 의미가 달라진다**는 점이 핵심이다.

| 위치 | `nargin` | `nargout` |
|---|---|---|
| **함수 바깥**에서 이름을 인수로 | 그 함수가 **받을 수 있는** 입력 개수 | 그 함수가 **낼 수 있는** 출력 개수 |
| **함수 안**에서 인수 없이 | 이번 호출에 **실제로 들어온** 입력 개수 | 이번 호출에서 **실제로 요청된** 출력 개수 |

## 함수 바깥에서 조회하기

함수 이름을 **문자열**이나 **function handle**로 넘긴다.

[`example/ch06/ex0615_nargin_nargout.m`](../../example/ch06/ex0615_nargin_nargout.m):

```matlab
nargin('sin')      % 1
nargin('rem')      % 2
nargin('surf')     % -1
nargout('max')     % 2
nargout('size')    % -1
nargin(@rem)       % 2  — handle 로 넘겨도 된다
```

```
nargin('sin')   = 1   (입력 1개)
nargin('rem')   = 2   (입력 2개)
nargin('surf')  = -1  (음수 = 가변 입력)
nargout('sin')  = 1   (출력 1개)
nargout('max')  = 2   (출력 2개)
nargout('size') = -1  (음수 = 가변 출력)
nargin('motion')  = 1
nargout('motion') = 3
```

**음수는 "가변"을 뜻한다.** `surf`의 `-1`은 "고정 입력 0개 + `varargin`"이라는 의미다. 일반적으로 `-n`은 "고정 인수 `n-1`개 뒤에 가변 인수가 붙는다"를 뜻한다.

`surf`가 가변 입력인 이유는 슬라이드가 설명한 그대로다. 배열 하나만 주면 인덱스 번호를 x·y 좌표로 삼아 그리고, `x, y, z` 세 개를 주면 지정된 좌표로 그린다. 함수 안에서 `nargin`을 보고 어느 쪽인지 판단하는 것이다.

## 함수 안에서 쓰기 — 생략된 입력 채우기

`nargin`을 함수 안에서 인수 없이 쓰면 **이번에 실제로 들어온 입력 개수**가 나온다. 생략된 인수에 기본값을 채우는 가장 흔한 패턴이다.

[`example/ch06/sol0615_1.m`](../../example/ch06/sol0615_1.m):

```matlab
function V = cyl_volume(r, h, r_inner)
if nargin < 2
    h = 1;
end
if nargin < 3
    r_inner = 0;
end
V = pi * (r.^2 - r_inner.^2) .* h;
end
```

`cyl_volume(2)`, `cyl_volume(2, 5)`, `cyl_volume(2, 5, 1)` 모두 동작한다.

## 함수 안에서 쓰기 — 요청된 출력만 계산하기

`nargout`을 함수 안에서 쓰면 **호출한 쪽이 몇 개의 출력을 요구했는지** 알 수 있다. 비싼 계산을 "요청됐을 때만" 하도록 미룰 수 있다.

[`example/ch06/star1.m`](../../example/ch06/star1.m):

```matlab
function A = star1()
% STAR1  별을 그리고, 출력이 요청된 경우에만 꼭짓점 좌표를 반환한다.
theta = 0 : 4*pi/5 : 4*pi;
r     = ones(1, numel(theta));
polarplot(theta, r, LineWidth=2)
axis off

if nargout == 1
    A = [theta(:), r(:)];   % 요청됐을 때만 계산한다
end
end
```

- `star1` — 그림만 그린다. `nargout`은 0이므로 `A`는 아예 만들어지지 않는다.
- `A = star1` — `nargout`이 1이 되어 꼭짓점 좌표가 함께 돌아온다.

[`example/ch06/ex0615_star1.m`](../../example/ch06/ex0615_star1.m)에서 두 경우를 나란히 실행한다.

## varargin — 개수가 정해지지 않은 입력

마지막 입력 자리에 `varargin`을 쓰면 남은 인수가 전부 **cell array**로 모인다. `varargin{k}`로 꺼낸다.

[`example/ch06/sumall.m`](../../example/ch06/sumall.m):

```matlab
function total = sumall(varargin)
% SUMALL  개수가 정해지지 않은 입력들을 모두 더한다.
%   varargin 은 입력들을 모아 담는 cell array 다.

total = 0;
for k = 1:nargin
    total = total + sum(varargin{k}, 'all');
end
end
```

```
sumall(1, 2, 3)          = 6
sumall(1:10)             = 55
sumall(1:10, [1 2; 3 4]) = 65
```

`varargin`이 있으면 `nargin`은 실제로 들어온 총 개수가 된다.

## varargout — 개수가 정해지지 않은 출력

출력 쪽도 마찬가지다. `varargout`은 cell array이고, `nargout`만큼 채워 넣으면 된다.

[`example/ch06/myminmax.m`](../../example/ch06/myminmax.m):

```matlab
function varargout = myminmax(v)
% MYMINMAX  요청된 출력 개수만큼 최솟값, 최댓값, 범위를 순서대로 반환한다.
%   ... (도움말 블록과 nargin 기본값 블록은 파일 참고)

if nargout >= 1, varargout{1} = min(v); end
if nargout >= 2, varargout{2} = max(v); end
if nargout >= 3, varargout{3} = max(v) - min(v); end
end
```

> 이름을 `minmax`가 아니라 `myminmax`로 한 것은 Deep Learning Toolbox에 같은 이름의 함수가 있어 가려버리기 때문이다(6.1의 shadowing 함정).

[`example/ch06/ex0615_varargin.m`](../../example/ch06/ex0615_varargin.m)에서 `v = [4 -2 9 1]`에 대해:

```
출력 1개: -2
출력 2개: -2, 9
출력 3개: -2, 9, 11
```

`varargin`/`varargout`은 반드시 **인수 목록의 마지막**에 와야 한다. `function f(a, b, varargin)`은 되지만 `function f(varargin, a)`는 안 된다.

> **[보강]** R2019b부터는 `arguments` 블록으로 기본값과 타입 검증을 선언적으로 쓸 수 있다.
> ```matlab
> function V = cyl_volume(r, h)
> arguments
>     r (1,:) double {mustBePositive}
>     h (1,:) double = 1
> end
> ```
> `nargin < 2` 패턴보다 읽기 쉽고 잘못된 입력을 자동으로 걸러준다. 다만 교재와 시험은 `nargin` 방식을 쓰므로 둘 다 알아두는 것이 좋다.

## ⚠️ 함정

- **`nargin('sin')`과 함수 안의 `nargin`은 다른 것이다.** 앞은 "정의상 받을 수 있는 개수", 뒤는 "이번에 들어온 개수". 함수 안에서 `nargin('나자신')`이라고 쓰면 정의상 개수가 나와서 항상 같은 값이 된다.
- **`nargin`이 음수로 나왔다고 오류가 아니다.** 가변 인수 함수라는 뜻이다.
- **`varargin`은 cell array다.** `varargin(1)`은 cell 한 칸을, `varargin{1}`은 그 안의 값을 준다. 중괄호를 써야 한다.
- **`nargout == 0`인데 출력 변수에 값을 안 넣어도 되는 건 그 출력을 요청하지 않았을 때뿐이다.** `A = star1`을 호출했는데 `if` 조건이 안 맞아 `A`를 채우지 않으면 `출력 인수 "A"이(가) 할당되지 않았습니다` 오류가 난다.
- **함수를 `star1()`이 아니라 `star1`로 쓰면서 출력을 받으면** 그것도 `nargout == 1`이다. 괄호 유무는 `nargout`과 관계없다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다. 시험 대비용으로 추가한 것이다.

1. 원기둥(또는 속이 빈 관)의 부피를 구하는 함수 `cyl_volume(r, h, r_inner)`를 작성하라. `h`가 생략되면 1, `r_inner`가 생략되면 0으로 처리한다. 입력 1·2·3개인 세 경우를 모두 호출해 확인하고, 입력을 4개 넣으면 어떤 오류가 나는지도 보여라.
2. 벡터를 받아 요청된 개수만큼 평균·표준편차·최솟값·최댓값을 순서대로 반환하는 함수 `describe`를 `varargout`으로 작성하라. 또 `varargin`으로 여러 벡터를 받아 전체 평균을 내는 `mean_all`도 작성하라.
