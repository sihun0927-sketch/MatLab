# 6.3 나만의 toolbox와 search path

## MATLAB이 함수를 찾는 순서

함수 이름을 만나면 MATLAB은 정해진 순서로 찾아본다.

1. **현재 실행 중인 파일 안의 local function**
2. **현재 폴더(current folder)**
3. **search path** — 등록된 폴더 목록을 **앞에서부터** 차례로

세 곳 어디에도 없으면 `인식할 수 없는 함수 또는 변수입니다` 오류가 난다. 먼저 찾은 쪽이 이기므로, 같은 이름이 여러 곳에 있으면 순서가 곧 우선순위다.

path 전체를 보려면 Home 탭의 **Set Path**를 누르거나 command window에 `pathtool`을 친다. 텍스트로 보려면 `path`를 친다.

## 폴더 추가하기

함수를 여러 개 만들어 모아두면 그것이 곧 나만의 toolbox다. 그 폴더를 path에 추가하면 어느 폴더에서 작업하든 쓸 수 있다.

| 방법 | 설명 |
|---|---|
| `pathtool` → **Add Folder** | 대화상자로 추가. **Save**를 누르면 영구 적용 |
| `addpath(폴더)` | 코드로 path 맨 앞에 추가 (이번 세션 한정) |
| `addpath(폴더, '-end')` | path 맨 뒤에 추가 (우선순위 낮음) |
| `rmpath(폴더)` | 제거 |
| `savepath` | 현재 path를 영구 저장 |

> 공용 컴퓨터(학교 실습실 등)에서는 **path를 영구 변경하지 말 것.** 다른 사용자의 환경을 망칠 수 있다. `addpath`만 쓰고 `savepath`는 하지 않으면 MATLAB을 껐다 켰을 때 원래대로 돌아온다.

## 예제

`example/ch06/mytoolbox/`에 온도 변환 함수 세 개를 만들어 두었다.

- [`c2f.m`](../../example/ch06/mytoolbox/c2f.m) — 섭씨 → 화씨
- [`f2c.m`](../../example/ch06/mytoolbox/f2c.m) — 화씨 → 섭씨
- [`k2c.m`](../../example/ch06/mytoolbox/k2c.m) — 켈빈 → 섭씨

[`example/ch06/ex0603_search_path.m`](../../example/ch06/ex0603_search_path.m):

```matlab
tbox = fullfile(pwd, 'mytoolbox');

fprintf('addpath 전 exist(''c2f'') = %d\n', exist('c2f', 'file'));

oldPath = path;                 % 원래 path 를 저장해 두고
addpath(tbox);                  % 내 toolbox 폴더를 추가한다

fprintf('addpath 후 exist(''c2f'') = %d\n', exist('c2f', 'file'));
fprintf('which c2f → %s\n', which('c2f'));

path(oldPath);                  % [보강] 검증 후 원래 path 로 되돌린다
```

```
addpath 전 exist('c2f') = 0  (0 = 못 찾음)
addpath 후 exist('c2f') = 2  (2 = .m 파일 발견)
which c2f → ...\example\ch06\mytoolbox\c2f.m
0, 25, 100 °C = [32 77 212] °F
212 °F = 100 °C
300 K  = 26.85 °C
```

**하위 폴더는 자동으로 포함되지 않는다.** `mytoolbox`가 현재 폴더 바로 아래에 있어도, 추가하기 전에는 `exist`가 0이다. 하위 폴더까지 한꺼번에 넣으려면 `addpath(genpath(폴더))`를 쓴다.

## 우선순위 확인하기

[`example/ch06/sol0603_2.m`](../../example/ch06/sol0603_2.m)는 같은 이름 `c2f`를 일부러 두 군데 두었다. 하나는 `mytoolbox`(path 위), 하나는 파일 끝의 local function이다.

```
which c2f  → ...\example\ch06\sol0603_2.m
c2f(100)   = -999   ← 같은 파일의 local function 이 이긴다
call_by_name('c2f', 100) = 212   ← mytoolbox 쪽 c2f
which -all c2f:
    "...\example\ch06\sol0603_2.m"
    "...\example\ch06\mytoolbox\c2f.m"
```

local function이 언제나 먼저다. `which -all`을 쓰면 같은 이름이 몇 군데 있는지 전부 보인다.

> **[보강]** 각 함수의 H1 line을 모으면 toolbox 목차가 된다. 폴더 안 `.m` 파일을 `dir`로 훑고 `help`의 첫 줄만 뽑으면 된다([`sol0603_1.m`](../../example/ch06/sol0603_1.m)).
> ```
> mytoolbox 목차:
>   c2f    C2F  섭씨를 화씨로 변환한다.
>   f2c    F2C  화씨를 섭씨로 변환한다.
>   k2c    K2C  켈빈을 섭씨로 변환한다.
> ```
> MATLAB 정식 toolbox는 폴더에 `Contents.m`을 두고 여기에 목차를 적어둔다. `help 폴더이름`을 치면 그 내용이 나온다.

## ⚠️ 함정

- **`addpath`는 기본으로 path 맨 앞에 넣는다.** 내 함수가 내장 함수를 가려버릴 수 있다. 걱정되면 `'-end'`를 붙인다.
- **`addpath`만으로는 영구적이지 않다.** MATLAB을 다시 켜면 사라진다. 영구히 하려면 `savepath`(공용 PC에서는 금지) 또는 `startup.m`에 `addpath`를 적어둔다.
- **현재 폴더가 path보다 먼저다.** 작업 폴더에 같은 이름의 파일이 있으면 toolbox 버전이 무시된다. 결과가 이상하면 `which 이름`부터 확인한다.
- **하위 폴더는 자동 포함이 아니다.** `genpath`가 필요하다. 반대로 `genpath`는 `.git`, `private` 같은 폴더도 다 끌고 오니 주의한다.
- **path에 있는데도 못 찾으면** `rehash`를 한 번 쳐본다. 파일을 방금 만든 경우 캐시가 갱신되지 않았을 수 있다.

## 연습문제

1. `mytoolbox` 폴더를 `addpath`로 추가한 뒤 `k2c`, `c2f`를 연달아 써서 `[200 273.15 300 400]` K를 섭씨와 화씨로 각각 바꿔 출력하라. 추가 전후의 `exist`와 `which` 결과도 비교하라. 마지막에 path를 원래대로 되돌려라.
2. `mytoolbox`의 `c2f`와 이름이 같은 local function `c2f`를 스크립트 끝에 만들어, 둘 중 어느 쪽이 호출되는지 확인하라. `which -all`로 두 곳 모두 있음을 보이고, 다른 파일을 거쳐 부르면 어느 쪽이 쓰이는지도 확인하라.
