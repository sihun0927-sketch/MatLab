# 6.1.3–6.1.4 다중 입출력, 입출력 없는 함수

## 6.1.3 입력이 여러 개인 함수

내장 함수가 여러 입력을 받듯이 사용자 정의 함수도 그렇게 만들 수 있다. 정의줄 괄호 안에 쉼표로 나열하면 된다.

[`example/ch06/elemprod.m`](../../example/ch06/elemprod.m):

```matlab
function output = elemprod(x, y)
% ELEMPROD  두 배열을 원소별로 곱한다.
%   output = ELEMPROD(x, y) 는 x 와 y 를 원소별로 곱한 결과를 반환한다.
%   x 와 y 는 크기가 같거나 한쪽이 스칼라여야 한다.

if nargin == 0
    x = 1:5;
    y = 5:-1:1;    % [보강] 인수 없이 실행해도 되도록 넣은 기본값
end

a = x .* y;        % a 는 local variable — workspace 에 남지 않는다
output = a;
end
```

[`example/ch06/ex0613_multiple_inputs.m`](../../example/ch06/ex0613_multiple_inputs.m):

```
elemprod(x, y) =
     5     8     9     8     5
elemprod(x, 10) =
    10    20    30    40    50
exist('a', 'var') = 0
```

입력 순서가 곧 의미다. `elemprod(x, y)`의 `x`는 첫 번째 인수를 받는다. 호출하는 쪽의 변수 이름과 함수 안의 이름이 같을 필요는 전혀 없다.

중간 계산에 쓴 `a`는 함수가 끝나면 사라진다. 이것이 **local variable**이며 6.1.6에서 자세히 본다.

## 출력이 여러 개인 함수

`max`가 최댓값과 그 위치를 함께 돌려주듯, 사용자 함수도 여러 값을 반환할 수 있다. 출력 변수를 **대괄호로 묶어** 나열한다.

[`example/ch06/motion.m`](../../example/ch06/motion.m):

```matlab
function [distance, velocity, acceleration] = motion(t)
% MOTION  시간 t 에서의 거리, 속도, 가속도를 계산한다.
%   [d, v, a] = MOTION(t) 는 거리 d = t.^3, 속도 v = 3*t.^2,
%   가속도 a = 6*t 를 한 번에 반환한다.
%
%   출력을 하나만 받으면 distance 만 돌아온다.

if nargin == 0
    t = 0:2:10;    % [보강] 인수 없이 실행해도 되도록 넣은 기본값
end

distance     = t.^3;
velocity     = 3 * t.^2;
acceleration = 6 * t;
end
```

호출하는 쪽도 대괄호로 받는다. [`example/ch06/ex0613_multiple_outputs.m`](../../example/ch06/ex0613_multiple_outputs.m):

```matlab
[d, v, a] = motion(t);

d_only     = motion(t);      % 출력을 하나만 적으면 첫 번째만 돌아온다
[~, v_only] = motion(t);     % ~ 로 앞의 출력을 건너뛴다
```

```
    t     distance    velocity    acceleration
    __    ________    ________    ____________
     0         0          0             0
     2         8         12            12
     4        64         48            24
     6       216        108            36
     8       512        192            48
    10      1000        300            60

출력 하나만 받으면 distance: [0 8 64 216 512 1000]
두 번째 출력만: [0 12 48 108 192 300]
```

핵심 규칙 두 가지:

- **출력은 정의한 순서대로 앞에서부터 채워진다.** 세 개 중 두 번째만 받고 싶어도 `[~, v] = motion(t)`처럼 자리를 지켜야 한다.
- **출력을 적게 받는 것은 허용**되지만, 정의된 개수보다 **많이 받으면 오류**가 난다.

> **[보강]** 여러 값을 묶어 돌려주는 또 다른 방법은 하나의 구조체(struct)나 배열로 반환하는 것이다. 값이 서로 성격이 다르고 개수가 늘어날 것 같으면 `s.distance`, `s.velocity`처럼 struct가 읽기 쉽다.

## 6.1.4 입력도 출력도 없는 함수

대부분의 함수는 입력을 받아 출력을 내지만, 둘 다 없는 함수도 있다. 그림을 그리거나 메시지를 찍는 함수가 그렇다.

[`example/ch06/star.m`](../../example/ch06/star.m):

```matlab
function [] = star()
% STAR  극좌표에 5각 별을 그린다. 입력도 출력도 없다.
%   STAR 는 값을 반환하지 않고 figure 창만 연다.
%   대괄호 [] 는 "출력이 빈 배열", 빈 괄호 () 는 "입력 없음"을 뜻한다.

theta = 0 : 4*pi/5 : 4*pi;   % 144도씩 5번 건너뛰면 별이 된다
r     = ones(1, numel(theta));
polarplot(theta, r, LineWidth=2)
axis off
end
```

- **대괄호 `[]`** — 출력이 빈 배열이다. 즉 돌려줄 값이 없다.
- **빈 괄호 `()`** — 입력이 없다. 아예 생략하고 `function star`라고 써도 된다.
- `axis off`를 넣으면 극좌표 격자가 사라져 별만 남는다.

command window에서 괄호 없이 `star`라고만 쳐도 호출된다. 값은 돌아오지 않고 figure 창만 열린다.

[`example/ch06/ex0614_star.m`](../../example/ch06/ex0614_star.m):

![star](img/ex0614_star.png)

반환값이 없으므로 `z = star`처럼 받으려 하면 오류가 난다.

```
예상된 오류: 출력 인수가 너무 많습니다.
```

입력이 없는 내장 함수도 많다. `clock`은 현재 시각을, `pi`는 원주율을 돌려준다. 값을 반환하지 않는다고 해서 쓸모없는 함수는 아니다.

## ⚠️ 함정

- **출력 순서 착각**: `[v, d] = motion(t)`라고 쓰면 `v`에 거리가, `d`에 속도가 들어간다. 변수 이름이 아니라 **위치**가 대응을 결정한다.
- **출력을 하나만 받았는데 다 받은 줄 안다**: `d = motion(t)`는 오류 없이 조용히 첫 번째 출력만 준다. 세 개가 필요하면 세 개를 다 적어야 한다.
- **입력 개수 초과**: 정의보다 많이 넣으면 `입력 인수가 너무 많습니다` 오류가 난다. 적게 넣는 것은 함수가 그 인수를 실제로 쓰기 전까지는 오류가 아니다(6.1.5의 `nargin` 참고).
- **`function [] = star()`의 대괄호를 빼고 `function star()`로 써도 된다.** 다만 대괄호가 있으면 "출력 없음"이 눈에 더 잘 보인다.
- **그림 그리는 함수는 `figure`를 새로 열지 말지 결정해야 한다.** `star`는 현재 축에 그리므로, 앞에서 그린 그림 위에 덮어 그려질 수 있다. 호출 전에 `close all`이나 `figure`를 쓰는 습관이 안전하다.

## 연습문제

> **[보강]** 아래 연습문제와 그 해답은 슬라이드에 없다. 시험 대비용으로 추가한 것이다.

1. 직각삼각형의 두 변 `a`, `b`를 받아 빗변과 두 예각(도 단위)을 반환하는 함수 `right_triangle`을 작성하라(입력 2개, 출력 3개). `a = [3 5 8]`, `b = [4 12 15]`에 적용해 표로 출력하고, 출력을 하나만 받으면 무엇이 나오는지 확인하라.
2. 벡터를 받아 평균, 표준편차, 원소 개수를 반환하는 함수 `stats`를 작성하라. 출력을 1개만 받은 경우와 `~`로 두 번째만 받은 경우를 각각 출력해 비교하라.
3. 입력도 출력도 없는 함수 `unit_circle_box`를 작성하라. 단위원과 그 외접 정사각형을 같은 축에 그리고 `axis equal`을 적용한다. 출력을 받으려 하면 오류가 나는 것도 확인하라.
