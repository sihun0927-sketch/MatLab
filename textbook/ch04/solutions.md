## 4.1 배열의 정의·결합·인덱싱

**1.** 1부터 20 사이의 3의 배수 벡터.

```matlab
v = 3:3:18   % 21은 20을 넘으므로 18에서 멈춘다
```

`시작:증가폭:끝`은 "끝"을 넘지 않는 선에서 최대한 많은 값을 만든다. 3의 배수를 3씩 늘려가면 3, 6, 9, ..., 18까지는 20을 넘지 않지만 다음 값인 21은 20을 넘으므로 여기서 멈춘다.

[코드 보기](../../example/ch04/sol0401_1.m)

**2.** `end`와 콜론 연산자로 부분행렬 추출.

```matlab
M = [4 8 1 6
     3 5 9 2
     7 0 2 4];

lastColumn = M(:,end)          % [6;2;4]
subMatrix  = M(2:end, 1:2)     % [3 5; 7 0]
```

`M`이 몇 행·몇 열인지 몰라도 `end`를 쓰면 "마지막 열"과 "마지막 행"을 정확히 가리킬 수 있다. `2:end`는 "2행부터 마지막 행까지"라는 뜻이다.

[코드 보기](../../example/ch04/sol0401_2.m)

**3.** `b = 1:-1:5`의 결과.

`b`는 1에서 시작해 -1씩 줄어드는데, 목표인 5는 1보다 크다. 감소하는 방향으로는 5에 절대 도달할 수 없으므로, 조건을 만족하는 원소가 하나도 없다. 이런 경우 MATLAB은 에러를 내지 않고 **1x0 빈 배열**을 반환한다.

```matlab
b = 1:-1:5      % 1x0 empty double row vector
isempty(b)      % true
```

## 4.2 원소별 연산과 meshgrid

**1.** `*` vs `.*`.

```matlab
A = [1 2; 3 4];
B = [1 2; 3 4];

A * B     % [7 10; 15 22]  - 선형대수 행렬곱
A .* B    % [1 4; 9 16]    - 같은 위치 원소끼리 곱함
```

`*`는 선형대수의 행렬곱 규칙(안쪽 차원이 같아야 함)을 따르고, `.*`는 같은 위치에 있는 원소끼리 곱하는 원소별 연산이기 때문에 두 결과가 다르다.

[코드 보기](../../example/ch04/sol0402_1.m)

**2.** `meshgrid`로 크기가 다른 두 벡터 합치기.

```matlab
x = 1:3;   % 1x3
y = 1:4;   % 1x4

[X, Y] = meshgrid(x, y);   % X, Y 모두 4x3
Z = X + Y;                  % 4x3
```

`meshgrid(x, y)`가 만드는 `X`, `Y`의 크기는 `[length(y), length(x)]`, 즉 `y`의 길이만큼 행, `x`의 길이만큼 열을 갖는다.

[코드 보기](../../example/ch04/sol0402_2.m)

**2.** `magic(5)`의 행/열/대각선 합 확인.

```matlab
A = magic(5);

colSums      = sum(A);              % 각 열의 합
rowSums      = sum(A, 2)';           % 각 행의 합
mainDiagSum  = sum(diag(A));         % 주대각선 합
antiDiagSum  = sum(diag(fliplr(A))); % 반대쪽 대각선 합
```

5x5 마방진에서는 이 네 가지 값이 모두 65로 같다.

> **[보강]** n×n 마방진의 합("매직 상수")은 공식 `n(n^2+1)/2`로 미리 계산할 수 있다. n=5이면 `5*(25+1)/2 = 65`로, 위 실행 결과와 정확히 일치한다.

**2.** `char` → `string` 변환과 `strlength`.

```matlab
names = char('Kim', 'Lee', 'Park')   % 3x4, 짧은 이름은 공백으로 패딩됨
namesStr = string(names)              % padding 그대로 유지된 3x1 string
strlength(namesStr)                   % [4;4;4]
```

`char`로 만든 배열은 가장 긴 이름(`Park`, 4글자)에 맞춰 모든 행이 공백으로 채워진다. 이 상태에서 `string`으로 변환해도 패딩 공백은 사라지지 않으므로, `strlength`는 세 이름 모두 4를 반환한다. 패딩 없는 글자 수를 원한다면 처음부터 큰따옴표로 `["Kim","Lee","Park"]`처럼 문자열을 직접 만들어야 한다.

이 문제는 4.4의 함정 중 "char에서 변환한 string은 패딩 공백이 남는다"를 직접 확인해 보는 것이 목적이다. 데이터를 char 배열로 받아서 string으로 변환해야 하는 경우(예: 오래된 파일 입출력 함수의 결과), 이런 패딩 공백을 놓치면 이후 비교·검색 연산에서 예상과 다른 결과를 얻을 수 있다.
