# 4.3 특수 배열

이 절의 함수들은 하나같이 "직접 값을 하나하나 입력하지 않고도" 특정 패턴의 배열을 빠르게 만들어 준다. 4.1에서 배운 대괄호 문법으로 같은 배열을 만들 수도 있지만, 크기가 커질수록 함수를 쓰는 쪽이 훨씬 간단하고 실수도 줄어든다.

MATLAB은 자주 쓰이는 형태의 배열을 손쉽게 만들 수 있도록 여러 함수를 제공한다: `zeros`, `ones`, `diag`, `magic`. 여기에 배열을 뒤집는 `fliplr`, 합을 구하는 `sum`, 전치(`'`)까지 함께 살펴본다.

## 4.3.1 `zeros` — 0으로 채워진 배열

```matlab
zeros(3)         % 3x3, 전부 0
zeros(2, 4)      % 2x4, 전부 0
```

## 4.3.2 `ones` — 1로 채워진 배열

```matlab
ones(3)          % 3x3, 전부 1
ones(2, 4)       % 2x4, 전부 1
```

[전체 코드 보기](../../example/ch04/ex0403_zeros_ones.m)

`zeros`와 `ones`는 나중에 값을 채워 넣을 배열을 미리 만들어 둘 때(preallocation) 자주 쓴다. 반복문 안에서 배열을 한 원소씩 늘려가며 채우면(4.1의 "배열 확장"처럼) MATLAB이 매번 더 큰 배열을 새로 만들어 복사해야 해서 느려진다. 결과 배열의 크기를 미리 알고 있다면, `zeros`로 그 크기만큼 배열을 만들어 두고 값만 채워 넣는 것이 훨씬 효율적이다.

## 4.3.3 `diag` — 대각선 추출과 대각 행렬 생성

`diag`는 입력이 **행렬**이냐 **벡터**이냐에 따라 정반대로 동작한다.

```matlab
A = [1 2 3
     3 4 5
     1 2 3];

diag(A)          % 입력이 행렬 -> 주대각선을 열벡터로 "추출": [1;4;3]
diag(A, 1)       % 두 번째 입력으로 주대각선 기준 위/아래 대각선 지정: [2;5]

v = [1, 2, 3];
diag(v)          % 입력이 벡터 -> v를 대각선에 놓은 정방행렬 "생성"
```

[전체 코드 보기](../../example/ch04/ex0403_diag.m)

> ⚠️ **함정**: `diag`는 입력 타입(행렬 vs 벡터)에 따라 "추출"과 "생성"이라는 정반대의 일을 한다. 함수 하나가 입력에 따라 다르게 동작한다는 점을 기억해 두자.

`diag(vector)`로 대각 행렬을 만드는 성질을 이용하면, 기존 행렬의 대각선에만 값을 더할 수도 있다.

```matlab
A = magic(4);
A_plusDiag = A + diag([10 20 30 40])   % 대각선 원소에만 각각 10,20,30,40을 더함
```

> **[보강]** 4.1의 concatenation과 4.3의 `zeros`/`ones`를 함께 쓰면, 작은 블록을 이어 붙여 원하는 패턴의 큰 행렬(block matrix)을 만들 수 있다.

```matlab
topBlock = [ones(2,2), zeros(2,2)];
bottomBlock = [zeros(2,2), ones(2,2)];
blockMatrix = [topBlock; bottomBlock]   % 좌상단·우하단은 1, 나머지는 0인 4x4
```

[전체 코드 보기](../../example/ch04/ex0403_diag_zeros_blocks.m)

> **[보강]** 슬라이드에는 없지만 `zeros`, `ones`, `diag`와 같은 계열의 함수로 **`eye`**(단위행렬, identity matrix)가 있다. `eye(n)`은 대각선만 1이고 나머지는 0인 `n×n` 배열을 만든다. `diag(ones(1,n))`으로도 같은 결과를 얻을 수 있지만 `eye`가 더 짧고 의도가 분명하다.

```matlab
I = eye(3)          % 3x3 단위행렬
I2 = eye(2, 4)       % 정사각형이 아니어도 만들 수 있다 (2x4)
```

[전체 코드 보기](../../example/ch04/ex0403_eye.m)

## 4.3.4 `magic` — 마방진

`magic(n)`은 모든 행의 합, 모든 열의 합, 그리고 두 대각선의 합이 전부 같은 정방행렬(마방진)을 만든다. `n`은 2보다 커야 한다. 실용적인 용도는 딱히 없지만, 배열 함수를 연습하기 좋은 소재다.

```matlab
A = magic(4)

sum(A)              % sum(A) 기본은 "열" 합 -> 1x4 행벡터
sum(A, 2)            % 두 번째 인자 2 -> "행" 합
sum(A')              % 전치(') 후 sum -> 행 합과 같은 결과

sum(diag(A))         % diag로 대각선을 추출한 뒤 sum으로 합산 (함수 중첩 = nesting)
```

> ⚠️ **함정**: `sum(A)`는 기본적으로 **열** 합을 구한다. 행의 합을 원한다면 `sum(A, 2)`처럼 두 번째 인자로 방향(dimension)을 명시하거나, `sum(A')`처럼 전치한 뒤 합해야 한다.

> **[보강]** 마방진은 수백 년 동안 수학자들의 흥미를 끈 소재다. 알브레히트 뒤러(Albrecht Dürer)의 1514년 판화 "멜랑콜리아 I"에는 4x4 마방진이 등장하는데, 맨 아래 줄 가운데 두 칸에 제작 연도(1514)가 들어가 있다. 벤저민 프랭클린도 마방진을 연구한 것으로 알려져 있다. MATLAB은 `load durer`로 이 판화 이미지를 예제 데이터로 제공한다.

## `fliplr`로 반대쪽 대각선 확인하기

`fliplr(A)`는 배열을 좌우로 뒤집는다 (각 행의 열 순서를 반대로). 마방진을 좌우로 뒤집은 뒤 대각선을 뽑으면 원래 배열의 "반대쪽" 대각선(anti-diagonal) 합을 구할 수 있다.

```matlab
A_flipped = fliplr(A);
sum(diag(A_flipped))   % 반대쪽 대각선 합도 마찬가지로 같은 값이 나온다
```

[전체 코드 보기](../../example/ch04/ex0403_magic_fliplr.m)

> **[보강]** `sum(diag(A))`처럼 함수 호출을 다른 함수의 입력으로 넣는 것을 **nesting(중첩)**이라 부른다. 슬라이드에는 용어만 짧게 나오지만, 이후 챕터에서도 자주 쓰이는 개념이므로 기억해 두면 좋다.

## 어떤 함수를 언제 쓸까

| 원하는 것 | 함수 |
|---|---|
| 전부 0인 배열 | `zeros(m,n)` |
| 전부 1인 배열 | `ones(m,n)` |
| 대각선만 1인 정방행렬 | `eye(n)` |
| 벡터를 대각선에 놓은 정방행렬 | `diag(vector)` |
| 행렬에서 대각선만 뽑기 | `diag(matrix)` |
| 행·열·대각선 합이 같은 정방행렬 | `magic(n)` (n>2) |
| 배열을 좌우로 뒤집기 | `fliplr(A)` |
