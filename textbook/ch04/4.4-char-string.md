# 4.4 문자 배열과 문자열 배열

지금까지는 숫자 배열만 다뤘지만, 그래프에 제목을 붙이거나 파일 이름을 만들거나 데이터에 설명을 붙이려면 텍스트도 다뤄야 한다. MATLAB은 텍스트를 저장하는 두 가지 데이터 타입, **문자 배열(character array)**과 **문자열 배열(string array)**을 제공한다.

- **문자 배열**: 글자 하나하나가 배열의 원소 하나다. 각 글자 자체에 의미가 있을 때 적합하다 (예: DNA 염기서열).
- **문자열 배열**: 텍스트 덩어리 하나가 배열의 원소 하나다. 대부분의 경우(사람 이름, 책 제목 등 텍스트 전체가 하나의 의미 단위일 때) 적합하며, 현재 MATLAB에서 권장하는 방식이다.

> **[보강]** MATLAB은 원래 문자 배열만 있었고, string 타입은 2016b에 추가되었다. 대부분의 MATLAB 함수는 하위 호환을 위해 문자 배열과 문자열을 둘 다 받아들인다. 그래서 오래된 문서에서는 문자 배열을 "string"이라고 부르기도 하니 헷갈리지 않도록 주의하자.

MathWorks가 드는 대표적인 문자 배열 예시는 **DNA 염기서열**이다. 각 글자(A, T, C, G)는 그 자체로 의미가 있고 순서가 중요하므로, 이런 데이터는 문자 배열로 표현하는 것이 자연스럽다.

```matlab
dna = 'ATCGGCTA';        % 각 글자가 그 자체로 의미를 가진다
dna(1)                    % 'A' - 첫 번째 염기
dna(2) = 'G';              % 인덱싱으로 특정 염기만 치환할 수도 있다
```

[전체 코드 보기](../../example/ch04/ex0404_dna_example.m)

반대로 환자 이름이나 책 제목처럼 텍스트 덩어리 전체가 하나의 의미 단위라면, 다음 절에서 다룰 **문자열(string)**로 저장하는 것이 옳다.

## 4.4.1 문자 배열 (character array)

**작은따옴표**로 문자 배열을 만든다. 인덱싱은 숫자 배열과 완전히 같은 방식으로 동작한다.

```matlab
H = 'Holly';        % 1x5 char 배열
H(5)                % 'y' - 숫자 배열처럼 인덱싱한다

J = 'MATLAB is fun'; % 공백도 글자 하나로 센다
length(J)            % 13
```

### 2차원 문자 배열과 `char` 함수

문자 배열을 세로로 이어 붙여(2차원으로) 여러 단어를 저장하려면, 모든 행의 글자 수가 같아야 한다.

```matlab
% 이름마다 길이가 달라 그냥 세로로 합치면 에러가 난다:
% M = ['Steven';'Jasmin';'David';'Terrell';'Maria']
% Error using vertcat: Dimensions of arrays being concatenated are not consistent.
```

`char` 함수에 여러 문자 배열을 인자로 넘기면, 짧은 쪽을 공백으로 채워서(padding) 길이를 맞춘 뒤 2차원 배열로 만들어 준다.

```matlab
M = char('Steven', 'Jasmin', 'David', 'Terrell', 'Maria')  % 5x7 char 배열
M(3,:)               % 'David  ' - 행/열 인덱싱도 그대로 된다

size(M)              % [5 7]
numel(M)             % 35 (전체 원소 개수)
length(M)            % 7  (가장 큰 차원의 크기)
```

[전체 코드 보기](../../example/ch04/ex0404_char_arrays.m)

> ⚠️ **함정**: 문자 배열끼리 `+`를 하면 텍스트를 이어붙이는 게 아니라, 각 글자의 **문자 코드(ASCII 값)끼리 숫자 덧셈**을 한다. 예를 들어 `'a' + 1`은 `98`(double 타입)이 된다. 텍스트를 이어붙이려면 문자 배열이 아니라 **string**을 써야 한다.

## 4.4.2 문자열 배열 (string array)

**큰따옴표**로 문자열을 만들거나, `string` 함수로 기존 문자 배열을 변환한다.

```matlab
M = char('Steven', 'Jasmin', 'David', 'Terrell', 'Maria');  % 5x7 char (패딩됨)
N = string(M)        % char 배열의 "행 하나"가 string 원소 하나가 된다 (5x1)
                      % char 배열에서 왔으므로 패딩 공백이 그대로 남는다

P = ["Steven"; "Jasmin"; "David"; "Terrell"; "Maria"]  % 큰따옴표로 직접 생성
                                                         % -> 불필요한 공백이 없다
```

[전체 코드 보기](../../example/ch04/ex0404_string_arrays.m)

### 문자열은 텍스트 덩어리를 하나로 유지한다

문자 배열과 가장 큰 차이는 인덱싱 결과다. 문자열 배열은 원소 하나가 글자가 아니라 **문자열 전체**이므로, 인덱싱하면 그 원소 전체가 그대로 나온다.

```matlab
N(2)   % "Jasmin " (전체 문자열 하나)
P(2)   % "Jasmin"
```

### `+`로 문자열 연결하기

문자 배열과 달리, **문자열은 `+`로 이어붙일 수 있다.**

```matlab
A = "Holly";
B = "Moore";
A + " " + B          % "Holly Moore"
```

숫자 등 다른 타입과 `+`로 연결하면, MATLAB이 자동으로 문자열로 변환해서 이어붙여 준다. 그래프 제목처럼 숫자가 섞인 텍스트를 만들 때 유용하다.

```matlab
Test = 11;                       % double
GraphName = "Trial Run " + Test  % "Trial Run 11"
```

[전체 코드 보기](../../example/ch04/ex0404_string_concat.m)

> **[보강]** string이 없던 시절에는 숫자를 텍스트에 넣으려면 `num2str`로 먼저 char 배열로 바꾼 뒤, 대괄호로 이어붙여야 했다. `+` 자동 변환은 이 과정을 한 번에 해결해 준다.

```matlab
Test = 11;
viaPlus = "Trial Run " + Test          % string + 숫자 -> 자동 변환, 한 번에 끝

n = num2str(Test);                      % (구식) 숫자 -> char 배열로 직접 변환
viaNum2str = ['Trial Run ', n]          % (구식) char 배열은 대괄호로 이어붙인다
```

[전체 코드 보기](../../example/ch04/ex0404_num2str_vs_plus.m)

> **[보강]** 소수점 자리수 같은 형식까지 지정하고 싶다면 `sprintf`가 편리하다. `%d`는 정수, `%.2f`는 소수점 둘째 자리까지의 실수를 뜻하는 형식 지정자(format specifier)다.

```matlab
viaSprintf = sprintf("Trial Run %d", Test)     % "Trial Run 11"
pi_text = sprintf("pi = %.2f", pi)               % "pi = 3.14"
```

[전체 코드 보기](../../example/ch04/ex0404_sprintf_vs_plus.m)

### 문자열의 크기와 글자 수

`size`, `length`는 문자열 배열에도 숫자 배열과 똑같이 동작한다 (배열 자체의 크기). 반면 **`strlength`는 각 문자열 원소의 글자 수**를 알려준다.

```matlab
size(P)          % [5 1]
length(P)        % 5   (배열의 원소 개수 = 이 배열에서는 가장 큰 차원)
strlength(P)     % [6;6;5;7;5]  (원소마다 실제 글자 수)
```

> ⚠️ **함정**: `length`는 "배열의 크기"를, `strlength`는 "문자열 하나하나의 글자 수"를 알려준다. 둘을 헷갈리면 완전히 다른 값을 얻는다. 또한 `char`로 패딩된 문자 배열을 `string`으로 변환하면, 패딩된 공백까지 그대로 `strlength`에 포함된다는 점도 주의해야 한다.

### 두 타입 사이를 오가기

`string`과 `char`는 서로 변환할 수 있다. 오래된 함수 중에는 여전히 문자 배열만 받는 경우가 있으므로, `isstring`, `ischar`로 현재 타입을 확인하고 필요하면 `char()`로 되돌릴 수 있다는 것을 알아두면 편리하다.

```matlab
s = "Holly Moore";
c = char(s)              % string -> char (일부 옛 함수가 char를 요구할 때 사용)

isstring(s)               % true
ischar(c)                 % true
```

## 정리

- 각 글자 자체가 의미를 가지면 **문자 배열**(작은따옴표), 텍스트 덩어리 전체가 의미를 가지면 **문자열**(큰따옴표)을 쓴다.
- 특별히 문자 배열이 필요하다는 문서가 없다면, 대부분의 경우 **문자열을 쓰는 것이 낫다**.
- MATLAB 함수 대부분은 두 타입을 모두 받아들이도록 만들어져 있다.
