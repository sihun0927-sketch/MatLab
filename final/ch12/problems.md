## 문제 12-01 (절 12.1 · 옳은 설명 고르기)

다음 코드를 실행했다. 옳은 설명을 고르시오.

```matlab
syms p q
h = 3*(p - 2)^2/(p^2 - 4*p + 4)
syms g(p,q)
g(p,q) = p^2 - 2*q;
r = g(4,3)
E = p*q == 12
```

① `h`를 `3`으로 단순화해도 p = 2에서 `h`가 정의되지 않는다는 정보는 그대로 남는다.

② `r`의 값은 `10`이고, Workspace에서 `r`의 Class는 `double`이다.

③ `E`는 equation이며, 마지막 줄을 `E = p*q = 12`로 써도 같은 equation이 만들어진다.

④ `h`를 만드는 줄은 `.^`, `./` 같은 array 연산자를 쓰지 않았으므로 오류가 난다.

⑤ `r`의 결과 `10`은 화면에 들여쓰기 없이 표시된다.

## 문제 12-18 (절 12.6.1 · 빈칸에 들어갈 코드 고르기)

## 문제 12-19 (절 12.6.2 · 틀린 설명 고르기)

다음 코드에 대한 설명으로 틀린 것을 고르시오.

```matlab
syms x(t)
eqn = diff(x,t,2) + 9*x == 0;
Dx = diff(x);
s1 = dsolve(eqn);
s2 = dsolve(eqn, x(0) == 2, Dx(0) == 0);
s3 = dsolve(eqn, x(0) == 2, x(1) == 5);
```

① 2차 미분방정식에 경계 조건을 주지 않았으므로 `s1`에는 미지 상수 `C1`, `C2` 두 개가 들어 있다.

② `Dx`는 x의 도함수를 나타내는 새 symbolic function이고, `Dx(0) == 0`은 t = 0에서 dx/dt = 0이라는 조건이다.

③ `s2`는 한 지점(t = 0)에서 x와 dx/dt를 아는 초기값 문제이고, `s3`은 x를 서로 다른 두 t 값에서 아는 경계값 문제다.

④ `s2`는 수학적으로 $x = 2\cos(3t)$와 같다.

⑤ `dsolve`는 어떤 미분방정식이든, 어떤 경계 조건이든 항상 기호 해를 구하므로 수치 기법은 필요 없다.
