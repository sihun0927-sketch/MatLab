## 문제 13-02 (절 13.1.2 · 옳은 설명 고르기)


③ `a`를 구하는 줄에는 방식이 적혀 있지 않으므로 cubic spline이 기본으로 쓰인다.

④ 슬라이드에 따르면 cubic spline에 필요한 데이터 점은 최소 3개이므로, `x = 0:2; y = [3 7 4];`로 줄여도 조건을 만족한다.

## 문제 13-15 (절 13.6 · 오류가 나는 줄·원인 고르기)

dy/dt = 3t², y(0) = 1 을 0 ≤ t ≤ 2 에서 풀려고 다음 코드를 실행했더니 오류가 났다. 오류가 나는 줄과 원인으로 옳은 것을 고르시오.

```matlab
dydt = @(t) 3*t.^2;               % 1번 줄
tspan = [0, 2];                   % 2번 줄
y0 = 1;                           % 3번 줄
[t, y] = ode45(dydt, tspan, y0);  % 4번 줄
```

① 1번 줄: 식에 y가 없는 anonymous function은 만들 수 없다.

② 4번 줄: ode45는 미분방정식 함수를 t, y 두 입력으로 호출하는데, `dydt`는 입력이 t 하나뿐이다.

③ 2번 줄: time span에는 시작·끝 시각 외에 중간 시각도 들어 있어야 한다.

④ 4번 줄: 출력 `[t, y]`를 지정하면 안 되고 `ode45(dydt, tspan, y0)`로만 호출할 수 있다.

⑤ 4번 줄: `dydt`를 넘길 때 `ode45(@dydt, tspan, y0)`처럼 `@`를 붙여야 한다.

## 문제 13-16 (절 13.6 · 틀린 설명 고르기)

다음 코드에 대한 설명으로 틀린 것을 고르시오(슬라이드 기준).

```matlab
f = @(t,y) -0.5*y;
[t, y] = ode23(f, [2, 6], 4);
```

① 셋째 입력 `4`는 t = 2에서의 y 값, 즉 y(2) = 4라는 초기 조건이다.

② 슬라이드에 따르면 ode solver들은 형식이 같아서, `ode23`을 `ode45`로 이름만 바꿔도 같은 입력으로 호출할 수 있다.

③ `ode45`와 `ode23`은 둘 다 Runge-Kutta 기법을 쓰며, 방정식의 거동을 모를 때 처음 시도해 볼 solver다.

④ `[t, y] =`를 빼고 `ode23(f, [2, 6], 4)`만 실행하면 해의 그래프가 그려진다.

⑤ 슬라이드의 solver 표에서 `ode15s`와 `ode23s`는 nonstiff 미분방정식용이다.

## 문제 13-17 (절 13.6.1 · 오류가 나는 줄·원인 고르기)

두 1계 미분방정식의 연립 dy₁/dt = y₂, dy₂/dt = −4y₁ 을 풀려고 다음 스크립트를 실행했더니 1번 줄의 `ode45` 호출에서 오류가 났다. 원인으로 옳은 것을 고르시오.

```matlab
ode45(@sys2, [0, 1], [2, 0])     % 1번 줄
function dy = sys2(t, y)         % 2번 줄
dy = [y(2), -4*y(1)];            % 3번 줄
end
```

① 1번 줄: 이름이 있는 함수는 `@` 없이 `sys2`로 넘겨야 한다.

② 1번 줄: 초기 조건 `[2, 0]`은 열벡터 `[2; 0]`으로 써야 한다.

③ 3번 줄: `dy`가 행벡터다. 연립방정식 함수의 출력은 1계 도함수 값들의 열벡터여야 한다.

④ 2번 줄: 함수 안에서 `t`를 쓰지 않으므로 입력에서 `t`를 빼야 한다.

⑤ 2번 줄: 미분방정식 함수는 프로그램 끝에 둘 수 없고 별도 M-file로만 저장해야 한다.
